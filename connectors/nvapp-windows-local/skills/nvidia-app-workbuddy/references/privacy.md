# Data and permission disclosure

This package adds no remote endpoint, telemetry collector, download helper, or executable file. WorkBuddy uses the existing Windows `cmd.exe` only to launch a fixed path to the already installed NVIDIA bridge, which relays to NVIDIA's local backend. The fixed `/d /c` launcher disables Command Processor AutoRun and passes no arguments to the bridge. It must not interpolate user input or run extra commands. This does not assert that NVIDIA App itself has no network activity.

Tool results can reveal installed games/apps, driver versions, feature settings, process IDs, and active game information. WorkBuddy may include those results in its conversation/model processing under its own service settings and privacy terms. Local MCP transport is not a promise that all conversation data stays on-device.

Six documented tools inspect state. Six can launch applications, change game/feature settings, or perform Overlay actions. Recording/screenshot/replay actions can create local media and capture visible or audible content using existing NVIDIA settings. Use them only for the user's clearly requested action. Enabling Instant Replay or Highlights can leave background capture enabled until disabled. This skill excludes enabling Desktop Capture and does not upload capture media.

Adapter 0.2.2 follows the upstream token-free connection: no password form, credential collection, token environment mapping, or secret-discovery procedure is included. Token-free connection and six native read workflows were verified on NVIDIA App 11.0.9.560; the fixed launcher passed an isolated parser/protocol check, and a WorkBuddy 5.8.2 session performed a driver-status read on 2026-10-14. This does not establish persistent installation or approval of the new ZIP. No writes were tested. Token-free setup is not a guarantee of write authorization or isolation from all other local clients. Do not expose the local service remotely. Server access controls and WorkBuddy tool permissions still apply; this adapter does not raise access or add narrower server-side scopes.

To stop this integration, disconnect/disable it through WorkBuddy. To stop NVIDIA MCP access for other clients, the user can check the relevant control in a compatible NVIDIA App build. Disconnecting the connector does not stop an existing recording, undo changed settings, or delete captured files; those are separate actions requiring user intent.

For public submission, the publisher must provide an actual support contact and privacy statement covering its deployment and support practices, and obtain acceptance of the token-free local access model. This technical disclosure is not a substitute for those publisher details.
