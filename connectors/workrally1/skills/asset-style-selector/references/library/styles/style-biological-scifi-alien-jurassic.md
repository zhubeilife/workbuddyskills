# 生物惊悚科幻 · 视觉风格提示词

## 分类定位
- **大类**：【一】仿真人
- **中类**：科幻
- **标准名**：生物惊悚科幻
- **原名**（内部标识，不外显）：生物科幻（异形／侏罗纪）

## 风格参考（Reference）
生物机械美学的太空惊悚、史前巨兽写实冒险。核心是**有机生命体的敬畏与恐惧**——湿润生物质感、巨兽体量压迫、造物失控的紧张，**区别于机器人科幻的金属冷硬**。

## 第一性拆解（Style Decomposition）
- **打光**：低照度硬光切割，闪烁频闪/爆闪，湿润表面高光，逆光剪影勾勒巨兽轮廓，丁达尔光束穿雨雾
- **色彩**：暗黑生物质感基调，冷绿/石板灰/血褐，太空生物向偏黑蓝金属光泽，史前巨兽向偏丛林墨绿与泥土褐
- **构图**：巨兽体量对比（微小人类 vs 庞然巨物）、幽闭走廊或雨林纵深、局部特写獠牙鳞甲、低角度仰视压迫
- **参照**：生物机械设计、低照度硬光摄影、悬念调度
- **场景/氛围**：湿润有机质感、蛋巢/围栏/飞船内舱、暴雨与雾气、被追猎的原始恐惧与造物敬畏

## 使用说明
1. 文生图时，将上方「结构化提示词」整段作为风格底，拼接你的主体内容（生物 / 场景 / 动作）。
2. 结构化提示词适合 Midjourney / Stable Diffusion 等；需要中文模型可改用「中文提示词」。
3. 本风格主打**有机生物恐惧**：太空生物向偏 biomechanical、史前巨兽向偏 prehistoric/jungle realism，两者可择一强化；想加恐怖感可加 "dread, suspense, wet glistening skin, dripping saliva"。
4. 可按需替换 [打光]/[色彩]/[构图]/[参照]/[场景] 模块强化或微调风格倾向。
