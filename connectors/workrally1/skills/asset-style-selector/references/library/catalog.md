# 风格库目录（87 种）

> `asset-style-selector` 的**统一87种风格库目录**，同时用于四项推荐、全库浏览、分类查找和直接点名选择，不另设固定四分支入口。运行规则见 [../../SKILL.md](../../SKILL.md)。推荐与浏览阶段只读本目录，选定后再读对应风格文件。

## 提示词结构

**风格 - 相机胶片参数/渲染器 - [打光方案] + [色彩调性] + [构图描述] + [画家参照] + [场景/氛围]**，末尾为该风格的质感尾缀。

## 目录

格式：`**标准名**（对外显示） ｜ 原名：[内部原名](风格文件) · 场景关键词（内部参考）`。链接指向同目录下 `styles/`。匹配时同时看标准名、原名、分类和场景关键词；对外只显示标准名。
