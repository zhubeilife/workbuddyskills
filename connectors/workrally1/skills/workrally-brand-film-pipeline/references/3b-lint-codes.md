# §3b 机检项清单 · story_lint.py

本文件承接 SKILL.md §3b 的完整检查项表（`story_lint.py` 全部检查码）。
规则与阈值以 `scripts/story_lint.py` 实现为准；本表只作对照与定位。

严重度：表内未标注的默认 FAIL 阻断；写「给 WARN」的只提示、不阻断提交。

---

| 代码 | 检查什么 |
|---|---|
| V00 | 台账写了 `rule_version`，据此选当前档或旧项目档；没写按当前档并给 WARN |
| E00 / D00 / D03 | 剧情事件和台词都登记了来源 `origin=script`，ID 不重复；镜头里用到的台词都在台词表里 |
| E01 | 每个镜头都挂了 `event_refs`，且指向存在的剧情事件 |
| E02 | 每条剧情事件至少被一个镜头落实，原剧情一条不漏拍 |
| D01 / D02 | 台词分段拼接后与原文逐字相等；每句原台词都出现在某个镜头里 |
| D04 | 每段台词都有 `window`，且落在本镜时间里 |
| D05 | 语速 3.5–4.2 字/秒：中文按字，英文按音节估算，数字每位算一个，标点不计；时窗两端各有 0.05 秒容差 |
| D06 | 同一人的台词时窗不重叠；两人重叠给 WARN（抢话时保留） |
| T01 | 台账里单元内镜头时间首尾相接，从 0 开始、在单元时长结束 |
| T02 | `transition` 只用 硬切 / 叠化 / 匹配剪辑；`continuous` 单元只有一个镜头 |
| A00 | `audio_policy` 取值合法 |
| G00 | 走位单元每镜都有 `camera` 和 `subjects`，字段完整，`fov` 在换算表里 |
| G01 | 写成入画或前景的人和地标，按机位、朝向和视场角确实在画面里，不在摄影机背后 |
| G02 | `frame` 写的画面左、中、右与机位算出来的一致；左右写反判 FAIL，中间与两侧之差给 WARN |
| G03 | 写成不入画的人却在视场内，给 WARN（有遮挡时保留） |
| P00 | 台账里的单元和提示词文件的单元一一对应 |
| P01 | 导演层文字里没有「上一镜头 / 刚才 / 继续 / 接着 / 同上」等上下文指代词，每条提示词独立可读 |
| P02 | 没有泄漏「第 N 集 / 第 N 场 / EP-N / 1-1 夜」等场次编号；台账里的单元号、镜号也不能出现在正文里（CHAR / SC 等资产逻辑编号不算） |
| P03 | 每个单元否定词不超过 5 个；【默认摄影】、【声音方案】的固定文字、引号里的台词和剧本原文不计入，声音方案后面自己加的句子照常计入 |
| P04 | 参考图只用「第 N 张图片」，出现 `@图` 判 FAIL |
| P05 | 【光线与色彩】写出主光源、方向、摄影机所在侧和色板 |
| P06 | 镜头行 `[起–止秒] 镜头N` 首尾相接、编号连续、在单元时长结束；每个镜头内的分拍首尾相接并覆盖整个镜头 |
| P07 | 台账里本单元的每句台词都在提示词里逐字出现 |
| P08 | §4a 必备段落齐全（有台词的单元还要有【人物】）；不再出现【生成单元】【整体叙事】【对白原文】等停用段；顺序不符给 WARN |
| P09 | 每个镜头有分拍、「表演：」和「背景：」，有人物时写「站位：」；第一镜有「首帧：」，最后一镜有「本镜结束：」 |
| P10 | 【总控】的「共 N 个镜头」与时间轴、台账一致；转场句与台账一致（全是硬切写「镜头之间只用硬切」，否则写「镜头K-1到镜头K{转场}」并在还有硬切时写「其余硬切」）；第 2 镜起每镜以「镜头N：{转场}。」开头；一镜到底单元写「一镜到底」 |
| P11 | 每个镜头行写了机位朝向：「朝西」或「拍向{地标}」 |
| P12 | 每段台词在它所在镜头的分拍行里，引号后紧跟时窗；时窗与台账 `window` 一致，并落在所在分拍里 |
| P13 | 多镜头单元的【光线与色彩】方向写世界方位，不写「画面左 / 右」 |
| P14 | 视场角只用换算表里的 7 个值，并与台账 `camera.fov` 一致 |
| P15 | 「站位：」里每人第一个画面位置（画面左 / 中 / 右、不入画、画外）与台账 `subjects.frame` 一致；左右或入画与否相反判 FAIL，中间与两侧之差给 WARN |
| P16 | 本单元每位说话人在【人物】里写了「声线：」，同一角色各单元的声线文字完全一致 |
| P17 | 提示词长度不超过 `--max-prompt-words`，超过 90% 给 WARN |
| P18 | 【声音方案】以 §4a 对应分支的固定文字开头，逐字照抄 |
| P19 | 「构图和运镜以本提示词为准」在【参考绑定】里只写一次，重复给 WARN |
