# 视觉计划方法

## 先判断是否需要图

每张图都必须让读者更快理解或更准确感受内容，否则不添加。按内容信号选择：

| 内容信号               | 视觉形式 |
| ---------------------- | -------- |
| 层级、框架、体系       | 思维导图 |
| 对比、因果、归属关系   | 概念图   |
| 步骤、顺序、时间线     | 流程图   |
| 有可靠来源的数字或趋势 | 数据图   |
| 值得单独记忆的核心观点 | 文字卡   |
| 人物、冲突、故事或比喻 | 场景插画 |

正文图可以为零。数量、格式和大小服从本次 CLI 返回的约束，宁少勿滥。

## 覆盖完整性门

生命周期、矩阵和跨公司比较图在进入生产前，必须建立逐图覆盖表：

- 生命周期：列出正文和各来源出现的全部阶段，逐阶段标记是否进入图中；
- 矩阵：列出全部轴、象限、行列和例外，避免只画最醒目的格子；
- 跨公司比较：对每家公司或材料逐项核对同一维度，不把某一来源未覆盖的部分伪装成共同结论。

合并多个来源时，每个阶段或单元都要标明“该来源直接覆盖”“由另一材料延伸”或“作者推导”。来源
没有覆盖而由其他材料补出的部分可以保留，但必须在读者可见图注或标签中说明；不能为了画面整齐
静默补齐，也不能遗漏会改变读者理解的阶段。覆盖表是内部检查，不作为来源追溯过程展示给读者；
读者可见成品只保留必要的范围和延伸标注。

## 选择生产方式

- 产品截图、用户拥有版权的照片和品牌资产必须由用户明确指定，不扫描目录寻找；
- 封面、场景和氛围图可用宿主图片生成能力，提示写清主体、构图、情绪、色板和禁项；
- 含精确文字、数字或关系的图优先结构化绘制，避免生成模型写错字或伪造数据；
- 只使用当前命名输入或本轮明确提供的视觉偏好。没有品牌信息时保持中性，不猜颜色、Logo 或人物。

视觉阶段必须产出一张内容相关的真实封面。语义计划不能把提示词、建议图或尚未写入 CLI 分配位置
的结果声称为真实素材。真实文件的解码、路径、数量、优化和安全检查由本阶段 CLI 完成，不转交
审校阶段重复推断。

生成封面时服从当前工作项返回的比例、推荐尺寸和 `crop1To1`。预设或自定义模式按 `safeArea` 构图；
自动模式保持可供横向选取的留白，不自行伪造检测坐标。生成后必须查看真实 2.35:1 成图和 CLI 给出的
1:1 裁切预览，确认主题、标题和关键元素仍完整可辨；仅通过宽高比校验不能证明主体安全。
不合格时在当前分配位置重做，不能把方图、普通 16:9 横图或仅在提示词里声称合规的图片推进。

完成前逐图回读正文与 Research：覆盖表有任何未解释缺口、轴不对齐或来源延伸未标注，就停在本阶段
修正；不能用“示意图”三个字豁免完整性。
