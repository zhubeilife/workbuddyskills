# 结构选型参考

需要比较路线或澄清某个环节的作用时，按需阅读相应部分。以下方法不是穷尽分类，也不限定语义动作的组合。

## 解释矛盾：情境 → 冲突 → 问题 → 答案

适合已有情境出现变化、困难或新的选择，需要引出明确问题的文章。情境建立与读者有关的必要
条件；冲突说明这些条件下的矛盾为何值得关注；问题收敛阅读期待；答案用解释、证据或方案回应。
问题可以隐含，答案也可前置，由大纲决定具体路线。没有真实冲突时直接解释或论证，不虚构旧认识再推翻。

## 解决问题：具体场景 → 后果 → 原因 → 方案 → 证据或案例

适合读者已经遇到困难、需要解决办法的文章。场景让读者识别自己的处境；后果说明实际代价；原因
解释为什么会发生；方案回应原因；证据展示效果与适用条件。后果只写有依据的部分，不放大焦虑；
未经验证的方案注明待验证，不能写成已经有效。

## 解释概念：现实疑问 → 关键区别 → 证据 → 答案与边界

适合读者不理解一个对象或混淆相近概念的文章。从能理解的疑问进入，用同一场景说明区别，再用
材料支撑区分，最后说明它能解释什么、不能解释什么。不要把术语定义依次排列就当作解释完成。

## 论证观点：结论 → 理由 → 证据 → 反例或限制 → 行动

适合读者已了解背景、需要判断一个主张是否成立的文章。先给有边界的结论，各理由回答不同疑点，
证据紧跟它支持的理由，反例说明结论何时不适用。确有可执行建议才落到行动；读者缺少必要背景时
先补最小说明，不把尚待证明的结论冒充共识，也不在每章末尾重申一次观点。

## 讲述经历：目标 → 阻碍 → 动作 → 转折 → 结果与意义

适合材料有连续事件、读者需要理解人物如何走到结果的文章。交代当时想做什么、遇到什么阻碍、
据此采取什么动作；转折来自真实结果或新信息；意义限定在经历能支持的判断。没有转折就顺着事实
收束，不强加意外、失败、顿悟或情绪。

## 教授方法：目标 → 前提 → 步骤 → 示例 → 检查清单

适合读者需要照着完成具体任务的文章。目标说明做到什么程度，前提说明准备与适用条件，步骤按
实际依赖排列，示例展示关键操作，检查清单帮助读者判断是否做对。示例可放在对应步骤中，不为
凑齐结构重复一遍教程；材料只够比较用途时，不承诺可执行教程。

## 实践复盘：发生 → 约束 → 处理 → 验证 → 可借用边界

适合有处理过程和结果证据、需要提炼可借用经验的文章。先交代事件，再说明当时的限制与取舍，
写实际处理及验证结果，最后限定别人能借用的条件。验证缺失时保留缺口并缩小主张，不把尝试写成
成熟方法，也不以今天的答案替当时的人安排判断。

## 对比选择：选择问题 → 比较标准 → 关键差异 → 条件化建议

适合读者要在多种工具、方案或做法间选择的文章。先说清要做哪个决定，再由任务约束推导比较标准，
用材料比较会改变选择的差异，最后说明什么条件下选什么。不同职责的工具先解释分工再比较组合，
不硬排高下。必要的并列、表格和一致维度可以保留；不能只逐个介绍对象而没有共同选择问题。

按材料与读者变化选路线，不按热点、技术或第一人称自动套用。两种都合理时推荐更贴合本篇的
一种，有实质取舍再说备选；局部可用案例或并列解释，整篇保持一条推进主线。

相近路线看文章最终要交付什么：讲述经历重在人物如何走到结果，实践复盘还要解释处理与验证
能支持哪些经验；有个人经历不等于必须复盘。对比选择帮助读者决定用什么，教授方法帮助读者
实际完成任务；只有优缺点与适用条件时，不能因选了教程结构就把操作细节当成已有材料。

可合并非必要呈现，不能删除核心问题、主张、必要证据与限制；缺失时缩小或删除对应主张，或保留
待核验、不可外推边界。不要为套满框架编材料，也不要用对称段落、固定三点或煽动收尾。
