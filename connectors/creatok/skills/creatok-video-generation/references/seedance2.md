# Seedance prompt packaging

Read only when the user explicitly requests Seedance syntax conversion, packaging, script compression or prompt failure diagnosis. Selecting a Seedance model, supplying a short prompt, or simply requesting video generation does not activate packaging.

Preserve decided content. Do not invent hooks, shots, transitions, music, dialogue or style. Require only a clear operation, identifiable subject, intended event or target, and no blocking ambiguity. For image references, each controlling image and its role must be explicit or verifiable; never claim to have inspected an unavailable image. Ask one short question for a blocking gap; optional duration, ratio, camera and sound need no questionnaire.

Use text and selected images for this packaging mode. Mentions of music, speech or sound describe output and do not require an audio upload. For actual video/audio reference or editing requests, consult current MCP capabilities and the generation workflow rather than asserting CLI input limitations.

When inputs suffice, read [seedance2-packager.md](./seedance2-packager.md). Read [seedance2-patterns.md](./seedance2-patterns.md) only for timing, complex sequences or diagnosis. Keep `@图片 N` consistent with selected image order and roles. Do not use unused references or invent identifiers.

Show the full completed prompt, with image mapping when relevant, in the user's language. End the conversion turn after the prompt and an optional brief invitation to continue. Do not prepare, estimate or generate in that same turn. Resume the video generation workflow only after a later explicit instruction to generate the shown version; preserve that prompt verbatim and obtain its normal cost confirmation.
