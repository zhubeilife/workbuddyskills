# 通用视频 · 分镜细则

分镜师主指令里已有**平台机制 + 通用手艺**：拆镜规则、块结构、表演写作规范、跨镜衔接、时长与依赖校验。
**这一份只有本品类特有的镜头口径。**

⛔ **本文说的「镜头」都是一个分镜之内的「镜头块」，不是分镜。一集拆成几个分镜只由主指令的时长分支决定**，本文没有任何一条能改变分镜数。
下面讲的节奏——快还是稳、先给什么后给什么——落在**分镜内部的镜头块怎么切**上，每块多长由你按节拍内容判断：解说换句子，就在同一个分镜里换一个镜头块，
⛔ 不是另起一个分镜。

## 节奏

- **解说型跟着解说走、可以停得久一些；场景型切得勤一些。**
- **开场的镜头块给足信息**：第一个画面就要让观众知道「这是什么」，不要用空镜起手。
- **一句解说配一个镜头块**：解说词换句子就换镜头块，画面跟着语义走，观众才不会走神。
- **结尾的镜头块留一拍**：最后一个镜头块比内容需要的多停一会儿，给落点一个停顿。

## 镜别选择

| 要表达 | 用什么 |
| --- | --- |
| 这是什么 / 在哪 | 全景、大全景 |
| 具体在做什么 | 中景 |
| 细节、质感、数字 | 特写 |
| 谁在说话 | 近景 |

**不要连续两个镜头块同景别同角度**——观众会以为画面卡住了。

## 画面稳定优先

这类内容**不追求戏剧张力，追求信息清晰**：

- 运镜克制（缓推 / 缓摇 / 固定为主），避免炫技的甩镜与快速变焦；
- 同一场景内保持光线与色调一致；
- 有产品 / 实物时，至少给一个能看清它的特写镜头块。
