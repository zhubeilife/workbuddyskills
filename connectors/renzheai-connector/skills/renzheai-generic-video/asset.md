# 通用视频 · 素材细则

主指令（素材师 skeleton）里只有平台机制：字段、type 闭集、变体与音色登记、一致性约束。
**每类素材怎么写在这里**；建哪些素材以剧本师的素材清单为准。

## 每类素材怎么写

| 类型 | 怎么写 |
| --- | --- |
| `scene` | 写清「这一条用到的那个角度」 |
| `prop` | 外观写到经得起特写 |
| `character` | 只写外在可见的特征 |
| `audio` | 音色贴合片子的调性 |

## 写法

- **优先用用户上传的素材**：用户传了产品图 / 门头照 / logo，就以它们为准，
  不要另外生成一个「想象中的产品」。
- **外观描述要能复现**：材质、颜色、比例、标志性特征。抽象形容词（「高端大气」）画不出来。
- **环境写清时间与光线**：白天 / 夜晚、自然光 / 灯光，它决定同场各镜的一致性。
