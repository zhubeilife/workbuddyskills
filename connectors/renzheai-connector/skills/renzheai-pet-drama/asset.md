# 萌宠短剧 · 素材细则

主指令（素材师 skeleton）里只有平台机制。**每类素材怎么写在这里**；建哪些素材以剧本师的素材清单为准。

## 每类素材怎么写

| 类型 | 怎么写 |
| --- | --- |
| `character` | **核心素材**；宠物的样子一次定好，跨集不漂 |
| `scene` | 按宠物的高度去想这个空间 |
| `prop` | 写清故事里用到它时的样子 |
| `audio` | 宠物的声音贴合它的人设 |

## 宠物主角是重中之重

- **写到能跨集复现**：物种 + 品种 + 体型（胖瘦、大小）+ 毛色与花纹的位置（「白肚皮、背上一块橘色、尾巴尖是黑的」）
  + 眼睛颜色 + 一个记忆点（缺了一角的耳朵、红色项圈带铃铛、小领结）。⛔ 不写「很可爱」「很有灵性」这类没法画的形容。
- **用户传了自家宠物的照片，以照片为准**：毛色、花纹、脸型、眼睛颜色照着还原，⛔ 不要自行美化或换品种；
  照片里看不清的部位才按同品种的常见样子补。
- **主条是它本来的样子**（真实姿态的动物）；剧本里拟人的造型（站着穿西装、挂工牌、系围裙）是清单里的变体，
  `variant_of` 回链主条，脸和毛色与主条保持一致。开不开口与造型无关：四脚着地的猫一样可以说话。
- **风格按项目的视觉风格来**：真实质感、3D、卡通都可以；⛔ 不要自作主张把真实的猫画成卡通、或反过来。
- 一群宠物同时出场时，彼此要有一眼分得清的区别（毛色、体型、配饰），别画成一窝双胞胎。

## 宠物的声音

- 说话的宠物（开口或内心 OS）都要一条音色，**贴合它的人设**：高冷的猫偏冷淡低沉、话痨小狗偏明亮急促、老狗偏憨厚。
- 声音一旦定下系列沿用；宠物的变体共用同一条声线，不因换了衣服就换声音。
