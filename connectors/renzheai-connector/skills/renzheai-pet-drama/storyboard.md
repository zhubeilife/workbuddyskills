# 萌宠短剧 · 分镜细则

分镜师主指令里已有**平台机制 + 通用手艺**：拆镜规则、块结构、表演写作规范、跨镜衔接、时长与依赖校验。
**这一份只有以宠物为主角的剧情特有的镜头口径。**

⛔ **本文说的「镜头」都是一个分镜之内的「镜头块」，不是分镜。一集拆成几个分镜只由主指令的时长分支决定**，本文没有任何一条能改变分镜数。
下面讲的节奏——快还是慢、先给什么后给什么——落在**分镜内部的镜头块怎么切**上，每块多长由你按节拍内容判断：
一次「宠物做坏事 → 被抓包 → 装无辜」是同一个分镜里的几个镜头块，⛔ 不是几个短分镜。

## 机位：放低到宠物的高度

- **缺省机位贴着宠物的视线高度**：人只露到小腿、沙发像一座山——这就是「宠物视角」的世界，观众会自然站到宠物那边。
- 主人与宠物同框时，宠物仍是画面主体；要表现「人类居高临下」再从上往下拍宠物，那是一次刻意的选择。
- **主体够大、脸要看得清**：宠物的戏全在眼睛、耳朵、胡须和尾巴上，近景与特写是这个品类的主力。

## 节奏：铺垫给足，反应要停

- **先立住再出事**：开场先给宠物一个标志性的动作或表情，再进入状况。
- **反应镜头块不可省**：被抓包的那一下、听到「洗澡」两个字的那一下，给宠物一个停住的近景——
  瞪圆的眼睛、僵住的爪子、慢慢移开的视线，萌感就在这一停里。
- **反转前收一口气**：反转落地之前留一个短暂的静止或对视，反转再来；不要和前一个动作挤在同一块里。
- **笑点收在动作上，泪点收在停住的画面上**：笑点落在一个干脆的动作或表情后就切走；泪点让最后一个镜头块停得久一些。

## 宠物说话怎么拍

- **开口说的台词**：写清是它在说、嘴在动、口型跟着台词走；拟人的姿态（站立、拿东西、穿衣）照剧本写，
  剧本没写拟人就是一只真实姿态的动物在说话。说话时仍带一点动物的小动作，别演成一个套着动物头的人。
- **剧本里写成内心 OS 的那几句**：嘴不动，画面老老实实拍它「表面上」在做的那件事
  （歪头、甩尾、耳朵向后贴、慢慢眨眼），反差就在这一层。
- 同一个镜头块里有人类和宠物都在说话时，写清谁在说，别让宠物替人类对口型。

## 宠物的样子跨块不漂

宠物主角每一块都按素材图的样子出现：毛色、花纹、体型、配饰（项圈、领结）不因景别和光线变化而走样；
有变体素材（穿西装版）就在用到的那一块里引用变体，不在 prompt 里临时改它的衣服。

## 字幕与文字

心里话、对白由后期剪辑配字幕；⛔ 不要在 video prompt 里让视频模型写字（写出来多半是乱码）。
工牌、门牌、时间卡这类确实要上画面的字，只在素材清单里有对应的文字素材图时引用那张图。
