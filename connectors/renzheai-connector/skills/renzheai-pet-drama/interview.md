# 萌宠短剧 · 访谈与落库参数

主指令里有**通用的那一整套**：`create_project` / `create_episode` 要凑齐哪些字段、各字段用什么工具收、
收尾怎么核对复述确认、换皮流程、补设定门槛。**这一份是本品类的访谈提纲**——问什么、怎么问、
本品类特有的字段怎么填、复述里念哪几行。

## 必须聊清的三件事

1. **宠物主角是谁**——什么动物、什么品种、毛色花纹、叫什么名字；一群宠物就逐只说清。
   用户说「我家猫」「我家狗」，就请 ta 把照片传上来，**以照片为准**还原毛色、花纹、品种特征，不再追问外观细节。
   没有照片、也没说外观的，问一句「它长什么样」，或按故事需要由你定（复述里标「我起的」）。
2. **这一集的小故事**——一个反差（动物做了一件人类的事）+ 一个落点（反转的笑点，或一个泪点）。
   用户只给了设定（「我家猫去上班」）没给故事，就由剧本师在设定里找一个反转，不追问情节。
3. **单集还是系列**——系列 = 同一只（同一群）宠物每集一个新故事（落库仍是 `anthology`），主角形象跨集复用；
   用户说「做一套」「每天一集」「做成账号日更」就是系列。

⛔ **不问宠物「怎么说话」**：宠物该说话就说话，开口还是内心 OS 是剧本师按故事定的写法，不是要用户选的设定。

## 顺带确认

- **主人要不要出镜**：主人是配角，要出镜就问一句是谁演（用户本人的照片 / 由你定一个形象）；只在画外出声也行。
- **基调**：搞笑还是温情，故事里读得出就不问；完全读不出时按搞笑走、结尾可以带一点暖。
- **多长**：材料里读得出（用户说过 / 发在哪）就直接用，完全没信息才 `ask_user_number`，范围 4-600 秒。
  **默认 60 秒**：用户放手时直接取它；要问时长时，它就是 `ask_user_number` 的 default。

## 参数怎么收（先判三态，缺信息的才问）

每一项开口之前先看手上已经有什么——**用户给得越全，问得越少**：

1. **用户明说了，或材料里能直接读出** → **直接采用，不弹卡、不追问**。
   材料 = 用户的话、贴来的故事、上传的宠物照片或文档。
2. **能从上下文合理推断** → 采用、不弹卡，最终复述里这一项后面标「按你的材料推断」并写明依据
   （「我家橘猫当霸总」→ 系列；「发抖音给粉丝看」→ 竖屏）。
3. **完全没有信息** → 才问：
   - 离散字段弹卡：时长 / 画幅 / 项目名候选
   - 开放内容纯文字：主角是什么宠物、这一集讲什么

- **视觉风格按通用规则收**：用户点名了就直接采用；没说就 `ask_user_choice` 传 `preset_pool='video_style'`
  （系统自动注入全部内置风格 + 自定义框，**不要自己列风格名、也不要替用户排除任何风格**）。
- ⛔ 不要因为某一项「是离散字段」就弹卡——材料里有答案的，答案就是答案，不是「默认值」，别让用户再点一次。

## 落库前：复述 → 确认

复述照主指令的共用模板走，本品类在〔品类字段〕那一格写这几行：

```
- 主角: XXX               ← 品种 + 毛色 + 名字；系列时写明「每集都是 ta」；有照片写「按你的照片」
- 基调: XXX               ← 搞笑 / 温情
```

这些信息落在哪：**主角、基调写进世界观**（`theme_prompt`，系列各集共用）；
**这一集的小故事**写进这一集的剧情指令。
⛔ 发在哪只用来决定时长和显示方向，不进世界观、不进剧情指令；世界观和剧情指令里也不写画幅 / 横竖屏。

复述完**同一轮紧接着** `confirm_action`，确认后按主指令的落库方式调。

**这一次复述 + `confirm_action` 是整个流程唯一的一张确认卡**：采用的、推断的、用户选的字段全部并进它，
每项后面标来源（`按你的材料` / `按…推断` / `你选的` / `我起的`）；⛔ 不许先弹一张「确认默认值」再弹一张「确认创建」。
用户给的是成品剧本、要求照它做时，复述里多一行「剧本：按你的原文转录（一个字不改）」。

## 再做一集

系列的下一集 = 同一只（同一群）宠物、一个新的小故事。只聊「这一集讲什么」+ 时长，
主角、基调、风格沿用。
