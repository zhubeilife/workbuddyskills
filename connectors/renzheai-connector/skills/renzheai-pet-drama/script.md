# 萌宠短剧 · 编剧细则

剧本师主指令里已有**平台机制 + 通用编剧手艺**：工具怎么调、产出形态、块 id 纪律、
台词法则、人设与配角格式、画面文字四问、换皮重制、自检与合规。
**这一份只有以宠物为主角的剧情特有的东西。**

## 看点是反差萌：动物 × 人类的事

每一集先在心里定下**那一个反差**，整集都围着它转：

- **动物做人类的事**：猫咪打卡上班、狗狗开会汇报、仓鼠炒股、宠物版霸总谈判；
- **用人类的口吻说动物的事**：猫把打翻杯子说成「物理实验」、狗把拆家说成「装修」；
- **动物天性撞上人类场面**：开着会突然去追激光笔、谈判桌上忍不住踩奶、霸总被一根逗猫棒收服。

反差越具体越好笑：「猫去上班」只是设定，「猫在工位上把同事的键盘当床睡、被老板抓到时说在给它充电」才是戏。
**动物的天性是笑点的弹药库**——猫的高冷、记仇、踩奶、推东西下桌；狗的热情、护食、拆家、听到「出去玩」就疯——
写之前先想这只宠物最像它自己的那几个习惯，把它们放进人类的场面里。

## 故事骨架：日常 → 出状况 → 宠物式应对 → 反转 → 落点

| 段落 | 要做到 |
| --- | --- |
| **日常** | 开场就让人看见「这是一只什么样的宠物、在过什么样的日子」，一个标志性动作或一句台词立住性格 |
| **出状况** | 一件具体的小事：主人要出门、冰箱里有肉、来了一只新猫、被派了一个任务 |
| **宠物式应对** | 用它的逻辑处理人类的事——认真、笨拙、理直气壮，越认真越好笑 |
| **反转** | 结果出人意料：计划翻车、被主人当场抓包、原来另有隐情、高冷的它其实偷偷在乎 |
| **落点** | 一个笑点收住，或一个泪点收住（它一直等在门口、它把最爱的玩具留给生病的主人）；不两头都要 |

反转是这个品类的命门：**观众猜到的结局不算反转**。写完回头问一句「前面有没有埋一个让结尾成立的细节」。

## 宠物的「说话」怎么写

- **该说话就说话**：这是 AI 视频，宠物开口说台词是常态——台词照普通角色的对白写，它在说、嘴在动。
  动作可以拟人（站起来、拿手机、穿西装），也可以就是一只真实姿态的猫狗，看故事需要；
  但**保留一点动物本性**才有萌感——说着话耳朵会抖、生气时毛会炸、紧张时会舔爪子。
- **内心 OS 是一种手法，不是限制**：要「表面乖巧、心里吐槽」这种反差时，把那几句写成画外音心里话，
  动作块里写它表面上在做的事（心里：「这个人类又在自作多情」；画面：乖巧地蹭主人的手）。
  它可以和开口说话在同一集里混着用（对主人只「喵」一声，转头对着镜头吐槽）。
- **人类听不听得懂宠物说话，由故事决定**：「鸡同鸭讲」是一种笑点，宠物和主人正常对话也是一种玩法；
  同一个系列前后保持一致就行。
- 宠物的语气要有**人设**：高冷毒舌的猫、热情话痨的狗、戏精的仓鼠。一个口头禅能帮系列立住招牌。

## 短时长里只打一个反差

一集短，就只用一个反差、一个反转；别把三四个梗堆在一起，每个都来不及笑。
开场第一下就要让人看到「宠物在做人类的事」或听到它的第一句话——观众划走前要先被这只宠物抓住。

## 画面上的字

萌宠剧常想上字：宠物的「工牌」、心里话的字幕气泡、「主人上班后第 1 小时」这类时间卡。
都照通用细则「画面文字」的四问走（以下是例子，不是清单）：

- **心里话 / 对白** → 由后期配字幕，剧本里写成台词或 OS 就够，⛔ 不写「△ 画面上浮现文字：……」。
- **时间卡**（「主人出门后第 3 小时」）→ 优先用画面说时间（窗外天色、挂钟、主人钥匙开门的声音）或一句 OS 带出；
  只有它本身就是这个系列的固定包装时，才规划成一张文字素材。
- **工牌、门牌、招牌这类道具上的字** → 确实要被看清时，列成文字素材或画进对应道具 / 场景的素材图里。

## 素材清单列什么

- **宠物主角是核心**，系列各集**复用同一条**，不每集重建；一群宠物逐只列。
  同一只宠物的不同造型（穿西装的上班版、戴睡帽的居家版）各列一条变体，`variant_of` 回链主条。
- **主人与其他人类角色**：有台词或反复出镜的才列。
- **场景**：家里的那几处（客厅、沙发、窗台、猫爬架、门口）通常就够；拟人剧再加故事发生的地方（办公室、会议室）。
- **推动反转的关键物必列**（被推下桌的杯子、藏起来的肉、主人的拖鞋、逗猫棒）。
- **音色**：每只说话（开口或内心 OS）的宠物与有台词的人类各列一条（宠物的声音跟着宠物走）。
- ⛔ 不列：只在台词里提到、画面上不出现的东西；一次性路人。
