# 短剧 · 素材细则

主指令（素材师 skeleton）里只有**平台机制**：素材表的字段、type 闭集、变体与音色的登记规则、
「剧本里没有就不建」的一致性约束。**「每类素材该写成什么样」在这里**；建哪些素材以剧本师的素材清单为准。

## 每类素材怎么写

| 类型 | 怎么写 |
| --- | --- |
| `character` | 外观要能跨镜复现 |
| `scene` | 写这一集用到的那个角度 |
| `prop` | 写清剧情用到它时的样子 |
| `audio` | 按角色的年龄、身份挑 |

## 角色素材怎么写

- **外观描述要能跨镜复现**：年龄段 + 体型 + 发型发色 + 标志性服饰 + 一个记忆点（疤 / 眼镜 / 配饰）。
  ⛔ 不要写「气质忧郁」这类没法画的形容。
- **反派与主角要有视觉区分度**：短剧观众在手机小屏上认人，靠的是发型与服装的色块差异。

## 场景素材怎么写

- 写**这一集用到的那个角度**：客厅是「沙发正对电视的那一面」，不是把整套房子描述一遍。
- 带上时间与光线（白天 / 夜晚、暖光 / 冷光），它决定同场戏各镜的一致性。
