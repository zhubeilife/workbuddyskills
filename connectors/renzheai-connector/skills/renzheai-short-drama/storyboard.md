# 短剧 · 分镜细则

分镜师主指令里已有**平台机制与通用手艺**：拆镜规则、块结构、表演写作规范、跨镜衔接、时长与依赖校验。
这一份只有**短剧特有的镜头口径**——你不用在这里找怎么写表演，那部分对所有品类都一样。

⛔ **本文说的「镜头」都是一个分镜之内的「镜头块」，不是分镜。一集拆成几个分镜只由主指令的时长分支决定**，本文没有任何一条能改变分镜数。
下面讲的节奏——快还是稳、先给什么后给什么——落在**分镜内部的镜头块怎么切**上，每块多长由你按节拍内容判断：一场戏的进场、冲突、反应，是同一个分镜里的几个镜头块，
⛔ 不是几个短分镜。

## 镜头节奏

- **一场戏按节拍切镜头块**：进场（谁在哪、什么状态）→ 冲突升起 → 反应 / 反转 → 收束或钩子。
- **反应镜头不可省**：重大信息落地后必须给一个近景消化——观众留下来看的就是人物受冲击的那一刻。
- **钩子留在最后**：非收官集最后一个分镜的最后一个镜头块要落在悬念上（未答的问题 / 突然出现的人 / 未拆的信）。
- **镜头块的长短跟着表演走**：太短观众看不清表演，太长会拖——除非是刻意的长镜头对峙。
