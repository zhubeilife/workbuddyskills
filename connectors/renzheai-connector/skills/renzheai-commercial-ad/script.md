# 广告片 · 脚本细则

剧本师主指令里已有**平台机制 + 通用编剧手艺**：工具怎么调、产出形态、块 id 纪律、
台词法则（信息前置 / 动作可视化）、人设与配角格式、换皮重制、自检与合规。
**这一份只有本品类特有的东西** —— 别在这里找台词怎么写、人物怎么立。

## 骨架：钩子 → 痛点 → 方案 → 证据 → 行动

| 段落 | 占比 | 要做到 |
| --- | --- | --- |
| **钩子** | 前 3 秒 | 一个具体的画面或一句反常识的话，让人停下 |
| **痛点** | 接下来 20% | 说出观众正在经历的那个麻烦，越具体越好 |
| **方案** | 40% | 产品怎么解决它——**演示，不是描述** |
| **证据** | 20% | 数字 / 对比 / 真实使用画面，给一个相信的理由 |
| **行动** | 最后 2-3 秒 | 明确说下一步做什么 + 品牌露出 |

15 秒以内的素材可以压成「钩子 → 方案 → 行动」三段，但**行动指令一秒都不能省**。

## 前 3 秒的写法（决定这条素材的生死）

有效的开场只有这几类，挑一个：

- **反常识断言**：「洗衣机才是家里最脏的地方」
- **可见的痛点瞬间**：手忙脚乱、东西掉一地、屏幕上刺眼的报错
- **结果前置**：先给出令人意外的效果，再回头讲怎么做到
- **直接点名人群**：「租房党看过来」——精准但会缩小覆盖，投放窄人群时才用

⛔ 一律不要：logo 开场、慢慢推近的空镜、「在这个 XX 的时代」、自报家门式旁白。

## 台词纪律

- **每句话都要能被验证**：说「3 秒速热」就要有 3 秒的画面，说「万人好评」就要有依据。
  用户没给依据的数字**不要编**——换成不需要证明的说法，并在 summary 里列出缺哪些数字，由调用方去问用户。
- **广告法红线**：不用「最」「第一」「国家级」「唯一」「彻底根治」这类绝对化 / 医疗承诺用语。
  拿不准就改写成事实描述（「连续三年销量第一」→ 有数据来源才写，没有就删）。
- **口播要短**：一句话不超过 15 个字，念出来要顺。按语速三档折算时长，别超时。

## 素材清单列什么

- **产品本体必列**（`prop`，核心素材）；包装状态 / 使用状态 / 剖面演示这类多形态各列一条变体，`variant_of` 回链。
- **使用场景 2~3 个够了**，广告不需要复杂空间。
- **出镜的使用者列 1~2 个**——他们是人群代表，不是角色。
- **有口播就为口播的说话人列一条音色。**
- ⛔ 不列：竞品；画面上不出现、只在口播里提到的东西。

## 什么不该做

- 不要设计人物弧线与反转（观众没时间跟你走情节）；
- 不要在一条里塞两个诉求；
- 不要把行动指令做成一闪而过的小字——它要念出来；确需上画面的走「画面文字」，做一张卡。
