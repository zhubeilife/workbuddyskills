# 广告片 · 访谈与落库参数

主指令里有**通用的那一整套**：`create_project` / `create_episode` 要凑齐哪些字段、各字段用什么工具收、
收尾怎么核对复述确认、换皮流程、补设定门槛。**这一份是本品类的访谈提纲**——问什么、怎么问、
本品类特有的字段怎么填、复述里念哪几行。

## 必须聊清的六件事

1. **推什么**——产品 / 服务 / 品牌本身。要具体到「哪一个产品的哪一个型号」。
2. **给谁看**——目标人群的年龄、身份、场景（宝妈刷抖音 / 白领午休 / 车主等红灯）。
   ⛔ 「所有人」不是答案，追问一句「最想打动的是谁」。
3. **一句话诉求**——看完观众要记住的**唯一**一件事。
   用户列了五个卖点，就问「如果只能留一个，留哪个」，其余降级为支撑点。
4. **投在哪**——抖音 / 视频号 / 朋友圈 / 开屏 / 电梯屏。决定画幅、时长。
   ⚠️ 电梯屏与开屏**通常静音播放**：照样要口播，静音观众看的是台词字幕（台词字幕在「剪辑」页点「生成字幕」出），
   画面也要自己把事情讲清楚。
5. **多长**——材料里读得出（脚本时间轴 / 需求写明 / 用户说过）就直接用，完全没信息才 `ask_user_number`。信息流建议 15-30 秒，品牌 TVC 30-60 秒，
   开屏 5-15 秒。超过 60 秒要提醒「投放成本会明显上升，且完播率掉得很快」。
   **默认 30 秒**：用户放手时直接取它；要问时长时，它就是 `ask_user_number` 的 default。
6. **要观众做什么**——下载 / 下单 / 到店 / 搜索关键词 / 加微信。
   **这一项必须有**，没有行动指令的广告等于没投。

## 顺带确认

- **有没有品牌规范**：logo、主色、slogan、必须出现的法务声明。有就让用户把图片传上来——这些要原样出现在画面上的，只能用真图。
- **能不能用真人**：用户有代言人 / 素人出镜素材吗；没有就全靠生成。
- **有没有禁忌**：竞品名、绝对化用语（「最」「第一」）、行业限制词。
  ⚠️ 广告法禁用词是硬红线，写脚本时一律避开，拿不准就换个说法。

## 参数怎么收（先判三态，缺信息的才问）

每一项开口之前先看手上已经有什么——**用户给得越全，问得越少**：

1. **用户明说了，或材料里能直接读出** → **直接采用，不弹卡、不追问**。
   材料 = 用户的话、贴来的文案 / 脚本、上传的文档、发来的链接。
   范例：文案自带时间轴「0-3 秒 … 55-60 秒」= 60 秒；文档写明「30 秒」= 30 秒；文案标了语气 = 调性已定。
2. **能从上下文合理推断** → 采用、不弹卡，最终复述里这一项后面标「按你的材料推断」并写明依据
   （发抖音 / 视频号 / 小红书 → 竖屏；官网首屏 / 展会大屏 → 横屏）。
3. **完全没有信息** → 才问：
   - 离散字段弹卡：投放平台 / 时长 / 画幅 / 项目名候选
   - 开放内容纯文字：推什么、给谁看、一句话诉求、行动指令

- **视觉风格不做推断**：用户点名了风格就直接采用；没说就 `ask_user_choice` 传 `preset_pool='video_style'`
  （系统自动注入全部内置风格 + 自定义框，**不要自己列风格名**）。
- ⛔ 不要因为某一项「是离散字段」就弹卡——材料里有答案的，答案就是答案，不是「默认值」，别让用户再点一次。

## 落库前：复述 → 确认

复述照主指令的共用模板走，本品类在〔品类字段〕那一格写这几行：

```
- 推广对象与人群: XXX      ← 推什么 + 给谁看，整合成一段
- 核心诉求: XXX            ← 唯一那一件事
- 行动指令: XXX
```

这些信息落在哪：**推广对象与人群、核心诉求写进世界观**（`theme_prompt`，同项目各条共用）；
**这一条怎么讲**（开头钩子 + 主体 + 行动指令）写进这一条的剧情指令。
⛔ 投放平台只用来决定时长、显示方向和开头怎么抓人，不进世界观、不进剧情指令，也不单列一行；
世界观和剧情指令里也不写画幅 / 横竖屏。

复述完**同一轮紧接着** `confirm_action`，确认后按主指令的落库方式调。

**这一次复述 + `confirm_action` 是整个流程唯一的一张确认卡**：采用的、推断的、用户选的字段全部并进它，
每项后面标来源（`按你的材料` / `按…推断` / `你选的` / `我起的`）；⛔ 不许先弹一张「确认默认值」再弹一张「确认创建」。
用户给的是成品脚本 / 文案、要求照它做时，复述里多一行「剧本：按你的原文转录（台词一个字不改）」。
`story_mode` / `finale_style` / `is_finale` 按 SKILL.md 直接填，不问、不复述。

## 再做一版

同项目下建下一条 = 换个版本（不同开头 / 不同时长 / 不同人群切入）。
只聊「这一版跟上一版差在哪」+ 时长，项目级设定沿用。
