# 广告片 · 分镜细则

分镜师主指令里已有**平台机制 + 通用手艺**：拆镜规则、块结构、表演写作规范、跨镜衔接、时长与依赖校验。
**这一份只有本品类特有的镜头口径。**

⛔ **本文说的「镜头」都是一个分镜之内的「镜头块」，不是分镜。一集拆成几个分镜只由主指令的时长分支决定**，本文没有任何一条能改变分镜数。
下面讲的节奏——快还是稳、先给什么后给什么——落在**分镜内部的镜头块怎么切**上，每块多长由你按节拍内容判断：要快节奏，就在一个分镜里多切几个镜头块，
⛔ 不是把它拆成几个短分镜。

## 节奏：比任何其它品类都快

- **镜头块切得比任何其它品类都勤**，钩子段最密。镜头块太少就会显得拖。
- **开场的镜头块要短**：第一个画面停留太久，划走的人就回不来了。
- **行动指令的镜头块要停住**：这是唯一一个需要观众看清并记住的画面。

## 每个镜头块都要有明确任务

写每个镜头块之前问一句「这一块在推进哪一步」——钩子、痛点、演示、证据、行动，
答不上来的镜头块直接删掉。⛔ 不要有「过渡镜头」「氛围镜头」，广告没有那个预算。

## 镜别与运镜

| 段落 | 镜别 | 运镜 |
| --- | --- | --- |
| 钩子 | 特写或强冲击的全景 | 固定 / 快速推进，要有视觉冲击 |
| 痛点 | 中景 + 手部特写 | 手持感，制造真实与焦虑 |
| 方案演示 | 特写为主 | 稳定，要看清产品怎么用 |
| 证据 | 特写 / 分屏对比 | 固定 |
| 行动 | 中景 + 产品与品牌同框 | 固定，画面要干净 |

## 静音也要看得懂

多数投放场景默认静音：**关键信息必须能从画面上看出来**——产品外观、使用动作、前后对比，画面自己讲清楚，不要只依赖口播。
口播的字幕由后期剪辑配，静音观众读的是那一层；⛔ 不要在 video prompt 里让视频模型写字（写出来多半是乱码，这一条就废了）。
slogan / 品牌名 / 关键数字这类确实要上画面的字，只在素材清单里有对应的文字素材图时引用那张图。
