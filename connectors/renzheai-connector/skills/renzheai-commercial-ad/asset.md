# 广告片 · 素材细则

主指令（素材师 skeleton）里只有平台机制。**每类素材怎么写在这里**；建哪些素材以剧本师的素材清单为准。

## 每类素材怎么写

| 类型 | 怎么写 |
| --- | --- |
| `prop` | **核心素材**；用户传了产品图就以图为准，不要自行想象外观 |
| `scene` | 写简洁，广告不需要复杂空间 |
| `character` | 写清人群特征（年龄段 / 身份），**别设计性格与背景故事** |
| `audio` | 音色要贴合人群（面向宝妈的别用低沉男声） |

## 产品素材是重中之重

- **必须与真实产品一致**：用户上传的产品图是唯一依据。没有图时照常干活，在 summary 里写一句
  「没有产品照片，画面里的产品外观只能是示意」，由调用方转告用户。
- **写清材质、颜色、比例、logo 位置**——广告里产品会出现在特写里，任何不一致都会被看出来。
- 用户没提供依据的具体品牌 logo 或包装细节不要编——宁可留白。

## 人物素材

- 只写**外在可见**的特征：年龄段、体型、发型、穿着、一个记忆点。
- ⛔ 不要写性格、背景、动机——广告人物是「人群代表」不是角色。
- 品牌有代言人 / 指定形象时以用户提供的素材为准。
