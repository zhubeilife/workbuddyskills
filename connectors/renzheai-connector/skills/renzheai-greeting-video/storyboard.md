# 祝福视频 · 分镜细则

分镜师主指令里已有**平台机制 + 通用手艺**：拆镜规则、块结构、表演写作规范、跨镜衔接、时长与依赖校验。
**这一份只有祝福视频特有的镜头口径。**

⛔ **本文说的「镜头」都是一个分镜之内的「镜头块」，不是分镜。一集拆成几个分镜只由主指令的时长分支决定**，本文没有任何一条能改变分镜数。
下面讲的节奏——快还是慢、先给什么后给什么——落在**分镜内部的镜头块怎么切**上，每块多长由你按节拍内容判断：
要停得住，就在一个分镜里少切几个镜头块、让每一块留够时间，⛔ 不是把它拆成几个短分镜。

## 节奏跟着场合走

- **喜庆、搞笑**（拜年、开业、年会）：镜头块可以切得勤一些、动作热闹一些，但点名与祝福两处要停住。
- **温馨、庄重**（生日给长辈、纪念日、婚礼、毕业）：镜头块切得少、每一块停得住，运镜慢而稳，以缓推和固定为主。
- 用户点名了节奏就照用户的来。

## 先给谁、最后停在哪

- **开场先让人认出是谁、为了什么**：第一个镜头块就给到被祝福的人（或送祝福的形象）和场合的标志物同框，
  别用空景慢慢铺。
- **「那件事」给近景和细节**：回忆里的那碗面、那张旧照片、那只手——细节特写比大场面更动人。
- **结尾停住**：最后一个镜头块落在祝福上——主角面向镜头说出祝福、或画面定在祝福字卡 / 场合标志物上，
  停留得比其它块长，⛔ 不要在祝福语之后再切走。

## 被祝福的人要看得清

- **用了照片的人，脸要清楚**：给近景、中近景，正面或微侧，光线柔和充足；⛔ 不要背光、大俯仰角、远到看不清脸的构图。
- **表情真诚**：笑容、眼含泪光、举杯、拥抱这类明确的动作情绪；别写细微到看不出来的表演。
- **一群人送祝福**（全家、部门）：先给一个所有人同框的画面，再逐个给近景；人多时⛔ 不让每个人都轮流开口。

## 字幕与文字

台词与祝福语的字幕由后期剪辑配；⛔ 不要在 video prompt 里让视频模型写字（名字写错一个字，这条祝福就废了）。
名字卡、祝福字卡这类确实要上画面的字，只在素材清单里有对应的文字素材图时引用那张图；
横幅、蛋糕上的字随场景图 / 道具图带进来，video prompt 里只说「横幅」「蛋糕」，不复述上面的字。
