# 祝福视频 · 编剧细则

剧本师主指令里已有**平台机制 + 通用编剧手艺**：工具怎么调、产出形态、块 id 纪律、
台词法则、人设与配角格式、换皮重制、自检与合规。
**这一份只有祝福视频特有的东西** —— 别在这里找台词怎么写、人物怎么立。

## 一条只送一份祝福

开场就让人知道「这是送给谁的」，结尾落在那一句祝福语上。中途不岔出第二件事，
不拿片子顺带宣传什么、也不塞和这个人无关的段子。

## 骨架：点名 → 那件事 → 心意 → 祝福

| 段落 | 要做到 |
| --- | --- |
| **点名** | 一开场就叫出名字或称呼，配上场合的标志物（蛋糕、红灯笼、婚纱、学士帽），一眼知道是送给谁、为什么 |
| **那件事** | 一段共同的回忆、对方的一个特点、这一年 ta 做成的一件事——**整条片子的分量都在这里** |
| **心意** | 送祝福的人想说的那句心里话：感谢、骄傲、想念、陪伴 |
| **祝福** | 一句祝福语点题，然后停住 |

短的片子可以把「那件事」和「心意」压成一段，但**点名和祝福一个都不能省**。
搞笑调性也照这个骨架走：笑点长在「那件事」上（ta 的一个口头禅、一次出糗），落点仍是真心的祝福。

## 写具体，别写华丽

- **一个具体的细节胜过十个形容词**：「每天早上六点给我煮的那碗面」比「无私的爱」有力，
  「入职第一天把打印机弄卡纸的你」比「勤奋努力」记得住。
- **只用用户给的事**：用户没讲的经历、性格、成就 ⛔ 不编——编出来的「回忆」被祝福的人一看就知道是假的，
  整条片子的心意就没了。用户说「你看着写」时，写场合本身（这一年、这个节日、这一刻），不虚构两人之间的往事。
- **少用成语堆砌和套话**：「万事如意、心想事成、步步高升」可以出现在祝福语里，但不能撑起整条片子。
- **口吻跟着送祝福的人走**：子女对父母、丈夫对妻子、老板对员工、公司对客户，称呼和说话方式各不一样，
  别让老板对员工说出撒娇的话、也别让孩子对妈妈打官腔。
- 被祝福的是一群人（全体员工、各位客户）时，「那件事」写这群人共同经历的（这一年一起熬过的项目、一起搬进的新办公室），
  点名用用户给的称呼。

## 名字、称呼、祝福语一字不改

用户给的名字、称呼、昵称、祝福语原文，**逐字照用**：不改字、不换同音字、不润色、不加标点修饰、不把口语改成书面语。
用户给的是一大段想说的话，就按原话断成几句台词，⛔ 不改写意思也不删掉 ta 觉得重要的那几句；
实在超出时长，在 summary 里写明「哪几句放不下」，由调用方去问用户删哪句，不要自己挑。

## 这类片子常撞上的「画面上的字」

都照通用细则「画面文字」的四问走（以下是例子，不是清单）：

- **祝福语** → 先是台词，由送祝福的人或旁白念出来；用户要它上画面的，结尾做一张写着祝福语原文的字卡素材。
- **被祝福人的名字** → 念出来；要上画面的（片头大字「致 小雅」），做一张名字卡素材，图上的字照用户给的原文。
- **横幅、门头、背景墙上的字**（「热烈庆祝 XX 公司开业」「新婚快乐」）→ 长在场景上，写进那个场景行的 `reason`，不单列字卡。
- **蛋糕上、贺卡上、红包上的字** → 长在那件东西上，写进那件道具行的 `reason`；只有要给特写、必须看清时才单列一张字卡。
- ⛔ 不要让字幕、名字、祝福语以「浮现」「打出」的方式写进剧本让视频去生成——字幕由后期剪辑配。

## 素材清单列什么

- **主角是核心**：被祝福的人、送祝福的人、或代为送祝福的形象——片子里谁出镜就列谁。
  用户传了照片的人，清单里写明「以照片为准」；同一个人不同时期（小时候、现在）各列一条变体，`variant_of` 回链。
- **场景 1~3 个**：场合的现场（生日餐桌、年夜饭、婚礼现场、新店门口），加上「那件事」发生的地方（如果要拍）。
- **场合的标志物必列**：蛋糕、红包、灯笼、月饼、戒指、学士帽、开业花篮——一眼认出场合靠它们。
- **要上画面的名字卡 / 祝福字卡**按通用细则列成文字素材，`name` 按用途起（「片头名字卡」「结尾祝福卡」），字只写在 `reason` 里。
- **旁白与每个开口的人各列一条音色。**
- ⛔ 不列：只在台词里提到、画面上不出现的人和东西；用户没提过的亲友、同事——别为了热闹造人。

## 什么不该做

- 不要设计冲突、误会、反转——那是短剧的活，祝福片里出现「差点搞砸」也要轻轻带过、马上落回心意；
- 不要一条里同时祝两个场合（「生日快乐兼新年快乐」）除非用户就是这么要的；
- 不要把结尾做成开放式留白——最后一句一定是祝福。
