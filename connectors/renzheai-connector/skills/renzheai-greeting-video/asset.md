# 祝福视频 · 素材细则

主指令（素材师 skeleton）里只有平台机制。**每类素材怎么写在这里**；建哪些素材以剧本师的素材清单为准。

## 每类素材怎么写

| 类型 | 怎么写 |
| --- | --- |
| `character` | **核心素材**；用户传了照片就以图为准 |
| `scene` | 场合一眼认得出 |
| `prop` | 上面有字的，字写进 `reason` |
| `special` | 图上的字照清单原文，一字不改 |
| `audio` | 贴合口吻：孩子对父母用清亮的童声，公司对客户用稳重的声音 |

## 照片里的人以图为准

- 用户传了被祝福的人 / 送祝福的人的照片，**长相、发型、体型以照片为准**，⛔ 不自行想象外观、不美化成另一个人。
- 照片里的衣着可以按场合换（拜年换红衣、婚礼换礼服），但脸和体态不动；换装各建一条变体，`variant_of` 回链。
- 没有照片时照常干活，在 summary 里写一句「没有照片，画面里的 ta 只能是示意」，由调用方转告用户。

## 形象 / 吉祥物

- 代为送祝福的可爱形象：颜色、造型、一个记忆点写清楚，风格按项目的视觉风格来。
- 用户有自己的形象（公司吉祥物、家里的宠物照片），以图为准。

## 字卡与带字的东西

- 名字卡、祝福字卡：字按清单 `reason` 里的原文逐字照抄，大字、少字，版式贴合场合（拜年红底金字、婚礼浅色烫金）。
- 横幅、门头、蛋糕上的字画在那张场景图 / 道具图里，原文同样一字不改。
