# 历史故事 · 素材细则

主指令（素材师 skeleton）里只有平台机制。**每类素材怎么写在这里**；建哪些素材以剧本师的素材清单为准。

## 每类素材怎么写

| 类型 | 怎么写 |
| --- | --- |
| `character` | **核心素材**；写明朝代、身份、年龄段 |
| `scene` | 写明朝代与建筑形制 |
| `prop` | 写清材质、形制、纹饰 |
| `special` | 字要写准，用时代对得上的字体与载体 |
| `audio` | 旁白沉稳有叙事感；人物音色贴合年龄与身份 |

## 按时代考据，这一条比什么都重要

- **每一条都先写朝代**：服饰、发式、冠帽、建筑、器物都由朝代决定；同一集里的素材必须是同一个时代的样子。
- ⛔ **不出现时代错误**：明朝人穿清朝的马褂、汉朝人坐高背椅这类错，观众一眼就能挑出来。
  穿越式讲法里从现代过去的人照现代人的样子（这本身就是设定），古代的人和物仍按那个朝代来。
  拿不准的细节写「该朝代常见的……」，不要硬编一个具体的形制。
- **身份写在穿戴上**：官服的颜色与补子、甲胄的形制、平民的布衣——身份差别靠穿戴一眼分清。
- **同一人物跨年龄 / 身份阶段**各建一条变体（少年、中年、称帝后），外貌的延续性写清：脸型、一个记忆点。
- 用户上传了人物画像、文物照片、遗址照片，**以图为准**，描述照着图写，不要自行想象外观。

## 文字素材

字要写准：人名、地名、年号逐字核对，不写错字、不写简繁混用（同一张图里统一一种）。
地图只画讲解需要的那几个地名与那一个形势，不堆细节。
