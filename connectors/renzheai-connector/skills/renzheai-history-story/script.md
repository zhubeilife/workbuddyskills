# 历史故事 · 编剧细则

剧本师主指令里已有**平台机制 + 通用编剧手艺**：工具怎么调、产出形态、块 id 纪律、
台词法则、人设与配角格式、画面文字的四问、换皮重制、自检与合规。
**这一份只有讲一段真实历史特有的东西。**

## 一集讲清一段史事

整集围着一个人（他的一个转折，或他的一生）、或一件事的来龙去脉转：开头抛出来，结尾讲到结局。
中途牵出的旁支（另一位人物、另一场战事）一句带过或留给下一集。
判据：**看完的人能不能用一句话说出「这一集讲的是谁、做了什么、结果怎样」**——说不出来，就是塞多了。

## 骨架：悬念开场 → 背景 → 关键事件推进 → 结局 → 一句评点或余味

| 段落 | 占比 | 要做到 |
| --- | --- | --- |
| **悬念 / 反常识开场** | 前 10% | 一个让人想知道「为什么」的切口：结局先抛（「他打赢了每一场仗，却死在自己人手里」）、一个反常识的事实、一件文物的怪处。⛔ 不要从「公元某年，某某出生于……」起手 |
| **背景** | 15% | 只交代看懂这件事必需的：什么时代、什么局面、主角是谁。⛔ 不铺整段朝代史 |
| **关键事件推进** | 50% | 两三个节点一步步推：每个节点是一个选择或一次碰撞，**因为 A → 于是 B → 没想到 C** |
| **结局** | 15% | 按史实讲清结果，回应开头的悬念 |
| **评点 / 余味** | 最后 10% | 一句点题的评点，或一个留在心里的画面（一座留存至今的城墙、一件躺在博物馆里的文物）。⛔ 不长篇说教 |

`serial` 时：骨架照用，开场可以用一句话接上集（「上一回说到……」），结尾停在下一段历史的入口上；
最后一集讲到这段历史的终点。

## 穿越式讲法

用户要穿越式的讲法（现代人穿越回去亲历、讲述人带观众走进现场）时，穿越的人是**观察者和讲述者**：
他看到、听到、问到的都是真事，历史照史实发生——⛔ 不让他改变历史，也不让古人做史书里没有的事。
他的反应、吐槽、和古人的搭话是演绎，可以写；古代的部分照下面「史实与演绎分开」。

## 史实与演绎分开（这类片子的生命线）

1. **史实部分不许动**：人物、时间、地点、官职、事件经过与结果按史实写。⛔ 不编造史实、不张冠李戴
   （把甲的事安到乙头上、把两个年代的事拼成一件）、不为了戏剧性改结局。
2. **演绎只补细节、不改结论**：为了好看补的对话、心理、场面属于合理演绎，可以写；
   但演绎出来的东西不能推出与史实不同的结论，也不能替历史人物安一个史书里没有的动机当成定论。
3. **说清是哪一种说法**：正史与野史 / 民间传说 / 后世演义有出入时，旁白明说是哪一种
   （「史书记载……」「民间传说……」「小说里写的是……而正史里……」）；史学界有争议的，说「一种说法是……」，不下定论。
4. **用户给了资料，以资料为准**：资料与通行说法冲突时照资料写，并在 summary 里点出冲突的那一处，由调用方转告用户。
5. **拿不准的不写死**：具体年份、数字（兵力、伤亡、寿命）没把握就不给，或用审慎说法（「约」「据记载」）；
   缺关键信息时在 summary 里列出缺了什么，由调用方去问用户。

## 旁白与台词怎么写

- **旁白是主线**：讲述人负责交代时间、因果和评点，像讲故事而不是念年表。一句只说一件事，句子要短。
- **人物台词少而准**：只在关键时刻给人物一两句——表态、抉择、临终、对峙。史书里有原话的（名句、奏对）优先用原话，
  可以在后面跟一句白话解释；演绎的台词用当代人听得懂的话，⛔ 不硬写半文不白的腔调，也不混进现代网络用语。
- **专有名词先给画面再给名字**：官职、地名、器物第一次出现时，旁白顺手解释一句它是什么。
- **年份与地名念出来**：「公元前二〇九年」「大泽乡」由旁白念清，字幕由后期配。

## 年份、地名、地图怎么上画面

照通用细则的「画面文字」四问走，本品类的落点是：

- 年份、地名、人物身份**一律先写成旁白**——念出来就够了，台词字幕由后期配。
- **必须被看见才讲得清的**（一张形势地图、一块写着名字的匾额、一份诏书的关键一行、片头的年份标题卡）才规划成文字素材，
  `asset_intent` 里列一行 `type='special'`，正文只写它怎么出现。一集里挑最关键的一两张，不是每个地名都做卡。
- 「行军路线一路画过去」「疆域一点点扩张」这种会动的图做不了：变化交给旁白和画面再现，需要的话只给终态那一张图。

## 再现场面怎么写

关键事件的每个节点写一个**看得见的场面**：朝堂上的对峙、营帐里的密谈、城头的一眼、一件器物被捧出来。
写在 `action` 块里，写观众要看清的人与事，⛔ 不写景别和镜头手法，怎么拍归分镜师。
千军万马的大场面点到为止：用一处局部（一面倒下的旗、一匹空鞍的马）代替全景铺开。

## 素材清单列什么

- **主角人物是核心**，再加推动这段史事的两三个关键人物；`serial` 的主角**跨集复用**同一条，不每集重建。
  同一人物不同年龄 / 身份阶段（少年、称帝后）各列一条变体，`variant_of` 回链。
- **每条人物、场景、器物都写明朝代**：时代决定服饰、发式、建筑、器物，素材师按它考据。
- **场景 2~4 个**：事件发生的关键地点（宫殿、营帐、城楼、战场一角）。
- **推动情节的器物必列**：玉玺、兵符、诏书、那件文物本身。
- **文字素材**：上面「年份、地名、地图怎么上画面」一节挑出的那一两张。
- **旁白（或讲述人）音色一条**，有台词的人物各一条。
- ⛔ 不列：只在旁白里提到、画面上不出现的人和物。

## 什么不该做

- 一集讲一个人的一生时，只挑两三个转折节点讲透，不逐年铺成流水账；
- 不要把演绎的细节写成「史书记载」；
- 不要用现代价值观给古人贴标签，评点就事论事；
- 不要用「震惊」「你绝对不知道」这类标题党话术代替真正的悬念。
