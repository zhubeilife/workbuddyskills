# 企业宣传片 · 素材细则

主指令（素材师 skeleton）里只有平台机制。**每类素材怎么写在这里**；建哪些素材以剧本师的素材清单为准。

## 每类素材怎么写

| 类型 | 怎么写 |
| --- | --- |
| `scene` | **核心素材**，写法见下方「场景素材写法」 |
| `prop` | 写清特写下看得到的外观细节 |
| `character` | 写清工种与着装，**不写性格** |
| `audio` | 成熟稳重、中等语速，别用夸张的广告腔 |

## 真实素材优先，这一条比什么都重要

用户上传的厂房 / 团队 / 产品照片是**唯一可靠的依据**。这类片子会被客户拿去和现实对照，
生成一个「想象中的车间」是很危险的。

- 用户传了素材 → 以图为准，描述照着图写；
- 用户没有素材 → 照常干活，在 summary 里写一句「画面只能是行业通用的示意场景，和贵司实际情况会有出入，
  可以先去拍一些照片」，由调用方转告用户。

## 场景素材写法

- 写清**规模感**：面积、层高、设备排布密度——这是「实力」的视觉来源。
- 写清**整洁度与秩序**：地面、走线、标识牌。
- 写清**光线**：车间通常是高顶灯 + 自然光，办公区是均匀白光。

## 人物素材写法

- 只写外在：工种、着装（工装 / 白大褂 / 商务）、年龄段、状态（专注操作 / 讨论）。
- ⛔ 不要写姓名、职位头衔、个人故事——除非用户明确提供了真实人物信息。
- ⛔ 不写摆拍感的「员工对镜头微笑」类状态。
