# 企业宣传片 · 脚本细则

剧本师主指令里已有**平台机制 + 通用编剧手艺**：工具怎么调、产出形态、块 id 纪律、
台词法则（信息前置 / 动作可视化）、人设与配角格式、换皮重制、自检与合规。
**这一份只有本品类特有的东西** —— 别在这里找台词怎么写、人物怎么立。

## 骨架：我们是谁 → 我们凭什么 → 我们怎么做 → 找我们

| 段落 | 占比 | 要做到 |
| --- | --- | --- |
| **开场定位** | 前 10% | 一句话说清这是谁、做什么。**不要**从「随着时代发展」起手 |
| **实力支撑** | 30% | 用数字与画面证明规模与能力：厂房、设备、团队、资质 |
| **过程展示** | 40% | 怎么把事情做好的——流程、标准、细节。这一段最能建立信任 |
| **价值与愿景** | 15% | 给客户带来什么。可以有一点情绪，但要落在具体收益上 |
| **收尾** | 最后 5% | logo + slogan + 联系方式，干净利落 |

## 解说词纪律（这类片子的核心产出就是解说词）

1. **每句话都要有事实支撑**：写「技术领先」必须紧跟一个能证明的东西
   （专利数 / 设备型号 / 检测标准）。**没有支撑的形容词一律删掉**。
2. **数字优先**：「20 年」「3 万平米」「服务 500+ 客户」「良品率 99.6%」。
   ⛔ 用户没提供的数字**绝对不要编**——这类片子会被客户拿去核实。
   缺数字就写不需要证明的说法，并在 summary 里列出缺哪些数字，由调用方去问用户。
3. **句子要短**：一句 20 字以内，念出来自然停顿。长句在配音里会糊成一片。
4. **少用第一人称炫耀**：「我们是行业领导者」不如「连续三年通过 XX 认证」。
   让事实说话，把判断留给观众。
5. **按语速三档估时**：解说词字数 ÷ 语速 = 时长，严格对齐，别超时。

## 素材清单列什么

- **场景是核心**：厂区外观、车间、办公区、会议室、实验室，通常 4~6 个。
- **产品、设备、证书、样品只列画面上要给特写的。**
- **员工列 2~3 个**（操作工、工程师、管理者这类工种代表）。
- **列一条解说音色。**
- ⛔ 不列：竞品；未经授权的客户方可识别标识；用户没提供依据的资质证书与奖项。

## 什么不该做

- 不要编造荣誉、客户名、数据；
- 不要写「打造」「赋能」「生态闭环」这类听不出具体含义的词；
- 不要设计人物剧情——员工出镜是「在工作」，不是在演戏；
- 不要留悬念——这类片子要的是清晰，不是好奇。
