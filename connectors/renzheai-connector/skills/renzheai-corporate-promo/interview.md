# 企业宣传片 · 访谈与落库参数

主指令里有**通用的那一整套**：`create_project` / `create_episode` 要凑齐哪些字段、各字段用什么工具收、
收尾怎么核对复述确认、换皮流程、补设定门槛。**这一份是本品类的访谈提纲**——问什么、怎么问、
本品类特有的字段怎么填、复述里念哪几行。

## 必须聊清的六件事

1. **这家公司做什么**——一句话说清主营业务。听不懂就追问，
   ⛔ 不要拿「提供综合解决方案」这种话当答案。
2. **给谁看、在什么场合放**——客户洽谈 / 展会大屏 / 官网首页 / 招聘宣讲 / 投资路演。
   场合决定时长与画幅：**展会大屏通常静音循环**（照样要解说词，静音观众看的是台词字幕，
   台词字幕在「剪辑」页点「生成字幕」出），官网首屏 60 秒以内最好。
3. **最想让人记住哪三件事**——规模？技术？服务？历史？团队？
   逼用户排序，**只做前三个**，多了就都记不住。
4. **有什么可验证的事实**——成立年份、员工数、厂房面积、专利数、
   服务过的知名客户、认证资质、产能数字。
   ⚠️ **这一项是这类片子的生命线**：没有具体事实的宣传片就是一堆空话。
   用户给不出来就直说「没有具体数字的话，片子会显得很空，要不要先去要一份公司简介」。
5. **有没有实拍素材**——厂房、车间、办公区、团队、产品的真实照片或视频。
   有就让用户传上来（`ask_uploaded_asset_meta`），**真实素材永远优于生成画面**。
6. **多长**——材料里读得出（脚本时间轴 / 需求写明 / 用户说过）就直接用，完全没信息才 `ask_user_number`。完整版 2-3 分钟，展会循环 60-90 秒，
   社媒短版 30-60 秒。超过 3 分钟要提醒「客户很少看完，建议做长短两版」。
   **默认 60 秒**：用户放手时直接取它；要问时长时，它就是 `ask_user_number` 的 default。

## 顺带确认

- **品牌规范**：logo 文件、主色、标准字、slogan。
- **禁忌**：不能提的客户名、不能拍的区域、需要规避的表述。
- **联系方式**：结尾要不要放电话 / 官网。用户要放二维码时说清：二维码在成片里只是示意——视频模型会重画、扫不出来，
  要可扫的码，成片导出后用剪辑软件贴一张上去。

## 参数怎么收（先判三态，缺信息的才问）

每一项开口之前先看手上已经有什么——**用户给得越全，问得越少**：

1. **用户明说了，或材料里能直接读出** → **直接采用，不弹卡、不追问**。
   材料 = 用户的话、贴来的文案 / 脚本、上传的文档、发来的链接。
   范例：文案自带时间轴「0-3 秒 … 55-60 秒」= 60 秒；文档写明「30 秒」= 30 秒；文案标了语气 = 调性已定。
2. **能从上下文合理推断** → 采用、不弹卡，最终复述里这一项后面标「按你的材料推断」并写明依据
   （发抖音 / 视频号 / 小红书 → 竖屏；官网首屏 / 展会大屏 → 横屏）。
3. **完全没有信息** → 才问：
   - 离散字段弹卡：播放场合 / 时长 / 画幅 / 项目名候选
   - 开放内容纯文字：做什么、记住哪三件事、可验证的事实

- **视觉风格不做推断**：用户点名了风格就直接采用；没说就 `ask_user_choice` 传 `preset_pool='video_style'`
  （系统自动注入全部内置风格 + 自定义框，**不要自己列风格名**）。
  这类片子通常偏写实 / 商务质感，可以在 question 文字里点名推荐，但不要替用户删选项。
- ⛔ 不要因为某一项「是离散字段」就弹卡——材料里有答案的，答案就是答案，不是「默认值」，别让用户再点一次。

## 落库前：复述 → 确认

复述照主指令的共用模板走，本品类在〔品类字段〕那一格写这几行：

```
- 公司与业务: XXX          ← 做什么 + 给谁看
- 三个记忆点: ①XXX ②XXX ③XXX
- 支撑事实: XXX            ← 数字 / 资质 / 客户，逐条列
```

这些信息落在哪：**公司与业务、三个记忆点、支撑事实写进世界观**（`theme_prompt`，同一家公司各版本共用）；
**这一条怎么讲**写进这一条的剧情指令。
⛔ 播放场合只用来决定时长、显示方向和节奏，不进世界观、不进剧情指令，也不单列一行；
世界观和剧情指令里也不写画幅 / 横竖屏。

复述完**同一轮紧接着** `confirm_action`，确认后按主指令的落库方式调。

**这一次复述 + `confirm_action` 是整个流程唯一的一张确认卡**：采用的、推断的、用户选的字段全部并进它，
每项后面标来源（`按你的材料` / `按…推断` / `你选的` / `我起的`）；⛔ 不许先弹一张「确认默认值」再弹一张「确认创建」。
用户给的是成品脚本 / 文案、要求照它做时，复述里多一行「剧本：按你的原文转录（台词一个字不改）」。
`story_mode` / `finale_style` / `is_finale` 按 SKILL.md 直接填，不问、不复述。

## 再做一版

同项目下建下一条 = 换用途版本（展会版 / 招聘版 / 短版）。
只聊「这一版给谁看、要保留哪几个记忆点」+ 时长，其余沿用。
