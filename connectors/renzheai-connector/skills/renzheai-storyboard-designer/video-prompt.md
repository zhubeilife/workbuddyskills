# 视频提示词写作规范

> ⭐ **核心理念**：视频提示词是给**视频模型**看的**电影级完整画面描述 + 可听内容**，是本镜画面叙事的**源真相**。单镜内按剧本节拍拆成若干**镜头块**（shot 块），每块含 **镜头四要素**（运镜 + 主体动作 + 空间位置 + 音频）。
> ⭐ **分镜图基于视频提示词派生**：分镜图（用户按需产出）由「分镜图提示词」依据本镜视频提示词的画面描述生成。两者描述**同一份画面、禁止互相矛盾**。
> ⛔ **外观交给 @图片N 定妆照**：角色长什么样 / 穿什么由素材参考图承担，视频提示词写**动作 / 运镜 / 空间 / 表情节拍**，不复述外观服饰长相。

---

## ⭐⭐⭐ 产出形态：`video_segments` 是 VideoDoc 对象（结构化块流，不是文本）

你产出的是**语义字段**，排版与标记**一个都不写**——`镜头N：` 前缀、`<>`、`{}`、「说」后的空格、台词缩进、块间空行、`@图片N` 编号，全部由渲染器拼。写库时有语义 lint：正文手打 `{}` `<>` `@图片N` `镜头N：` 字面量会被打回并告诉你该写进哪个字段。

```
VideoDoc = {
  refs:   [引用段数组]        ← 声明区：@图片N / @音频N / 参考@视频N 的真源
  blocks: [块数组]            ← 正文块流，按叙事顺序排
}

块（block）两种：
  {kind:'text', negative:<布尔>, segs:[…]}      ← 自由文字块：镜头总纲 / 本段结尾画面 / 负向约束清单
  {kind:'shot', duration_sec:<秒>, beats:[…]}   ← 一个镜头块（渲染成「镜头N：」段，N 按块序自动算）

镜头块内的节拍（beat）三种，**顺序即事件顺序**（音效在台词前=先响、在后=后响）：
  {kind:'text', segs:[…]}                                            ← 画面描述（可内联 @图片N 绑定）
  {kind:'sfx',  text:'木门爆裂声'}                                    ← 一条音效（不带 <>）
  {kind:'line', block_id, speaker_name, speaker_ref, delivery,
   text, lang, continuity?, offscreen?}                               ← 一句台词
```

五条硬规则（lint 强制）：

1. **`duration_sec` 每个镜头块必填**——本镜头块持续几秒（正数）。⛔ **永远写「这一块几秒」，不写起止时间**（起止是渲染器按块序累加的推导值）。全部镜头块的 duration_sec 之和 ≈ 本镜 `total_sec`（容差 ±max(2秒, 20%)），超差会被打回。
2. **`block_id` 每句台词必填**——本句对应的剧本 dialogue 块 id，从本镜 `script_block_ids` 里选（拆镜时就是你填的那套 id）。它是配音链的对位键，渲染文本里不出现。唯一例外：手动镜（`script_block_ids` 为空）台词是自创的，省略 block_id。
3. **台词与音效只能是镜头块内的 beat**——text 块和画面描述里写台词 / 音效字面量会被 lint 打回。
4. **`lang` 每句台词必填**——这句台词的语言（`Chinese` / `English` / `Japanese` / `Korean` / `French` / `German` / `Italian` / `Spanish` / `Portuguese` / `Russian` / `Arabic` 闭集）。中文剧统一 `Chinese`；哪句是什么语种就标什么，逐句判断。
5. **`negative` 每个 text 块必填**——`true` = 这一块是负向约束清单（写「画面中不出现X / 禁止生成X」的块），`false` = 普通描述段（镜头总纲 / 结尾画面等）。显式给值，不省略。

## 文档构成（blocks 按此顺序排）

1. **`refs` 声明区**：各素材 image 段 + 说话人 voice 段（+ 换皮集 video 段）。排序与必挂条件见下方「引用声明区规范」。⛔ 不写分镜图段（`kind:'keyframe'`）——那一项由系统自动维护，不归你写。
2. **镜头总纲**（1 个 text 块，1 句）：内容类型 + 风格 + 色调 / 氛围 + 电影级运镜。⛔ 不写时长、不写画幅比例。
3. **各镜头块**（shot 块 × N）：每块 = duration_sec + 有序 beats（画面四要素 text beat → sfx beat → line beat，顺序按事件自然展开）。
4. **`本段结尾画面：[…]`**（1 个 text 块）——每镜都写（含末镜），内容与 `ending_frame_desc` 字段同步。本集末镜的结尾画面 = 下一集开头画面的参考；`>15 秒` 多镜集里还是下一镜承接依据（见下方「跨镜衔接规则」章节）。
5. **末尾兜底包**（2 个 text 块：质量包 `negative:false` + 负向约束包 `negative:true`）：按场景动态挂载，见下方「末尾兜底包」章节。

⛔ **铁律 1**：每镜都写「本段结尾画面」text 块。
⛔ **铁律 2（最常漏的坑）**：本镜有说话人（在场角色 / 画外声源）且素材清单里有对应音频素材 → **必挂 voice 段**。漏挂后果：派单不带参考音频 → 默认 TTS → 音色完全跑偏，等于浪费一次生成。判定流程见下方「@音频N 规则」。
⛔ **铁律 3**：**正文全篇禁任何秒数 / 时长表述**（`0-3秒` / `本镜约 N 秒` 等）——视频模型官方明文「对精确时间的支持不稳定」；时长信息只活在 `duration_sec` 字段里，你写的文字里不出现。

## ⭐ 镜头分镜法 ≠ 拆镜

| 概念 | 用法 | 工具 |
|---|---|---|
| **拆镜** | `duration_sec > 15` 时按贪心填段算法拆成多个 shot，每段独立视频提示词 | `begin_storyboard` → 逐镜 `insert_shot` |
| **镜头分镜法** | **单镜内**用多个 shot 块拆切镜节拍，全在**同一个** VideoDoc 里 | 单个 shot 的 blocks 里多个 shot 块 |

⛔ 看到剧本里有 3-4 个节拍 / 说话人换，**不要直接拆 3-4 镜**——先看 `duration_sec`：≤15 秒 → **1 镜**，节拍全用镜头块表达；>15 秒 → 才按贪心填段拆镜。

## 镜头块怎么分

- 按事件发生顺序组织，一个事件 / 节拍 / 情绪转折 = 一个镜头块，**不按 total_sec 机械映射**
- ⭐ **镜头块不设数量上限**：节拍多就多写——4、5、6、7… 块都正常。块多 = 单镜内切镜快、节奏强
- 每块的 `duration_sec` 按节拍内容估：一句台词 + 反应约 2-4 秒，纯氛围空镜 1-3 秒，总和 ≈ 本镜 `total_sec`
- 镜头块之间允许「沉默间隔」（中间块只有画面 + 音效不出台词）

## ⭐ 镜头四要素（每个镜头块必有，最高优先级）

官方推荐组织逻辑：「运镜或镜头切换方式 → 主体动作与表情 → 位置或空间变化 → 音频信息」。每块必须显式包含 4 类信息（顺序自由，按叙事自然展开）：

| # | 要素 | 写什么 | 落在哪 |
|---|---|---|---|
| 1 | **运镜或镜头切换** | 景别 + 运镜方式 | 画面 text beat："中景平稳跟拍" / "硬切特写" / "全景缓慢推近" |
| 2 | **主体动作 + 表情** | 肢体动作 + 情绪外化 | 画面 text beat：「角色名+图片绑定」+ 具体身体细节 |
| 3 | **位置 / 空间变化** | 主体在画面中的位置 / 移动路径 | 融入画面 text beat，回答"主体在画面什么位置？" |
| 4 | **音频信息** | 本块的音效 / 台词 | sfx beat / line beat（顺序即先后） |

**自检**：写完每块回查 4 类是否都有，缺一就补。
**纯特写定格 / 无主体移动**：空间要素用「画面正中」「中央定格」等位置词显式标注。
**纯音效块（无台词）**：仍写画面四要素 text beat 再接 sfx beat。
⛔ **不复述角色外观服饰长相**——要素 2 写**动作 + 表情**，不是长什么样。

### 镜头语言词汇库（写画面 beat 时挑词）

| 类别 | 关键词 |
|---|---|
| **景别** | 大远景 / 远景 / 全景 / 中景 / 近景 / 特写 / 大特写 |
| **运镜** | 推镜头 / 拉镜头 / 摇镜头 / 移镜头 / 跟拍 / 环绕拍摄 / 航拍 / 手持跟拍 / 希区柯克变焦 |
| **角度** | 平视 / 俯拍 / 仰拍 / 低角度 / 鸟瞰视角 / 鱼眼镜头 / 第一人称视角 / 主观视角 |
| **节奏** | 慢动作 / 快切 / 延时摄影 / 一镜到底 / 升格拍摄 / 硬切 / 卡点 / 定格慢放 |
| **焦点** | 浅景深 / 深景深 / 焦点转移 / 虚化背景 / 选择性对焦 |
| **特殊** | 遮挡擦镜转场 / 无缝渐变转场 / 环绕摇镜快切特写 |

⛔ **一镜一运镜**（官方：单个镜头只指定 1 种运镜，叠加会增加不稳定）：一个镜头块只指定 1 种运镜。
⛔ **相邻镜头块运镜不重复**：形成快慢 / 高低 / 景别对比。

> **换皮集补充**（仅换皮集且本镜成功调了 `trigger_reference_video`）：refs 里挂 video 段（渲染成 `参考@视频1的运镜、景别、动作节奏。`）——它是引用指针不是画面描述。详见下方「@视频N 规则」。


## ⭐ 视频模型拍得稳的写法（每个镜头块都照这五条）

视频模型擅长的是「一个清楚的主体、做一件清楚的事」，写得越贪心越容易拍崩。快慢、切得勤不勤由品类细则定，这五条与快慢无关：

1. **一个镜头块只做一个主要动作**：先看到人，再看到他拿起杯子，再看到他喝——一个节拍里要发生三件事就拆成三块，别塞进同一块。
2. **主体够大、一眼找得到**：主体与关键物在画面里占得住，别缩在角落、别被前景挡住；远景交代一次「在哪」就够，戏放在中景、近景。
3. **背景简单，不堆杂物**：画面里只放这一块需要的东西。场景本身就要热闹（集市、宴会、发布会）时，热闹放在背景，主体前面留出空间。
4. **表情、动作写清楚**：关键情绪要有一个看得见的动作或明确的表情托底，不只靠细微的眼神变化传达——模型拍不准，观众在手机上也看不清。
5. **不闪烁、不频闪**：⛔ 不写强光爆闪、频闪灯、大面积快速变色——画面会抖花，看着也难受。

## ⭐ 动作描述要求（要素 2 写到位）

### 1. 肢体细化 + 程度量化
动作具体到**手 / 腿 / 头 / 肩背**等部位，并补**幅度 / 速度 / 力度**：
- ❌ 笼统：「他生气地走过来」
- ✅ 细化量化：「他**用力**蹬地、**大步**跨过来，右手**猛地**拍上桌面」

### 2. 动作过渡衔接
写明**相邻镜头块之间**的状态承接：上一块收在什么状态，这一块就从那个状态接着动（「借着转身的惯性顺势抬手」）。镜头块内部只写已经在动作中的状态，不写慢过渡（见下方「写状态，不写过程」）。

### 3. 情绪具象外化（替代抽象情绪词）
⛔ 不写「很悲伤」「非常愤怒」——用**具体身体细节**把情绪演出来：

| 抽象情绪 | 外化为动作 / 细节 |
|---|---|
| 悲伤 | 低头、肩膀微微颤抖、眼眶泛红、手指无意识攥紧衣角、泪在眼眶打转没落下 |
| 喜悦 | 嘴角抑制不住上扬、眉眼舒展、脚步轻快、下意识哼起小曲 |
| 紧张 / 焦虑 | 频繁看向门口、手指敲击、呼吸急促、眼神闪躲、啃咬指甲 |
| 愤怒 | 双拳紧握、下颌线紧绷、胸口剧烈起伏、眼神如刀、从牙缝挤出话 |
| 释然 | 长舒一口气、紧绷的肩膀放松、露出淡淡微笑、抬头望向远方 |

## ⭐ 主体定义与引用

官方原句：「每次涉及主体时需明确指代，避免省略」。主体身份只在 refs 声明区写一次（`desc:'是<素材标题>。'`），正文靠内联绑定指代。

### 画面描述里的主体绑定（text beat 的 segs 混排）

正文**每次**主体出现都必须绑定素材引用，**禁止裸用角色名**。写法：text beat 的 `segs` 里，角色名 text 段后面紧跟一个 image 段（`ref` = 该角色 asset_id、`desc` 空），再接**以空格开头**的后续文字：

```json
{"kind":"text","segs":[
  {"type":"text","value":"硬切中景，王大牙"},
  {"type":"image","ref":"char-wangdaya"},
  {"type":"text","value":" 一脚踹开木门、大步跨入站到画面中间门前"}
]}
```

渲染成 `王大牙@图片3 一脚踹开木门…`（编号自动复用声明区的号）。空格是断句防歧义（`@图片N` 后不能紧接动词）。同一镜头块内同一角色每次出现都重新绑定，不省略。

### 台词的说话人绑定（line beat 字段承担）

台词**不用**内联绑定——`speaker_name` + `speaker_ref` 字段就是绑定：渲染器自动拼成 `王大牙@图片3 粗哑咆哮地说 {…}`。`speaker_ref` = 说话角色的 asset_id；画外声源（无在场角色）= `null`（渲染时不出 @图片N）。

## 引用声明区规范（refs）——编号由渲染器按顺序派

⛔ **绝对禁止**编造 asset_id、引用素材清单里不存在的素材、手写 `@图片N` / `@素材N` / `@img1` 等字面量。编号规则：image / voice / video **各自独立计数**，按启用段顺序从 1 派号；同一 asset_id 多处出现复用同一个号。

### @图片N 规则

- 素材 image 段 `{type:'image',ref:'<asset_id>',desc:'是<素材标题>。'}`；`<素材标题>` 照搬素材清单 `title` 原文。编号不归你写——渲染层按 refs 里的排列顺序依次派号
- ⛔ **每个 image 段都必须带 `ref`**（素材清单里会出图的素材的 asset_id：角色 / 场景 / 道具 / 特殊视觉），没有 `ref` 的 image 段会被写入校验打回
- ⛔ **refs 里不写分镜图段**（`kind:'keyframe'`）：本镜有了分镜图提示词或分镜图之后，系统自动把分镜图那一项放到引用列表首项（补进去就是启用的——用户要了分镜图就是要拿它当参考，他可以在依赖面板关掉；它排在全部素材之前，编号由渲染层按顺序重算）
- ⭐ **重要素材前置**（官方：越需要精准参考的越靠前）：按类型优先级 **character > scene > prop > special** 排，同类型内主角 > 配角、主场景 > 副场景

### @音频N 规则（⛔ 必填条件，不是可选）

voice 段 `{type:'voice',ref:'<音频素材 asset_id>',desc:'是<音频素材标题>的音色参考。'}`。`ref` 指向**独立音频素材**：在场角色的音色是命名 `<角色>-音色`、`speaker_asset_id` 指向该角色的 `type='audio'` 素材；画外声源（画外解说员 / 播音员 / 旁白）是 `speaker_asset_id` 为空的独立画外音频素材。

**判定流程**：
1. 取拆镜时写入的 `dialogue_speakers` 数组（顺序 = 本镜首次说话顺序）
2. 顺序遍历，给每个说话人找对应音频素材：在场角色找它的 `<角色>-音色`；画外声源本身就是那条画外音频素材
3. 找得到 → 挂一条 voice 段；找不到（群体说话人 / 群众甲乙类）→ 跳过，不要为它现编一条
4. 上限 3 条（视频模型参考音频上限）；同一说话人多次说话只占 1 条；超 3 个说话人只取前 3 个有素材的
5. ⛔ 一致性：voice 段顺序 = `dialogue_speakers` 顺序、数量 ≤ 它的数量

### @视频N 规则（⭐ 仅换皮重制集，`film_breakdown_id` 非空时）

本镜成功调了 `trigger_reference_video` 后，对本镜调 `update_video_prompt`，refs 里放**一个** video 段 `{type:'video',desc:'的运镜、景别、动作节奏。'}`（渲染成 `参考@视频1的运镜、景别、动作节奏。`，「参考」前缀由渲染器拼；`enabled` 省略，默认禁用、用户按需开启）。随 `insert_shot` 写的那一版参考视频还没截取，不写 video 段；工具没调成功 / 非换皮集 → 不写 video 段。

## 台词写法（line beat）

| 字段 | 写什么 |
|---|---|
| `block_id` | 本句对应的剧本 dialogue 块 id（∈ 本镜 `script_block_ids`）。手动镜（自创台词）省略 |
| `speaker_name` | 说话人名字。**有角色素材的一律照抄素材清单里的 `title` 原文**（素材叫「阿桃-药堂伙计」就写「阿桃-药堂伙计」，别自己简称成「阿桃」）——全链路一个角色只有一个名字，用户在分镜页换说话人时选的也是这个名字；没有素材的画外声源 / 群体按下方规则写声源名 |
| `speaker_ref` | **只能填 character 素材的 asset_id，或 `null`**。它的作用是往提示词里插一个 `@图片N` 告诉模型「这个说话人长这样」——所以没有画面形象的说话人（纯画外声源 / 群体）一律 `null`。⛔ **绝不填 audio 素材的 asset_id**（详见本表下方「speaker_ref 与 dialogue_speakers 值域不同」） |
| `delivery` | **含引导动词的全短语**：「压着火地说」「粗哑咆哮地说」「怒吼道」「喃喃道」——从 dialogue 块的 `emotion` 派生（emotion=`粗哑咆哮` → `粗哑咆哮地说`），TTS 语气靠它。引导动词是开集，贴合语境选。⛔ 只写这一句怎么念，不写整个项目的口音 / 腔调 / 录音质感 |
| `text` | 台词正文，剧本 dialogue 块 `text` **原文一字不动**（不带 `{}`、不带引号、保留语种标点）。唯一例外：手动镜台词按用户诉求自行设计 |
| `lang` | **必填**，这句台词的语言（闭集见上方硬规则 4）。中文台词 `Chinese`，逐句判断 |
| `continuity` | **可选**，仅一个值 `cutoff`：这句话被视频结尾**故意切断**（片尾钩子：「其实我早就知道——」戛然而止）。只能标在最后一个镜头块的最后一句台词上（lint 强制）。普通台词不写此字段 |
| `offscreen` | **可选** `true`：**有形象的角色**在画面外说这句话（人不在画框内 / 不开口，声音在）。旁白不用它——旁白没有角色形象，用 `speaker_ref: null` 表达 |

- 小语种台词：`text` 写该语种**原文**（日语台词写日文，不写中文再标日语）、`lang` 标对应语言；`delivery` 恒中文、只写语气（如 `轻声说`）。⛔ delivery 里不写「用日语」这类语种提示——语言唯一真源是 `lang`，语种提示由渲染层派生拼接
- ⛔ 一句台词内语言统一、避免中英混用（专有名词 / 品牌名除外）——中英夹杂配音容易读崩
- ⛔ `text` 里不能内嵌任何引用或标记（lint 打回）——全句唯一引用位是 `speaker_ref`

**内心 OS / 画外音 VO**：元信息放 delivery，纯台词放 text：

| 类型 | 写法 |
|---|---|
| 对白 | delivery=`低声说`，speaker_ref=角色 |
| 内心 OS | delivery=`内心独白说`，speaker_ref=角色 |
| 画外音 VO | speaker_name=`画外旁白`（照抄那条音频素材的名字），delivery=`说`，纯画外声源 speaker_ref=`null`；说话人是有形象的角色时 speaker_ref 填该角色、标 `offscreen:true` |

**声源归属**（决定 voice 段 `ref` + `dialogue_speakers` 填什么）：对白 / 内心 OS 是在场角色自己的声音——voice 段挂该角色的 `<角色>-音色`、dialogue_speakers 填角色 asset_id。画外音 VO：说话人有在场角色素材 → 按在场角色处理；纯画外声源 → voice 段挂独立画外音频素材、dialogue_speakers 填该音频素材 asset_id 当伪 speaker。群体说话人（看客群 / 众人 / 围观百姓）→ 没有音色素材可挂，不写 voice 段，dialogue_speakers 也不填它。

### ⛔ `speaker_ref` 与 `dialogue_speakers` 值域不同，不要互相套用

两个字段都叫「说话人」，但**做的事完全不同**，audio 素材 asset_id 只有后者收：

| | 填什么 | 干什么用 |
|---|---|---|
| line beat 的 `speaker_ref` | **只有 character 素材 asset_id 或 `null`** | 渲染成 `@图片N`，给模型看**这个人长什么样** |
| shot 的 `dialogue_speakers` | 角色 asset_id；纯画外声源填它那条 audio 素材 asset_id 当**伪 speaker** | 语速统计 / 台词归属 / voice 段排序依据，**不进画面** |

把 audio 素材填进 `speaker_ref` 会被写入校验打回（`INVALID_SEGMENT_REFS`，报错点名是哪一句台词）：渲染器把 `speaker_ref` 当画面引用渲成 `@图片N`，派单要去取那条素材的参考图，而音色素材永远没有图。`speaker_ref` 填空字符串同样会被打回——没有画面形象就是 `null`。

画外声源与群体的正确写法：`speaker_ref: null` + `speaker_name` 写声源名（「画外旁白」「看客群」）。画外声源的音色由配音链路按 `speaker_name` 与音色素材名互含匹配接上（「画外旁白」↔「画外旁白-音色」），**所以 `speaker_name` 要与素材清单里那条 audio 的名字对得上**；群体没有音色素材，声音由视频模型按台词自己演。

## 音效写法（sfx beat）

- 一条音效一个 sfx beat，`text` 只写内容本身（`木门爆裂声`），⛔ 不带 `<>`（渲染器补；带了 lint 打回）
- 放的位置 = 它响的时刻：画面 beat 之后、台词 beat 之前 / 之后——**beat 顺序就是时间顺序**
- **音效从剧本 action 块（`△` 动作）推导**（「门被踹开」→ `木门爆裂声`），与画面动作呼应——action 块在视频提示词里唯一的声音存在形式
- ⛔ **禁写任何 BGM / 背景音乐**——每镜独立生成、跨镜 BGM 无法衔接，音乐由后期挂全局轨；末尾兜底包已主动拦截模型自动配乐

## 画面内文字 —— 视频模型不写字，字只来自素材图

视频模型画不出可读的字：让它照一句描述去写中文，出来的多半是乱码，这一条视频整条作废。所以
**video_prompt 里没有任何一句话是在让模型写字**，画面上的字只有一个来源——素材清单里的**文字素材图**
（`type='special'`，时间卡 / 片名 / slogan / 联系方式卡 / 企业名墙 / logo 这类）。

**默认**：画面里不出任何文字（末尾兜底包「禁止生成任何文字或字幕」拦掉）。

**⛔ 台词不上画面**：解说员 / 角色说的话只进 line beat，不许再以「画面下方浮出说明文字」「屏幕打出这句话」的
形式重复一遍——跟读台词的字幕由后期剪辑配，永远不进 video_prompt。

**唯一例外：本镜引用了文字素材**（剧本 `action` 块写了它怎么出现，素材清单里有同名的图）。此时仅该镜：

1. refs 声明区照常挂这张图的 image 段（按类型优先级排在 special 位，`desc` 照搬素材 `title`）。
2. **只写这张图怎么出现，不复述图上的字**：画面 text beat 里用内联 image 绑定段引用它，写它在画面哪里、
   什么时候、怎么进怎么出、停多久，并写明「保持参考图原样，不变形、不重绘、不增减文字」。
   ⛔ 不写字的内容、字体、字色——图上都有；prompt 里一出现引号包住的那几个字，模型就会自己动手写。

   ```json
   {"kind":"text","segs":[
     {"type":"text","value":"黑场，画面中央 转场时间卡"},
     {"type":"image","ref":"special-transition-timecard"},
     {"type":"text","value":" 由虚到实淡入，保持参考图原样、不变形不重绘不增减文字，停留至镜头结束。"}
   ]}
   ```

   - ❌ `画面中央浮现白色文字「三天后」，简体无衬线、居中、由浅到清晰淡入。`（在让模型写字）
3. **负向约束包第一句换成带引用的版本**，同样用内联 image 绑定段（⛔ 不手打编号），其余句子不变：

   ```json
   {"kind":"text","negative":true,"segs":[
     {"type":"text","value":"除 转场时间卡"},
     {"type":"image","ref":"special-transition-timecard"},
     {"type":"text","value":" 所示画面外，禁止生成任何其它文字或字幕。不要生成Logo，不要生成水印。禁止生成任何背景音乐。"}
   ]}
   ```

   本镜引用了两张文字素材就两张都写进「除 … 外」里。
   引用的素材里有 logo 时，后面那句「不要生成Logo」改成「不要生成其它Logo」——否则同一段里一边引用 logo 图、一边禁止 logo，自相矛盾。

**⛔ 清单里有这张图、剧本写了它出现 → 必须引用，不许留给「后期」。** 文字素材不是后期加的字——它是一张参考图，
要由视频模型在这一镜里放进画面；你不引用，成片里就没有它。素材的 `summary` / 说明里哪怕写着「后期呈现」「后期叠加」
也照引不误（后期字幕轨只出台词字幕，出不了这张图）。图还没生成不是不引用的理由——那是派单前用户去素材页点生成的事。

**⛔ 剧本要字、素材清单里没有对应的图 → 这段字不上画面。** 剧本 `action` 块写了「字幕打出：…」
「画面浮现文字…」「时间卡…」，而 `get_project_materials` 里找不到对应的文字素材时：

- 该镜照常拍，画面只写场景与动作，负向约束包照常用默认那句；这个 `action` 块照常计入 `script_block_ids`
  （覆盖校验要它），只是不把字写出来。
- ⛔ 不退回去用文字描述让模型写字，不自己脑补一张字卡，不改剧本，不建素材。
- **summary 里点名**：「第 3、5 镜剧本要求出现画面文字（『三天后』『这些，都算信息安全』），素材清单里没有
  对应的图，未上画面；需要的话先在素材页补一条文字素材」——由调用方转告用户。
- 屏幕、纸张、招牌这类场景里的道具同理：写它在那、亮着、被翻动，⛔ 不写上面有什么字。

## ⭐ 末尾兜底包（最后两个 text 块，按场景动态挂载）

视频模型的固定 bug（双胞胎 / 字幕乱蹦 / 水印 / 画质糊 / 脸崩 / 风格漂移）用兜底句防御。兜底包按句子性质拆成**两个 text 块**：

### 质量包（`negative: false`，正向质量描述）

```
镜头稳定。高清，细节丰富，电影质感。
```

按条件加句：

| 加句 | 触发 | 挂句 |
|---|---|---|
| 稳定包 | refs 含 character 素材（画面有人物） | `人物面部和身体比例稳定不变形，动作连贯自然，不僵硬，无穿模无卡顿。` |
| 风格锚定 | `video_style_desc` 非空且非纯写实 | 从配方提炼 1 句凝练锚定（镜头+质感+调性关键词）；配方为空退回 `video_style` 裸标签判断，纯写实不挂 |

### 负向约束包（`negative: true`，禁止类句子，所有镜必挂）

```
禁止生成任何文字或字幕。不要生成Logo，不要生成水印。禁止生成任何背景音乐。
```

⛔ **「禁止生成任何文字或字幕」这句是防字幕事故的关键防线，必须覆盖**（本镜引用了文字素材图时，按「画面内文字」章节换成「除 <文字素材> 所示画面外，禁止生成任何其它文字或字幕」那一句，仍然覆盖）。按条件加句：

| 加句 | 触发 | 挂句 |
|---|---|---|
| 双胞胎兜底 | 画面明确出现 ≥2 个可辨识人物（含路人群组） | `视频全程禁止出现外形、着装、配饰完全一致的人物，禁止生成同款分身、双胞胎效果，同一画面中仅保留单个对应人物，不出现人物重复复刻。`（官方原句 100% 照搬） |

两个块都是块内单换行分句（块内换行是内容，你自己写）。⛔ 禁止类句子只进负向约束包，不混进质量包或其它描述块。

## ⛔ 禁写清单

| 禁写 | 原因 |
|---|---|
| 正文手打 `{}` `<>` `@图片N` `镜头N：` 字面量 | 标记归渲染器；lint 打回并指路该写进哪个字段 |
| 「将@视频1延长Xs」/「接续上段画面」等跨片续接句 | 每镜独立生成，衔接靠本镜首个镜头块选对景别 / 机位（见「跨镜衔接规则」章节） |
| 非换皮集写 video 段 | 只有换皮集有参考视频 clip |
| 「版本一 / 版本二」「另一版本」 | 每镜只产 1 版 |
| 画幅 / 比例 / 横竖屏 / 帧率（「9:16竖屏」「2.35:1宽银幕，24fps」） | 派单参数决定 |
| 分辨率 / 画质规格（8K / 4K / 超清） | 派单参数决定 |
| 「@图片N为首帧」 | 参考图是外观 / 剧情参考，不是首帧 |
| 正文任何秒数 / 时长表述 | 时长只活在 `duration_sec` 字段；官方明文时间理解不稳定 |
| 画面描述裸用角色名（无 image 绑定段） | 必须内联绑定（见「主体定义与引用」） |
| 任何 BGM / 背景音乐描述 | 跨镜无法衔接，后期挂全局轨 |
| 角色服饰 / 外观 / 定妆 / 长相 | 外观由 @图片N 定妆照承担；写动作 / 表情可以 |
