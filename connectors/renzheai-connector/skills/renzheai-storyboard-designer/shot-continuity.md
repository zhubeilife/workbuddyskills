# 跨镜衔接规则（`>15 秒` 多镜集专用）

> 适用范围：**仅 `duration_sec > 15` 拆成多个独立 shot 的集**。`≤15 秒` 必 1 镜的集没有「上下镜」之分，本章不涉及。
> 物理前提：每个 shot **独立生成**（视频不接续上一片），合并时硬切。上一镜结尾与下一镜开头之间没有像素级连续——衔接的连贯感**只能靠镜头语言设计**做出来，不靠模型自动延续。

相邻两镜（shot N → shot N+1）的切换若没有镜头语言逻辑，观众会感到「割裂 / 跳切」。下面四条法则把割裂消解成「有意的切镜」。**这是分镜师跨镜设计的核心职责，每个 `>15 秒` 多镜集都要落。**

## 法则 1：上一镜结尾驱动下一镜开头

写 shot N+1 的 video_prompt 前，**先读 shot N 的 `ending_frame_desc`**（上一镜已随它那次 `insert_shot` 入库，`get_storyboard` 即可拿到；同一轮里你手上也有刚写过的那份）。N+1 **镜头1**（开头镜头）的机位 / 景别 / 主体方位都要**针对 N 的结尾状态**来定，而不是孤立地从剧本重新起一个画面。

- 承接体现在 N+1 镜头1 **选的景别 + 机位**上：上镜结束于中景、主体在画面右侧朝左 → 本镜镜头1 就写「特写，机位绕到左前方约 45°，主体仍在画面右侧」。
- ⛔ **不要在 video_prompt 里写「承接上镜 / 上镜结束于 X」这种喂给 Seedance 的跨片续接句**——每镜独立生成、没有上一片像素可接，写了模型也接不上。承接是**设计决策**（镜头1 选对景别 / 机位），不是写给模型的文字。
- keyframe 从 video_prompt 派生、自然继承这份承接，不必再单独做一套衔接设计。

## 法则 2：相邻镜必跨景别

shot N 的**末项景别** 与 shot N+1 的**首项景别** **必须跳变 ≥1 级**。景别梯度：

```
远景 → 全景 → 中景 → 近景 → 特写
```

- ❌ 中景 → 中景、近景 → 近景：相邻同景别 = 观众感到「卡顿了一下」，而非换了视角
- ⚠️ 中景 → 近景：仅差 1 级且方向连续，跨度偏小——优先**跨 1 级以上**
- ✅ 中景 → 特写、全景 → 中景、特写 → 全景

景别由**分镜师有最终话语权**（见上方「cameraWork 规则」章节）——剧本的景别括号是参考起点，为衔接可调整 shot 边界的首末景别。

## 法则 3：不越轴（轴线一致）

同一场戏内，相邻镜要保持主体的**银幕方位**与**视线 / 身体朝向**一致，不要让主体在切换瞬间左右翻面（越轴 = 最强的割裂感）。

- 上一镜主体在画面左侧、面朝右 → 下一镜主体仍应在左侧、仍朝右（机位可绕，但不跨过两个主体连线那条「轴线」到对侧）
- 两人对话：A 在左看右、B 在右看左，这组**银幕方位关系跨镜锁死**，每一镜都遵守
- `ending_frame_desc` 的「银幕方位 / 视线朝向」两项就是判断越没越轴的依据——所以那两项必须写准

## 法则 4：`>30°` 机位夹角

连续两镜拍同一主体时，机位绕主体的水平夹角 **必须 `> 30°`**。

- 夹角 `≤ 30°` → 观众觉得画面只是「卡了一下」，不像换了视角（与法则 2 同源，一个管景别一个管角度，配合用）
- 在 N+1 video_prompt 镜头1 的机位上体现：相机位置相对 N 结尾机位绕主体 `> 30°`，但**不越法则 3 的轴线**

## 自检（每个非首镜的 video_prompt 写完后过一遍）

- [ ] 已读上一镜 `ending_frame_desc`，本镜镜头1 的景别 / 机位据此承接（法则 1）
- [ ] 相邻镜首末景别跳变 ≥1 级（法则 2）
- [ ] 主体银幕方位 / 视线朝向跨镜一致，没越轴（法则 3）
- [ ] 机位夹角 `> 30°`（法则 4）

任一不过 → 调整 video_prompt 镜头1 的景别 / 机位再写。keyframe 派生时自然继承。
