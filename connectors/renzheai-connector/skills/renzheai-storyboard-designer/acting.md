# 表演写作规范（video prompt 的「戏」层）

> ⭐ **核心公理：表演是压力下的行为，不是情绪展示。** 角色**要**一样东西（对着某人的动词：逼他认账 / 求她留下 / 让全场相信我不怕），有东西**拦着**（对方要的相反 / 第三者在场 / 自己拉不下脸），于是他**做**——情绪只是这场争取的副产品，永远不直接写。上方「动作描述要求」章节的情绪具象外化表解决「情绪词怎么翻译成身体细节」；本章解决更上游的问题：**这些身体细节从哪来**——从目标、障碍、策略里来。
> 本章的落点：镜头块画面 text beat 里**要素 2（主体动作 + 表情）怎么写出戏**，以及 **line beat `delivery` 的取向**。外观 / 机位 / 光线不归本章管。

## ⭐ 写之前答三问（每个有人物的镜头块）

1. **他此刻要什么？**——动词 + 指向具体对象：「逼苏衡认账」「让王大牙先动手」。⛔ 不是状态——「很愤怒」「很委屈」没法演
2. **什么拦着他？**——对方要的相反 / 在场的第三者 / 自己的脸面
3. **这一块他用什么招？**——策略动词：逼、哄、激、求、拖、吓、换筹码

三问答不出，写出来的就是摆拍：人物站在正确的位置做正确的动作，画面里却没有戏。

## ⭐ 节拍 = 镜头块：换块必换招

镜头块的切分口径（一个事件 / 节拍 / 情绪转折 = 一块）同时就是表演节拍。两条硬要求：

- **换块处表演必须有可见变化**：一次停顿 / 姿态变 / 速度变 / 视线转移——至少一样。上一块还在逼、这一块开始哄，先让身体变（松开揪着的衣领、放缓动作）观众才看得到「换招」
- **一个劲儿到底 = 拍平**：整镜全程咆哮 / 全程哭 / 全程冷笑，等于只有一个节拍。一招不奏效，活人会**换招**

## ⭐ 倾听与反应（对白镜的质量线）

戏不在台词里，在台词**之间**。对白镜头块除了「谁在说」，必须写「谁在听、听成什么样」：

| 要求 | 写法 |
|---|---|
| **反应先于台词结束** | 说话人 line beat 的同块 / 相邻块里给听者一笔反应——话说到一半，对方脸上已经有答案。⛔ 听者空脸等对方说完才「开机」= 死戏 |
| **想了才说** | 重要问话之后，回答者先有一个可见的「决定瞬间」——视线移开一瞬 / 喉结滚动 / 呼吸一顿——再开口。不假思索立刻接话 = 背词 |
| **评估瞬间** | 重大信息落地（噩耗 / 威胁 / 羞辱）后给消化时间：一个近景的怔住 / 眼神失焦。最值钱的画面往往是「看到事件的那张脸」 |

## 身体四参数 + 手头事务

**四参数**——给主要人物先定物理状态，身体比心理先讲故事：

| 参数 | 两极 |
|---|---|
| 重心 | 高（挺胸抬下巴——自信 / 攻击性 / 高位）↔ 低（塌肩含背——疲惫 / 恐惧 / 屈从） |
| 速度 | 快而碎（紧张 / 心虚）↔ 慢而省（控制 / 威胁——最危险的人动得最少） |
| 开合 | 敞开（方肩摊掌）↔ 闭合（抱臂 / 缩脖 / 侧身避开） |
| 呼吸 | 浅快（慌）↔ 深慢（稳）。刚跑完的人不可能平稳说话——声音必须贴身体状态 |

**手头事务**：剧本给了角色正在做的事（擦碗 / 数钱 / 磨刀 / 缝补），就把台词压在事务上说——手上有真事干，假戏就少；剧本没写的事务与道具不要自己加。**中断即标点**：正在做的事在某句话上突然停住（数钱的手停在半空），那句话就成了事件。

**距离即戏**：人物间的距离变化就是关系变化——写清**谁向谁逼近、停在多近、谁退开、谁僵住**。贴到脸前压低声音，比隔屋咆哮吓人。距离变化放在换块处（距离变 = 节拍变）。

**地位写进身体**：高位 = 头稳、动作少、敢停顿、占空间、随手动别人的东西；低位 = 小动作多、频繁摸脸理发、说话破碎、眼神请示。**地位反转是最强的镜头**：老板露怯的那一秒、下属突然收起笑的那一秒。

## ⭐ 眼神生命（治「死鱼眼」——AI 生成感的头号来源）

在「四要素表情 / ending_frame_desc 视线朝向」之上，每个有人物的镜头块至少写一次**具体的眼神行为**：

- **视线有目标且会动**：扫向门口 / 落回对方脸上 / 瞟一眼桌上的银子又收回——⛔ 禁止全程死盯一点
- **眨眼质感贴状态**：紧张 = 快而碎地眨；掌控 = 少而慢——那是选择，不是冻结
- **眼先于头**：视线先到目标，头再跟上——念头从眼睛里先出来，话才跟上
- 节拍变，眼神跟着变：换块处最省的表演变化就是一次视线转移

## ⭐ 写状态，不写过程

视频模型接得住「状态」、接不住「连续过程」：「从怀里掏出匕首、举过头顶、狠狠挥下」这类三连动作链容易崩——写**已经在动作中**的状态：「匕首挥落到一半」「箭步冲出半途」「僵在门口、一只脚还在门槛外」。节拍之间靠镜头块硬切状态，不写慢过渡。

## delivery 的表演口径（line beat）

- delivery 一律从剧本 emotion 派生（见上方「台词写法」章节）

## 群像（画面 ≥2 人时）

- **反应错峰成波浪**：一个先笑、第二个慢半拍、第三个没懂——⛔ 全场同步同款反应一眼假（双胞胎兜底管长相，这条管行为）
- **威胁时刻全场静止**：常态下群像保持微动（换重心 / 交换眼神 / 小声嘀咕），关键威胁一落，**全停**——喧闹到静止的反差就是标点
- **强者静、弱者躁**：最危险的人动作最少；危险感写在**周围人**的紧绷上，不写在危险者的张牙舞爪上。⛔ 剧本没写的暴力预告（狞笑 / 慢转身 / 停顿蓄力）不要自己加
- **移动要有动机**：没人无缘无故横穿画面——写成「朝什么去 / 躲什么开」：逼近（施压）、转身背对（拒绝）、起身站着（夺权）、冲突中反而坐下（更高压）、停在门口（决定瞬间）

## ⛔ 烂表演速查（写完对着修）

| 症状 | 画面里的样子 | 修法 |
|---|---|---|
| 表情演情绪 | 挑眉 / 咧嘴 / 五官用力「摆」情绪 | 删掉你自己加的表情指令（剧本写的照写），写目标 |
| 等台词 | 对方说话时听者空脸，说完才「开机」 | 台词进行中就写听者反应 |
| 一个调到底 | 全程咆哮 / 全程哭 | 换块换招 |
| 手势图解台词 | 说「这么大」双臂张开 | 手势要么先于话、要么与话相反、要么没有 |
| 无来由爆发 | 上一块还平静，这一块嚎啕 | 先铺克制，爆发要有触发事件那一笔 |
| 瞬间恢复 | 强事件后下一块像没事人 | 下一块带余波：手还在抖 / 声音还哑 |
| 越近景越用力 | 特写里五官大幅表演 | 景别越近动作越少——特写只留眼神和一个念头 |
| 死鱼眼 | 直勾勾盯死一点、不眨眼、无神 | 「眼神生命」全套 |

## 表演自检（并入写入前自检）

- 每个有人物的镜头块答得出三问（要什么 / 什么拦着 / 用什么招）
- 换块处有可见的表演变化
- 对白块写了听者；重要回答前有「决定瞬间」
- 每个有人物的镜头块至少一次具体眼神行为，无全程死盯
- 情绪零抽象词、全部外化（上方「动作描述要求」章节的外化表）
- 群像错峰反应；威胁点全场静；强者静、弱者躁
- 只有状态，没有三连动作链
