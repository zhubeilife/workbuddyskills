# 分镜图提示词写作规范（黑白炭笔手稿版）

每个分镜的 `keyframe_prompt` 字段是一份**黑白分镜速写手稿**（Storyboard Rough / 故事板手稿）的图像生成提示词，给文生图模型用来产出该分镜的**分镜图**——一张满版宫格的黑白速写分镜预览，每个 panel 是一格**松散、快速、gestural 的单色铅笔速写**小画面：**角色画成简化通用的"替身速写"**（传达性别/身材/年龄/角色定位 + 姿态 + 动作 + 表情情绪，但**不复刻五官、不追求像某个具体人**），**场景 / 道具按 @图片N 参考图画成可辨识的样子**（校门口、话筒该是什么样还是什么样）。整张画面是黑白的，**只在标注层用红 / 蓝箭头 + 绿 / 橙文字**做调度标记。

⭐ **本版定位 = 镜头调度速写，不是成片预览**：分镜图的职责是把**机位 / 景别 / 走位 / 动作 / 节拍 / 情绪**传清楚，**不是**把角色长相画得跟参考图一模一样。角色身份由视频派单时的角色参考图（视频提示词里的角色素材图）承担——分镜图里的人只是占位替身，画太像反而会让视频模型直接抄分镜图的脸、而不是用真实角色参考图。所以角色一律**松散通用、点到为止**。

**为什么场景 / 道具仍要按参考图画**：分镜图是视频生成的剧情参考图——它默认随视频提示词一起送进视频模型，被参考空间结构与道具位置。场景 / 道具画成可辨识的真实样子（按 @图片N），能把空间基底和关键道具锁准；**但角色不同——角色要的是"画面里有个什么样的人在做什么"，不是"这个人是谁"**，所以角色只借参考图的大致类型，画通用替身。

**为什么这里可以画彩色箭头（彩色版禁止、本版允许）**：整张图是明显的**黑白炭笔手稿 / 导演故事板**，视频模型会把它识别为「设计稿 / 调度参考」而不是「成片画面」，因此叠在上面的红 / 蓝箭头、绿 / 橙文字会被当作分镜标注读取，**不会被渲染进成片**（成片仍按 video_prompt 出彩色、无箭头）。这跟彩色写实分镜的处理逻辑相反——彩色写实图上画箭头会被当画面元素污染成片，所以彩色版禁止；黑白手稿版反过来要求用箭头表达动作 / 运镜。

**整张图就是满版的分镜 panel 宫格**：所有信息都写进每个 panel 里，每格自洽地表达「这一拍」的画面、人物动作、机位、视线、运镜；运镜靠 panel **序列递进**自然带出（②推近 → ③更近）。panel 越多 = 给视频模型的参考帧越多。

## 术语

| 术语 | 含义 |
|---|---|
| **分镜图** | 当前提示词要生成的**产物**：一张黑白分镜速写手稿（满版宫格预览，角色通用替身、场景道具可辨识）|
| **分镜图提示词** | 用来生成"分镜图"的 prompt（对应代码字段 `keyframe_prompt`）|
| **视频提示词** | 用来生成视频的 prompt（对应代码字段 `video_prompt`）；本镜的分镜图默认随它一起送进视频模型 |

⛔ 写作时务必区分清楚：**本规范写的是"分镜图提示词"**，分镜图本身是这份 prompt 要生成的产物，不是参考输入。

## ⛔ 产出形态：`keyframe_segments` 是 **KeyframeDoc 对象**（不是纯文本、不是数组）

本规范用**纯文本**讲清分镜图提示词的格式 / 编号 / 版块 / 示例——这是你**构思**的依据。调 `update_keyframe_prompt` 时传的是 **KeyframeDoc 对象** `{refs, blocks}`（`update_keyframe_prompt(shot_id, keyframe_segments={refs:[...], blocks:[...]})`，与 update_video_prompt 的 VideoDoc 同构、只是更窄），构思好整段纯文本后装进结构：

- `refs` = 声明区：每条素材一个 image 段 `{type:'image',ref:'<asset_id>',desc:'作为X参考。'}`。⛔ desc **不带** `\n`（编号后端算、分行展示由渲染负责）。
- ⛔ refs **只放素材 image 段**——不放 `kind:'keyframe'` 段（分镜图是本提示词要生成的产物，不是参考输入）、**没有 voice / video 段**（生图不吃音色与参考视频）。
- `blocks` = 正文：**只有 text 块**（`{kind:'text',segs:[{type:'text',value:'…'}]}`）——分镜图是单帧画面，**没有 shot 块、没有台词 line、没有音效 sfx**。整个正文（整体速写描述 / 标题副标题 / Storyboard Panels / 图例说明 / 负面约束）装进**一个 text 块**；正文不含 @图片N 内联标记。
- 编号 N 不写，后端按 refs 里 image 段顺序算；块间空行渲染器补，text 块 value 开头**不写** `\n\n`。

## ⛔ @图片N 由声明区的顺序决定（你只管顺序，编号不归你写）

**声明区要列全本镜全部素材**（character / scene / prop / special）。派单时按 `keyframe_segments` 声明区 image 段的顺序，把每条启用素材的图依次传给生图模型；渲染层按同一个顺序派号（第 N 条 = `@图片N`）。所以**声明区的排列顺序就是参考图的先后**——越需要精准参考的越靠前，按类型优先级 character > scene > prop > special 排。

## ⭐ 写作锚：以该镜 video_prompt 为视觉来源

⛔ **核心约束**：分镜图提示词的画面内容必须**基于该镜已写好的 `video_prompt` 写**——video_prompt 是本镜画面叙事的**源真相**（每个「镜头N」段含镜头四要素：景别 / 运镜 / 主体动作 / 表情 / 空间位置），分镜图按它**派生**，**禁止与 video_prompt 矛盾**（视频模型同时吃 video_prompt + 分镜图，两者不一致会让它产出错乱）。

具体映射（全部落到 **panel** 里）：

| video_prompt 内容 | → | panel 里怎么画 |
|---|---|---|
| 镜头总纲（风格 + 色调 + 氛围） | → | 整张手稿的基调 / 副标题（黑白灰阶）|
| 「镜头N」段的**景别 + 运镜** | → | 该镜头对应 panel 的取景框大小；运镜 / 动作方向用 panel 序列递进 + **红色箭头** 标 |
| 「镜头N」段的**主体动作 + 表情**（角色名@图片N） | → | panel 内人物动作姿态（**通用替身速写**：借 @图片N 角色参考图的大致类型，但松散简化、不复刻五官），**且按动作阶段拆成多格**；位移方向用**蓝色箭头**标 |
| 「镜头N」段的**空间位置**（左 / 中 / 右、移动路径） | → | panel 内替身的银幕方位 + 走位（蓝色箭头）|
| 台词引出语的**情绪 / 语气** | → | panel 内人物表情 + 视线方向；情绪用**橙色文字**注释 |
| `<音效>` / `{台词}` | → | 声音不入图；但台词「谁对谁说」决定 panel 内说话人 / 听者的相对站位 + 视线 |
| `本段结尾画面：…`（= `ending_frame_desc`） | → | 末尾 panel + 终态画面 |

镜头设计（景别 / 机位 / 运镜）**video_prompt 已经定了**——分镜图**照它画**，把 video_prompt 各「镜头N」段的画面拆成 panel 序列，用每个 panel 的取景 + 文字标签 + **红色箭头**（运镜 / 动作方向）表达，**不要另设一套跟 video_prompt 不同的景别 / 机位 / 走位**（那就是矛盾）。剧本块（`script_block_ids` 引用的内容）仍可作为补充语境（人物关系 / 道具细节），但**画面取舍以 video_prompt 为准**。

⛔ **禁绝对秒数**：分镜图上的所有时序信息用 **panel 序号** + 位置词表达，**禁止写 `0-3s` / `2.5s` / `0-8s` 等秒数**。理由：分镜图作为剧情参考送进视频模型时，图上的秒数文字会被视频模型识别为现实文字（污染画面）或时间锚（触发视频模型时间不稳定问题）。

**panel 序号约定**（图内唯一时序锚）：

- panel 按**剧本节拍 + 动作阶段顺序**排布：从左到右、从上到下，序号 ①②③… 从 1 累加
- panel 间的时序引用统一用 panel 序号（`②→④` = 从 panel ② 持续到 ④；`整镜` = 跨本镜所有 panel）

⛔ 图上**不写「镜头N」字样**——「镜头N」是 video_prompt 的切镜标识，分镜图的 panel 是节拍/动作阶段粒度，两者粒度不同，混写会让视频模型把 panel 序号误当切镜序号。

## ⛔ 视觉风格（黑白松散速写 + 彩色标注）

整张分镜图是**黑白单色**多面板速写手稿，**不区分 videoStyle**（不管项目是 CG / 写实 / 仿真人，分镜图一律黑白速写）：

- **整体笔触**：**松散、快速、gestural 的铅笔速写草稿**——寥寥几笔带过、低完成度，像分镜师现场快速勾的故事板 rough；**不要**画成高完成度的精细写实素描（不要每根发丝 / 每道褶皱都渲染）；不是纯线稿、不是 wireframe 线框，可有少量灰阶明暗交代体积但点到为止
- **角色（最重要）**：画成**简化通用的"替身速写"**——借 @图片N 角色参考图的**大致类型**（性别 / 年龄 / 身材 / 角色定位）+ 大致发型轮廓，但**五官简化通用、不复刻、不追求像某个具体人**；**仍要画出表情情绪**（震惊 / 无奈 / 振奋等，靠简练的眉眼嘴角传达）和姿态动作。⛔ 不要把角色画成参考图里那张脸的精细灰阶复刻。
- **场景 / 道具**：按 @图片N 参考图画成**可辨识**的样子（空间结构、关键道具看得出是什么），用速写笔触表达即可
- **唯一的颜色 = 标注层**：仅红 / 蓝箭头 + 绿 / 橙文字用色，画面本身不出现任何彩色填充

**颜色编码图例（精简版，必须在 prompt 里出现）**：

| 标记 | 含义 |
|---|---|
| **红色箭头 red arrow** | 动作方向 / 运镜方向 / 冲击力方向（出拳、冲入、镜头推拉的向量）|
| **蓝色箭头 blue arrow** | 人物走位 / 移动 / 闪避方向（位移轨迹）|
| **绿色文字 green text** | panel 标题 / 景别标注（如「全景·开场」）|
| **橙色文字 orange text** | 情绪 / 导演注释（如「冷静，蓄势」）|

> 关键句（必须在 prompt 里出现）："Loose, quick, gestural black-and-white pencil storyboard rough — sketchy and unfinished, NOT a polished photorealistic render. Characters are simplified generic stand-in figures: borrow only the broad type from the @图片N character refs (gender / age / build / role) and convey posture, action and emotion, but DO NOT replicate exact facial likeness — keep faces loose and generic. Scenes and props are drawn recognizably from the @图片N refs (spatial layout and key props readable). Color used ONLY for annotation: red arrows for action / camera-move direction, blue arrows for character movement / dodge, green text for shot-size labels, orange text for mood notes. No color fill anywhere in the picture."

⛔ **场景 / 道具的外观由 @图片N 参考图承担**（画可辨识）；**角色只借参考图的大致类型、画通用替身**（不复刻五官）。见下方「参考图覆盖原则（按 role 分轨）」。

## 核心结构（六版块）

每个分镜图提示词必须按以下顺序写：

1. **素材声明区**（prompt 开头第一行，@图片N 引用本镜全部素材；⛔ 只给生图模型读、不画到图上）
2. **整体设计板描述**（黑白松散速写基调 + 颜色编码图例 + 版面布局指令）
3. **标题 + 副标题**
4. **分镜节拍 Storyboard Panels**（★主版面，占 ≥90% 高度；按剧本节拍 + 动作阶段拆 8-16 个 panel，每格黑白速写渲染、角色通用替身、场景道具按参考图可辨识、配文字标签 + 红/蓝箭头）
5. **图例 / 文字标签说明**（底部薄条，说明颜色编码 + panel 内文字标签含义）
6. **负面约束 Negative Constraints**（⛔ 给生图模型的生成指令，写在 prompt 末尾，不画到图上）

## ⭐ 整体版面布局（必须遵守）

设计板自上而下分三个区域，**高度占比硬约束**：

```
┌─────────────────────────────────────────────────┐

├─────────────────────────────────────────────────┤
│                                                 │
│         分镜节拍 Storyboard Panels（★主版面）   │
│           2-4 行 × N 列大网格，8-16 格           │ ≥90% 高
│  ┌──┬──┬──┬──┬──┐                           │   每个 panel 是一格黑白松散速写小画面：
│  │①│②│③│④│⑤│                           │   - 松散快速、低完成度
│  ├──┼──┼──┼──┼──┤                           │   - 角色通用替身、场景道具按 @图片N 可辨识
│  │⑥│⑦│⑧│⑨│⑩│                           │   - 红/蓝箭头标动作/走位
│  ├──┼──┼──┼──┼──┤                           │   - 角落小字标签：序号+景别+机位/运镜+动作
│  │⑪│⑫│⑬│⑭│⑮│                           │
│  └──┴──┴──┴──┴──┘                           │
```

⛔ **硬约束**（必须在 prompt 里显式说明）：

- **整张图就是 Storyboard Panels 大网格，占 ≥90% 高度**，2-4 行 × N 列，单格够大能看清角色/道具，所有信息都进 panel
- 顶部标题区 ≤5%，底部图例 / 文字标签说明 ~5%，其余全给 panels
- **严格网格布局，多面板边界清晰，不跨格 / 错格 / 合并格**
- **画布固定 16:9**（分镜图版式，与成片视频画幅无关）：版面指令里明写「16:9」；⛔ 不写竖版 / 竖屏 / 9:16，也不写分辨率画质词（8K / 4K / 超清）
- ⛔ **负面约束不占版面**——它是 prompt 末尾的生成指令，不画进图

## 1. 素材声明区（必须，prompt 第一行 —— 只给模型读，不画到图上）

@图片N 逐条声明本镜**全部素材**（按类型优先级排列），再换行进入正文。

⛔ **这一段是给生图模型的素材映射说明**（让它知道 @图片N 各是谁、怎么用：场景/道具画可辨识、角色画通用替身），**绝不能作为文字渲染到分镜图上**——分镜图上不出现「素材参考：角色@图1（李白）…」这类字样，素材声明只活在 prompt 文本里。

### 格式

```
@图片1作为<素材标题><角色|场景|道具>参考。@图片2作为<素材标题><角色|场景|道具>参考。@图片3作为…。

【黑白分镜手稿 · 分镜 X-Y · 主标题】
…后续正文…
```

### 字段映射

- `@图片N` 编号严格对应声明区 image 段的第 N 条（character / scene / prop / special 全编号、按类型优先级排列）
- `<素材标题>` 取自素材清单的 `title`，**原样复制**，不要改写或意译
- 每条声明标清素材类型（角色 / 场景 / 道具 / 特效），帮模型理解怎么用这张图

### 一致性硬约束

- 每条 asset_ref 在声明区**有且仅出现一次**（渲染层按声明顺序从 1 连续派号）
- **声明区是本提示词引用素材的唯一入口**，正文中不要再出现 `@图片N` 这类内联标记
- 该镜剧本（`script_block_ids` 引用的块）里出现但**没有素材**的配角 / 群演（如「王大牙的两名跟班」）：用剧情称呼在正文里写动作站位即可，不占 @图片N 编号

## 2. 整体设计板描述

必须说明：黑白松散铅笔速写 / Storyboard Rough / 导演手绘故事板草稿 / 多面板宫格布局 / 严格网格结构 / 影视分镜提案板。

**把「视觉风格」节的关键句 + 颜色编码图例抄进 prompt**（黑白松散速写、不区分 videoStyle、**角色画通用替身不复刻五官** / 场景道具按 @图片N 参考图可辨识、仅标注层用红/蓝箭头 + 绿/橙文字）。

**必须显式写明版面布局指令**（照搬到 prompt 里）：

> 整张图是 16:9 画布上的 Storyboard Panels 大网格主版面（占 ≥90% 高度，2-4 行 N 列，8-16 个 panel，单格足够大能看清角色 / 道具 / 场景）；顶部 1 行薄条放主标题 + 副标题「黑白分镜手稿」（占 ~5%，**不放素材声明**）；底部 1 行薄条放颜色编码图例 + 文字标签说明（占 ~5%）。严格网格、多面板边界清晰。

## 3. 标题 + 副标题

- **主标题**：4-8 个中文字，简洁有戏剧感（如「沙砾藏锋」「暗中觉醒」「锋芒初露」）
- **副标题**：**黑白分镜手稿**（固定文案）
  - ⛔ **副标题不写秒数 / 时长**——本镜时长用户可随时在 UI 上改，印在图上的秒数只会过时误导；且分镜图作为剧情参考送进视频模型时秒数文字会被当时间锚（视频模型时间不稳定）
  - ⛔ **副标题不写镜头数、不写 videoStyle**——「镜头N」是 video_prompt 的切镜标识，画到分镜图上会被视频模型误当切镜锚

## 4. 分镜节拍 Storyboard Panels（★唯一主版面）

整张图的**全部内容**，占 ≥90% 版面，2-4 行 × N 列大网格 —— 每个 panel 是一格**黑白松散速写小画面**，自洽地表达这一拍。

### 每个 panel 自带

| 元素 | 怎么画 |
|---|---|
| 画面 | 该取景范围内的黑白松散铅笔速写（单色、低完成度、寥寥几笔带过，可有少量灰阶但点到为止）|
| 角色 | **通用替身速写**：借 @图片N 角色参考图的大致类型（性别/年龄/身材/定位），松散简化、**不复刻五官**；画当前动作 / 姿态 / 表情情绪 / 视线 |
| 道具 | 按 @图片N 道具参考图画成**可辨识**的样子（速写笔触），放在画面对应位置 |
| 场景 | 按 @图片N 场景参考图的结构画成**可辨识**的环境（速写笔触）|
| 动作 / 走位 | **红色箭头** = 动作 / 运镜 / 冲击方向；**蓝色箭头** = 人物走位 / 移动 / 闪避方向 |
| 文字标签 | panel 角落小字：`序号 + 景别 + 机位/运镜词 + 动作`；景别 / 标题用**绿色文字**，情绪 / 注释用**橙色文字**，其余黑色 |

### 调度信息用红/蓝箭头 + 彩色文字标签

机位 / 运镜 / 动作 / 走位用**红 / 蓝箭头 + 角落文字标签**表达——因为整张图是黑白速写手稿，视频模型识别为设计稿，箭头 / 文字不会被渲染进成片：

- 红色箭头：出拳 / 冲入 / 镜头推拉 / 冲击力方向
- 蓝色箭头：人物从 A 走到 B / 侧身闪避 / 后退的位移轨迹
- 文字标签示例：`②中景·Cam1缓推近·林博士前倾`（机位绿字、情绪橙字）、`⑤特写·锁定显微镜·凝重`
- 视线用文字写（「视线锁定显微镜」），方向性强的也可用蓝色细箭头辅助

### 运镜靠 panel 序列递进

**运镜由 panel 序列自然带出**，逐格表达：

- 推拉摇移 = 连续几格景别/机位渐变（②中景 → ③近景 → ④特写），把推近过程一格一格画出来，运镜方向用红箭头标在格内
- 在发生运镜那格的文字标签里写机位（`②Cam1缓推近`），下一格画推近后的画面
- 多机位切换：每格文字标签各标自己的 Cam（②Cam1 → ⑤Cam2）
- 把整镜运镜拆成逐格的渐变画面给视频模型当中间参考帧，**不写**「Push In 整镜」这种跨全镜的总览句

### Panel 数量规则

Panel 按**剧本节拍 + 动作阶段**拆，给视频模型尽量多的参考帧：

- 每个独立节拍（一个动作 / 一个表情拐点 / 一次说话人切换 / 一次景别变化）至少 1 个 panel
- ⭐ **粒度细到动作阶段 / 机位推进**：一个连续动作（如「弯腰捡起麦穗」）拆成「起身 → 弯腰 → 捡起」多格；一次推镜拆成「中景 → 近景 → 特写」多格——像动画关键帧那样给中间过程
- **Panel 总数推荐 8-16 个**（超过约 16 格每格太小、角色/道具看不清）
- 镜内节拍 / 动作阶段越多就拆越多 panel（到上限 16），目标是给视频模型尽量多的参考帧

### 跨镜首 panel 承接（`>15 秒` 多镜集）

**非首镜**：写本镜 keyframe 前先 `get_storyboard` 读上一镜的 `ending_frame_desc`，并在素材声明区之后用**一句承接关系句**点明（如「承接上镜结尾——上镜止于主体居右、视线朝左、中景；本镜跳特写、机位绕至左前」）。具体落到首个 panel 上：

- **首 panel 景别**相对上镜末项**跳变 ≥1 级**（上方「跨镜衔接规则」法则 2）
- **机位 `>30°`**：在首 panel 文字标签写机位承接（如 `Cam1 相对上镜右前45°绕至左前约80°`），且不越法则 3 的轴线（法则 4）
- **不越轴**：首 panel 主体的**银幕方位**（左/中/右）与**视线朝向**跟上镜结尾一致（读上镜 `ending_frame_desc.银幕方位 / 视线朝向`），机位可绕，但站位不跨过两主体连线那条轴线翻到对侧（法则 3）

### 段落格式（必须分行书写）

```
4）"分镜节拍 Storyboard Panels"（占据整张图 ≥90% 版面，2-4 行 × N 列黑白速写大网格，每格松散速写渲染）：展示 N 张编号 panel——

① 全景·开场铺垫：实验室全景，林博士站在中央右后的实验台前，视线指向左前方；
② 中景·靠近：Cam1 缓推近（红箭头标推近方向），林博士保持原位微微前倾；
③ 近景·发现：显微镜在画面右下，林博士视线锁定显微镜；
④ 近景·表演拐点：林博士表情由微笑转凝重，原地不动；
⑤ 特写·细节：特写显微镜镜片反光，林博士神情专注；
⑥ 中景·终态定格：拉回中景，画面定格，对应视频结尾画面。
```

格式要点：

- 段首引导句以 `——` 结尾，**后接换行 + 空行**
- 每个 panel **独占一行**，行内格式：`<圆圈数字> <景别>·<节拍名>：<画面描述 + 红/蓝箭头标记 + 角落文字标签>；`
  - 圆圈数字：`① ② ③ ④ ⑤ ⑥ ⑦ ⑧ ⑨ ⑩ ⑪ ⑫ ⑬ ⑭ ⑮ ⑯ ⑰ ⑱ ⑲ ⑳`——按剧本节拍 + 动作阶段顺序累加，图内唯一时序锚
- panel 之间用 `；` 分隔，**最后一条**用句号 `。`
- 段落最后一行之后**必须空一行**

⛔ Panel 文字标签**绝对禁止**写秒数（`0s` / `2.5s` / `4-8s` 等）和「镜头N」字样——时序全靠圈号序号顺序表达。

## 🔴 全局硬约束：参考图覆盖原则（按 role 分轨）

⛔ **本版的核心规则：场景 / 道具锁定参考图，角色只借大致类型画通用替身。** 这是 mono 版跟彩色版最大的差别——彩色版要求角色也严格复刻参考图，本版**故意不复刻角色**。

**scene / prop / special（锁定参考图）**：外观由参考图承担——按 @图片N 画成**可辨识**的样子（空间结构 / 关键道具看得出是什么），**正文不复述外观**，只写它当下怎么用 / 在画面里的状态。同一素材在所有 panel 保持一致。prompt 里写一句：「场景 / 道具按对应 @图片N 参考图画成可辨识的样子（速写笔触），所有 panel 一致」。

**character（通用替身，⛔ 不复刻）**：角色参考图**只用来判断大致类型**（性别 / 年龄段 / 身材 / 角色定位 / 大致发型轮廓），画成**简化通用的速写替身**——**不复刻五官、不追求像那张脸**。正文写角色当下的动作 / 姿态 / 表情情绪 / 视线 / 站位即可。prompt 里写一句：「角色画成简化通用的替身速写，借参考图的大致类型但不复刻五官、不画成某个具体人，保留表情情绪与动作」。

| 素材类型 | 参考图怎么用 | ✅ 正文写 | ❌ 别做 |
|---|---|---|---|
| **character** | 只借大致类型（性别/年龄/身材/定位/发型轮廓）| 当前动作 / 姿态 / 表情情绪 / 视线 / 站位 / 关系 | ⛔ 复刻五官、画成参考图那张脸的精细灰阶、高完成度写实头像 |
| **scene** | 锁定（画可辨识的空间结构）| 当前取景范围 / 主体在场景里的位置 / 临时光线 | 文字复述建筑细节 / 墙面纹理（参考图已覆盖）|
| **prop** | 锁定（画可辨识的形态）| 当前怎么被使用 / 剧情功能触发 / 位置状态 | 文字复述形态 / 纹理 / 字迹（参考图已覆盖）|

为什么角色要通用：分镜图会作为剧情参考喂视频模型，角色画太像会让视频直接抄分镜图的脸、而不是用真实角色参考图（视频提示词里的角色素材图）；通用替身则迫使视频模型从真实角色参考图取身份。**角色通用化比"画得像"更优先。**

## 5. 图例 / 文字标签说明

底部薄条写一句：颜色编码（红箭头=动作/运镜方向、蓝箭头=走位/位移、绿字=景别/标题、橙字=情绪注释）+ panel 角落小字 = 分镜标注（序号 / 景别 / 机位 / 运镜 / 动作），**不是画面内容**。

## 6. 负面约束 Negative Constraints

⛔ **定位：这一段是给生图模型的「生成指令」，放在 prompt 最末尾**——约束模型怎么画，不是版面内容，不给它编版面序号、不在版面布局里留位置。

**全局基础**（照搬到 prompt 末尾）：

```
Negative Constraints / 负面约束：
- 整体必须黑白松散铅笔速写；画面主体不要任何彩色填充（颜色只用于红/蓝箭头 + 绿/橙文字标注）
- 不要照片级真实感 / 真实摄影质感 / CG 渲染 / 上色插画——保持手绘故事板草稿质感
- ⛔ 角色不要复刻参考图的人脸、不要画成某个具体人、不要高完成度精细写实头像——角色一律简化通用替身
- 不要过度精细 / 每根发丝每道褶皱都渲染——保持松散快速、点到为止
- 不要水印 / 参考图以外的 logo / 杂乱文字 / 错误汉字
- 不要多余肢体 / 角色变形 / 多余手指
- 不要跨格 / 错格 / 合并格，严格网格布局，多面板边界清晰
- panel 角落的文字标签与红/蓝箭头是分镜标注，不要当画面内容、视频里不要出现这些标注
```

## 自检清单（写分镜图提示词前）

### 结构 / 引用
- [ ] **产出是 KeyframeDoc 对象 `{refs, blocks}`**：refs 每条素材一个 image 段（desc 不带换行）+ blocks 一个 text 块；无 keyframe / voice / video 段、无 shot 块；编号 N 不手写、text 块开头不写 `\n\n`（见上方「产出形态」）
- [ ] 开头有素材声明区，**列全本镜全部素材**（character / scene / prop / special），按类型优先级排好顺序（编号由顺序决定，不手写）
- [ ] ⛔ **素材声明只在 prompt 里、不画到图上**——顶部薄条只渲染主标题 + 副标题，图上无「素材参考：角色@图…」字样
- [ ] `<素材标题>` 与素材清单的 title 完全一致（不改写、不意译）
- [ ] **画面内容全部来自本镜 video_prompt 与 `script_block_ids` 引用的剧本块（action 块 / dialogue 块）/ ending_frame_desc**——不要漏掉剧本块里的动作/站位/表情节拍
- [ ] 整体描述写明黑白松散速写 + 颜色编码图例 + 「角色画通用替身不复刻五官 / 场景道具按 @图片N 参考图画可辨识、不文字复述外观」
- [ ] 版面布局指令照搬到 prompt：整张图是 Storyboard Panels 大网格（≥90%），信息全进 panel
- [ ] 版块齐全（声明区 / 整体描述 / 标题副标题 / Storyboard Panels / 图例+文字标签说明 / 负面约束）

### Panel 节拍 / 时间锚（视频模型合规）
- [ ] **Panel 数量按剧本节拍 + 动作阶段拆细**，推荐 **8-16 个**——多给视频模型参考帧
- [ ] 连续动作 / 推镜**拆成多格**画出中间过程（起身→弯腰→捡起 / 中景→近景→特写）
- [ ] Panel 锚是**自身圈号序号 ①②③…**，**图上不出现「镜头N」字样、不出现绝对秒数**
- [ ] 运镜由 **panel 序列递进** + 红箭头 + 角落文字标签表达，不写「Push In 整镜」跨全镜总览句
- [ ] 副标题写 `黑白分镜手稿`（**不写秒数、不写镜头数、不写 videoStyle**）

### Panel 内容
- [ ] 每格黑白松散速写画面（单色、低完成度、点到为止），场景/道具按 @图片N 参考图画可辨识
- [ ] ⛔ **角色画通用替身**——借参考图大致类型但不复刻五官 / 不画成具体某人 / 不画高完成度精细头像，但保留表情情绪与动作
- [ ] 调度信息（机位/运镜/动作/走位）用**红/蓝箭头 + 角落文字标签**（红=动作/运镜、蓝=走位/位移）
- [ ] 参考图覆盖原则按 role 分轨：scene / prop 锁定参考图、不文字复述外观；character 只借大致类型画通用替身

### 视觉风格
- [ ] 整张图黑白松散铅笔速写（不要高完成度精细写实），画面主体无彩色填充（颜色仅红/蓝箭头 + 绿/橙文字）
- [ ] 负面约束段含基础（黑白速写/不要彩色填充/不要照片写实/角色不复刻人脸/不要过度精细/不要错别字/不要跨格）
- [ ] 负面约束段含「panel 角落文字标签与红/蓝箭头是分镜标注，不要当画面内容、视频里不要出现」
