# 漫剧 · 分镜细则

分镜师主指令里已有**平台机制 + 通用手艺**：拆镜规则、块结构、表演写作规范、跨镜衔接、时长与依赖校验。
**这一份只有漫剧特有的镜头口径。**

⛔ **本文说的「镜头」都是一个分镜之内的「镜头块」，不是分镜。一集拆成几个分镜只由主指令的时长分支决定**，本文没有任何一条能改变分镜数。
下面讲的节奏——快还是慢、先给什么后给什么——落在**分镜内部的镜头块怎么切**上，每块多长由你按节拍内容判断：
一段旁白配的几幅画面、一次打脸的「压—放—反应」，是同一个分镜里的几个镜头块，⛔ 不是几个短分镜。

## 节奏：快，爽点处停得住

- **缺省切得勤**：漫剧观众手指一划就走，镜头块切换比真人短剧更密，一块只交代一件事。
- **爽点要亮相**：身份揭晓、实力爆发、反派跪下那一下，给一个停得住的镜头块——主角正脸或全身亮相，背景可以用特效光、速度线、气浪烘托。
- **反应镜头不可省**：打脸之后切到围观者、反派的脸，表情要夸张、读得出来（瞠目、冷汗、腿软）。
- **钩子留在最后**：非收官集最后一个分镜的最后一个镜头块落在悬念上（未说完的狠话、刚出现的人、将要揭开的身份）。

## 旁白段落：画面不能停

旁白多是漫剧的常态，但旁白期间画面不能变成静止的插图：

- **旁白配动作**：讲前因时给回忆画面里的人在动，讲设定时给主角的状态变化，⛔ 不要一整段旁白配同一个不动的画面。
- **内心独白给近景**：os 段落切到说话人的脸，表情和 os 的内容对上（嘴上笑、心里冷——脸上就是那个笑里带冷）。
- **旁白讲到的不一定都要画**：画面跟着旁白里最关键的那个形象走，其余交给声音。

## 构图与运镜：竖屏、主体大

- **主体居中、够大**：竖屏小屏看人靠脸和发型色块，人物以中景、近景为主；全景交代一次「在哪」就够。
- **对峙用上下或前后**：竖屏放不下左右两个人的全身，用前景背影 + 后景正脸、或仰拍 / 俯拍拉出强弱关系。
- **运镜可以夸张**：冲击时刻快推、仰拍、环绕都可以，漫剧的镜头语言本来就比真人大一号；但平常的对话戏保持稳定，留给爽点去夸张。
- **特效贴合画风**：法术、气场、系统光效画成和项目视觉风格一致的样子，⛔ 不要在漫画风里突然混进写实的爆炸。

## 字幕与文字

对白、旁白、系统提示的字幕由后期剪辑配；⛔ 不要在 video prompt 里让视频模型写字——对白气泡、系统面板上的字、拟声字都不写（写出来多半是乱码）。
系统面板只写它亮起、浮现的样子，不写上面的字。
确实要上画面的字（定格亮相的拟声大字、必须被看清的那页退婚书），只在素材清单里有对应的文字素材图时引用那张图。
