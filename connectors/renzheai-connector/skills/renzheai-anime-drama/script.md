# 漫剧 · 编剧细则

剧本师主指令里已有**平台机制 + 通用编剧手艺**：工具怎么调、产出形态、块 id 纪律、
台词法则、人设与配角格式、画面文字四问、换皮重制、自检与合规。
**这一份只有漫剧特有的东西**：小说改编、旁白与内心独白、爽点与钩子、漫剧常见的「画面上的字」、素材清单、跨集承接。

## 小说原文怎么改

用户给了原文，剧本就**从原文来**，⛔ 不另起炉灶、不改人名、不换情节走向。

- **照原文改编**（缺省）：保留原文的关键情节和点睛的台词（狠话、名场面那几句一个字不动），
  删掉的是铺陈：大段环境描写、心理分析、作者议论、重复的过渡。
  一段描写能变成一个动作或一个表情的，就写成 `action` 块；只能靠讲的，压成一两句旁白。
- **一字不改**（用户要求时）：原文的对白和叙述按原文转录成 `dialogue` 块，旁白就是原文叙述；
  `action` 块只补画面，不改写原文。篇幅装不下这一集的时长，在 summary 里如实说「原文这一段念下来超出时长」，由调用方转告。
- **切在哪**：剧情指令写明了讲到哪就到哪；没写就照时长切，切点落在钩子上，⛔ 不切在一场戏的半中间。

## 旁白与内心独白

漫剧的旁白比真人短剧多得多，这是体裁本身，不是偷懒。但旁白要**补画面给不了的东西**：

- **该旁白讲的**：前因（「上一世，我被她害得家破人亡」）、时间跳跃（「三年后」）、身份与设定（「我觉醒了神级系统」）、
  主角心里的盘算（「这一次，我不会再让任何人欺负我」）。
- ⛔ **不看图说话**：画面上正在发生的事（「他推开了门」「她哭了」）不用旁白再讲一遍。
- **视角全集统一**：第一人称就一直是「我」，第三人称就一直是说书人，⛔ 不在同一集里来回换。
- **内心独白写成 os**：角色心里话用 `dialogue` 块标 os，和旁白分开——旁白是讲故事的人，os 是这一刻这个人在想什么。
  常见的反差写法：嘴上客气、os 里吐槽或冷笑。
- **旁白和对白要交替**：一整段旁白讲到底，画面就成了一张张静图。讲一两句就要回到人物的对白和动作上。

## 爽点与钩子

- **开场就进冲突**：第一场戏直接是被退婚、被羞辱、重生醒来、系统激活这类「事发了」的时刻，⛔ 不从起床吃饭讲起。
  背景交代用一两句旁白带过。
- **先压后放**：先让主角受气（被看不起、被陷害、被逼到墙角），再一口气翻身（身份揭晓、实力碾压、当众打脸）。
  放的那一下要干脆，⛔ 不要放到一半又解释半天。
- **反应要写足**：打脸之后那一圈人的反应（瞠目、腿软、改口）是观众最爱看的部分，`action` 块写清谁、什么反应。
- **漫画式的夸张可以写**：震惊到瞳孔地震、额头冒冷汗、气得发抖——漫剧的表演本来就比真人大一号，照写在动作和神态里。
- **每集结尾停在钩子上**：一句狠话、一个身份将揭未揭、一个危机刚冒头；⛔ 不打「未完待续」，用台词、动作或一句旁白留扣。

## 漫剧常撞上的「画面上的字」

漫画里到处是字，视频里一个都不能让模型现写。照通用细则「画面文字」的四问走（以下是例子，不是清单）：

- **对白气泡、旁白框** → 那就是台词和旁白，写成 `dialogue` 块；⛔ 不写「气泡里写着……」，台词字幕由后期剪辑配。
- **系统提示 / 系统面板 / 属性栏**（「叮！任务完成，奖励……」）→ 由「系统」念出来，写成 `dialogue` 块（说话人写系统，算画外音）；
  画面只写面板亮起、光芒闪烁，⛔ 不写面板上的字。
- **拟声字**（「轰！」「咚——」）→ 那是声音，写进 `action` 块的声音和动作里；
  只有这个大字本身就是画面重点、要定格亮相的，才走第 3 问规划成文字素材，一集里不多于一两张。
- **招牌、牌匾、功法卷轴的书名、退婚书** → 观众不需要读的照常写它在那、不写字；关键的那一句由人念出来；
  只有那一页必须被看清时才列成文字素材。

## 素材清单列什么

- **有台词的角色必列**；跨集出现的角色复用同一条，别每集重列。
- **同一角色的不同形态各列一条变体**（重生前 / 重生后、突破前 / 突破后、变身、换上礼服），`variant_of` 回链主条。
  漫剧的形态变化往往就是爽点本身，形态写准了画面才接得住。
- **场景一集通常 2~4 个**；法宝、信物、退婚书这类推动情节的物件列，装饰性的不列。
- **音色**：旁白列一条（第一人称旁白可以就是主角的音色，在 `reason` 里写明）；具名说话人各列一条；系统音单列一条。
  群众 / 路人不列。
- ⛔ 不列：只在旁白或台词里提到、画面上不出现的人或物。

## 跨集承接与收尾

`get_story_bible` 返回的 `story_mode` 决定这一节走哪条路，**第 1 步读到它就先判**：

- **连续剧**（`serial`，本品类的缺省）：第 2 集起，开场先接住上一集的钩子（直接续上那个动作、或接住那句话），
  观众一看就知道「接着上集」；首集（本集 `sequence_number` 为 1）跳过承接，开场直接立主角、抛全剧的核心钩子。
  非大结局的集结尾都留钩子。大结局那一集按 `finale_style` 收：`closed` 把伏笔逐条交代、给明确结局；
  `open` 主线解决、留一个想象空间的收尾。
- **单元剧**（`anthology`）：本集按剧情指令写一个自洽完整的故事，⛔ 不承接上集、不留跨集钩子；
  `finale_style` 作用于每一集：`closed` 结尾点题收干净，`open` 故事完整、留一点余味。
