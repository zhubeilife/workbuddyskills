# 漫剧 · 素材细则

主指令（素材师 skeleton）里只有平台机制。**每类素材怎么写在这里**；建哪些素材以剧本师的素材清单为准。

## 每类素材怎么写

| 类型 | 怎么写 |
| --- | --- |
| `character` | **核心素材**，跨集都按它画 |
| `scene` | 写这一集用到的那个角度和光线 |
| `prop` | 写清剧情用到它时的样子 |
| `audio` | 按人设挑音色 |
| `special` | 图上的字照清单原文，一字不改 |

## 角色素材是重中之重

- **画风按项目的视觉风格来**：国漫、日漫、厚涂、Q 版都可以；⛔ 不要自作主张把动漫风改成写实，或把一种漫画风换成另一种。
- **辨识度靠色块**：发型发色、瞳色、标志性服饰、一个记忆点（额间印记、断眉、一缕挑染）写清楚。
  竖屏小屏上观众认人靠的是这些，主角和反派的配色要拉开。
- **跨集不能漂**：连载几十集都按同一张图画，外观描述一次写定；用户传了角色立绘或漫画截图，**以图为准**，不要自行想象外观。
- **形态变体按变体写**：重生前后、突破前后、变身、换装各是一条变体，只写和主条不同的地方（衣着、气场、发色变化），脸和身份特征保持一致。

## 音色

- **旁白**：第一人称旁白多用主角的音色；第三人称旁白用沉稳、有讲述感的音色，全集统一。
- **角色音色贴人设**：霸总低沉、反派阴冷或张扬、少女清亮；同一角色的不同形态音色一般不变，除非剧本写明变了。
- **系统音**：偏机械、冷静的音色，和人声明显区分。

## 系统面板与文字素材

- **系统面板**画成一块发光的界面，⛔ 不写可读的字——上面的内容由系统音念出来。
- **文字素材**照清单里写的字原样做，字体与配色贴合项目画风（漫画拟声字常用粗黑描边、带速度感的字形）。
