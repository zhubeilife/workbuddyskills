# 电商产品宣传 · 脚本细则

剧本师主指令里已有**平台机制 + 通用编剧手艺**：工具怎么调、产出形态、块 id 纪律、
台词法则（信息前置 / 动作可视化）、人设与配角格式、换皮重制、自检与合规。
**这一份只有本品类特有的东西** —— 别在这里找台词怎么写、人物怎么立。

## 骨架：亮相 → 痛点 → 演示 → 参数 → 下单

| 段落 | 占比 | 要做到 |
| --- | --- | --- |
| **产品亮相** | 前 15% | 第一秒就把商品完整露出来——观众是冲着它来的，别绕弯子 |
| **痛点唤起** | 15% | 一个具体的糟糕瞬间（洒了 / 卡住了 / 不够用了） |
| **卖点演示** | 45% | 三个卖点逐个**演示**：怎么用、什么效果。**演给人看，不是说给人听** |
| **规格参数** | 15% | 尺寸 / 材质 / 容量 / 配件，由解说词念清楚；要上画面的做成一张参数卡，列进素材清单当文字素材 |
| **下单引导** | 最后 10% | 明确说「点击下方链接」/「加入购物车」+ 优惠信息 |

15 秒以内的主图视频压成「亮相 → 一个核心卖点演示 → 参数卡」，下单引导交给页面本身。

## 卖点怎么写才有说服力

- **能拍出来的才写**：「304 不锈钢」要有材质特写，「一键折叠」要有折叠动作。
  拍不出来的卖点（「设计理念」）降级或删掉。
- **给可比较的量**：「续航 12 小时」比「续航持久」强，「比旧款轻 40%」比「轻便」强。
  数字必须来自用户提供的规格，**不要自己估**。
- **对比是最强的武器**：有对比素材就用前后 / 左右分屏，一秒说清优势。

## 这类片子常撞上的「画面上的字」

都照通用细则「画面文字」的四问走（以下是例子，不是清单）：

- **价格 / 促销数字（9.9 元、第二件半价）** → 进解说词；确实要上画面的，做成一张价格卡素材，不在每一镜角落挂价签。
- **包装上的品牌名、成分表** → 靠产品真图带进去；没有真图时只写产品的样子，不去描述包装上印了什么字。
- **卖点句** → 是解说词，不是文字卡；一个卖点一张卡的做法不要用。

## 口播纪律

- **一句一个信息点**，15 字以内。
- **不喊口号**：「买它！」这类话在带货直播里有效，在挂链接的视频里显得廉价。
- **合规红线**：食品不谈功效，化妆品不谈治疗，保健品不谈疾病，
  一律不用「最」「第一」「彻底」「无副作用」。拿不准就改成事实描述。

## 素材清单列什么

- **商品本体 + 配件 + 包装是绝对核心**（`prop`）。包装状态 / 开箱状态 / 使用状态 / 折叠收纳状态各列一条变体，
  `variant_of` 回链主条——它们在分镜里会被分别引用，合成一条会让画面出现前后不一致。
- **使用场景 1~3 个**，简洁为主。
- **演示的人通常只需要手部**；要出全身时才列一个使用者。
- **有口播就为口播的说话人列一条音色。**
- ⛔ 不列：竞品（对比用「同类产品」的泛化描述，不出现可识别品牌）；用户没提供的赠品与配件；
  夸大的使用效果场景（比如实际做不到的清洁效果）。

## 什么不该做

- 不要虚构使用效果（对比画面尤其不能夸张）；
- 不要出现用户没提供的赠品、优惠、售后承诺；
- 不要设计剧情——买家想看的是产品，不是小品。
