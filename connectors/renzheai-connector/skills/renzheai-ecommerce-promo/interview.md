# 电商产品宣传 · 访谈与落库参数

主指令里有**通用的那一整套**：`create_project` / `create_episode` 要凑齐哪些字段、各字段用什么工具收、
收尾怎么核对复述确认、换皮流程、补设定门槛。**这一份是本品类的访谈提纲**——问什么、怎么问、
本品类特有的字段怎么填、复述里念哪几行。

## 必须聊清的六件事

1. **卖什么**——具体到型号 / 规格 / 颜色。聊到卖什么时**点名一次产品实拍图**（照主指令「真实素材」的规矩：
   只提一次、不当关卡、复述里不再提；用户传了就用 `ask_uploaded_asset_meta` 收元信息）：
   电商视频里产品外观与实物不符是致命问题。
2. **挂在哪**——淘宝主图 / 详情页 / 抖音商品卡 / 视频号小店 / 小红书。
   ⚠️ **主图视频通常静音自动播放且时长受限**（多数平台 ≤30 秒，部分 ≤9 秒）：
   照样要口播，静音观众看的是台词字幕（台词字幕在「剪辑」页点「生成字幕」出），画面也要自己把卖点演清楚。
3. **解决什么问题**——买家在什么场景下需要它、现在的替代方案有什么不好。
   ⛔ 「质量好」不是问题解决，追问一句「买家最常抱怨同类产品的哪一点」。
4. **最强的三个卖点**——逼用户排序，按重要性给出 ①②③。
   材质 / 容量 / 续航 / 尺寸 / 工艺 / 售后都可以，但要**能被拍出来**。
5. **有没有可对比的东西**——前后对比、与旧款对比、与常见做法对比。
   对比是这类视频最有效的说服手段，有就一定要用上。
6. **多长**——材料里读得出（脚本时间轴 / 需求写明 / 用户说过）就直接用，完全没信息才 `ask_user_number`。主图视频 9-30 秒，详情页 30-90 秒，
   带货短视频 30-60 秒。
   **默认 30 秒**：用户放手时直接取它；要问时长时，它就是 `ask_user_number` 的 default。

## 顺带确认

- **有没有实拍素材**：产品各角度照片、使用场景照、细节特写。和第 1 条的产品实拍图合在那一次里点名，不另提。
- **规格参数**：尺寸、重量、材质、容量——这些数字会进解说词；要上画面的会做成一张参数卡素材。
- **合规红线**：不能出现的功效宣称（食品/化妆品/保健品尤其严），
  不用「最」「第一」「根治」「无副作用」这类绝对化用语。

## 参数怎么收（先判三态，缺信息的才问）

每一项开口之前先看手上已经有什么——**用户给得越全，问得越少**：

1. **用户明说了，或材料里能直接读出** → **直接采用，不弹卡、不追问**。
   材料 = 用户的话、贴来的文案 / 脚本、上传的文档、发来的链接。
   范例：文案自带时间轴「0-3 秒 … 55-60 秒」= 60 秒；文档写明「30 秒」= 30 秒；文案标了语气 = 调性已定。
2. **能从上下文合理推断** → 采用、不弹卡，最终复述里这一项后面标「按你的材料推断」并写明依据
   （发抖音 / 视频号 / 小红书 → 竖屏；官网首屏 / 展会大屏 → 横屏）。
3. **完全没有信息** → 才问：
   - 离散字段弹卡：挂在哪 / 时长 / 画幅 / 项目名候选
   - 开放内容纯文字：卖什么、解决什么问题、三个卖点、对比点

- **视觉风格不做推断**：用户点名了风格就直接采用；没说就 `ask_user_choice` 传 `preset_pool='video_style'`
  （系统自动注入全部内置风格 + 自定义框，**不要自己列风格名**）。
  电商画面通常干净明亮、产品占主体，可以在 question 文字里点名推荐。
- ⛔ 不要因为某一项「是离散字段」就弹卡——材料里有答案的，答案就是答案，不是「默认值」，别让用户再点一次。

## 落库前：复述 → 确认

复述照主指令的共用模板走，本品类在〔品类字段〕那一格写这几行：

```
- 商品与买家: XXX          ← 卖什么 + 给谁 + 解决什么问题
- 三个卖点: ①XXX ②XXX ③XXX
- 对比点: XXX              ← 没有就写「无」
```

这些信息落在哪：**商品与买家、三个卖点、对比点写进世界观**（`theme_prompt`，同一商品各条共用）；
**这一条怎么讲**写进这一条的剧情指令。
⛔ 挂在哪（投放位置）只用来决定时长、显示方向和节奏，不进世界观、不进剧情指令，也不单列一行；
世界观和剧情指令里也不写画幅 / 横竖屏。

复述完**同一轮紧接着** `confirm_action`，确认后按主指令的落库方式调。

**这一次复述 + `confirm_action` 是整个流程唯一的一张确认卡**：采用的、推断的、用户选的字段全部并进它，
每项后面标来源（`按你的材料` / `按…推断` / `你选的` / `我起的`）；⛔ 不许先弹一张「确认默认值」再弹一张「确认创建」。
用户给的是成品脚本 / 文案、要求照它做时，复述里多一行「剧本：按你的原文转录（台词一个字不改）」。
`story_mode` / `finale_style` / `is_finale` 按 SKILL.md 直接填，不问、不复述。

## 再做一条

同项目下建下一条 = 换用途（主图版 / 详情页版 / 带货版）。
只聊「这一条挂在哪、要突出哪个卖点」+ 时长，其余沿用。
