# 电商产品宣传 · 分镜细则

分镜师主指令里已有**平台机制 + 通用手艺**：拆镜规则、块结构、表演写作规范、跨镜衔接、时长与依赖校验。
**这一份只有本品类特有的镜头口径。**

⛔ **本文说的「镜头」都是一个分镜之内的「镜头块」，不是分镜。一集拆成几个分镜只由主指令的时长分支决定**，本文没有任何一条能改变分镜数。
下面讲的节奏——快还是稳、先给什么后给什么——落在**分镜内部的镜头块怎么切**上，每块多长由你按节拍内容判断：要多角度、快节奏，就在一个分镜里多切几个镜头块，
⛔ 不是把它拆成几个短分镜。

## 节奏

- **节奏偏快、多角度**；参数镜头（引用参数卡素材图的那个镜头块）要停得久一些，让人看清。
- **第一个镜头块就是产品**：完整外观、干净背景、光线充足。⛔ 不要用空镜或场景铺垫开场。
- **每个卖点都有两种镜头块**：中景交代动作 + 特写给细节。
- **结尾的镜头块要停住**：产品 + 引导，画面干净。

## 镜别：特写占一半以上

电商视频的本质是**让人看清商品**：

| 要表达 | 镜别 |
| --- | --- |
| 整体外观、比例 | 中景 / 全景（带参照物更好） |
| 材质、做工、接缝、logo | 微距特写 |
| 怎么用 | 中景 + 手部特写 |
| 容量、尺寸 | 带对照物的中景（放硬币 / 手机对比） |

## 产品呈现的硬要求

- **多角度**：正面、侧面、背面、细节至少各一个镜头块——买家在网上看不到实物。
- **光线均匀**：产品视频要亮、要干净，避免大反差与彩色光污染。
- **背景不抢戏**：纯色或简洁场景，产品永远是画面主体（占画面 40% 以上）。
- **有手部演示**：手拿着的产品能让人判断真实尺寸，比纯静物图有效得多。

## 静音友好

主图视频与商品卡通常静音播放：**每个卖点都要能从画面上看懂**——怎么用、什么效果，演出来，不靠口播补。
口播的字幕由后期剪辑配，静音观众读的是那一层；⛔ 不要在 video prompt 里让视频模型写字（写出来多半是乱码，这一条就废了）。
参数段落要上画面的数字，只在素材清单里有对应的参数卡素材图时引用那张图。
