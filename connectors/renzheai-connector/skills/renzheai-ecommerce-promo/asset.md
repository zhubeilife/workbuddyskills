# 电商产品宣传 · 素材细则

主指令（素材师 skeleton）里只有平台机制。**每类素材怎么写在这里**；建哪些素材以剧本师的素材清单为准。

## 每类素材怎么写

| 类型 | 怎么写 |
| --- | --- |
| `prop` | 绝对核心，必须与用户上传的产品图一致 |
| `scene` | 简洁为主，不要抢产品的戏 |
| `character` | 出全身时只写年龄段与着装 |
| `audio` | 语速偏快、亲和，别用广告腔 |

## 产品素材：以用户上传的图为唯一依据

**这一条没有商量余地**——电商视频里的产品外观与实物不符会直接导致差评与退货。

- 用户传了产品图 → 严格照图建条：颜色、比例、材质、logo 位置、接缝走向逐项写清；
- **没传图** → 照常干活，在 summary 里写一句「没有产品图的话，画面里的商品只能是示意，
  和实物一定会有出入，挂链接是有风险的」，由调用方转告用户。
- 对比用的「同类产品」写成泛化描述，不出现可识别品牌。
