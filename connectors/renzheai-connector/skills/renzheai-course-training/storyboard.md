# 课程培训 · 分镜细则

分镜师主指令里已有**平台机制 + 通用手艺**：拆镜规则、块结构、表演写作规范、跨镜衔接、时长与依赖校验。
**这一份只有教学视频特有的镜头口径。**

⛔ **本文说的「镜头」都是一个分镜之内的「镜头块」，不是分镜。一集拆成几个分镜只由主指令的时长分支决定**，本文没有任何一条能改变分镜数。
下面讲的节奏——快还是稳、先给什么后给什么——落在**分镜内部的镜头块怎么切**上，每块多长由你按节拍内容判断：
要让学员看清一个步骤，就让那个镜头块停得住，⛔ 不是把它拆成几个短分镜。

## 节奏：稳，跟着讲解走

- **画面跟着讲解词的步骤换**：讲到第几步，画面就停在第几步的动作上；讲解换下一步，镜头块才跟着换。
- **一个镜头块只演一个动作**：先看到手放上去、再看到按下去、再看到结果——别一块里连做三步，学员跟不上。
- **讲师讲解与示范交替**：讲师出镜说一句要点 → 切到示范画面演给你看 → 必要时回到讲师。⛔ 不要讲师一口气讲完再集中放演示。
- **结尾停住**：小结的镜头块给讲师正面、稳定的画面；有小结卡的，让它停得够学员看完。

## 步骤要看得清

- **操作类以近景、特写为主**：手和被操作的东西（按钮、阀门、扫码枪、单据）是主体，占满画面的主要位置。
- **先交代在哪、再进细节**：一个新场景先给一个中景或全景说清「这是收银台 / 这是配电柜」，然后再推到手上的动作。
- **同一套步骤机位一致**：一串连续步骤用同样的机位和角度拍，学员靠画面不变认出「还是同一个地方，进到下一步了」。
- **结果要拍出来**：每一步做完之后的状态（灯亮了、单子打出来了、阀门关上了）给一下，学员才知道自己做对了没有。

## 正误对比的构图

- **错误和正确两段用同一个构图**：同一个机位、同一个人、同一个场景，只有做法不同——差别才一眼可见。
- **错误的那一处要看得到**：没戴的手套、站错的位置、跳过的那一步，构图上让它处在画面显眼的位置。
- 错误段落可以略压暗或偏冷，正确段落恢复正常光；⛔ 不要用闪烁、红光爆闪这类刺眼的方式标「错」。

## 运镜

- **固定机位为主**，缓推进细节；教学画面要的是看清，不是好看。
- ⛔ 不要手持晃动、快速甩镜、频繁变焦——学员会跟丢正在看的那个东西。
- 讲师讲解的镜头块以正面中景为主，像面对面上课。

## 画面上的字

讲解词的字幕由后期剪辑配；⛔ 不要在 video prompt 里让视频模型写字（步骤编号、要点、按钮上的字写出来多半是乱码）。
小结卡、条款卡这类确实要上画面的字，只在素材清单里有对应的文字素材图时引用那张图；
软件界面、设备面板一律引用用户上传的截图 / 照片素材，没有截图就只写操作动作，不描述界面上的字。
