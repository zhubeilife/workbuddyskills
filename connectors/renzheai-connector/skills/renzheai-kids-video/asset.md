# 儿童视频 · 素材细则

主指令（素材师 skeleton）里只有平台机制。**每类素材怎么写在这里**；建哪些素材以剧本师的素材清单为准。

## 每类素材怎么写

| 类型 | 怎么写 |
| --- | --- |
| `character` | **核心素材**；造型一次定好 |
| `scene` | 背景简单，不堆杂物 |
| `prop` | 造型简单，一眼认得出 |
| `audio` | 旁白温柔、语速偏慢；角色音色贴合形象（小兔子用清亮的童声） |

## 主角素材是重中之重

- **一个让孩子记得住的样子**：颜色、造型、一个记忆点（红色背带裤、一只耷拉的耳朵）写清楚；
  系列视频每一集都按它生成，造型不能漂。
- **风格按项目的视觉风格来**：卡通、绘本、黏土、3D、真人都可以；⛔ 不要自作主张把真人改成卡通、或反过来。
- 用户传了主角的形象图（自己的 IP、绘本角色、孩子的照片），**以图为准**，不要自行想象外观。

## 气氛跟着故事走

用户没提时，角色和场景默认温和明亮。故事需要怪物、黑夜森林、暴风雨这类紧张的东西（勇气主题、万圣节、冒险），
**照清单写**，造型与气氛按故事要的分寸来——给孩子看的「紧张」是有点害怕、最后被化解，
⛔ 不做血腥、残缺、惊吓式特写这类画面。
