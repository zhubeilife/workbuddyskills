# 儿童视频 · 编剧细则

剧本师主指令里已有**平台机制 + 通用编剧手艺**：工具怎么调、产出形态、块 id 纪律、
台词法则、人设与配角格式、换皮重制、自检与合规。
**这一份只有给孩子看的视频特有的东西。**

## 一集只讲一件事

开场就让孩子知道「今天讲什么」，结尾回到这件事上收住。中途不岔出第二条线，不加大人才懂的梗。

## 故事骨架：熟悉 → 遇到一件事 → 试一试 → 解决 → 温暖收尾

| 段落 | 要做到 |
| --- | --- |
| **熟悉** | 主角出场打个招呼，在孩子熟悉的地方（家里、幼儿园、公园、森林小屋） |
| **遇到一件事** | 一个具体的小麻烦或小好奇：牙齿黑黑的、找不到妈妈、种子为什么不发芽 |
| **试一试** | 主角试了不止一次（**重复三次**最好记：第一次没成、第二次差一点、第三次成功） |
| **解决** | 靠自己想办法、或朋友 / 大人帮忙，解决方式是好的示范 |
| **温暖收尾** | 一句话点出这件事，然后安心地结束（睡前故事落在「晚安」上） |

儿歌和科普也照这个思路：儿歌 = 主歌讲一件事 + 副歌反复唱那一句；科普 = 一个「为什么」+ 一个孩子见过的类比 + 一个答案。

## 按年龄段写话

| 年龄段 | 句子 | 用词 | 情节 |
| --- | --- | --- | --- |
| 0~3 岁 | 极短，三五个字一句 | 名词、动作、拟声词（汪汪、哗啦啦） | 几乎没有情节，一个动作一个动作地重复 |
| 3~6 岁 | 短句，一句只说一件事 | 生活里见得到的东西，少抽象词 | 一个小麻烦 + 重复三次 + 解决 |
| 6~9 岁 | 可以稍长，能有因果 | 可以出现新词，但马上用画面解释 | 可以有一点小悬念和小反转 |

- **重复是好事**：关键句、口头禅、副歌要反复出现，孩子靠重复记住。
- **多用拟声词和问句**：「咚咚咚，是谁呀？」让孩子跟着说。
- **道理藏在故事里**：⛔ 不要在结尾长篇说教，一句话点到就够；更不要用「不听话就……」吓唬孩子。

## 内容安全（给孩子看的底线，与画面风格无关）

- **不教危险动作**：玩火、爬窗、独自下水、把小东西放进嘴里、乱吃药——孩子会模仿。
  故事真需要这类情节，只能以「这样很危险」的方式出现，并由大人制止或化解，⛔ 不能演成好玩的事。
- **紧张要被化解**：用户没提时故事默认温和；用户要的题材需要怪物、黑夜、冒险（勇气主题、万圣节），照写，
  紧张感最后一定被化解、结尾安心；⛔ 不写血腥、残忍、惊吓式的桥段。睡前故事全程平静。
- **不用暴力或羞辱解决问题**：不打骂、不嘲笑、不起外号，不拿外貌、身材、口音开玩笑。

## 素材清单列什么

- **主角是核心**，再加一两个朋友 / 家人；系列视频的主角**跨集复用**同一条，不每集重建。
  同一个主角的不同状态（睡衣版、雨衣版）各列一条变体，`variant_of` 回链。
- **场景 2~3 个够了**，宁少勿杂。
- **推动「那一件事」的关键物必列**（牙刷、小种子、雨伞、绘本）。
- **旁白与有台词的角色各列一条音色。**
- ⛔ 不列：画面上不出现、只在旁白里提到的东西。

## 什么不该做

- 不要写大人才懂的双关和反讽；
- 不要一集里讲两个道理；
- 不要让负面角色「赢」在结尾。
