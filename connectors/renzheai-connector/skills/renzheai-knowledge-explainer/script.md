# 知识科普 · 编剧细则

剧本师主指令里已有**平台机制 + 通用编剧手艺**：工具怎么调、产出形态、块 id 纪律、
台词法则、人设与配角格式、画面文字的四问、换皮重制、自检与合规。
**这一份只有讲清一个知识点特有的东西。**

## 一集只讲懂一件事

整集围着一个问题转：开头抛出来，结尾答干净。中途想到的相关知识（「顺便说一下……」）一律不岔出去，
留给下一集。判据：**看完的人能不能用一句话把答案讲给别人听**——讲不出来，就是塞多了。

## 骨架：钩子 → 类比 → 拆解 → 结论 + 一句带走的话

| 段落 | 占比 | 要做到 |
| --- | --- | --- |
| **钩子** | 前 10% | 一个反常识的问题或现象，让人想知道答案：「你每天喝的水，可能有一部分恐龙也喝过」。⛔ 不要从「大家好，今天给大家讲一下」起手 |
| **类比** | 20% | 用观众天天见的东西搭一座桥：电流像水流、免疫系统像保安。先让人「大概懂」 |
| **拆解** | 50% | 一步一步讲原理，每一步只多讲一层，**因为 A → 所以 B → 于是 C**，不跳步 |
| **结论** | 15% | 回到开头那个问题，用一句话正面回答 |
| **带走的话** | 最后 5% | 一句能记住、能转述的话，或一个生活里用得上的提示 |

系列有固定的开场 / 收尾口头禅时，放在钩子之后、带走的话之后，别让它挤掉钩子。

## 事实纪律（这类片子的生命线）

1. **不编造**：研究、实验、统计数字、专家说法、出处——用户资料里没有、又不是公认常识的，**一个都不写**。
   ⛔ 不写「哈佛研究发现」「据统计 80% 的人」这类凭空来的话。
2. **用户给了资料，以资料为准**：资料与常识冲突时照资料写，并在 summary 里点出冲突的那一处，由调用方转告用户。
3. **拿不准的说法要么删、要么审慎**：「一般认为」「多数情况下」「目前的主流解释是」；
   有争议的话题不下定论。⛔ 不要为了钩子更劲爆，把「可能」写成「一定」。
4. **类比要标边界**：类比只是帮人理解，在它会误导的地方补一句「但和水流不一样的是……」。
5. **健康 / 医疗 / 财经类**不给具体用药、剂量、投资建议；访谈约定了结尾提示就照写一句。
6. 缺关键数字时，不硬凑——写不依赖这个数的说法，并在 summary 里列出缺了什么，由调用方去问用户。

## 解说词怎么写

- **解说词是主线**：知识靠解说员（或出镜讲解人）念出来，画面负责演示。每一句都要能配一个画面。
- **一句只说一件事、句子要短**：长句子配音念出来就糊了，观众跟不上逻辑。
- **术语先给画面再给名字**：先讲「光在空气里被撞得四处乱跑」，再说「这叫散射」；术语一集里别超过两三个。
- **多用问句推进**：「那为什么傍晚又是红的？」——每一个问句就是下一步拆解的入口。
- **数字要能感知**：「38 万公里」不如「开车不停也要开半年」；要用数字就用一个，别连着报一串。
- **有出镜讲解人时**：讲解人对着镜头说是本品类的常态，照写；ta 的口吻在整个系列里保持一致。

## 关键概念与数据怎么上画面

照通用细则的「画面文字」四问走，本品类的落点是：

- 知识点里的数据、关键词、结论句，**一律先写成解说词**——念出来就够了，台词字幕由后期配。
- **必须被看见才讲得清的**（一个公式、一张结构示意图、一组对比数据、结论那一句的定格卡）才规划成文字素材，
  `asset_intent` 里列一行 `type='special'`，正文只写它怎么出现。一集里挑最关键的那一两张，不是每个知识点都做卡。
- 「数字一路涨上去」「曲线慢慢画出来」这种会动的图做不了：变化交给解说词和画面演示，需要的话只给终态那一张。

## 演示怎么写

拆解段里的每一步，都写一个**看得见的演示**：一杯水、一束光、一个实验、一个生活场景、一个放大的微观示意。
演示写在 `action` 块里，写观众要看清的东西（光穿过水杯后分成了几道颜色），⛔ 不写景别和镜头手法，怎么拍归分镜师。
抽象到拍不出来的概念（利率、熵）用生活场景演：存钱罐、乱掉的房间。

## 素材清单列什么

- **出镜讲解人**（有的话）是核心，系列**跨集复用**同一条，不每集重建；纯旁白就不列讲解人。
- **场景 2~3 个**：讲解人所在的固定空间（演播室 / 书房 / 实验台）+ 演示需要的一两个生活场景。
- **演示用的关键道具必列**：水杯、三棱镜、存钱罐这类推动讲解的东西。
- **文字素材**：上面「关键概念与数据怎么上画面」一节挑出的那一两张。
- **旁白（或讲解人）音色一条**：清晰、亲切、语速适中。
- ⛔ 不列：只在解说词里提到、画面上不出现的东西；用户没提供依据的图表与数据卡。

## 什么不该做

- 不要一集讲两个知识点；
- 不要堆术语显得专业；
- 不要为了反转编故事——知识本身的反常识就是钩子；
- 不要用「震惊」「99% 的人都不知道」这类标题党话术代替真正的问题。
