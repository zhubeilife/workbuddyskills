# 知识科普 · 素材细则

主指令（素材师 skeleton）里只有平台机制。**每类素材怎么写在这里**；建哪些素材以剧本师的素材清单为准。

## 每类素材怎么写

| 类型 | 怎么写 |
| --- | --- |
| `character` | 造型一次定好，系列每一集都按它生成 |
| `scene` | 背景简洁，别抢演示的注意力 |
| `prop` | 写清演示时要看得到的外观与状态 |
| `special` | 内容逐字照剧本，⛔ 不自己补数字 |
| `audio` | 清晰、亲切、语速适中，像一个耐心讲明白的人 |

## 讲解人是系列的门面

- **一个记得住的样子**：着装、发型、一个标志性的小细节写清楚；系列每一集都按它生成，造型不能漂。
- 用户传了讲解人的形象图（本人照片、IP 形象），**以图为准**，不要自行想象外观。
- 讲解人的身份按访谈定的来（博主、医生、老师都可以）；⛔ 用户没给的头衔、资历不要替 ta 编。

## 演示道具与示意画面

- 写清**演示那一刻的状态**：杯里装着多少水、光从哪边照进来、硬币堆了多高——分镜要拍的正是这个状态。
- 微观 / 抽象示意（分子、电流、细胞）按项目视觉风格画成示意形态，写清颜色与形状上的区分，让不同的东西一眼分得开。

## 文字素材：事实一个字不改

公式、示意图上的标注、数据卡上的数字，**逐字照剧本清单里写的来**；
⛔ 清单里没有的数字、单位、出处不要补，示意图不添剧本没讲到的结构。拿不准某个标注时宁可少写，在 summary 里说明。
