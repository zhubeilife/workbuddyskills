# 台词法则：信息前置 + 动作可视化

## 法则 1：信息前置，废话后置

视频台词是 **「功能性」** 的，首要任务是**传递信息、塑造冲突**——不是文学创作。
观众在几十秒到几分钟里只能接收有限信息，每句话都得干活。

### 三条铁律

**(1) 第一句必须抛核心**

人物开口的**第一句**必须包含以下之一：
- 身份（「我是张总的秘书」「我是这家公司的财务部长」）
- 冲突（「你凭什么动我女儿？」）
- 目标（「我今天就要让你滚出这个部门」）

**反例**（绕弯子）：
```
A：今天天气不错。
B：是啊，挺暖和的。
A：你最近怎么样？
B：还行吧。
A：我听说你要辞职了？  ← 第 5 句才进入冲突
```

**正例**（信息前置）：
```
A（嘲讽）：哟，听说你要辞职了？就你这样还能找到工作？  ← 第 1 句直接抛冲突
B（淡定）：不劳你费心。
```

### (2) 消灭一切「绕弯子」的对话

凡是不推进剧情 / 不暴露身份 / 不制造冲突 / 不提供必要信息的台词，**全部删掉**。

应当删除的典型台词：
- 寒暄（「你好」「最近怎么样」「天气真好」）
- 重复信息（角色 A 已经说过的事，角色 B 不要复述确认）
- 自我介绍式陈述（「我叫张三，今年 30 岁，是这家公司的部长」——身份用动作 / 制服 / 称呼暴露）
- 情绪宣泄式无信息独白（「天啊，怎么会这样，为什么是我」）

### (3) 潜台词动作化、行为化

不要让角色「直接说出心里想什么」——用动作 / 表情 / 微小细节代替。

**反例**：
```
张三（愤怒）：我心里非常生气，我感觉受到了极大的侮辱！
```

**正例**：
```
△ 张三脸色铁青，握紧拳头，指节发白。
张三（低声）：你最好祈祷我没听清。  ← 一句金句胜过 10 句"我很生气"
```

## 法则 2：动作可视化，写成看得见的动作

剧本是写给 **AI 视频生成模型** 看的「**说明书**」，每一句都要写成看得见的动作，必须用强视觉冲击力的「动作」代替无力的「形容词」。

### 两条铁律

**(1) 用动词代替形容词**

| ❌ 形容词描述 | ✅ 动词指令化 |
|------------|--------------|
| 「主角非常生气」 | 「主角猛地一拳砸在桌上，茶杯震碎」 |
| 「场景气氛紧张」 | 「时钟秒针一格一格跳动，每一格都像锤击；窗外乌云压顶」 |
| 「主角看起来很失望」 | 「主角的肩膀缓缓垂下，手中合同滑落到地上」 |

### (2) 指令化写作

每一条 △ 动作描写必须包含「**主体 + 关键动作 + 情绪/信息**」三件套：

| 元素 | 例子 |
|------|------|
| 主体 | 「张三」「反派」「监控录像画面」 |
| 关键动作 | 「猛地推开门」「眼神瞬间一冷」「画面定格」 |
| 情绪 / 信息 | 「愤怒地」「带着不易察觉的笑意」「手里攥着那张三年前的车票」 |

**反例**（文学化描写抢戏）：
```
△ 1990 年代的上海街头。夕阳染起梧桐叶，远处传来悠扬的口琴声。一辆老式黄包车缓缓驶过，车夫吆喝着古老的调子。
```
→ 这是散文，**不是可执行的画面动作**。AI 视频生成模型读不出可执行的画面。

**正例**（指令化）：
```
【上海街头 · 日 · 外】
△ 主角站在街角，手插风衣口袋，目光锁定对街黄包车。
△ 黄包车驶近 → 主角抬手 → 车夫拉停。
```
