# commit 前自检清单 + before/after 优化示例

## commit 前必勾自检清单

**调 `update_episode_script` 之前**，按以下清单**逐项**勾过——任何一项不通过就回去改，不允许带病提交：

> ⛔ **转录模式（用户给了成品剧本、按原文转录）只勾三组：D 块格式 / G 里 `asset_intent` 与 audio 那几条 / J 转录模式检查。**
> 其余各组（A 品类指标 / B 场景预算 / C 的念不完就砍 / E 经济检查 / F 人物格式 / H 的「已替换为虚构」/ I 的下集钩子）
> 都是给**创作**用的尺子，拿来量用户的原文只会得出「该改」的结论——而转录模式下**一个字都不许改**。
> 这些组里发现的问题（超时 / 踩合规红线 / 缺说话人）**只写进 summary 报出来，不动原文**。

### A. 品类细则里的自检项

- [ ] 你读的那份品类细则如果带自己的硬指标（结构档位、节奏模型、手法要求、收尾方式），**逐条过一遍**
- [ ] ⛔ 不要凭印象补一套自己的指标：细则里没写的不要发明，写了的一条都不要跳过

> 这一格刻意不写具体指标。它们随品类而异（这一类要的钩子密度，另一类压根不要钩子），
> 写死在这里就等于让所有品类照同一把尺子自检——而那把尺子只对其中一类是对的。

### B. 场景检查

- [ ] **场景数符合预算**：≤15s 默认 1 场（最多 2 场）；16-30s ≤3 场；每 +15s 预算 +1
- [ ] **每一次换景都满足白名单之一**：衔接动作（出画→入画运动连续）/ 叙事跳切（标题带闪回/回忆/梦境/想象标记）/ 时间跳跃（时间卡，已列进 `asset_intent` 文字素材）——逐个场景边界点一遍，**无理由硬切 = 不允许提交**

### C. 台词检查（核心硬指标）

- [ ] 心里按每句自己的选档语速（见「台词语速」章节，拿不准落标准档）念一遍全集台词，**台词估时 + 动作与留白时间和 `duration_sec` 对得上**：明显念不完 = 内容超了，明显还剩一大截 = 这一集写太瘦
- [ ] 念不完：**砍冗余字**（去掉「就是说」「然后」填充词）或 **砍次要节拍**；⛔ 不许改用更快的语速档硬塞
- [ ] 没有一句撞 6.5 字/秒红线（那是 TTS 物理上念不完的密度）
- [ ] 每句台词服务剧情：不水（不写"今天天气真好"）也不饿（该有的对话不要砍）
- [ ] **（换皮集）另按「换皮重制模式」一节末尾的「换皮集自检」清单补查**（台词映射确认卡那一条在那里）
- [ ] **（换皮集）句数严格相等**：新剧本台词总句数必须 = 台词映射确认卡上 `to` 非空的行数（你自己不许合并/拆分/增删；用户在卡上加的、清空的以卡为准）；不等 = 整集台词重写。不分题材，有拉片参考一律照此
- [ ] **（换皮集）专有名词换皮抽查**：随机取 5 句，确认原片的人名 / 店名 / 招式名 / 地名都换成了映射表的新名（**措辞可沿用原句、不强制改写**，但专有名词必须换皮）
- [ ] **（换皮集）字符数对齐抽查**：同样这 5 句逐句数字符——**按字符总数（含标点，与台词映射确认卡右上角的「N字符」同口径，不是只算发声字符）**，偏离原句超 ±2 字符的句子改到 ±2 以内，否则该镜装不下原片时间码
- [ ] **每句台词都建成 dialogue 块**：剧本里每出现一句人物台词，`content` 里就有一个 `type='dialogue'` 块（对着剧情逐句点一遍）；多人对话场的第 3 / 第 4 个说话人（圆场话）最易漏建块，重点核；每个块 `speaker` 填人名、`emotion` 与情绪一致（正文若写「拍胸脯，得意」则 emotion 就是「拍胸脯，得意」，不许只抄情绪丢动作）、`text` 只放台词原文（不带人名 / 情绪 / 冒号）

### D. 块格式检查

- [ ] 每个 `scene_heading` 块 text 严格为 `【地点 · 时间 · 内外】`（叙事跳切场加第 4 段标记，如 `【老宅院 · 日 · 外 · 闪回】`）；**不带 `###` 等任何 markdown 前缀**、没有编号 / 秒数 / 景别
- [ ] 每个 `action` 块 text 以 `△` 全角三角符开头，**一个动作一个块**
- [ ] 全文搜「特写」「近景」「中景」「全景」「远景」「慢镜」「快切」「推近」「镜头」：除了人物「对着镜头 / 看进镜头」这类直面观众的表演，一处都不留——改写成观众要看清的内容（见「铁律 4」）
- [ ] 每个 `dialogue` 块三字段拆开：人名进 `speaker`、情绪进 `emotion`、`text` 只有台词原文（不带人名 / 括号 / 冒号 / `△`）
- [ ] 任何块的 text 都是纯文本（无 `###` / `**` / 列表符等 markdown 符号）
- [ ] `content` 里没有「人物表 / 世界观 / 调性」这类非剧本块（会污染 storyboard 覆盖校验）
- [ ] **每一处「画面上有字」都走过四问**（见「画面文字」章节）：全文搜「字幕」「打出」「浮现」「显示」「屏幕上」「弹出」——不需要读懂的没写出字；能念出来的（含手机消息 / 合同 / 余额 / 片尾钩子）已是 `dialogue` 块；静止且必须被看见的，`action` 块只写怎么出现、`asset_intent` 里有对应的文字素材行；会动会变的字、「常驻」在角落或画面下沿的字没写进剧本（全文搜「常驻」「始终」「一直挂」；含设备上自己会变的数字：全文搜「跳到」「跳动」「滚动」「一秒一秒」「从…到」——变化已改由人报出来，只有要定格看清的终态才是文字素材）
- [ ] **没有矫枉过正**：写字 / 读信这类「字是动作一部分」的戏没被删；用户明确不要人声的片子没被硬塞解说词；没有画面文字需求的集，清单里没有凭空多出文字素材
- [ ] **（修订场景）块 id 纪律已守**：已先 `get_episode_script` 拿当前块数组；未改动块原样带原 id 传回、改动块沿用原 id、新增块不带 id、删除块不传；没有编造 id（详见「修订纪律」章节）

### E. AI 视频经济检查

- [ ] 每场都含「主体 + 关键动作 + 情绪/信息」三件套
- [ ] 没有纯环境空镜场次（无角色 / 无动作 / 无信息）
- [ ] 没有文学化散文描写（夕阳染梧桐叶式）

### F. 人物检查

- [ ] 所有有台词 / 推动剧情的配角都有名字（不是「官员」「马仔」「服务员甲」）
- [ ] 每个配角首次出场的 `action` 块都符合「[名字]（[身份]，[1 句辨识度]）」格式；台词块 `speaker` 只写名字
- [ ] 主角符合「标签化 + 极致化」（一句话能说清是哪种类型）
- [ ] 反派有明确的"功能"（不是为了反派而反派）

### G. 项目衔接检查

- [ ] 已调 `get_story_bible`，先看 `story_mode` 再勾下一条
- [ ] `story_mode='serial'`：本集开场按品类细则接住了上集 cliffhanger（首集除外）
- [ ] `story_mode='anthology'`：本集是**独立完整的故事**（自己的开头 / 冲突 / 结局），没有承接上集的字句、也没留跨集悬念钩子
- [ ] **收尾对上了 `finale_style`**：按品类细则里那张「怎么收尾」的表核对（`serial` 只作用于收官那一集，`anthology` 每一集都按它收）
- [ ] `asset_intent` 建条清单已建：正文点名的角色 / 场景 / 道具 / 特效各一行（列了就建）；群演 / 路人**一律**并入群像 prop（有没有台词都并入，不给群体立 character），正文没写的环境陈设没进清单
- [ ] **具名说话人都有对应 audio 条目**：列了 `character` 条目的说话人都在 `asset_intent` 里有一条 `type='audio'`（在场角色 → `<角色名>-音色`；画外解说员 / 播音员 / 旁白 → 各自独立一条，一集多个画外音互不合并）——逐个点一遍，漏了 = 缺音频，回去补
- [ ] **群体说话人没有音色条目**：看客群 / 众人 / 围观百姓这类集体说话人，`asset_intent` 里既没有 character 也没有 audio，只并进群像 prop——群体不是一个人、指定不了音色，给它建音色会让下游分镜把音色素材当画面参考引进来，整集视频卡住派不出去
- [ ] **文字素材没有顶替解说词**：卖点句 / 要点句 / 结论句都在 `dialogue` 块里（片子静音播放也一样写）；文字素材通常 0~3 张，超了逐张问一遍「它是个东西，还是在替谁说话」
- [ ] **文字素材行的 `reason` 写全了**：要上图的原文一字不差写在里面；现实里真实存在的信息（联系方式 / 二维码 / logo / 企业与客户名称 / 真人 / 产品）注明了「真实信息，需用户上传图片」
- [ ] **用户上传素材的硬要求两档已逐条点过**：`must_appear_in_script=true` 且本集首发的、以及任务描述点名的，每张都在 `content` 块里真的写到了且列进 `asset_intent`；其余 user_uploaded 按剧情需要取舍，**没有为了凑数硬塞的戏份**

### H. 合规检查

- [ ] 已对照「内容合规自检清单」章节逐条扫描
- [ ] 没有触碰红线（政治 / 暴力 / 软色情等）
- [ ] 灰区元素已做技巧性规避
- [ ] 剧情里第三方的商业敏感词（快递品牌 / 注册商标 / 真实人名 / 真实地址）已替换为虚构；用户自己的品牌、产品、人员和用户提供的真实信息照写

### I. 收尾检查

- [ ] `story_mode='serial'` 且不是终集：末尾留了下集钩子
- [ ] `summary` 字段已写，80 字内包含「主角 + 事件 + 结果」
- [ ] 准备一次性 commit：`update_episode_script` 一次传齐 summary + content（块数组）+ asset_intent

### J. 转录模式检查（仅转录模式勾；创作模式跳过）

- [ ] **台词逐字比对**：把 `content` 里每个 `dialogue` 块的 `text` 对着用户原文念一遍——一个字不多、一个字不少、没换近义词、没补语气词
- [ ] **句数与顺序**：台词句数 = 原文句数，先后顺序与原文一致；没有合并两句、没有拆开一句、没有挪位置
- [ ] **没有为压时长删句缩句**：台词估算超过 `duration_sec` 时原文照落，summary 里报两个数（估算约 X 秒 / 集时长 Y 秒）
- [ ] **合规只报不改**：踩红线的句子、真实品牌 / 人名 / 公司名**原样保留**，summary 里逐条点出「哪一句 / 踩了哪条」，由用户决定换不换
- [ ] **推断的说话人已报**：原文没写明谁说的台词，`speaker` 按上下文填了，并在 summary 里点出是哪一句
- [ ] **原文里的画面文字已分流**：与某句台词内容重复的字幕 / 说明文字没有做成画面（台词原样保留）；台词里没有的独立信息已规划成文字素材；summary 里报了各有几处
- [ ] `summary` 概述之后接了「按原文转录，原文有 N 处问题未改：① … ② …」或「按原文转录，未改动任何台词」

任何一项 ❌ → 不允许 commit，回去改。

## before/after 优化示例：「雀神争霸赛 EP3」反面案例

下面这段是**典型的"AI 摄制反例"**——7 处硬伤集中体现。把它改成符合本 prompt 规则的版本，能直观看到差距。

### ❌ Before（7 处硬伤）

```
△ （全景）冠军背影面对历届冠军合影墙，射灯冷光映照在深色木质墙面上。

△ （中景）VIP休息室门被猛地撞开，身着古代官服的官员踉跄冲入，看到冠军立刻跪拜。
**官员**（激动）：皇上！微臣终于找到您了！

△ （特写）冠军转身，眼神瞬间错愕，但迅速恢复威严。

△ （中景）官员从怀中掏出卷轴状"圣旨"，马仔从门外冲入拉扯官员。
**马仔**（慌乱）：这哪来的疯子！出去！
**官员**（挣扎）：皇上！臣有要事禀报！这是密旨！关乎社稷安危！

△ （中景）官员突然被一股无形力量拽向门外，冠军伸手欲抓却落空。

△ （特写）冠军若有所思的脸，眼神深邃。
**冠军**（画外音）：这到底是...
```

### 7 处硬伤标注

1. **第 1 段纯环境空镜浪费预算**：「射灯冷光映照在墙面」没有角色 / 没有动作 / 没有信息推进——这段视频生成约 ¥2-5，纯亏
2. **场次描写文学化抢戏**：「深色木质墙面」「眼神深邃」这种诗化描写对 AI 视频生成是噪声，浪费 token
3. **「冠军转身错愕」段落信息量为零**：整段只有 △ 且没有任何剧情推进——把"震惊"外化成一句「你叫我什么？」，一句话就把信息给出去了
4. **台词节奏不合理**：第 4 段约 2.5 秒塞 5 句台词 30+ 字，撞穿 6.5 字/秒红线，TTS 物理上念不完（按标准档念要 6-8 秒）
5. **人物功能化**：「官员」「马仔」无名无姓，工具人
6. **缺 `scene_heading` 块 + 脱主线**：没有 `【地点 · 时间 · 内外】` 场次标题块，分镜师无法绑定场景资产；玄幻穿越跟「雀神争霸赛」麻将主线零关联，没有承接上集 cliffhanger
7. **每段开头标景别**：「（全景）」「（中景）」「（特写）」是分镜师的活（见「铁律 4」）——删掉，想让观众看清的东西直接写进动作里

### ✅ After（修复全部 7 处）

⚠️ 注意：
- 速记展示，**一行 = 一个块**（落库按「示例速记约定」还原成 `content` 块数组）
- **2 个场景、3 个场景段、2 次换景**——主场景演到底，换景只有「闪回」叙事跳切这一处（切进、切回，白名单），场景数符合 15 秒场景预算
- **每场都按戏剧需要配多句台词**——台词驱动剧情，动作作为伴随表演

```
【VIP休息室 · 日 · 内】

△ 张万雀（30岁，西装，「金牌雀神」徽章）抚摸奖杯。

△ 门被踹开，老周（户部侍郎，瘦削三缕长须）扑通跪下。

老周（嘶哑）：皇上！臣找您八年了！

张万雀（皱眉）：你认错人了，老头。

老周（叩首）：臣不敢认错！陛下印记还在！

张万雀（瞳孔骤缩，低声）：你叫我什么？

【金銮殿 · 日 · 内 · 闪回】

△ 龙椅、金銮殿，张万雀身穿龙袍俯视群臣，画面一闪而过。

老周（os，颤抖）：江山危矣，请陛下回宫！

【VIP休息室 · 日 · 内】

△ 画面切回。老周展开泛黄圣旨，双手颤抖。

△ 张万雀缓缓起身，捡起飘落脚边的圣旨。

张万雀（眼神骤变）：朕……回来了。
```

### After 修复对照表

| 原硬伤 | 修复方式 |
|------|---------|
| 纯环境空镜 | 改成「主角抚摸奖杯」+ 配角踹门入场 + 老周台词「皇上！臣找您八年了！」—— 三件套齐全 |
| 文学化描写 | 砍掉「射灯冷光」「眼神深邃」，改成可执行的动作指令 |
| 「冠军错愕」段落信息量为零 | 改成台词主导「你叫我什么？」+ 闪回画面 + 老周台词，一句话把信息交代出去 |
| 台词节奏不合理 | 全集 6 个 dialogue 块约 60 字，标准档语速约 13 秒，加动作留白铺满 15 秒 |
| 人物功能化 | 「官员」→「老周（户部侍郎，瘦削三缕长须）」；「马仔」→「李三」类有名有姓角色（本版收进保安线可省则省） |
| 缺 `scene_heading` 块 + 脱主线 | 补 `【地点 · 时间 · 内外】` 场次标题块；唯一换景用「闪回」标记走白名单；保留奖杯 + 金牌雀神身份呼应「雀神争霸赛」主线 |

合计：15 秒、2 个场景、3 个场景段、2 次白名单换景（闪回切进、切回）；台词句数按戏剧需要决定；动作作为台词的伴随表演；所有出场人物有名字 + 身份 + 辨识度；接住了「张万雀实为失踪皇帝」的伏笔。**这才是合格的 AI 摄制脚本**。
