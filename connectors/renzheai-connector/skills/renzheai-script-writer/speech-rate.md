# 台词语速（三档）

台词念多快是**物理事实**，不是创作判断——同一句话按不同情绪念出来，出口时长能差一倍。三档语速是估时用的尺子，不是对内容的限制。

## 三档

| 档位 | 语速 | 什么时候用 |
|---|---|---|
| 紧凑 | 6-6.5 字/秒 | 争吵、逼问、追逐、抢白——语速本身就是戏的一部分 |
| 标准 | 4-5 字/秒 | 日常对话、平稳叙事、信息交代 |
| 舒缓 | 3 字/秒 | 独白、抒情、临终托付、强调金句 |

⭐ **逐句选档，拿不准就落标准档。** 同一场戏里不同的句子可以走不同档位——逼问用紧凑、回答用舒缓，那本身就是节奏设计。

## 这三个数字含什么、不含什么

**含句内的正常换气与语气停顿。** 4-5 字/秒 就是一个人自然说话的速度，不是「不喘气地念」的速度。⛔ **不要在选好档之后再叠一层「停顿预算」**——那是重复计算，估出来的时长会膨得离谱。

**不含剧情性的长停顿。** 沉默对视、欲言又止、情绪转折前的留白、听完之后的反应镜头——这些是**画面时间，不是台词时间**，单独计进动作时长，不要摊进语速里。

## 保底：时间必须容得下台词

台词念不完会被截断。任何一段台词所在的时间段：

```
可用秒数 ≥ 台词字数 ÷ 该句选档语速 + 该段的动作与留白时间
```

这是**下限，不是目标**——算出来至少 6 秒，就不能只给 5 秒；觉得这段需要更从容，给更多秒数是正当的。

⛔ **红线 6.5 字/秒**。一段台词的 `字数 ÷ 可用秒数 > 6.5` 时，TTS 物理上念不完：实测表现是抢在窗口边缘念完（听感急促失真），再紧一点会**整句丢弃**——而且接口返回成功、不报任何错，事后才发现这句没声音。撞上红线只有两条路：给更多秒数，或者把这句台词写短。
