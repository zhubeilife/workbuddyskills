# 人设容器 + 配角硬格式

## 核心理论：人设即容器

**观众在这么短的篇幅里记不住复杂人物**，只记**标签 + 极致化**。把人物当作"情绪容器"——容器形状越简单、辨识度越高，观众越容易投射情感。

### 主角设计：标签化 + 极致化

**标签化**：主角必须有 1-2 个核心标签，一句话能说清。

| 类型 | 标签例子 |
|------|--------|
| 都市逆袭 | 装穷大佬 / 隐藏富婆 / 王者归来 |
| 复仇爽剧 | 复仇女王 / 重生归来 / 八年磨剑 |
| 甜宠 | 高冷总裁 / 傲娇千金 / 暖男小奶狗 |
| 古装 | 扮猪吃虎 / 庶女逆袭 / 隐世大佬 |
| 悬疑 | 法医天才 / 通灵神探 / 心理猎手 |

**极致化**：标签里的特质要打到**满分**。
- ❌「比较低调的隐藏大佬」→ 模糊
- ✅「连服务员制服都穿了，每天给前妻倒水擦桌子」→ 极致

### 主角弧的 1 句话

每个主角在 story_bible 里应该有 1 句话弧线，描述「从 X 状态变成 Y 状态」。

例子：
- 「林浅：从被逼离婚的小白花 → 揭开自己 X 集团董事长身份的反杀者」
- 「叶青云：从师门被灭的孤胆剑客 → 复仇与爱情两难、最终归隐山林的侠客」

本集剧本要**承担这条弧线的一段位移**——不是停留在原状态。

## 主角小传 5 件套（写本集前必备，不持久化）

每个核心人物，在你内部「思考脚手架」里列出：

| 字段 | 内容要求 |
|------|--------|
| **视觉形象** | 外貌 + 穿着 + 关键标记物（如：「30 多岁，刚毅沧桑，破旧棉袄 + 毡笠 + 花枪 + 酒葫芦」） |
| **身份背景** | 1 句话（如：「前八十万禁军教头，现沧州囚犯」） |
| **核心标签** | 1-2 个（如：「隐忍不发 / 悲情英雄 / 杀神降临」） |
| **性格特点** | 1 句话（如：「原本委曲求全，被逼入绝境后展现极强爆发力」） |
| **金句 / 招牌动作** | 1 句台词或 1 个动作（如：「这世道，逼好人做鬼！」/ 「拔枪前先擦剑」） |

写本集时，**核心人物的台词、动作、反应都要从这 5 件套里推导**——确保人物形象统一、有辨识度。

## 配角硬格式：禁「功能名」

### 严禁

「官员」「马仔」「服务员甲」「路人乙」「秘书 A」「保安 B」——所有**抽象功能名**禁止用作配角名字。

这种命名表明你在「为了推剧情而塞工具人」，不是在塑造真实人物。**真实配角必须有名字 + 身份 + 1 句辨识度**。

### 硬格式

每个配角第一次出场，必须按以下格式介绍：

```
[名字]（[身份]，[1 句辨识度：外型/口头禅/招牌动作]）
```

硬格式只写在该角色**首次出场的 `action` 块**里；台词块的 `speaker` 只写名字，⛔ 不放身份描述。

**对比**：

| ❌ 反例 | ✅ 正例 |
|--------|--------|
| 「官员（激动）：皇上！臣有要事禀报！」 | 「△ 老周（户部侍郎，瘦削，三缕长须，说话总带一声咳）扑通跪下。」+「老周（激动）：皇上！臣有要事禀报！」 |
| 「马仔（慌乱）：这哪来的疯子！」 | 「△ 李三（保镖队长，光头，左耳一枚银钉，习惯用粤语骂人）冲上前拦住。」+「李三（慌乱）：边度嚟嘅疯子？！」 |
| 「服务员甲走过来倒水」 | 「小颜（21 岁实习生，扎马尾，胸前有名牌，端盘子总是双手）走过来倒水」 |

### 例外

仅在「**一闪而过、不开口、不影响剧情**」的极次要人物可用功能名（如「△ 两个保安守在门口」）。**但凡有台词或推动剧情，必须有名字 + 1 句辨识度**——群体说话人（众人 / 围观百姓）与画外声源（画外解说员 / 播音员）除外，照常用称呼或声源名。

## 反派设计：明写「功能」防功能化

### 为什么反派常常写得功能化？

写作者把反派当成"推剧情的工具"——任务完成就消失。结果反派**没有动机、没有方法论、没有失败回路**，只是「为了挨打而存在」。

### 解药：给反派明写「功能」字段

每个反派（你内部思考脚手架）必带：

| 字段 | 例子（陆谦 · 林冲反派） |
|------|---------------------|
| **视觉形象** | 尖嘴猴腮，富贵锦衣，斗篷 |
| **身份背景** | 高太尉心腹，林冲昔日「好友」 |
| **核心标签** | 卖友求荣 / 阴险小人 |
| **功能（明写！）** | 激化矛盾，充当复仇祭品 |

「**功能**」字段写明白后，作者会**自然限制自己**——不会让反派戏份膨胀、不会让反派抢主角光环、不会塞超出剧情功能的多余戏。

### 反派三原则

1. **动机要足够**：不能为了反派而反派。给一个具体原因（嫉妒 / 利益 / 背景）。
2. **方法论要专一**：每个反派有一种擅长的压制手段（**身份压 / 能力压 / 情感压 / 尊严压 / 困境堆**——5 选 1）。不要 5 种都用。
3. **失败方式要解气**：反派的败局必须呼应他的方法论。例如靠「身份压制」的反派，败在主角隐藏身份揭晓。

## 角色出场的 5 秒法则

每个角色**出场后 5 秒内**，观众必须能记住他的「**身份 + 立场**」。手段：

- **称呼**：另一人对他喊「李总」「老周」「张主任」（用别人的嘴定身份）
- **制服 / 道具**：警服 / 西装 / 旗袍 / 工牌 / 名牌包（视觉直接定身份）
- **第一句台词**：直接抛立场（「我今天就是来找你算账的」）
- **招牌动作**：拔枪 / 划火柴 / 摇酒杯 / 转钥匙（视觉记忆点）

四选 1 即可，不要全堆。**5 秒内做不到 = 配角失败**。
