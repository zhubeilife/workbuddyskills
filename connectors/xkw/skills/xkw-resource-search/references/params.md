## 公共搜索参数

七个资源搜索工具沿用以下公共字段；分类与场景的按工具差异，见 [调用速查](quickref.md#直接调用示例)。

| 字段                              | 用法                                                                                                                                                                |
| ------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `keywords`                      | 标题关键词，可选；服务允许关键词和结构化条件都省略，不等于能搜索全文                                                                                                                                |
| `size`                          | MCP 资源搜索单次最多 20 条，超过 20 会返回参数错误。Skill 未获数量要求时传 5；用户指定 1～20 条时按要求传入，超过时说明限制并先查最多 20 条。服务对省略、0 或负数仍默认 10。实际数量取决于命中数，只查第一页，无资源分页参数；不影响 `searchMetadata` 最大每页 100 的规则 |
| `grade` / `gradeId`             | 年级名称或真实编号；同一个年级 ID 可以在多个学段候选中出现                                                                                                                                   |
| `textbookVersion` / `versionId` | 教材版本名称或真实编号；同名时结合年级、课程等确认                                                                                                                                         |
| `textbook` / `textbookId`       | 教材或册次名称、真实编号；必须能唯一确定                                                                                                                                              |
| `chapter` / `catalogId`         | 章节名称或目录编号；必须能确定所属教材，只查当前章节节点                                                                                                                                      |
| `courseId` / `subjectId`        | 已知业务编号，不凭课程或学科名称猜值                                                                                                                                                |
| `knowledgePointId`              | 筛包含该知识点的整份资源，不查询单题                                                                                                                                                |
| `typeId`                        | 字符串，必须使用真实分类。专项工具不能改变固定范围；`resource` 可指定分类，省略时不限制资料类型                                                                                                             |
| `includeSubtypes`               | 通常省略。`resource` 设为真时必须提供 `typeId`，查询该分类及全部子类；试卷、课件工具设为真时必须同时提供允许的父分类；学案、作业工具始终包含全部子类                                                                              |
| `hasAnswer` / `hasExplanation`  | 只在用户明确要求有无答案、解析时传入；只是筛选标记，不返回正文                                                                                                                                   |
| `scenario`                      | 课件：1 课件、2 教案、3 两者；试卷、真题、模拟卷：1 中考、2 高考、3 两者，试卷需部署新增版本；未传或其他值不增加场景筛选。学案、作业、通用检索不使用该字段                                                                               |

名称和对应 ID 同时传入时，服务会校验一致性。不能把用户明确的年级、版本、章节限定只写在关键词中，也不能在出错后静默去掉这些限定。

## 筛选候选：searchMetadata

建议开放，用于查真实年级、版本、教材、章节或分类编号。它是辅助工具，不是每次搜索的必经步骤；简单关键词搜索或已知真实 ID 时直接调用搜索工具即可。完整名称能够唯一匹配时，也可以直接使用搜索工具的名称字段。

需要精确选教材或章节、名称有歧义、服务提示候选不唯一时再调用。`kind` 只能为 `年级`、`教材版本`、`教材`、`章节`、`资料类型`；`name` 是包含匹配，不能把任一同名候选直接当作唯一选择。

| kind | 其他可用条件                                                         |
| ---- | -------------------------------------------------------------- |
| 年级   | `gradeId`                                                      |
| 教材版本 | `gradeId`、`courseId`、`versionId`、`textbookId`                  |
| 教材   | `gradeId`、`courseId`、`versionId`、`textbookId`                  |
| 章节   | `textbookId` 必填，可加 `gradeId`、`courseId`、`versionId`、`parentId` |
| 资料类型 | `courseId`、`parentId`                                          |

所有候选查询支持 `name`、`page`、`size`。`page` 默认 1，`size` 默认 20、范围 1 到 100。章节不传 `parentId` 时查教材全部目录节点，传入后只查直接子节点。资料类型查询用于核对分类和选择通用检索的 `typeId`；有分类候选不代表该分类一定有资源命中。

### 结构化查询示例

用户要求八年级下册、人教版、“浮力”章节的课件，先确定年级、版本和教材。已有真实候选时复用，不重复查询。以下 801、901、1001、3001 均为演示编号，正式调用必须替换为真实返回值。

```json
{"name":"searchMetadata","arguments":{"requestDto":{"kind":"年级","name":"八年级"}}}
```

确认年级后查版本；仍有多个学科或版本候选时结合用户已知条件继续确定，不默认选第一项：

```json
{"name":"searchMetadata","arguments":{"requestDto":{"kind":"教材版本","name":"人教版","gradeId":801}}}
```

```json
{"name":"searchMetadata","arguments":{"requestDto":{"kind":"教材","name":"八年级下册","gradeId":801,"versionId":901}}}
```

确认教材后查章节：

```json
{"name":"searchMetadata","arguments":{"requestDto":{"kind":"章节","name":"浮力","textbookId":1001}}}
```

选定章节后调用课件工具：

```json
{"name":"courseware","arguments":{"requestDto":{"keywords":"浮力","scenario":1,"gradeId":801,"versionId":901,"textbookId":1001,"catalogId":3001,"size":5}}}
```

候选业务结果示例：

```json
{"kind":"章节","page":1,"size":20,"total":1,"hasMore":false,"items":[{"id":"3001","name":"浮力","parentId":"3000","textbookId":1001,"versionId":901,"gradeId":801,"courseId":2001}]}
```

这个对象没有 `code`、`data` 外层。`hasMore=true` 时按需继续翻页，不能认定当前页已覆盖全部候选。`items[].id` 是字符串，填入 `gradeId`、`versionId`、`textbookId`、`catalogId` 时转换为数值；资源分类 `typeId` 保留字符串。

候选中的 `description`、`versionName`、`gradeName` 等可帮助识别教材，仅使用实际返回字段。年级可能跨学段重复，但相同 `gradeId` 是同一个年级筛选值。当前工具没有学科、课程、知识点名称字典，不根据编号编造名称，也不根据名称编造编号。

## 学案和作业分类边界

原备份中记录的分类如下，实际归属和适用课程以实时 `searchMetadata` 为准：

| 分类        | 已知子类                                                     | 本次查询方式                                                |
| --------- | -------------------------------------------------------- | ----------------------------------------------------- |
| 学案 `4103` | 导学案 `410301`、学习任务单 `410302`、知识清单 `410303`、实验报告单 `410304` | `studyGuide` 查整个分支；`resource` 精确查指定子类                 |
| 作业 `4104` | 同步练 `410401`、单元卷 `410402`                                | `assignment` 查整个分支；`resource` 精确查指定子类                 |
| 题集 `4106` | 试题汇编 `410601`、专项训练 `410602`、综合训练 `410603`                | `resource` 查指定子类，或用父类编号及 `includeSubtypes=true` 查整个分支 |

可查询学案的直接子类来了解分类：

```json
{"name":"searchMetadata","arguments":{"requestDto":{"kind":"资料类型","parentId":"4103","size":100}}}
```

这不会使 `studyGuide` 支持子类 ID 精确筛选。只要学习任务单等某个子类时，将确认的分类编号传给 `resource`，按实际返回核对 `typeIdV4`。实验报告单等分类可能有课程限制，查看候选 `courseIds`，不假定所有课程可用。

`assignment` 不包含题集三类。用户明确要求覆盖产品所说的全部五种作业内容时，分别调用 `assignment` 和 `resource`（`typeId="4106"`、`includeSubtypes=true`），保持相同的关键词、年级等条件，再按 `documentId` 去重。不能把题集归属改成作业，也不能声称单个 `assignment` 已覆盖全部。
