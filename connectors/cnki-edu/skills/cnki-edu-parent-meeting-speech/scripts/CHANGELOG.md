## check_tone.py — 语气红线检查器（12 类规则）

当前 **v1.6**。

### v1.1 — 两项修正

1. **加否定语境排除**：「不点名批评」「不公布排名」等**正确写法**（在讲规则、在声明不会做）不再误报。
2. **加真实姓名点名检测**：`姓氏 + 名 + 负面词`。修复 v1.0 只认 `某某某` 占位符、对**真实姓名 100% 漏检**的缺陷。

### v1.2 — 修一处误报

否定判定**限同一句读**。此前「我们班考得不好，张三这次退步很大」里的"不好"会误把姓名点名压掉——否定词跨句生效，导致真阳被吞。

### v1.3 — 新增两类机制

1. **「元话语免责」类**：扫描"边界写在自己态度上"的句子——`我不做评价 / 我不私下定性 / 我不站队 / 我只说我看到的事实`。与「施压绑架」同为**否定式规则、不做否定排除**。
2. **「反例说明区豁免」**：话术卡中【不宜说】等**引用反例的说明区块**会引用红线原句作反面示例，整块跳过检测，否则反例引用会被误判为真实违规。

⚠️ **区块标记必须是中文方头括号 `【不宜说】`**；写成「不宜说」或 `━━ 不宜说 ━━` 时豁免不生效，反例会被当成真实违规。

### v1.4 — 修一处误报（姓名检测把"周"当姓氏）

实测误命中：「三次作业没交，分别是上周二、上周四和上周五」（命中"周四和"）、「这两周总不交」（命中"周总"）、「王五上周也迟到」（命中"周也"）。

修法三条：

1. 前一字为**时间修饰字**（上/下/本/这/那/每/数字）时，"周"不作姓氏；
2. 名字**不以虚字收尾**（和 / 或 / 与 / 的）；
3. 姓名扫描改为**允许重叠的手动扫描**（被否掉的位置只前进 1 字），以保住「这周周明退步了」里的真名"周明"。

### v1.5 — 补「请家长配合」高发区 + 收紧两处误报

**补齐（此前全部漏检）**：

- 原「施压绑架」只认 `务必管好 / 必须管好`，而「请家长务必督促」「请家长必须配合、尽快回复确认」「不要什么都交给学校」「家长也有责任」四类全漏——这正是家长最容易读成"老师在给我派活 / 甩锅"的地带。
  - 判定：`务必 / 必须 + 施压动词`须落在**对家长的呼求**里；`尽快 + 动作`须锚定在**小句开头**且该句不含"我 / 学校 / 老师"。
- 原「违规负担」只认"家长批改作业"紧邻写法，「请家长检查并批改一遍作业」漏检 → 放宽为 `家长…批改…作业`（仍要求出现"批改"，故不误伤"请家长看一眼作业本、签个字"）。

**收紧误报两处**：

- 「这个转变，初三必须完成」——讲学习转变，非施压。
- 「正常进行，不制止、不评论」——风险预案里的处置动作，非元话语（v1.3 遗留，历史 14 份稿件实测误报 2 处）。

**v1.5 回归**：新阳集 7/7 命中；三组阴集（含教师自述"我会尽快回复您"）均 0 命中；两份演示样例 0 命中；演示用违规草稿 9 → 11 处（新增"务必配合""尽快回复"两处真阳）；**14 份历史 docx 全部 0 命中**。

### v1.6 — 补四类真实盲区

1. **「绝对承诺」此前零覆盖**：原规则只认 `保证 + 成绩/分数/升学`，而「我保证以后不会再发生」「我承诺不会再出现」（冲突 / 安全类高发句）完全漏检 → 补 `(保证|承诺) + 不再/不会/不出现`。
   - 实现上新增 `SEG_NEG_EXEMPT_CATS`，**只豁免"片段内部否定"这一半，左侧窗口否定照旧生效**，故「我不能保证分数」（诚实表述）仍不报、「我保证不会再有下次」正常报。
2. **位次泄漏**：原「隐私泄露」只认"点名批评 / 某某某成绩 / 成绩排名"，「他这次掉到班里后十名了」「排到班里倒数第五了」漏检 → 补 `倒数第X / 后十名 / 排名第X`（**未收**裸词"名次 / 位次"，否则"不看重名次"会被误伤）。
3. **推给家庭**：`redlines.md` §4 标题早已含"不把责任推给家庭"，脚本此前未覆盖 → 补「你们在家是不是没管他」「你们家长平时是怎么管的」「孩子是自己的，家长得多上心」（窗口含中文冒号，否则「各位家长：不管多忙…」会误报）。
4. **人格否定**补「太笨了 / 太蠢了」。

**v1.6 回归**：新阳集 9 处命中（覆盖上述 8 类新场景）；四组阴集（含"我保证会跟您保持联系""我不能保证分数""各位家长：不管多忙"）均 0；五份演示样例 0；演示用违规草稿 11 → 13 处；**15 份历史 docx 仍全部 0 命中**。

## check_structure.py — 发言稿结构校验器

检查 §2 段（班情通报 / 学科学情概览）**段末是否有收口总结句**，检测「以第 X 件事直接收尾」等违规模式，并核对字数预算。
**D 项（提示级）**：开场钩子是否回收；「回到开头那句话」的被引内容是否真在开场，防悬空引用。

用法：`python check_structure.py <文本文件> --role <班主任|学科老师|兼任>`

> 设置 D 项的由来：§2 收口句曾只写在 `speech-roles.md` 正文里，**无脚本、无必跑项，等于软规则**——历史稿件实测 **7/12 份未收口**。

## check_policy.py — 政策数据来源校验器

扫描「涉及政策但缺来源」的句子（政策数值 / 规定性表述而无依据）。
认定来源只认：**文件名 / 文号 / 学校通知·规定 / 以…为准**，或占位标记 `<待核：…>` / `〔政策待核〕`。

用法：`python check_policy.py <文本文件>`（支持 .txt/.md/.docx）

> 由来：历史稿件实测 **8 份中 7 份**含"政策数值但无来源"（如"教育部要求不超过 90 分钟""课标要求 145 万字"）。政策数值易过期、各地口径不同，凭记忆写出即等于给用户埋错。

## check_advice.py — 建议依据校验器

扫描**请求句**中的高危领域词（作息睡眠 / 情绪心理 / 家庭因素 / 身体健康 / 电子产品 / 通用套话），若该领域词之前的文本里**找不到已确立的观察表述**（附近带"如果 / 是否 / 了解一下"等假设·询问标记的不算），即报「建议脱离事实」。

用法：`python check_advice.py <文本文件>`

> **命中需逐条人工确认，不是自动判违规。** 脚本查短语、人工查对应关系，两者不可互相替代：脚本会因"领域词附近出现观察词"而放行，也可能对确有依据的建议误报。

## check_docx.py — docx 结构校验器

XML 可解析 / 标签平衡 / **表格四项**（`tblW == ΣtcW`、`tblBorders` 存在、`tblStyle` 有效、`tblPr` 成对）/ **D 项 内部块零残留** / **E 项 标题零写作说明**。

用法：`python check_docx.py <文件.docx>`

> 由来：XML 非法的 docx，Word / Tencent Docs 会**静默容错打开**，肉眼难察觉，但表格会错乱或无边框。"能打开"不等于"结构正确"。
> **D 项由来**：曾把"带【沟通要素头】的整份 markdown"直接交给 Word 生成流程，把回复专用的四要素行原样印进三份讲稿（同批另两份干净，纯属当时写法不一致）→ 改为"规则 + 脚本"双保险。
> **E 项由来**：交付稿出现「第 7 页｜数据怎么看（三个口径）」——该页正文本就是三条口径，标题再标一次属"给写作者看的东西"漏进交付物，与【沟通要素头】同源。
> `【待补信息】` 与 `【0 时间分配总览】` 属交付内容，**不列入 D 项**。

## check_meta.py — 元信息泄漏检查器

扫描**待发出的回复草案 / 交付文本**，三级判定：

| 级别 | 内容 | 处理 |
|---|---|---|
| **P0** | 块名：红线自检 / 政策来源核对 / **质量自检** / 自检摘要 / 自检结果 / 元信息泄漏 / 内部执行项 | 必须删 |
| **P1** | 结论句与残留："N 命中""已检出""校验通过""无缺漏""tblW／列宽和一致""已修正 N 处""身份指向自查""建议依据核查""已跑""复检"；脚本自身输出格式 `[通过]`／`[不通过]`／`[跳过]`；模板残留词"占位符""写作要求""📌" | 必须删 |
| **P2** | 字数 / 时长类（"正文 N 字""朗读测算""字/分钟"） | 属 §6 白名单内的**控时说明，默认保留**，脚本仅提示、不影响通过 |

另单独标出**声明式前缀**（内部执行 / 不单独展示 / 不对外），提示**前缀不豁免**。

用法：`python check_meta.py <回复草案文件>`；用户明确索要自检结果时加 `--user-requested` 跳过；`--json` 供管道用。

⚠️ **只对待发出的回复 / 交付稿跑**，不要对 skill 自身文档跑（SKILL.md、redlines.md、本脚本为讲清规则必然包含这些词，会全量误报）。脚本输出同属内部动作，不写入回复。

> 由来（v1.7 扩充）：实测出现"**先声明不展示、随后仍逐项列结论**"——「质量自检（内部执行，按您上一条要求不再单独展示）：语气红线 0 命中、建议依据 0 命中、§2 收口句已检出、政策来源无缺漏、docx 结构校验通过（3 表 tblW 与列宽和一致）」。**挂前缀不豁免**：声明"内部""不展示"不改变"已输出"这一事实。
