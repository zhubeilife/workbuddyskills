# 发言稿 · 角色策略矩阵与结构模板

本文件是「班主任 / 学科老师双角色」家长会发言稿的核心策略层。**成稿前必须先在此锁定角色。**

---

## 一、角色判定细则

### 1.1 判定顺序（短路判定）

按下列顺序判定，一旦命中即停止：

> **三条来源是并列的，命中任一即为已确定角色，不得再开面板"确认"**；只有三条全部无信号才进入 1.3 询问。**附件 / 上传文件中的记载、同一工作区已有同类成稿里的角色口径，视同命中 ①/③**，不得以"不是用户亲口说的"为由降级为待确认（见 SKILL.md §5.3.1）。

| 顺序 | 判定来源 | 命中信号 | 判定结果 |
|---|---|---|---|
| ① | 用户显式声明 | "我是班主任" / "我是语文老师" / "我带班又教数学" | 直接采用，不再追问 |
| ② | 会议性质 | 面向全班家长的班会式家长会 | 班主任 |
| ② | 会议性质 | 面向本学科的学科家长会 | 学科老师 |
| ③ | 数据口径 | 全班全科综合数据（出勤、纪律、各科汇总） | 班主任 |
| ③ | 数据口径 | 单科成绩 / 作业 / 课堂数据 | 学科老师 |

### 1.2 冲突处理

- ① 与 ②/③ 冲突 → 以 ① 为准。
- ② 与 ③ 冲突 → 以 ② 为准，并在成稿时向用户说明所选角色。
- 显式声明为"兼任" → 走兼任模式（见第四节）。

### 1.3 无法判断时（强制询问）

三种来源均无信号时，**必须主动询问，不得默认**。推荐问法：

> 「这份发言稿是您以班主任身份面向全班家长，还是以某学科老师身份讲本学科？如果两者兼有，也请告诉我主次。」

若用户回答模糊，再补一问：

> 「那这次发言的主线是班级整体情况，还是某一个学科？我会按主线来组织内容。」

### 1.4 常见歧义场景

| 场景 | 处理 |
|---|---|
| 班主任兼某学科老师，只开一场家长会 | 兼任模式：班主任主干 + 学科专区 |
| 学科老师受邀在班主任家长会上讲 10 分钟 | 学科老师模式，时长按短时压缩（见 5.3） |
| 用户只说"家长会发言稿"未提角色 | 强制询问（见 1.3） |
| 用户提供的是**全班各科汇总表 / 全班成绩单** | 命中 ③ **即确定为班主任**，**直接采用、不再确认**（成稿时一句说明依据即可，见 `routing.md` §2.3） |
| 用户提供的是一份**单科**成绩 / 作业 / 课堂数据 | 命中 ③ **即确定为学科老师**，直接采用、不再确认 |

> ⚠️ **本表与 1.1 的关系**：1.1 已定"三条来源命中任一即为已确定角色"；本表**不得出现"默认倾向…但仍需确认"这类降级表述**——那是 v1.2 及更早的旧口径，会让 agent 把已知角色重新问一遍（典型违规见 `SKILL.md` §5.3.1）。

## 二、角色策略矩阵（完整版）

| 维度 | 班主任 | 学科老师 |
|---|---|---|
| 身份定位 | 班级管理者 + 家校共育枢纽 | 学科教学专家 |
| 核心目标 | 统一家校共育节奏、营造班级氛围 | 让家长理解本学科、会配合本学科 |
| 发言重心 | 班级整体氛围、班风班貌、共性问题、家校共育节奏 | 学科核心素养、本学科学情、作业与家庭辅导方法 |
| 第 2 段 | 班情通报（强化） | 学科学情概览（替换） |
| 第 3 段口径 | 全班全科整体 + 各科协同诊断 | 单科：均分、分数段、易错点、典型错误归因 |
| 数据来源 | 班级综合数据（出勤、纪律、各科汇总） | 本学科考试 / 作业 / 课堂表现数据 |
| 家庭建议方向 | 学习习惯、作息管理、亲子沟通、家校共育节奏 | 学科预习复习法、错题整理、记忆/计算/审题专项、辅导误区 |
| 典型问题类型 | 班级共性：纪律、手机、心理、集体意识 | 学科问题：不背单词、计算粗心、不会审题、畏难 |
| 时间分配 | 开场 5% / 班情 20% / 学情 30% / 家教 30% / Q&A+结束 15% | 开场 5% / 学科学情 40% / 学科方法 35% / 家教配合 15% / Q&A+结束 15% |
| Q&A 侧重 | 班级管理、心理健康、升学政策〔政策待核：涉政策数值须有依据〕 | 学科提分、作业量〔政策待核〕、辅导方法、考试技巧 |
| 语气基调 | 全局视角、统筹感、共育感 | 专业视角、方法论、可操作性 |
| 高频素材 | 班级故事、集体活动、班风细节 | 错题案例、学法示范、学科思维 |

## 三、共享层 vs 差异化层

**共享层（两角色通用，不随角色变化）**

- 五段式骨架：开场 → 班情/学科学情 → 学情分析 → 家庭教育建议 → Q&A + 结束
- 字数预算公式（30 min ≈ 4000-5000 字；45 min ≈ 6000-7000 字；60 min ≈ 8000-9000 字；朗读按 200 字/分钟）
- 学段基调：`stage-primary.md` / `stage-junior.md` / `stage-senior.md`
- Q&A 话术库：`qa-bank.md`
- PPT 大纲生成法（每章 1-3 张，每张 ≤5 行字 / 1 张图）
- 自检清单与合规红线

**差异化层（按角色切换）**

- 身份定位、核心目标、发言重心
- 第 2、3 段的取舍与口径
- 家庭建议方向、典型问题类型
- 时间分配比例、Q&A 侧重、语气基调

## 四、兼任模式（班主任兼学科老师）

适用于同一场家长会既要讲班级、又要讲本学科的情况。

**结构**：以模板 A（班主任版）为骨架，在第 3 段（学情分析）之后、第 4 段（家庭教育建议）之前插入独立段落：

```
## 附：本学科专区（8-10 分钟）
### 1) 本学科学情概览
### 2) 本学科学习方法与家庭配合
### 3) 本学科易错点与辅导误区
```

**时间再分配建议**（以 45 分钟为例）：

| 模块 | 时长 |
|---|---|
| 开场 | 2 min |
| 班情通报 | 8 min |
| 学情分析（全班） | 10 min |
| **本学科专区** | **9 min** |
| 家庭教育建议 | 10 min |
| Q&A + 结束 | 6 min |

**注意**：学科专区的内容必须来自本学科真实数据，不得与全班学情分析重复。

### 5.3 短时学科发言（10-15 分钟）

学科老师受邀在班主任家长会上发言时：

- 删除第 4 段「家庭教育建议」，保留开场 + 学科学情 + 学科方法 + 结束。
- 时间分配：开场 1 min / 学科学情 6 min / 学科方法 6 min / 结束 1 min（14 分钟版）。
- 聚焦 1-2 个最关键的学科问题，不求全。

### 5.4 模板 C · 兼任版

见第四节。

### 5.5 各段落写作要点

**1) 开场（~5%）**
- 真诚致谢家长出席（不空话）
- 一句有共鸣的金句或近期班级小故事切入
- 介绍流程与时间安排
- **⚠️ 钩子须同轴并可回收（硬性）**：开场用的小故事 / 引述孩子的一句话，是**全场的引子**，必须做到"**开场抛 → 正文答 → 结尾收**"三步俱全：
  1. **同轴**：钩子问的必须是**本场要回答的那个问题**。反例：钩子问"老师是不是不管不吵不闹的孩子"（**关注度**），正片讲"听懂 ≠ 会做"（**学法层级**）——两回事，钩子悬空。
  2. **正文回答**：在 §2 收口或 §3 机制处**明确回答**开场提出的那个问题。
  3. **结尾回收**：§6 首句回到这个钩子（见下 5) 结束语）。
  > **一句话自查法**：把开场那句话单独拎出来问——"**后面哪一段回答了它？**"答不上来 → 要么补一句回答，要么换钩子。
  > **机械提示**：`scripts/check_structure.py` 的 **D 项**（提示级）会扫"开场有引语钩子但全文无回扣句"。反扫依据：开场关键词在全稿的出现次数——**只出现 1 次（即开场自己）就等于没回收**。

**2) 班情通报（班主任）/ 学科学情概览（学科老师）**
- 班主任：本学期班级走过的足迹（用 3-5 个具体事例，而非"学风浓厚"），给家长"看得见"的画面感。
- 学科老师：本学科课堂生态、作业完成情况、学科活动与亮点，聚焦本学科。
- **段末必须收一句总结（硬性要求）**：讲完 3-5 个事例后，**段末要有一句话把事例收口**，把"这几件事"归结到一个面上，作为向第 3 段的过渡。**不得用"第 X 件事"直接收尾**（那样是列举未完，不是收口）。
  > **此项由 `scripts/check_structure.py` 强制校验**（SKILL.md §8.1 步骤 6），非人工目测。实测历史稿件 7/12 份在此项失守，务必跑脚本。
  - 收口句式参考：`所以这不是一个{X}问题，是一个{Y}问题` / `我想说的是：{一句话判断}` / `这几件事放在一起，其实指向同一件事——{判断}`。
  - 正例：*"所以这不是一个成绩问题，是一个「要不要自己动起来」的问题。"*
  - 正例：*"所以今天说一百句'初中很重要'都没用，得告诉孩子：你要开始换一种学法了。"*
  - 反例：*"第三件事，是关于集体活动。……"*（以列举项收尾，**段没收口**）
  - 反例：*"当然，也有需要关注的地方……这些我在班里讲过，也会继续跟。"*（只补了问题，**未升华**）
  - 学科老师版同理：学科学情概览段末也要收一句本学科的核心判断。

**3) 学情分析（~30%）**
- 班主任：总体数据：均分、各分段、与年级 / 上次比较（**不点名学生**）；总结突出表现 / 主要问题（每条都有数据 + 教学诊断）；关键学科或薄弱环节通报。
- 学科老师：本学科单科数据：均分、分数段、高频易错点、典型错误归因（**不点名学生**）。

**4) 家庭教育建议 / 家校配合（~30%）**
- 围绕教师列出的 2-3 件事展开。
- 每件事包含：**为什么重要 → 在校怎么做 → 家庭怎么配合 → 具体可执行动作**。
- **避免说教**：尽量用"我观察到的现象"开头。
- 班主任侧重学习习惯、作息、亲子沟通；学科老师侧重学科方法、错题整理、辅导误区。

- **⚠️ 主题绑定（硬性要求，防跨场景雷同）**：
  - 本段 2-4 件事里，**至少一半必须由「本学段特征 + 本次会议主题」直接推出**，且能指着本稿第 2、3 段说"这就是从那儿来的"。
  - **"睡眠/作息""换一种说话方式"这类跨学段通用项，全场最多只占 1 条**，且必须与本次主题挂钩后再写（例：初一开学讲作息 ≠ 初三中考前讲作息，落点必须不同）。
  - 每条建议必须能用一句话回答："**为什么是这次会议才要讲这条？**" 答不上来的，删掉或换成本主题专属的。

- **⚠️ 同场景泛化（硬性要求，防"同类会每次一样"）**：
  - 下表是**该主题下的可选方向池，不是必选清单**。每次开同类会**从中另选 2-3 个方向**，**不得沿用上一场的那几条**。
  - **至少 1 条必须是"本班专属"**：由本班近期实际现象推出，本表之外。**须主动向用户要班情**（用户已确认此流程）：先问"班里最近有什么普遍现象 / 您特别想让家长注意什么"，用户说没有时才退用 `<占位符>`。**不得用方向池里的通用项充数。**
  - **同一老师第二次开同学段同主题的会时，本段的建议条目必须与上次不重合**。做法：保留主题不变，**换切入角度**（例：都是初二期末，"上次讲错题怎么用，这次讲假期怎么衔接"）。
  - **⚠️ 本表非固定题单**：写成稿时必须按本班细节重建表述，**不得照搬表内文字**。

  | 会议主题 | 可选方向池（每次从中另选，非必选） |
  |---|---|
  | 开学动员 | 新学期节奏建立 / 书包与作业流程 / 亲子期待对齐 / 开学焦虑 / 座位与同伴变化 / 学期目标怎么定 |
  | 期中分析 | 复盘方法（错题怎么用）/ 单科失分的家庭归因 / 不追分数的沟通 / 分段变化怎么读 / 偏科的处理 / 考后情绪 |
  | 期末·年终 | 假期断层的补救 / 成绩归因方式 / 下学期衔接准备 / 假期作息与屏幕 / 复盘而非清算 / 春节期间的亲子张力 |
  | 升学衔接 | 学段落差预判 / 学科陡增的应对 / 心理预期管理 / 目标怎么定（保底-努力-冲刺）/ 抢跑习惯不抢跑知识 / 志愿与方向初谈 |
  | 专项主题（压力/手机/心理等） | 就着本主题的可执行动作 / 替代物怎么补 / 求助信号怎么认 / 家庭规则怎么定 / 什么时候该找专业人员 / 家长自己的情绪 |

- **⚠️ 政策边界（硬性要求）**：方向池里的"**志愿与方向初谈**""**升学衔接**"等属于政策主题。**谈原则、谈方法可以；谈具体政策数值 / 比例 / 分值 / 组合数 / 录取规则不行**——除非用户提供了官方文件依据。凡涉及政策数值，一律改为"**以本省 / 本市 / 本校官方文件为准**"，或标 `<待核：需政策依据>`。**不得对政策走向做预测。**

**5) Q&A + 结束（~15%）**
- 列出 5-8 个**家长可能现场提问**的预案（参考 `qa-bank.md`）。**总数封顶 8 条**——本班专属题虽要求 ≥2 条，但不得靠多写这类题突破 8 条上限。
- **⚠️ 取题口径（硬性要求）：按「角色 × 学段 × 主题」定方向，然后自己成题——不照抄题库。**
  - `qa-bank.md` 是**方向库不是答案库**：里面的题干是示例，用来示范"某个方向长什么样"。
  - **≥2 条必须是"本班专属题"**（题库里查不到题干，须结合本班实际自拟）。
  - **通用题（成绩下滑 / 作业量 / 报班 / 问名次）全场不超过 1 条**；若确要保留，必须改写成挂本次主题的版本。
  - **同一份稿内不得出现语义重复的两问**（如"成绩下滑怎么办"与"考不好怎么安慰"）。
  - **⚠️ 同场景泛化**：同一学段 + 同一主题的**第二场及以后**，取题须**换方向**（不是换措辞），并对照 `qa-bank.md` §6.3 台账避开已用方向。
  - **⚠️ 题干净化（硬性）**：题干**只写"家长当场会问的那句话"**，**不得带分类标签**——`Q1（本班）` / `Q2（本主题）` / `Q3（学段）` / `Q4（通用）` 这类**括号及括号内的文字一律去掉**，写成 `Q1：……` 即可。"本班专属 / 本学段 / 本主题 / 通用"是**写给你自己看的配额口径**，**只用于内部自检（见 §六 清单与 `qa-bank.md` §6.1 配额表）**，**不得写进题干、不得出现在交付给老师的稿子里**。
- 结束语：1 个具体的近期行动号召。
- **⚠️ 首句回扣开场钩子（硬性）**：§6 第一句宜**回到开场抛出的那个人 / 那件事**，与 §2（回答）、§4 一起形成"**开场抛 → 正文答 → 结尾收**"的闭环；开场若没有钩子，则不强行回扣。
  - **不得悬空引用（硬性）**：写"回到**开头那句话**：…"时，**被引的那句话必须真的出现在开场**。反例：§6 写"回到开头那句话：初二的分化是从'还用初一那套学法'开始的"——**该句全稿首次出现即在 §6 自身**，开场根本没有，听众按图索骥找不到，属**悬空引用**。正确写法是回扣**开场实际出现过的人或事**（"回到开头那个孩子"），或把被引判断句明确说成本段的判断（不谎称"开头"）。
  - 自查法：把呼应句里"开头那句话"对应的原文，**去开场段里搜一遍**——搜不到就是悬空。

**Step 4 · 配套 PPT 大纲（如要求）**
- 每章节 1-3 张 PPT 标题 + 要点（每张不超过 5 行字 / 1 张图）。
- **页标题只写标题本身（硬性）**：不得挂**写作说明括注**——`第 7 页｜数据怎么看（三个口径）` ❌、`家庭配合（共四条）` ❌、`现场提问（口径提示）` ❌。页内的几行要点**已经把条数摆出来了**，标题再标一次是**给写作者看的备注**，不是投给家长看的字。**序号类括注可留**（`班里的事（一）` ✅）。
- **给使用者本人的制作提示可留**：如"（现场按真实数据填）""（现场按需展开）"、大纲末尾的制作禁忌行——它们对**老师怎么用这份大纲**有用，不属上面要清的写作说明。
- **禁忌**：把发言稿原文塞 PPT。
