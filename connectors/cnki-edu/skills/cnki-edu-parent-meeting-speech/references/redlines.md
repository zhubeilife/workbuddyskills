# 负面清单 · 红线（反例 → 改写）

> 生成与改写话术时都必须遵守。`scripts/check_tone.py` 会按同一套分类自动扫描，命中即改写后复检。
> 用法：写完话术 → 跑脚本 → 若有命中 → 按本表改写 → 复检直至通过。
>
> **通用红线共 12 类**：第 1-8 类为基础八类，第 9 类「身份指向」、第 10 类「政策数据须有据」、第 11 类「建议脱离事实」、第 12 类「元话语与边界错位」为新增；第 13 节为发言稿专属。
> 第 9、10、11 类**脚本无法完全覆盖**：身份指向只能人工判；政策来源由 `scripts/check_policy.py` 辅助；建议依据由 `scripts/check_advice.py` 辅助（脚本只抓"领域词脱节"，**建议与事实的对应关系仍须人工逐条过**）。
> 第 12 类由 `scripts/check_tone.py`（v1.3 起）**自动扫描**。

## 1. 不评价人格与家庭（只说行为与影响）

| 反例 | 为什么不行 | 改写 |
|---|---|---|
| "这孩子就是懒" | 评价人格，家长会防御 | "本周三次作业未交" |
| "你们家不管孩子" | 指责家庭 | "想跟您了解下孩子在家的作业安排" |
| "他就是笨，教不会" | 定性、贴标签 | "这章的计算还不太熟，我们换个方式再讲一遍" |

## 2. 不泄露隐私（不点名、不比较、不提他人信息）

| 反例 | 为什么不行 | 改写 |
|---|---|---|
| "某某某又没考好" | 泄露他人成绩 | "这次整体平均分有波动，个别情况我私下沟通" |
| "你看看人家孩子" | 他生比较 | "可以看看孩子在<具体方面>的进步空间" |
| 群里提及某学生生病 / 家庭情况 | 隐私泄露 | 一律转私聊，不在群内提及 |
| "他这次掉到班里后十名了" | 把**具体位次**念给家长，等于公布排名 | "这次比上次下滑了一段，我先跟您说一声" |
| "排到班里倒数第五了" | 同上，且带羞辱感 | 只说变化幅度与科目，不说位次 |

> **位次一律不出口**（`check_tone.py` v1.6 已自动拦截）：不只是"名次/排名"这两个词，**倒数第五、后十名、排名第几**这类把位次念出来的写法同样是泄漏。要说程度，说"比上次下滑了一段""幅度不小"。

## 3. 不绝对承诺（不承诺分数、升学、安全、名额）

| 反例 | 为什么不行 | 改写 |
|---|---|---|
| "保证考上重点" | 超出职责的承诺 | "我们会按计划尽力辅导，结果还要看孩子状态" |
| "绝对安全，放心" | 无法兑现 | "活动按学校安全预案组织，全程有老师带队" |
| "名额肯定给你留一个" | 越权承诺 | "名额按规定评定，我会把情况如实反映" |
| "我保证以后不会再发生" | 冲突 / 安全类的高发句：事情本身不可控，保证必失信 | "我会按学校流程跟进，有结论第一时间告诉您" |
| "我承诺不会再出现这种情况" | 同上 | 同上一行 |

> **"保证 + 不再 / 不会" 是绝对承诺的另一种皮**（`check_tone.py` v1.6 已自动拦截）。承诺**结果**（分数、升学）和承诺**永不再犯**（"不会再发生"）是同一条红线。可以做的是承诺**动作**：「我会按流程跟进」「我会当面问他」。
> **对照组（不该报）**："我保证会跟您保持联系"（承诺动作，正当）、"我不能保证分数，但我能保证每次作业我都当面批"（诚实表述，正当）。

## 4. 不施压绑架（不连环催促、不道德绑架、不把责任推给家庭）

> **高危点位**：「请家长配合」这条线。家长最容易把"请配合"读成**老师在给我派活 / 甩锅**——分水岭不是措辞客不客气，而是**有没有先说清学校这半边做什么**。请求本身只给一件、量要小、要能立刻做。

| 反例 | 为什么不行 | 改写 |
|---|---|---|
| "请家长务必管好孩子" | 命令指责 | "想请家长在家配合关注一下<具体行为>" |
| "请家长务必督促孩子认真完成作业" | 施压（务必 + 督促） | "每天晚上花两分钟看一眼作业本，有订正痕迹就签个字" |
| "请家长必须配合，尽快回复确认" | 施压（必须 / 尽快） | "您方便的时候回我一声就行" |
| "孩子的作业家长要多费心，不要什么都交给学校" | 道德绑架 + 推责 | 先说清学校做什么，再提一件家里能做的事 |
| "成绩上不去，家长也有责任" | 责任转移，家长立刻转入防御 | 只讲观察到的行为与影响，不分配责任 |
| "不来的孩子可惜了" | 施压绑架 | "活动按自愿参加，不方便也没关系" |
| "尽快！马上！别怪我没提醒" | 连环施压 | 截止时间说一次，放句尾："请于<时间>前完成。" |
| "你们在家是不是没管他" | 把问题推给家庭，家长立刻转入防御 | 先说我这边观察到什么，再问"他最近在家写作业的情况怎么样" |
| "孩子是自己的，家长得多上心" | 责任转移，且带道德绑架 | 学校的动作先写清楚，家里那件小事放后面，不带评判 |
| "你们家长平时是怎么管的" | 质问式追责 | "想跟您对一下他最近在家的作息 / 作业时间" |

**⚠️ 不误报的两类写法**（`check_tone.py` v1.5 已按此设计，不要改回宽泛匹配）：
- **教师 / 学校自述**：「我这边尽快处理」「有结果我会尽快回复您」「学校将尽快答复」——这是好写法，不是施压。
- **讲知识 / 讲方法**：「这个转变，初三必须完成」「必须自己写出来才算数」——不在对家长的呼求里，不算施压。

**⚠️ v1.6 新增的不误报边界**（同样别改回宽泛匹配）：
- **家长作为呼语 + 转折**：「各位家长：不管多忙，麻烦每晚看一眼作业本就行」——"家长"后面的冒号/逗号即是句读边界，`你们家…不管` 类规则不跨句读。
- **正当的不必做**：「家长不用管作业的具体内容，看一眼有没有签字就好」——"不用管"不含"不管"，不命中。

## 5. 越权表述（家委不代学校做决定）

| 反例 | 为什么不行 | 改写 |
|---|---|---|
| "家委会决定，下周起收班费" | 家委越权 | 由老师/学校发布；家委只做"转发与统计" |
| "学校规定由我们班委执行" | 代学校宣布 | "根据学校通知，<内容>" |
| 家委解释收费政策 | 越权解释 | "具体规则请以老师通知为准" |

## 6. 涉钱必写规则（来源、自愿、退费）

| 反例 | 为什么不行 | 改写 |
|---|---|---|
| 只发一个收款码 | 缺少规则说明 | 金额 + 用途 + 来源（学校规定/自愿原则）+ 退费方式 + 截止方式 |
| "不交不许参加活动" | 强制、违规 | "本次活动自愿参加，不参加不影响其他权益" |
| 群里反复催缴 | 过度催缴 | 一条通知 + 一条温和催办，之后转私信 |

## 7. 冲突先降温（先共情、再事实、后渠道，私聊优先）

| 反例 | 为什么不行 | 改写 |
|---|---|---|
| 在群里逐条反驳家长 | 公开对线，冲突升级 | "具体到某个孩子的情况，我们单独沟通" |
| "是您自己没搞清楚" | 指责对方 | "可能是我表达得不够清楚，我再说明一下" |
| 群里让大家评理 | 拉人站队 | 先给结论止住话题，再私聊 |

## 8. 危机即转交（安全、心理危机走既定流程）

| 反例 | 为什么不行 | 改写 |
|---|---|---|
| 自行安慰、自行处置心理危机 | 超出职责，风险高 | "这类情况学校有专门流程，我会同步给心理老师" |
| 私自处理安全事件不上报 | 程序违规 | 先按学校预案处置并上报，再与家长同步 |
| 向家长下诊断 | 越界 | 只陈述观察到的行为，交由专业人员判断 |

## 9. 身份指向（新增 · 与脚本检查并列的人工层规则）

**规则**：套用模板后，**用户身份不得作为「同步 / 上报 / 转交 / 答复 / 请求」的对象出现**——那是"同步给自己"，逻辑不通、家长困惑。**但作为自称 / 身份声明出现是合法的**，不要过度修改。

**两种形态要分清：**

| 形态 | 判定 | 例 |
|---|---|---|
| ❌ **对象形态** | 前面有"给 / 向 / 请 / 由 / 报给 / 交给"等**指向词** → 冲突 | "我会**同步给班主任**"、"请**班主任**统一答复" |
| ✅ **自称形态** | 身份声明 / 被称呼 / 职责自述 → 合法 | "我是孩子的**班主任**" |

| 用户身份 | 反例 | 为什么不行 | 改写 |
|---|---|---|---|
| 班主任 | "我会同步给**班主任**和学校心理老师" | 同步给自己（对象形态） | "我会同步给**学校心理老师**（必要时报**学校德育处**）" |
| 班主任 | "这件事请**班主任**统一答复" | 同上 | "这件事**由学校**统一答复" |
| 科任老师 | "我会同步给**班主任**和学校心理老师" | ✅ 成立（科任发现问题先同步班主任） | 保留 |
| 家委 | "**家委会**决定下周起收班费" | 越权，且"家委"等于用户自己 | "根据**学校通知**……，家委会负责**转发与统计**" |

**执行**：逐句扫描 `班主任` / `科任老师` / `心理老师` / `德育处` / `学校` / `家委会`，判断该词是**对象形态**还是**自称形态**；仅当为对象形态且与用户身份重合时才需改写。完整工序见 `SKILL.md` 第 8.4 节。

**注意**：本条**无法由 `check_tone.py` 自动检出**（脚本查关键词，本条查句子的角色指向），必须人工逐句过。**脚本通过 ≠ 身份代入正确。**

## 10. 政策数据须有据（新增 · 半自动：`scripts/check_policy.py`）

**规则**：凡话题触及政策（升学衔接、志愿填报、中考 / 高考改革、指标到校、综合素质评价、新高考选科、作业时长 / 总量、考试管理与排名、手机管理、课标、收费与教辅、入学学籍……），**政策数据只能来自两种来源：**

| 合法来源 | 含义 |
|---|---|
| **(a) 用户提供** | 用户口述、粘贴的文本，或提供的附件 / 文件 |
| **(b) 官方文件** | 政府（国务院 / 教育部 / 省教育厅 / 市教育局等）发布的**通知 / 法规原文**，或**学校正式通知** |

**凡具体政策数值 / 年份 / 条款 / 适用范围，一律不得凭记忆写出**——这类数据易过期，且各地执行口径差异极大。来源未落实时，改写为 `<待核：需政策依据>` 并列入【待补信息】。

| 反例 | 为什么不行 | 改写 |
|---|---|---|
| "教育部要求初中书面作业不超过 90 分钟" | 无依据的全国统一数值（各地口径不同、易过期） | "作业总量有政策要求，**具体时长以本省市与学校通知为准**"；或据实引用文件名/文号 |
| "课标要求小学六年课外阅读 145 万字" | 数值无来源，可能记错 | "课标对课外阅读量有要求，<待核：需引用课标原文>" |
| "中小学不得将手机带入课堂" | 规定性表述无来源 | "**学校对手机有明确管理规定**（依据以学校通知为准）" |
| "新高考就是 3+1+2，选科有 12 种组合" | 模式与数字均为政策数据、且各省不同 | "本省选科模式与组合数**以省教育考试院官方文件为准**，<待核>" |
| "体育中考涨到 70 分了" | 分值各地不同，且逐年调整 | "体育中考分值各省不同，**以本省市最新文件为准**" |
| "某年出了个文件说……"（模糊引用） | 无法查证，等于没有来源 | 补全「文件名 + 文号 + 发布机构」，否则改写为 `<待核>` |
| "以后肯定要取消××" | 对政策做个人预测 / 解读 | "政策以教育主管部门发布为准，我不做预测" |

**规范句式（三件套）**：`依据 + 适用范围 + 免责指向`

> 据《XXX 通知》（文号 XXX）——**本省 / 本市具体执行以教育主管部门最新通知为准**。

**注意**：
- 单独的机构名（"教育部""教育局"）**不等于来源**——它只是政策主体，**必须有具体文件或明确指向**（"以…为准""据《…》"）才算落实。
- 涉及**地方差异**（中考体育分值、指标到校比例、加分政策、选科组合）→ **必须**落到"以本省 / 本市 / 本校官方口径为准"，**不得直接给全国统一数值**。
- 自检工具为 `scripts/check_policy.py`（政策类主题**必跑**）；它只认**文件名 / 文号 / 学校通知·规定 / 以…为准**，或占位标记 `<待核：…>` / `〔政策待核〕`。

## 11. 建议脱离事实（新增 · 半自动：`scripts/check_advice.py`）

**规则**：给出的每一条建议 / 请求，都必须能追溯到前文**已经陈述过的观察事实**——事实在前、建议在后，一一对应。

**为什么单列一类**：家长读到的不是"老师在给建议"，而是"老师在指什么"。一条与事实无关联的通用建议（全文只讲课堂纪律，却建议"帮孩子调整作息"），会被读成**"你们家没管好"**——它本质上就是第 1 类（评价 / 暗示指责家庭）换了层皮的说法，只是字面上没有评价词。

| 反例 | 为什么不行 | 改写 |
|---|---|---|
| 全文只讲课堂说笑、离开座位，末尾建议"帮孩子调整一下作息" | 建议与事实脱节，家长听成"怪我们没管好" | 删掉；换成接着事实的建议："晚上和他聊聊上课与同学相处的方式" |
| 借作息 / 情绪 / 家庭 / 电子产品归因，但没有任何对应观察 | 跳过了归因这一步 | 先摆事实："我注意到他这两天早读会打瞌睡"，再提调整作息 |
| 为凑够两条而补"多陪伴孩子""培养好习惯""营造家庭氛围" | 通用项凑数，读起来是套话 | 不足两条就**只给一条**；确需了解情况时改为提问："想先跟您了解下他最近在家的安排" |
| 发言稿里每个问题后面都挂同一条通用建议 | 建议与问题不对应，等于没给方法 | 一条问题配一条**由该问题推出**的方法；同类会须换方向 |
| "如果他最近睡得比较晚，帮他调整一下作息" | 用"如果…"把假设包装成事实，读完仍不知道依据是什么 | 要么补观察（"他这两天早读会打瞌睡"），要么改成了解式提问，**不得用"如果…"充当事实** |

**三条执行口径**：

1. **"最多两条"是上限，不是配额**——不足两条就给一条，**严禁凑数**。
2. **先归因、后建议，不得跳步**——外部因素（睡眠 / 情绪 / 家庭 / 身体 / 电子产品）**必须先有观察事实**，才能变成建议。
3. **自检问句**：逐条问**"这条建议，前面哪句事实在支撑它？"**——答不上来的，删。

**执行**：① 跑 `scripts/check_advice.py`（查"请求句中的高危领域词 ＋ 邻近无已确立观察"）；② 命中后**逐条人工确认**——有依据则保留并在**内部自检记录**中注明（结果不输出），无依据则删改；③ 复检直至通过。**脚本查短语，人工查对应关系，两者不可互相替代——脚本通过 ≠ 建议有依据。**

## 12. 元话语与边界错位（新增 · 自动：`scripts/check_tone.py` v1.3）

**规则**：沟通文本里**不写"解释自己这句话的性质"或"声明自己态度立场"的句子**；需要表达边界（不代学校定责、不擅自处理）时，**一律写在「处理程序」上，不写在「我的态度」上**。

**判据一句话**：这句话在讲**"我"（说话人自己的态度与免责）**，还是在讲**"事"（处理流程与责任归属）**？
- 指向"我"（我不评价 / 我不定性 / 我不站队）→ 家长读到的是**回避与免责**；
- 指向"事"（学校有流程 / 我按流程走 / 有结果告诉您）→ 家长读到的是**负责**。

**为什么单列一类**：这类句子是**元话语**——它不传递任何信息，只占行数；而且它把说话人**从"被指责的对象"挪到了"旁观者"的位置**。家长当下的诉求是"我孩子被打了，你怎么说？"，老师抢在家长开口前递上一句"我不做评价"，等于**主动把"给我个说法"这个诉求推开**。同时它还削掉了老师作为信源的可信度（"我只说我看到的"暗示我知道得不全）。**它服务的是老师自己的安全感，不是家长的知情需求。**

| 反例 | 为什么不行 | 改写 |
|---|---|---|
| "我只说我看到和问到的事实，不做评价。" | 元话语：解释自己这句话的性质，零信息量；等于在家长开口前把"要个说法"推开 | 把该给的态度给足 + 边界写进程序：**"动手打人这件事肯定不对，这一点我态度很明确。具体怎么处理，学校有统一的流程，我按流程走，有结果第一时间告诉您。"** |
| "后续处理我不私下定性。" | "定性"是教师内部术语；"我不…"指向自己，家长听成回避 | "具体怎么处理，学校有统一的流程，我按流程走，有结果第一时间告诉您。" |
| "老师不偏袒任何一方。" | 主动声明中立，反过来让人怀疑你心虚；家长此刻要的也不是中立 | 不声明立场，直接给**对行为本身**的价值判断 + 处理程序 |
| "我只是客观转达，不代表我的看法。" | 元话语 + 卸责：家长听完不知道学校到底怎么处理 | "我了解到的情况是……；具体怎么处理，学校有统一的流程。" |
| "我先声明，我不是来告状的。" | 元话语，反向暗示"这就是告状" | 直接说事，删掉这句 |

**两条不能写反的分寸（本类的核心）**：

1. **态度给足**：涉及学生冲突、受伤、被欺负这类事，**必须给出对「行为本身」的价值判断**——"动手打人这件事肯定不对"。这是对**行为**的表态，不是对**责任**的认定，学校立场一致，给双方家长都可说、不会自相矛盾。**不给这个表态，家长会认定你在和稀泥。**
2. **程序守住**：**不能给**的是具体责任认定与处分结果——"具体怎么处理，学校有统一的流程，我按流程走，有结果第一时间告诉您"。

**三层表述的顺序固定：事实层（讲经过）→ 态度层（表态）→ 程序层（讲归属）。** 三者位置写错，就会出现"先免责、再讲事实"这种读起来最冷的排法。

**不算违规的写法**（不要过度修改）：
- "我想先跟您了解一下孩子在家的安排。" —— 这是**说明意图**，不是自我免责，合法。
- "这件事由学校按流程处理。" —— 程序表述，合法。
- 稿子里的**旁白提示**（如"（只讲事实，不带情绪）"）属于不读出来的导演批注，合法；但**不能把它当成正文内容念给家长听**。

**执行**：跑 `scripts/check_tone.py`，命中「元话语免责」即改写后复检（v1.3 起自动覆盖，并已对【不宜说】等**引用反例的说明区块**做整块豁免）。**检查结果静默留存，不写入给用户的回复**——含改名后的「质量自检：语气红线 0 命中…」清单，以及"（内部执行）""按您要求不再单独展示"等**声明前缀**（前缀不豁免，见 `SKILL.md` §6「内部执行项」）。

## 13. 发言稿专属红线（在通用红线之上叠加，仅发言稿形态适用）

| 反例 | 为什么不行 | 改写 |
|---|---|---|
| "这次考试张三退步了，家长要管管" | 公开场合点名批评具体学生 | 只讲全班分段与共性问题，"个别情况会后一对一沟通" |
| "班里第 1 名是李四，95 分" | 公布排名、点名报分数 | "这次整体均分 82，高分段比上次多了 3 人" |
| "隔壁班这次平均分比我们高 5 分" | 横向比较其他班级 | 只与本校 / 本班自身历史数据比较 |
| 通篇罗列问题、不给方法 | 把家长会开成"控诉会" | 每个问题后紧跟一条可执行建议，且该建议须**由该问题推出**（见第 11 类） |
| "请家长每天批改作业 1 小时" | 违反"双减"、负担过重 | "在家提醒孩子在固定时段完成，并自查签名即可" |
| 跳过角色识别直接套模板 | 结构与侧重与角色不匹配 | 先完成角色路由再成稿 |

**补充**：仅在表扬亮点时教师可提及学生姓名，且需提前征得家长同意；**在公开场合点名批评学生绝对禁止**。
