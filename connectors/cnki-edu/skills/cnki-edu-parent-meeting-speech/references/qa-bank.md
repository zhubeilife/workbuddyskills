# 家长会高频提问与教师应对话术库（场景矩阵版）

> **使用方式（两步：先定方向，再现场成题）**
> 1. **定方向**：按「角色」→「学段」→「会议主题」锁定本场该覆盖的**提问方向**（见 §二 / §三 每条的「方向」标签）。
> 2. **成题**：把方向**改写成家长当场会问的那句话**，用本班、本次会议的具体细节填充。**不许照抄本库的题干。**
>
> **⚠️ 本库是"方向库"不是"答案库"**：§二 / §三 里列出的题目是**示例（示范某个方向长什么样）**，不是该场景的固定题单。
> 同一学段 + 同一主题的每一场，都应重新组卷——见 §六「同场景内泛化」。
>
> **硬性要求**：每场发言稿的 Q&A **共 5-8 条（总数封顶 8 条）**，其中——
> - **通用题（§一）最多 1 条**（问排名 / 作业量 / 报班 这类，各场景都问得到的）
> - **其余必须落在本学段 + 本主题的方向上**（从 §二 / §三 / §四 的**方向标签**取，不要求逐条对应示例题干）
> - **≥2 条须结合本班实际情况自拟**（本库没有对应示例的题；即"本班专属题"）
> - **同场景内不得复用上一次的题单**（见 §六）
> - **题干不得带分类标签**：写成"家长当场会问的那句话"即可，**`（本班）` `（本主题）` `（学段）` `（通用）` 这类括号及括号内文字一律不写进题干**——它们只是**内部配额口径**，用于自检，不进交付稿。
> 违反以上任一条，视为 Q&A 未完成泛化。
>
> **⚠️ 政策数据提示**：本库中标有 **〔政策待核〕** 的应答涉及政策（名次公布、作业时长、排名规定等）。这些表述给出的是**应对原则**，**其中具体数值不得直接照抄进稿件**——须由用户提供依据或以「以学校 / 上级文件为准」的口径软化；无依据时改写为 `<待核：需政策依据>`。详见 `SKILL.md` §5.5 与 `redlines.md` 第 10 类。

## 一、通用题（各场景通用，**每场最多取 1 条**）

> **⚠️ 本区是"每场最多 1 条"的稀缺池，不是默认题源。**
> 历次实测显示：旧稿最容易出问题的地方，就是 G1-G6 被整批搬进每一场（"成绩下滑 / 作业量 / 报班 / 问名次"四件套），
> 导致任何学段、任何主题的稿子都长一个样。**取 2 条及以上即视为不达标。**
> 想保留多条时，**必须把其中一部分改造成"挂本次主题"的版本**，并计入 §三 主题方向题。

**G1：能不能告诉我孩子在班里第几名？**
- （义务教育阶段）应答："按上级规定，学校不公开个人名次。〔政策待核：依据以学校正式通知为准〕我可以告诉您孩子所处的**分段**（靠前 / 中等 / 中后），以及这次和上次相比的**变化趋势**——这两样比名次有用。"
- （高中阶段）同上口径，可补充"年级位次区间"。

**G2：作业是不是太多了？孩子写得很晚。**
- 应答："书面作业总量是有政策要求的（**具体时长以本省市与学校通知为准**）。如果经常超时，请把**具体哪一科、大概花多久**告诉我，我来查这个环节。"〔政策待核：如需向家长报出具体分钟数，须先核到官方依据〕
- **注意**：先分辨"作业多"还是"效率低"，不要把责任直接推给某一科老师。

**G3：要不要给孩子报班 / 报辅导班？看别人都报了。**
- 应答："教育有不同节奏，关键是孩子'吃得下'什么。建议先看两条：① 课内作业能不能在规定时间内认真完成；② 有没有明确的短板科目。这两条不清楚时报班，往往是把钱换成焦虑。"

**G4：为什么这次考试这么难 / 老师讲得太快？**
- 应答："试题难度由教研组共同把关，我们也在做归因。如果具体到某节课，欢迎随时来听课或一对一沟通。"

**G5：孩子当着我的面很犟，说两句就吵，怎么办？**
- 应答："这个年龄段的普遍现象。三个建议：**冲突当场不升级**（他情绪上来时先不讲道理）、**不在他同学面前批评他**、**一次只谈一件事**。如果冲突频率明显超出正常，请告诉我，我们一起看。"

**G6：孩子在家不跟我们说话，问什么都不说。**
- 应答："常常是**问法**的问题。'今天怎么样'只能答'还行'。换成具体的——'你们班谁最能逗人笑''今天体育课打什么了'——他就有得说。别在他刚进门时问。"

## 二、按学段取题（**下列每题 = 一个"方向"的示例**，成稿时改写、不必照搬）

> 用法：先认准本学段该覆盖的**方向**（照护点），再自己组一两道具体的、带本班信息的题。
> 例：初二的"手机"方向，可以成题为"孩子最近夜里还摸手机怎么办"，也可以是"给他手机他要不要给" —— 方向相同，题不同，都合格。

### 2.1 小学（1-6 年级）| 方向：习惯 · 阅读 · 安全感

**P1：孩子挺聪明，就是粗心，怎么办？**
- 应答："'粗心'是个笼统的说法，**要先找出它具体长什么样**——是抄错数字、漏看条件，还是单位不统一？找出规律才能改。回家可以这样：让他把错题原题抄一遍，再重做，您只看他第二次对不对。"

**P2：要不要让他提前学 / 学奥数？**
- 应答："小学阶段最重要的不是抢进度，是**把习惯打好**——按时完成、书写工整、自己整理书包。这些比多学一年知识更影响长远。"

**P3：孩子不爱阅读，只爱看漫画，行不行？**
- 应答："漫画也是阅读，**先别断**。可以从'漫画+文字书'过渡，比如同一主题的漫画和故事书各准备一本，让他自己挑。"（**注意**：不评价孩子选什么书）

**P4：孩子在学校会不会被欺负？（低年级家长高频）**
- 应答："这是我特别重视的问题，咱们会后单独聊。**如果您观察到任何苗头——身上有不明伤痕、书本经常丢失、突然不愿上学——越早告诉我越好。**"

### 2.2 初中（7-9 年级）| 方向：适应 · 分化 · 关系 · 手机 · 自我价值

**J1（初一）：孩子小学成绩很好，这次考砸了，是不是退步了？**
- 应答："这叫**适应期回落**，不是退步。小学的知识密度和初中没法比，老本在新的评价方式下不顶用了，孩子要重建学习方法。**通常期中到期末之间会回升。** 要警惕的不是掉分，是他掉分之后**不学了**。"

**J2（初一）：七门课一起上，孩子顾不过来怎么办？**
- 应答："先区分是**时间不够**还是**方法不对**。前者可以定'三件事固定时段'（数英语各留固定时间，天天要有）；后者要看他是不是把时间全给了最怕的那一门。"

**J3（初二）：孩子偏科严重，要不要放弃某一科？**
- 应答："**不建议放弃，但可以调整投入结构。** 初二的分段会'黏住'，弱科拖下去，初三补的成本会翻倍。建议先看这一科是'基础断层'还是'方法不对'——断层的要回头补，方法的可以短期见效。"

**J4（初二）：孩子说学习没意思／不想学了，是不是心理有问题？**
- 应答："**先不要下判断。** 初二的孩子说'没意思'，很多时候是**挫败感**的表达，不是真的不想学。如果我们观察到他持续两周以上情绪低落、失眠、对什么都提不起兴趣，那我们再往心理支持的方向走。**这一条请单独跟我说。**"

**J5（初二）：孩子最近特别爱玩手机，管不住。**
- 应答："**先看时段，别先看时长。** 如果发现夜里还在用，要解决的是睡眠问题。建议谈规则而不是没收——约定'手机不进卧室'，这条比单纯禁止更容易执行。"

**J6（初三）：中考怎么准备？现在开始还来得及吗？**
- 应答："初三的关键不是从零开始，是**把三年知识做一轮系统复习**。现在开始完全来得及，但要有节奏：一轮过基础、二轮攻专题、三轮练套卷。**体育中考的分数也请一并规划进去**（各省分值不同）。"〔政策待核：如需向家长报出具体分值，须先核到本省市官方文件〕

**J7（初三）：孩子压力大，睡不好，要不要紧？**
- 应答："初三的焦虑和失眠是**高发**的，不是个别现象。建议三步：① 我们先观察 1-2 周并记录；② 可以让孩子去学校心理老师那儿做一次轻量沟通；③ 如果持续 4 周以上，建议到正规医院儿童青少年心理科。**不要自行下心理诊断。**"

### 2.3 高中（10-12 年级）| 方向：选择 · 动力 · 自我评价 · 睡眠与情绪安全

**S1（高一）：孩子说选科／分科不知道怎么选。**
- 应答："给原则，不给确定性预测。三个维度一起看：**学科优势**（哪科稳定得分）、**专业方向**（想读什么大类）、**本人意愿**。**选科模式与组合数各省不同、逐年微调，最权威的口径以本省教育考试院与学校通知为准。**"〔政策待核：不得向家长给出具体组合数 / 赋分规则，除非已核到官方文件〕

**S2（高二）：孩子现在学的这些，和高考关系大吗？他好像没什么动力。**
- 应答："高二的知识量最大，也是**'主动'这件事价值急速上升**的阶段——老师讲不完，家长也帮不上，最后只能靠自己往里钻。所以这不是成绩问题，是**要不要自己动起来**的问题。"

**S3（高二）：孩子说自己考不上好大学，是不是有点自我否定？**
- 应答："**先别急着鼓励，鼓励在初二到高二这个阶段经常起反效果。** 先听他把'考不上'的根据说完——往往是他和某个人或某个分数线在比。把那个参照物找出来，才有得谈。"

**S4（高三）：孩子说睡不着，要不要紧？**
- 应答："高三睡眠问题**要当成信号看，不是当成习惯看**。请留意三件事：**入睡时长、是否早醒、白天是否靠咖啡或提神饮料撑**。如果持续两周以上，请告诉我，我们一起判断要不要走学校的心理支持流程。"

**S5（高三）：孩子说要请假休息一天，我该答应吗？**
- 应答："**不要当场答应，也不要当场拒绝。** 先问一句'你是累了，还是不想面对什么？'——这两个的答案完全不同。前者可以休，后者要处理的是那件事。问完再定，并请同步我。"

**S6（高三）：孩子说不考了／不想去学校，怎么办？**
- 应答："**这属于信号，不是态度问题。** 请不要当场批评或讲道理，先稳住他的情绪，然后**尽快单独联系我**。这种情况学校有专门的流程，我们一起处理，不给孩子下判断。"

**S7（高三）：我在家已经很小心了，但孩子还是冲我发脾气。**
- 应答："高三孩子冲家长发脾气，很多时候**不是对您，是对着压力发的**——您只是离他最近的那个。建议：① 不当场还击；② 事后找个平和的时机说'我知道你最近很难'；③ **别把这理解成'我做得不够好'。**"

## 三、按会议主题取题（**下列每题 = 一个"方向"的示例**，成稿时改写）

### 3.1 开学动员 | 方向：新要求 · 节奏重建 · 翻盘窗口

**T1：新学期有什么新要求？家长要准备什么？**
- 应答：给 **2-3 条具体动作**（不列十条）：如"调整作息提前一周""准备好学习用品清单""建立固定的作业时段"。

**T2：孩子上一年没学好，这学期还来得及吗？**
- 应答："**学期初是最好的翻盘窗口**，因为所有人都在重新开始。建议从'一件小事'入手——不是全面加码，是先把一件事做稳。"

### 3.2 期中 / 期末分析 | 方向：成绩解读 · 分段变化 · 失分归因

**T3：这次成绩代表孩子的真实水平吗？**
- 应答："**单次成绩的参考价值有限。** 真正有信息量的是①和上次的**差值**、②各科之间是否**均衡**、③是**知识性失分**还是**非知识性失分**（审题、计算、涂改）。"

**T4：分段下面是哪一档？我孩子有没有希望往上走？**
- 应答："**分段不是固定的。** 但要说清楚一点：**年级越往上，往上走需要的力气越大**——尤其初二之后。所以现在还在中间段的孩子，是最值得加劲的一批。"

**T5：孩子说考得不好是因为粗心，是真的吗？**
- 应答："'粗心'经常是**没找到真原因时的解释**。请让他把错的题分成三类：**会但做错 / 半会不会 / 完全不会**。第一类才是真的粗心，后两类都是知识问题。"

### 3.3 升学衔接（小升初 / 初升高 / 高三动员）| 方向：抢跑什么 · 目标怎么定

**T6：要不要提前学下个学段的内容？**
- 应答："**不建议抢跑学科内容，建议抢跑'习惯'。** 比如初升高，先适应节奏变快这件事，比提前学完必修一更有用。"

**T7：目标学校 / 目标分数怎么定？**
- 应答："**不定死一个数，定一个区间。** 用一个'保底—努力—冲刺'的三档目标，比单一目标更能维持动力，也更能承受波动。"

### 3.4 专项主题（青春期 / 网络 / 心理 / 应对压力）| 方向：情感 · 替代物 · 是否就医

**T8：孩子好像有喜欢的人了，要不要管？**
- 应答："**不鼓励、不禁止、不查看。** 这个阶段重要的是他有没有**其他能说话的人**。如果他的世界只有那一个人，才需要真正介入。"

**T9：孩子沉迷网络 / 游戏，怎么办？**
- 应答："**先看它替代了什么。** 通常是替代了'成就感'（现实里得不到）或'关系'（现实里交不到）。堵住网络，得先补上那个缺口。"

**T10：孩子情绪状态不太好，需要看医生吗？**
- 应答："**我们不诊断。** 但可以给一个判断线：**持续两周以上 + 影响吃饭睡觉上学中任意一项**，就建议去正规医院儿童青少年心理科。在那之前，学校的心理老师可以做一次轻量沟通。"

## 四、教师与教学类（各场景共通，按需取用）

**E1：为什么不公布排名？别的学校都公布。**〔政策待核〕
- 应答："按上级规定，义务教育阶段不公开学生个人名次。〔政策待核：依据以学校正式通知为准〕**我可以给您更有用的东西——分段和变化趋势。**"

**E2：为什么给我家孩子少布置／多布置作业？**
- 应答："总量有政策要求（**具体以本省市与学校通知为准**），但'分层作业'允许差异化。基础不牢的孩子增加 A 层练习；学有余力的，拓展题是选做。您也可以反馈孩子的实际情况。"〔政策待核〕

**E3：老师，您觉得我家孩子现在这个状态，能考成什么样？**
- 应答：**绝对不给预测。** "考试结果受很多因素影响，我不做预测。我能做的是把**他现在的位置和接下来能做的事**跟您说清楚。"

## 五、投诉与冲突（各场景共通）

**C1（家长当场情绪激动 / 指责教师）：**
- 三步缓冲：① 真诚倾听不打断；② 共情但不立刻让步（"我理解您的担心"）；③ 建议私下深谈。
- **会场不是辩论场**，不要当众反驳家长。

**C2（家长当众提到别的孩子的问题）：**
- 立即制止并转私聊："涉及具体孩子的事，我们不在公开场合谈。" **保护被提及的学生。**

**C3（家长之间因观点不同争论）：**
- 快速打断、转向下一环节："这个我们私下交流。" → 会后分别沟通，**避免站队**。

## 六、同场景内泛化（**最重要的一节：防止"初二期末永远长一个样"**）

> **要解决的问题**：如果按"学段 + 主题"机械取题，那么"初二 + 期末分析"每次都会抽出同一批题，
> 同一老师连开三年初二期末，稿子会**逐字雷同**。本节就是防这个的。

### 6.1 组卷配额（每场必须不同）

> **总量封顶 8 条**（与 SKILL.md §六「共 5-8 条」一致）：下表各项**下限合计 5 条、上限合计 8 条**，任一项取上限时其余须相应压缩，**不得靠多加"本班专属题"突破 8 条**。

| 配额 | 条数 | 说明 |
|---|---|---|
| 通用题（§一） | **≤ 1** | 成绩下滑 / 作业量 / 报班 / 问名次 |
| 本学段方向题 | **2-3** | 从 §二 本学段的方向里选，**每次换一批** |
| 本主题方向题 | **1-2** | 从 §三 本主题的方向里选 |
| **本班专属题** | **≥ 2** | **必须结合本班实际自拟**：本班的高频问题、最近发生的事、本班家长上次问过的 |
| **全场合计** | **5-8 条（封顶 8）** | 超出 8 条即视为超配，须删减通用题或方向题 |

- **"本班专属题"是泛化的主力**：这类题本库里**没有现成题干**，必须自己写，天然不会雷同。
- **必须主动向用户要班情**（用户已确认此流程，不要静默用占位符敷衍）：产出 Q&A 前**先问 1-2 个本班细节**，
  推荐问法："班里最近有没有什么普遍现象，或者您特别想让家长注意的点？"
  - 用户给了 → 直接写进"本班专属题"。
  - 用户明确说"没有 / 先不用" → 才**退而用 `<占位符>`** 留出，并在收尾【待补信息】提示。
  - **任何情况下都不得用库里的题凑"本班专属"的数。**

### 6.2 同场景反复使用时的换题规则

同一老师、同一学段、同一主题，**第二次及以后开同类会**：
1. **本学段方向题必须换**：上一场用过的方向，本场不再用（对照下方"已用方向"表）。
2. 换题不是换措辞，是**换方向**（例：上次问"偏科要不要放弃"，这次可换成"同伴压力 / 异性交往 / 亲子沟通"）。
3. 宁可临时向家长征题（"您最想问我什么"），也不复用上一场。

### 6.4 自检口径（交付前逐条过）

1. 通用题（§一）是否 **≤ 1** 条？
2. **本班专属题是否 ≥ 2 条**？（本库查不到题干的）
3. **全场合计是否在 5-8 条之间（未超 8 条）**？
4. 本学段方向题是否**避开了 §6.3 中该学段"已用过的方向"**？
5. 是否**没有照抄本库题干**（题干应已按本班细节改写）？
6. **题干是否干净**——有没有残留 `（本班）` `（本主题）` `（学段）` `（通用）` 之类分类标签？**有即删**。
