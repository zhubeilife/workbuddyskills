# 缺陷类型词典（A–H 类）

用于第 2 步"分维度诊断·逐项排查"。逐条排查下面各项，命中的写进报告。

每条格式：**怎么看出来** → **怎么改**。

修改建议必须是可操作的、落到具体动作，不是态度。

> **用法提醒（很重要）**：本库是"缺陷类型词典"，用途是——做完**论证还原**（`references/06-deep-analysis.md`）后，用来校准你发现的核心缺陷属于哪一类、有没有漏掉更基础的问题。**不要把它当主流程逐条打钩**：逐条打钩会写出"清单式、每条差不多重"的浅报告，正是要避免的输出。先还原论断、判定核心缺陷，再用本库去支撑和校准。

---

## A 类 · 选题和定位（影响最大）

**A1 选题太大太空**
- 怎么看出来：标题带"浅谈/初探 + 核心素养/新课标/信息化"，没有学段、没有具体内容点
- 怎么改：加限定词收窄到"某学段 + 某知识点 + 某方法"。比如把"核心素养下的小学数学教学研究"改成"小学数学'图形与几何'单元里培养空间观念的追问策略"

**A2 主题跟投递渠道不对路**
- 怎么看出来：稿子方向跟目标刊物栏目或评比主题对不上
- 怎么改：换渠道（成本最低），或者调整主题重心去对栏目

**A3 文体用错**
- 怎么看出来：教学设计投论文评比；教育叙事投学术评比；纯经验总结投核心期刊
- 怎么改：见 `01-paper-types.md` 文末的处理表，给两个选择

**A4 标题太大，内容兜不住**
- 怎么看出来：标题承诺"研究""实证"，正文只有做法描述
- 怎么改：把标题改小，或者补上研究过程兑现承诺

**A5 标题承诺的角度在正文落不了地**
- 怎么看出来：标题含具体方法 / 教学法（项目化学习、单元整体、深度学习、跨学科…），或主打"X 视角 / 基于 X"，但正文没有呈现该方法的关键特征，实际是通用做法换个名；或只在第一段提一句 X，后面再没出现。
- 怎么改：要么在正文真把该方法的特征写出来（如项目化学习要有人驱动性问题、持续探究、公开成果），要么把标题改贴切，别让标题比内容"高半截"。

## B 类 · 结构和逻辑

**B1 该有的部分缺了**
- 怎么看出来：对照这类文章的结构骨架，有整块缺失（比如策略类没有"问题的提出"）
- 怎么改：按骨架补上，缺的部分补写 1-3 段

**B2 层级乱**
- 怎么看出来：一级标题之间不是并列关系（比如"一、背景 二、策略 三、成效 四、概念"）；有的标题是名词短语，有的是句子
- 怎么改：统一标题写法，按逻辑重排（背景→依据→做法→证据→结论）

**B3 段落太长，一段塞多个点**
- 怎么看出来：单段超过 400 字，或者一段里放了 3 个以上论点
- 怎么改：拆段，每段一个论点，第一句先亮出这段要说什么

**B4 关键词没界定，或者前后说的不是一回事**
- 怎么看出来：像"深度学习""单元整体教学"这类词，全文含义不一致，或者压根没解释过
- 怎么改：在第 1 节后面补一段"核心概念说明"，全文统一用法

**B5 开头没有"要解决什么问题"**
- 怎么看出来：第一段就开始讲做法
- 怎么改：前面加一段"问题的提出"，用一节具体的课堂困境切入（越具体越好）

**B6 结尾空转**
- 怎么看出来：结尾是"综上所述，我们要……"这种口号
- 怎么改：改回研究的问题上去回答，再说说哪些没解决、后面打算怎么办

## C 类 · 论证和证据

**C1 只有做法罗列，没有理论依据**（策略类、研究类最常见的致命伤）
- 怎么看出来：通篇"我这样做"，没有课标依据、没有引用教育学或心理学的说法
- 怎么改：至少补 3-5 处理论依据（课标原文 + 1-2 篇文献）。每一处都要跟一个具体做法绑在一起，不能只在开头堆一段

**C2 几条策略是并列堆着，不是层层递进**
- 怎么看出来："第一…第二…第三…"之间没有内在关系，换个顺序也不影响
- 怎么改：改成有先后关系的（比如"课前—课中—课后"，或者"识别—干预—巩固"），并说明为什么是这个顺序

**C3 没有成效证据**
- 怎么看出来：只有"效果良好""学生兴趣提高"，没有任何数据、对比或者别人的印证
- 怎么改：补前后对比（实验班和对照班的作业正确率）、学生作品、平台数据、听课老师评价，有一样补一样

**C4 数据撑不住结论**
- 怎么看出来：样本 12 个人却说"普遍提高"；百分比算错；只给百分比不给基数
- 怎么改：把结论说小一点，跟数据匹配；补上基数

**C5 把功劳全归给一个做法**
- 怎么看出来：把班级成绩提升全归因于某一个策略，没排除别的因素
- 怎么改：加一段"其他可能的影响和局限"，反而更可信

**C6 案例细节假**
- 怎么看出来：学生发言像标准答案，对话工整得不像真实课堂
- 怎么改：还原口语化与表达阻滞之处，把真实的失败瞬间也写进去

## D 类 · 文献

**D1 没有文献综述**（投期刊是致命伤，评比是中等问题）
- 怎么看出来：全文没有参考文献，或者只在文末列了几本教材
- 怎么改：补 8-15 篇近五年文献，按"别人做了什么—还缺什么—本文补什么"组织成 1-2 段

**D2 文献太旧**
- 怎么看出来：最新的文献是 5 年前的，或者大量引教材教参
- 怎么改：换成近三年的期刊文献

**D3 文献综述只"述"不"评"**
- 怎么看出来：一篇一篇罗列"某某认为…"，没有归纳也没有评价
- 怎么改：按主题归类，最后明确指出现有研究还缺什么

**D4 参考文献格式不规范**
- 怎么看出来：缺卷期页码、缺年份、缺文献类型标识（[J]/[M]/[D]）；著录项顺序不对
- 怎么改：按 GB/T 7714-2015 逐条改（见 `03-norms.md`），条目多时跑 `scripts/check_references.py` 辅助

**D5 正文引的和文后列的对不起**
- 怎么看出来：正文出现 [3]，文后找不到；或者文后有，正文从没引过
- 怎么改：一条条对上。**这是外审专家明确会查的一项，在报告里单独提一句**

**D6 参考文献查不到**
- 怎么看出来：文献条目信息残缺、刊物名可疑、年份和作者组合奇怪
- 怎么改：在文献核查环节逐条核对，标"查到了 / 信息对不上 / 没查到"。**没查到只能客观陈述"该条目本次未命中本库"，不写"不存在"、不写"请你确认 / 自行判断"**

## E 类 · 表达和格式

**E1 口语化、第一人称太多**
- 怎么看出来："我觉得""咱们班""特别棒"；"我"字密度过高
- 怎么改：换成书面表述。教育叙事类例外，保留第一人称

**E2 摘要写得不像摘要**
- 怎么看出来：写成"本文分三部分…"的介绍式；太短或太长；带"我认为"
- 怎么改：改成 150-300 字，说清"什么问题—怎么做的—得出什么"

**E3 关键词不合适**
- 怎么看出来：不到 3 个或超过 5 个；用"教学""教育"这种搜不出东西的泛词
- 怎么改：取 3-5 个能区分的词

**E4 图表不规范**
- 怎么看出来：没编号、没标题、没数据来源；用截图代替图表；表格没表头
- 怎么改：编号（图 1 / 表 1）+ 标题 + 数据来源，换成能编辑的表格

**E5 字数不达标或者超太多**
- 怎么看出来：跟目标场合的要求差得明显
- 怎么改：超了就删重复论证和重复案例；不够就补证据和文献

**E6 错别字和语病**
- 怎么看出来：专业名词写错（"建构主义"写成"构建主义"）；中英文标点混用
- 怎么改：逐处改，专业术语全文统一

## F 类 · 内容风险（可能直接被淘汰）

**F1 政治性、常识性、科学性错误**
- 怎么看出来：政策文件名或年份写错；引用了已经废止的文件；学科知识错
- 怎么改：逐处核对改正。这类错误在评比里可以直接淘汰

**F2 学生隐私没处理**
- 怎么看出来：出现学生真实姓名、班级、学校全称
- 怎么改：改化名，并在文中说明"文中学生均为化名"

**F3 AIGC 痕迹明显**
- 怎么看出来：段落长度高度均齐、排比密集、术语堆着但没有任何具体细节、"综上所述/值得注意的是"高频出现
- 怎么改：补真实课堂细节和个人化的数据，把句式节奏打散。不是删这些句子，是把它们锚定到真实场景

**F4 数据前后矛盾，或者好得不真实**
- 怎么看出来：前文说 40 人，后文说 38 人；提升幅度都是整数；统计量不可能
- 怎么改：核对原始材料改正，或者把这部分数据删掉

## G 类 · 调查报告 / 实验报告专项

**G1 结果分析只复述百分比，不解释**
- 怎么看出来：每段都是"X% 的同学……，这与……有关"，报完数字就结束，没有接着说"为什么、跟别的变量什么关系、和已有研究是否一致"
- 怎么改：每段报完数据加一句解释；能做交叉分析的（如不同群体对比）就做，把"影响有多大"量化出来

**G2 结论 / 建议与前面的发现脱节**
- 怎么看出来：第四节的建议基本是把第三节已说过的"原因"重说一遍，没有针对数据暴露的缺口给新动作；或者建议和前文数据完全接不上
- 怎么改：每条建议从前面某条具体数据长出；回应"数据里最有意思 / 最反常的发现该怎么解决"

**G3 对数据的因果或阶段解读过度**
- 怎么看出来：从相关直接推因果（如"79% 读 6 本以上"全归因于学校环境，没排除家庭 / 年级）；从偏好推认知阶段（如"只有 11.9% 喜欢漫画"推成"已从图像阅读转向文字阅读"）
- 怎么改：把绝对表述改成"这一结果可能反映……，需更大样本验证"；正文区分相关与因果

**G4 缺研究局限说明**
- 怎么看出来：单校、单班、自评问卷、小样本，全文没提任何局限，却下了普遍结论
- 怎么改：结尾加一段"研究局限"，说明样本范围、方法限制、结论不宜外推到哪里

## H 类 · 学科常见坑（按学科看论文容易在哪栽）

下面按学科列出教师论文高频的"名实不符 / 浅表化"缺陷，配合第 1 步识别出的学段学科调用。诊断时看论文是否真把该学科的关键特征写出来了，而不是只贴概念。

**语文**
- 文言文 / 古诗文类：警惕"只讲字词、不悟情志"的浅层处理；看是否落到文化自信 / 审美创造的素养点，而非翻译串讲。
- 跨学科 / 整本书阅读 / 学习任务群类：查是否守住语文学科主体性，是否真有"任务"驱动而非简单拼盘。
- 单元整体教学类（常见）：看是否真有素养目标的整合，还是把几篇课文攒在一起讲。

**数学**
- 单元整体 / 结构化教学类：看是否真有"知识结构化"（概念网、迁移），还是课时简单叠加。
- 情境 / 应用题类：看情境是否真实、是否服务于数学理解，还是为情境而情境。
- "三会"（会用数学的眼光 / 思维 / 语言观察世界）：看是否落地到具体环节，还是只贴标签。

**英语**
- 听力 / 口语类（如听力填词）：看策略是否真针对"听中捕捉关键信息""推断意图态度"等技能点，而非泛泛"多听多练"。
- 项目化 / 活动观类：课标核心是"英语学习活动观"（学习理解—应用实践—迁移创新）；若以"项目化学习"为框架，看是否落到活动观层级、是否真有迁移创新，而非只当标签。
- 数字化赋能类：看技术是否服务于目标、是否提到"教—学—评"一体化，是否炫技。

**道德与法治**
- 案例 / 情境教学类：看案例是否有时代性、是否真引发价值辨析，还是堆砌时事。
- 五大核心素养（政治认同、道德修养、法治观念、健全人格、责任意识）：看是否落到具体行为表现，还是口号式。

**历史**
- 史料 / 唯物史观类：看史料是否真实、有出处，论证是否用史料说话，而非结论先行。
- 大单元 / 主题教学类：看是否守住历史时序与史实准确性，避免为"大概念"牺牲具体史实。

**物理 / 化学 / 生物（科学类）**
- 实验 / 探究类：看实验设计是否真有探究（变量控制、可重复），还是验证性复述；数据是否真实呈现。
- 跨学科实践（课标新增）：看是否真跨学科解决问题，还是贴标签。

**地理**
- 区域 / 人地协调观类：看是否用真实地理事象支撑，图表是否规范、数据是否可信。

**体育与健康**
- 大单元 / 专项运动类：看是否真有结构化运动技能教学，还是零散课时。
- 体质健康类：看是否有过程数据，而非主观感受。

**艺术（音乐 / 美术）**
- 核心素养（审美感知、艺术表现、文化理解、创意实践）：看是否落到具体作品 / 活动，还是空谈美育。

**信息科技**
- 核心素养（信息意识、计算思维、数字化学习与创新、信息社会责任）：看是否真有计算思维 / 算法设计，还是只讲工具操作。

**小学科学**
- 探究 / 工程实践类：看是否有真问题驱动、证据支撑，还是步骤演示。

> 注意：以上只列与教研论文预审最相关的"看什么"，不复述课标原文；引用具体条款时建议用户核对原版课标，不要凭记忆编造条款序号。

## 报告里怎么排序

命中多条时，按"对论文质量的影响程度"自然排序。排序参考的优先级（仅用于决定先后，不贴标签）：

1. **致命项**（F1、A3 文体用错）→ 影响最大，排最前，并说明影响（如"会被评偏经验总结"）。
2. **资格项**（署名、刊物、字数）→ 在部分高要求场合常不被认可，排靠前。
3. **结构项**（B1、B4、C1）→ 影响框架完整度，排中前。
4. **证据项**（C3、C4、D1）→ 影响说服力，排中。
5. **格式项**（D4、D5、E 类）→ 影响规范性印象，排后。

报告里按上面的先后排成一条清单即可，每条自带"位置 / 具体问题 / 可改方向"，可顺带点一句影响。
