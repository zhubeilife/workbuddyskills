# 文献与主题核查

> 【内部文件 · 仅供 agent 参考，不进入交付报告或对外文档】本文件只讲文献与主题"查什么、怎么找、底线是什么"，不对外暴露工具名与实现细节；具体资源调度以运行时可用资源为准。

用于第 4 步，以及用户问如何接入学术文献检索时。

**定位说明**：这一步做的四件事（主题现状、参考文献真实性、参考文献相关性、观点与材料的文献支撑）是深层分析的关键增量，内置资源可用时必做；若内置资源本次不可用，则第 4 步整体跳过，文献只做 GB/T 7714 体例形式检查，不对真实性 / 相关性下任何判断、**不向用户披露资源是否可用**。前 3 步（识别文体、分维度诊断、归并模块）在资源不可用时一样完整照常完成。

**底线：绝对不许凭记忆编造文献。**

---

## 一、四件事（要核查什么）

> 每件事的"发现如何落到报告（优势 / 不足 / 建议）"，统一见 `references/05-resource-verification.md` 第七节落点表与 SKILL.md 第 4 步，本文件只讲"查什么"。

### 事 1 · 主题研究现状（判断本稿角度的新意与扎堆程度）

1. 从标题、摘要、关键词提炼核心主题词（如"中华优秀传统文化 + 中学语文 + 育人""数字化赋能 + 初中英语 + 听说 + 项目化学习"）。
2. 用关键词检索近 3-5 年同主题文章，看研究多不多、主要观点是什么。

### 事 2 · 参考文献真实性（逐条核对）

逐条检索文后文献，每条给一个结果：查到了 / 信息对不上 / 没查到（措辞见 `references/05-resource-verification.md` 第七节）。

两类结构性问题，脚本 `check_references.py` 也能辅助发现：
- **空条目**：文末出现 `[n]` 但后面没有内容，而正文有对应引用标记——"引文—文献"对不上。
- **未编号文献**：文末列了文献但没编 `[n]`，与正文引用无法对应。

### 事 3 · 参考文献相关性（核对贴不贴题）

不只要"真"，还要"相关"。检查所列文献是否直接支撑本稿核心观点，是否偏旧、缺近 3-5 年成果；对每条做相关性分级（强相关 / 弱相关 / 装饰性引用），并对照主题检索暴露的"绕不开基准文献"，指出本稿漏引了哪一类关键文献（如项目式学习的设计要素类、创新思维测评类）。**类型校准："绕不开的基准文献"仅指标题/纲要等权威规范、或被反复引用的奠基性权威文献；硕士论文、普通期刊、教辅普教类刊物、会议摘要等同类近期文献，只称"同类最直接重叠文献"，不得称"基准文献"或"绕不开"。**报告里涉及文献时用"文献""研究现状"等说法，**不要用"查重""创新性检测"这类字眼**。

### 事 4 · 观点与材料的文献支撑（核对关键论断站不站得住）

抽查稿子里靠"某研究指出 / 数据显示 / 据调查"撑起来的关键论断，核对两点：

1. 所引文献是否真能支撑该论断——有无张冠李戴（正文标 [4] 引"费曼学习法"，但 [4] 实为一篇单元教学期刊文）、把综述当论据、断章取义。
2. 稿子的核心结论或数据是否与被引研究、同主题文献明显矛盾。

## 二、资源底座与降级处理

### 唯一资源底座：已接入的文献与课标资源

本技能已内置一套文献与课标资源，**无需另装、无外部配置**，包含可直接用于预审的三类能力：

- **文献检索能力**：用于主题研究动态、参考文献真实性与相关性核对。
- **教材与课标核对能力**：先识别学段学科，再据此查教材、知识点，用于核实论文涉及的具体教学内容是否真实、是否贴合课标。
- **认知与证据核对能力**：用于核实论文对"学情 / 认知规律 / 典型错因"的论述有无依据。

本技能**不依赖任何其他外部检索工具或资源**，资源核对一律走这套内置资源，不另行安装或调用其他工具。

### 降级：内置资源不可用时的处理

若内置资源未连接或本次会话不可用，**直接按常规评审继续，不改用其他检索手段，也不提示用户去安装任何备选工具**：

- 第 4 步「资源核对」整体跳过，报告中不出现「资源核对要点」块（不留空块）。
- 参考文献只做 GB/T 7714 体例的形式检查（编号连续、著录项完整、标点规范等），不对其真实性、相关性下任何判断，也不在报告中写"未命中本库"等检索结果表述。
- 其余内容的诊断（识别文体、选题与结构、论证与材料、语言、文献体例形式）照常完成。
- 报告中绝不以"经XX检索 / 借助XX / 资源不可用"等过程性表述向用户解释资源是否可用。

## 三、四条底线

1. **没查到 ≠ 不存在。** 文献库查不到的条目，措辞只能是"未能核实，说明其未命中本库"，绝不说"不存在""系杜撰"等断言。
2. **报告中不出现工具名或"经XX检索 / 借助XX"等过程性表述**——把发现以结论性语言自然呈现（如"已有研究已较多，本稿与主流框架雷同"），不向用户解释用了什么工具、有没有用上。
3. **核查范围以本技能接入的文献库能查到的条目为限。** 库里查不到的（如通用教材、非本库出版的图书），不对其"真实性"下任何判断，只从相关性 / 适用性角度给建议，并建议作者核对来源。
4. **不下载、不转发全文**，只核对题录信息；**不批量抓取**，只核对稿子里实际引用的那些条目。
