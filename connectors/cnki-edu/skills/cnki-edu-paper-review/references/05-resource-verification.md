# 文献与课标资源用法

> 【内部文件 · 仅供 agent 调用资源核对能力时参考】本文件不进入交付报告或任何对外文档，也不对外暴露任何接口细节或实现信息；文内各"资源"均为能力代称，实际调用以运行时资源为准。任何接口别名或实现细节均属内部信息，绝不可进入报告或任何对外说明（见 SKILL.md 约束 #20）。

用于第 4 步「资源核对」，以及第 2 步「论证与材料」里涉及具体学段学科内容时的核实。

本技能已接入的文献与课标资源即连即用，无需另装。它的价值不只是"核对参考文献"——五类能力要按论文的学段与类型精准投放：主题研究动态地图、方法/理论适配判断、教学内容落地核实、数据/认知依据核实、参考文献真实性与相关性核对。本文件讲清楚"什么时候用哪类能力、怎么查、查到怎么落报告"。

> 核对原则（真实性底线、不编造、不披露工具名、只查库内）见 `references/04-literature-verification.md`，本文只讲能力怎么投、按学段类型怎么用、结果怎么读。

## 一、核对能力清单

| 能力 | 返回什么 | 能支撑的评审判断 |
|---|---|---|
| 文献检索能力 | 可用于综览同主题研究的篇名、摘要、目录与相关性 | 主题研究动态与饱和度、方法 / 理论主流框架、论点新意、参考文献题名核对 |
| 学段学科识别 | 小学 / 初中 / 高中各学科 | 先定位学段学科，再据此查教材 / 知识点，确定学段学科 |
| 教材与课标核对能力 | 教材版本、册次、单元等真实定位 | 核实"以 X 版 X 册 Y 单元为例""参照 X 教材"是否真实、章节是否如稿所述 |
| 知识点与课标对应核对能力 | 学科知识点与课标条目 | 核实核心知识概念、教学目标、重难点是否对应真实课标知识点 |
| 认知与证据核对能力 | 典型试题、解析与认知层级 | 核实论文对"学情 / 认知规律 / 典型错因"的论述有无依据（实证 / 试题类用） |

边界说明：教材与课标核对能力需要先拿到学段学科识别结果；当某学段暂未取得学段学科识别结果时，这部分内容核实自然跳过，改用文献检索能力完成主题与引用核查即可。其余能力与学段无关，所有类型通用。

> 【内部执行约定 · 仅 agent 可见】
> 以下仅供 agent 在执行核对时参考，**绝不以任何形式（原文、改写、暗示）进入评审报告或对外文档，也不对外暴露任何实现细节或接口信息**。核对所需的内容项与组织方式均以运行时接入的资源为准，本块不固化任何特定取值、字段或结构形态。
> - 主题检索与引用核对是同一核对能力的两种用法：主题模式用于综览研究动态，引用模式用于按题名精确核对文献。
> - 主题综览取足以覆盖聚类样本的数量即可，过多反而淹没在雷同篇名里；聚类时优先看小标题（目录）而非摘要。
> - 引用核对用文献准确题名 / 作者，按"查到 / 信息对不上 / 没查到"给出结论。
> - 任一核对偶发不可用：重试一次；持续不可用则按底线跳过该环节，不阻塞、不向用户解释。
> - **教材与课标等明细类核对返回内容体量较大**：这类核对的结果应先落地为文件再定向检索，不要试图整体通读；在落盘结果中按"关键词 → 所需层级"找命中锚点，只把核对所需的定位结论取作依据。若仍取不回，收窄查询范围重查一轮，再不行则跳过该环节，不得反复重试（详见 SKILL.md 约束 #21）。
> - **同一教学内容在资源中呈多级归类，且常跨不同版本、乃至必修与选修等不同课程模块重复分布**：核实时先确认文稿标注的版本册次，再判断该内容是否跨模块；稿未写版本册次的，如实写"稿未标注"，并以该学段主流版本下可核实到的位置作为参照说明，不臆断作者所用版本。
> - **课标类核对须先核对命中结果的学段归属**：小学 / 初中 / 高中课标分属不同规范文件，命中结果可能来自相邻学段。若命中条文与文稿学段不一致，只作参照，不得据此断言文稿引文有误；未能定位到引文原句时，一律按"未能核实到确切出处、建议作者核对原文"落笔，不对该文件的存在与否下判断。
> - **报告层硬纪律（与 SKILL 硬性约束 #12、模板自查清单一致）**：交付报告只写"资源核对要点"里的维度名（如"教材版本与单元核实""知识点与课标对应核实"）与结论事实，绝不出现任何资源名、能力名、工具名，也不写"经XX检索""借助XX库"等过程性表述；未命中条目只用本技能统一措辞"未命中本库"。

## 二、学段—类型—能力覆盖矩阵

先用第 1 步定文体与学段学科（见 `references/01-paper-types.md`），再按下表投放能力。**原则：有具体学段学科内容的中小学论文，把教材与课标核对能力 / 知识点与课标对应核对能力用满；有数据 / 认知声称的，把认知与证据核对能力用上；其余类型以文献检索能力为主。**

### 小学

| 论文类型 | 主题检索 | 引用核对 | 教材/知识点 | 认知与证据核对能力 |

| 作业设计 / 分层 / 习惯养成 | ✓ | △（常无文献） | ✓ | ✓（错因 / 认知） |
| 班级管理 / 德育 / 家校 | ✓ | ✓ | △（知识点非必跑） | — |
| 教育叙事 / 随笔 | ✓（看饱和度 + 写法） | —（常无文献） | — | — |

### 初中

| 论文类型 | 主题检索 | 引用核对 | 教材/知识点 | 认知与证据核对能力 |
|---|---|---|---|---|
| 学科教学 / 策略 / 衔接 | ✓ | ✓ | ✓ 强 | 非必跑 |
| 试题命制 / 讲评 / 学情分析 | ✓ | ✓ | ✓ | ✓ 强 |
| 实验 / 调查 / 行动研究 | ✓ | ✓ | 非必跑 | ✓（认知 / 数据） |
| 德育 / 班主任 / 青春期 | ✓ | ✓ | △ | — |

### 高中

| 论文类型 | 主题检索 | 引用核对 | 教材/知识点 | 认知与证据核对能力 |
|---|---|---|---|---|
| 学科教学 / 核心素养落地 | ✓ | ✓ | ✓ 强 | 非必跑 |
| 选修 / 校本 / 课题研究 | ✓ | ✓ | ✓ | 非必跑 |
| 试题 / 备考 / 深度学习 | ✓ | ✓ | ✓ | ✓ 强 |

### 通用（不分学段）

| 论文类型 | 主题检索 | 引用核对 | 教材/知识点 | 认知与证据核对能力 |
|---|---|---|---|---|
| 教育管理 / 教育信息化 / 跨学科专题 | ✓ | ✓ | —（无学段学科） | — |

✓ 用得上　△ 看情况

关键认知：

- **中小学学科类论文的最大增量在教材与课标核对能力 / 知识点与课标对应核对能力**：这是本资源区别于通用文献检索的独特价值——能核实"论据是否真有根有据"，而不只是"文献查不查得到"。
- **不同学段的真实情况差异很大**，直接决定"同类论文在该学段到底该怎么评审、怎么用深"——下一节专门展开。
- 注：`references/01` 文体图谱里的"课例研究""校本课程开发"两类归入对应学段的"学科教学"行，同样走教材与课标核对能力 / 知识点与课标对应核对能力。

## 三、各阶段教师论文的真实情况与评审侧重（重点做深中小学）

### 小学

- **常见类型**：教学策略 / 活动设计、作业设计（分层 / 趣味化）、班级管理 / 德育叙事、家校沟通、教育随笔、低段绘本 / 整本书阅读。
- **真实情况**：一线教师重课堂实操与活动可复制性，论文多从公开课 / 赛课提炼；低段重图文、游戏化、习惯养成；严格实证少，多为经验总结。
- **本资源怎么用深**：教材与课标核对能力 / 知识点与课标对应核对能力核实"以 X 版 X 册 Y 单元为例"——小学教材版本多（人教 / 北师大 / 苏教等），册次单元极易写错；核实知识点是否对得上真实课标。主题检索看同类策略是否扎堆（"情境教学""大单元"易泛滥）。
- **典型不足**：教材版本 / 册次写错、把活动设计当研究、理论堆砌与活动脱节、成效只有"学生兴趣提高"类空话。

### 初中

- **常见类型**：学科教学策略（重衔接 / 过渡）、试题命制与讲评、学情分析与错题研究、实验 / 调查 / 行动研究、中考备考、德育与青春期。
- **真实情况**：承上启下，认知从形象到抽象过渡；中考导向强；教师常做小课题、微研究，有一定数据但规范性参差。
- **本资源怎么用深**：教材与课标核对能力 / 知识点与课标对应核对能力核实教材单元与知识点（初中知识点结构化强，错配一眼可见）；认知与证据核对能力核实"学生易错点 / 认知层级"是否站得住——初中错题研究多，最该用；主题检索看方法主流（"单元整体""深度学习"）。
- **典型不足**：错因分析泛泛（"学生基础差"）、数据来源不清、把教辅题当研究素材、衔接论述想当然。

### 高中

- **常见类型**：学科核心素养落地、深度学习 / 大单元、选修与校本课程、课题研究（规划课题）、试题与备考、相对学术化的论文。
- **真实情况**：素养导向、高考 / 选考压力大；论文更学术、引用更规范；常依托课题，易写成"课题报告体"。
- **本资源怎么用深**：教材与课标核对能力 / 知识点与课标对应核对能力核实教材与素养点对应（高中分必修 / 选择性必修 / 选修，册次复杂）；主题检索看素养研究饱和度；引用核对更严格（文献多，错引影响大）。
- **典型不足**：素养"贴标签"、文献堆砌无对话、课题报告式写法（重过程轻论证）、把政策文件当论证。

## 四、逻辑路线（决策流）

```
第1步 定型：用 01 判断文体与学段学科
   ↓
第2步 定能力组合：按第二节矩阵，列出本次要投的能力
   ↓
第3步 主题研究动态（文献检索能力·主题模式）—— 全部类型必做
       综览篇名 / 目录 / 摘要 → 研究密度、主流角度、近年走向
   ↓
第4步 引用核对（文献检索能力·引用模式）—— 文后有参考文献的必做
       逐条题名核对：查到 / 信息对不上 / 没查到
   ↓
第5步 内容核实（学段学科识别 → 教材与课标核对能力/知识点与课标对应核对能力）—— 取到学段学科识别结果时
       核实版本 / 册次 / 单元 / 知识点真实且如稿所述
   ↓
第6步 数据 / 认知核实（认知与证据核对能力）—— 实证 / 试题类且有数据 / 认知声称时
       核实典型考法、认知层级、典型错因是否站得住
   ↓
第7步 落报告：按第七节"组合信号"与落点表，写进优势 / 不足 / 建议
```

任一环节工具不可用或信息缺失，跳过该环节、不阻塞、不向用户解释（见 `references/04` 底线）。

## 五、各类型怎么查（检索式构造）

检索文本尽量用"实体组合"而非整句，命中更准：

- **小学教学 / 策略 / 活动设计**：`小学 学科 知识点 / 课文 教学`（如"小学数学 分数的初步认识 教学"）、`小学 语文 整本书阅读 策略`。
- **初中学科教学 / 策略 / 衔接**：`初中 学科 知识点 教学`（如"初中物理 浮力 教学 难点"）、`学科 学段 理论名`（如"初中数学 单元整体 教学"）。
- **高中学科教学 / 素养 / 备考**：`高中 学科 核心素养 落地`、`高中 学科 大单元 教学`、`高中 学科 试题 备考 策略`。
- **作业 / 试题命制（各学段）**：`学科 学段 作业设计 分层`、`学科 学段 知识点 典型错因`；再用认知与证据核对能力验证该知识点的常见考法与认知层级。
- **德育 / 班主任（中小学）**：`德育 主题 班级 / 活动`（如"小学 德育 值日 习惯 培养"）、`班主任 家校沟通 策略`。
- **教育管理 / 信息化 / 专题**：`学校 管理 机制 主题`、`双减 课后服务 管理`、`学科 学段 数字化 / AI 教学模式`、`智慧平台 数据 成效`。
- **调查 / 实验 / 行动研究**：`研究方法 主题`（如"行动研究 小学语文 阅读"）看方法是否主流；有数据声称时用认知与证据核对能力核认知层级。
- **叙事 / 随笔**：`主题 教育叙事` 看同类写法的饱和度与常见切入点，作为"写法参考"而非"对错判断"。

提取什么：

- 主题检索：看**命中篇名与目录**，快速判断"这个领域主流在谈什么框架 / 角度"——这是判断"论点是否雷同、是否需要换角度"的依据。
- 引用核对：看**著录项是否吻合**（刊物、年份、卷期、作者），吻合 = 查到，不符 = 对不上。

## 六、组合信号（最大化利用的关键）

本资源的威力在"交叉对照"，不是单点查询。三对组合必须做：

1. **主题检索 × 论文理论主张**：主题检索暴露了同主题主流理论框架（如"任务驱动 / 学习活动观"），拿它对照本稿主打的理论 / 方法——真用到学科内容里了，还是只当标签？（落点：优势 or 名实不符的不足）
2. **教材与课标核对能力 / 知识点与课标对应核对能力 × 论文教学实例**：教材与课标核对能力告诉你"X 册 Y 单元到底讲什么、真实知识点是什么"，拿它对照本稿"以 X 单元为例"的描述——版本 / 内容对得上吗？夸大或想当然了吗？（落点：论据是否站得住的不足）
3. **认知与证据核对能力 × 论文数据 / 认知声称**：认知与证据核对能力告诉你"该知识点学生通常卡在哪一层级、典型错因是什么"，拿它对照本稿"学生普遍…""难点在于…"的论断——有无实证依据？（落点：材料有无根据的不足）

另外：**用主题检索结果反哺"建议"**。若检索显示近年同类研究多从 A 角度切入，建议就可以具体写"可借鉴 B 视角（如…）拉开差异"，而不是泛泛说"要有新意"——让建议本身被文献支撑。

## 七、结果落到报告的规则（与 `references/04` 一致）

| 现象 | 落点 |
|---|---|
| 同主题命中很多、角度雷同 | 不足：主题已饱和、区分度不足，指明雷同点 |
| 命中少量但本稿角度不同且有据 | 优势：新意 + 依据 |
| 同主题主流用 A 理论，本稿用 B 且与学科内容结合更好 | 优势 / 建议 |
| 本稿理论 / 方法只贴标签、与学科内容脱节 | 不足：名实不符 |
| 教材 / 知识点核实对不上或夸大 | 不足：论据站不住，说明怎么修正 |
| 知识点 / 重难点与课标层级不符（如低层级内容被拔高为重难点） | 不足：知识点对应失准，写明课标实际层级与稿述差异 |
| 数据 / 认知声称与认知与证据核对能力典型情况不符、无依据 | 不足：材料依据不足 |
| 参考文献著录项不符 | 不足：信息对不上，写明具体不符之处 |
| 参考文献未命中 | 不足：说明该条目未命中本库，**不写"不存在"** |
| 命中但与本稿无关、或缺直接支撑文献 | 不足：相关性不足，建议补哪一类 |

**底线**：绝对不凭记忆编造文献；报告中不出现工具名或"经XX检索"等过程性表述，把发现以结论性语言自然呈现；只核对稿子实际引用 / 声称且文献库能查到的条目，库里查不到的不对其真实性下判断、只评相关性并建议作者核对来源；不批量抓取、不下载不转发全文。

## 九、大结果集深度挖掘：把"检索结果很大"变成深度信号

文献检索能力（主题模式）在主流、流行的主题上往往返回十几到几十条高度相似的命中——**这不是"查到了就行"，而恰恰是最有价值的信号**：它说明这个主题已被充分研究，本稿的真实处境（研究重叠在何处、可差异化的空档在何处、该对话的基准文献是谁）都藏在这片结果里（注："基准文献"仅指标题/纲要等权威规范、或被反复引用的奠基性权威文献，硕士论文等同类型近期文献称"同类最直接重叠文献"，详见本节第 3 点类型校准）。当前最常见的失败写法是只挑两三个篇名写一句"已饱和、雷同"就收手，把一座矿当成一块石头。本节给出把大结果集挖深的固定流程。

**触发条件**：当主题检索命中 ≥ 10 条，且篇名 / 小标题（目录）高度同构（典型如"数字化 / 数智赋能 + 某学科 + 教—学—评 / 阅读教学 / 作业设计"），即进入深度挖掘，**不再只写"主题已饱和"**，而要落到"研究重叠在何处、如何差异化"的具体判断。

### 1. 切入点聚类：画出"文献景观地图"

把命中的篇名 + 小标题通读，按**研究切入点**（不是"都写了什么"）归为 3–5 类。例（《教—学—评一体化 · 初中英语》一轮命中可归为）：
- 第一类 理论框架型：谈"一体化"的内涵 / 路径 / 机制（如高琰等 2026、索怀文 2026）
- 第二类 学科案例型：以具体单元 / 课例呈现做法（如本文）
- 第三类 技术赋能型：用大数据 / AI 破解"应用形式化"困境（如塔娜 2026 概念图实验）
- 第四类 评价专项型：聚焦"以评促学 / 过程性评价"单点深挖

→ 把本稿放进地图：它在哪一类？该类是否最拥挤？相邻有没有空类可迁移？这一下就把"已饱和"升级成"你在 A 类里和一堆人写同款，C 类的'用技术破形式化'才是更少人做、且你已有素材可切入的空档"。

### 2. 论点级比对：把作者的"创新"逐条对到文献

从"论证还原"（`references/06-deep-analysis.md`）得到的核心论断，拆成 2–3 个**可检验的具体命题**（不是整篇主张，而是"本文说 X 能 Y / X 导致 Y"这种粒度）。对每个命题再用主题模式配该命题的子角度、或引用模式精确题名去查文献**是否已经建立该命题**：
- 命题已被主流文献覆盖、作者却当成本文贡献 → 不足写"该点已被 X（2026）等充分论述，本文再提属冗余，应改为与 X 对话或换切口"，这就是最深的新意 / 冗余判断，而非"区分度不足"空话。
- 命题确属文献空白 → 这是本稿真正的差异化，写进优势并建议作者在摘要 / 引言把它**明确立为贡献点**。

### 3. 必对话文献锚定：从结果里挑"最该对话的 3–5 篇"

**代表文献选取与列举约束（必须遵守）**：必须覆盖多个切入点类别、至少指名 3 篇且分属不同类别，避免只取 1–2 篇同质文献、或把单篇孤例当作"唯一缺引项"；每篇都要指名并写明与本文的具体重叠点 / 差异点 / 证据量级，分析深入，不浅尝辄止只列题名。命中结果极少时，以"这一类文献整体"呈现缺引，不强行凑数。

在大结果集里筛出**权威性最高、与本稿核心论断最直接交锋**的 3–5 篇（核心期刊、近年、相关度靠前、且覆盖了本稿的立论基础）。拿它与作者文末文献比对：
- 作者漏了其中关键几篇 → 不足写"同主题近年已有 Y（2026）等直接研究，本文未与之对话，建议补引并明确差异"；**只把笼统的"缺文献"升级为"漏了哪一类关键文献"，不轻易把单篇抬成"基准文献"**（见下方类型校准）。
- 作者已引其中部分 → 核实是否真在正文对话（而非挂尾），未对话则按第七节"挂尾式"处理。

> **【类型校准 · 关键防错】"绕不开的基准文献"不做类型泛化。**
> 只有以下来源才有资格称"基准文献 / 绕不开"：
> - (a) 课标、纲要、政策文件等**权威规范**；
> - (b) 被反复引用的**经典理论 / 奠基性文献**（通常发表于权威核心期刊，是某概念的源头或主流框架的定义者）。
>
> **硕士论文、学位论文、普通期刊、教辅普教类刊物、会议摘要等，一律不称"基准文献"、也不写"绕不开"**——它们只是"同类最直接重叠 / 代表性近期文献"。正确措辞是"同题近年实证已有散斯尔、陆毅、张倩楠(2026)等，本文未与之对话，建议补引并明确差异"，把单篇硕士论文写成"必应"是过度拔高。
>
> **孤例保护**：若主题检索只干净命中其中一篇（其余标注"题名以实际命中为准"），须以"这一类文献"整体呈现缺引，不把单篇孤例写成"唯一缺引的基准文献"。

### 4. 证据 / 方法基准：用 corpus 给"证据强度"定标尺

对实证 / 策略类稿，结果集同时暴露了**该领域什么叫"够格的证据"**（如行动研究要有前后测、案例要有样本量与对比、调查要附工具与回收率）。把本稿的证据摆到这把标尺上：
- 若本稿证据低于 field baseline → 不足写"在检索到的同主题实证中，前后测对照是多数研究的常见做法（如 X 2026），本文仅陈述'大幅提升'而无任何对比数据，证据强度低于该 corpus 常见的对照基准"。
- 若本稿证据已达 baseline 甚至更高 → 作为优势带具体事实肯定。

> **【类型校准 · 证据标尺】"证据标尺"描述的是本次检索到的同主题 corpus 中常见的证据做法，是对照基准而非全称判断，不得写成"该领域一律/普遍必须"。** 若检索样本较小，应注明"在检索到的 N 篇中，前后测对照是多数做法"，避免把一次命中的趋势拔高为普适结论；对应写法见第十一节维度⑤。

### 5. 深层文献比对（最深一层）：直接调取最相关文献的真实段落进行逐句对照

对最相关的 2–3 篇，用更细粒度的文献比对直接看它们实际怎么写"一体化 / 有效性"——直接比对：本稿的"创新点"是不是早在某 2024 文里就被同样写过？若是，则在不足里**指名**那篇并点出重叠处，这比"雷同"二字有说服力得多。

**落点对照表（挖掘产物 → 报告位置）**

| 挖掘产物 | 写进 | 写法要点 |
|---|---|---|
| 文献景观地图（类 + 本稿落点） | 资源核对要点·主题动态 + 不足 | 不写"已饱和"，写"你在 A 类、相邻 C 类空" |
| 论点级比对（冗余 / 空白） | 不足（新意） / 优势（空白即贡献） | 指名文献 + 具体命题 |
| 必对话文献遗漏 | 不足 + 建议 | "漏了 Y，建议补引并对话" |
| 证据基准对照 | 不足（证据弱）/ 优势（达标） | 用 corpus 实测的 field baseline 当标尺 |
| 深层文献比对 | 不足（最深冗余） | 指名 TOP 文献 + 重叠点 |

**纪律**：以上所有结论仍不出现工具名、不写"经XX检索"；只把可指名的事实（篇名、年份、类归属、命题重叠）写成结论性语言。**大结果集不是负担，是"作者研究重叠在何处、如何差异化"的最佳证据源。** 若更细粒度的文献比对暂不可用，则以"指名 TOP 文献 + 论点级比对"替代，仍须落到具体篇名与重叠点，不退回"已饱和"一句话收场。

## 十、价值可见设计原则（报告怎么呈现，与 SKILL 第 4 步一致）

用户看不到资源核对价值，通常不是因为没查，而是因为**查出来的结论被写成了泛泛而谈、且没有任何"资源支撑"的痕迹**。解决办法不是加"经XX检索"的声明（违反底线），而是让结论本身"硬"到一眼能看出有事实支撑。

**两条核心原则**

1. **结论要能指名道姓。** 主题检索到的就点出实际篇名与年份；教材核实的就写出"第几章第几节叫什么、与文述是否一致"；知识点就写出真实数量或版本差异。示例：
   - 弱："该主题已有较多研究，与主流框架相似。"（看不出价值）
   - 强："检索近年期刊，该方向已密集，如《数智融合背景下初中生数学错题整理体系的构建与实践》（2026）、《错题资源在初中数学教学中的运用探索》（2026）等，其'采集—归因—推送—闭环'框架与本文高度同构。"（价值可见：说明评审真的比对过文献）
2. **核实无误也要说"一致"，不止说"有问题"。** 教材定位一致、框架贴合主流、文献可查——这些"核实一致项"同样是该资源的贡献，写进优势或核查要点，价值才立体；只报问题会让人觉得"查了半天就找茬"。

**两类读者（同一份分析同时服务，但始终是分析不是评分）**
- **作者（一线教师）**：最想要"安心 + 可执行改法"——确认自己的教学实践站得住、具体哪里改、怎么改，也需要被点明"这部分已核实无误"。
- **看重客观依据的读者（如评委、教研员）**：最想要"有位置、有依据的分析"——能据此自行判断论文的规范性、创新性、论证严谨与材料真实。

**关于"资源核对要点"块**：模板与示例已统一收口在 `templates/pre-review-report.md`。关键纪律：若本次完全没做资源核对（工具不可用、只做了 GB/T 7714 体例检查），则**不写本块**——此时没有价值可展示，强行写"核查要点"反而失真。

**模块维度清单（本技能接入的文献与课标资源已即连即用，按本次实查择适用者写，不硬凑）**：六维度与各自的"必须拉出的硬事实 / 弱写法 / 强写法"统一收口在 **第十一节《六维度深挖标准》**（含 ①②⑤ 三项通用检索做不到的核心增量），写资源核对要点前必读该节，本处不再复述。简言之六维为：① 教材版本与单元核实；② 知识点与课标对应核实（第一核心增量）；③ 同类研究现状与选题位置；④ 研究方法 / 理论适配；⑤ 关键论断的证据标尺与认知依据（第二核心增量）；⑥ 参考文献真实性与相关性。其中 ①②⑤ 是通用文献检索做不到、本资源独有的"地基型"核对，必须写透、指名道姓，才是"发挥了本资源最大价值"；缺了它们，模块就会显得薄且与其他检索工具无异。

## 十一、六维度深挖标准（让"做深"可操作、可核对，且是通用模型做不到的）

> 本技能"资源核对要点"区别于通用大模型的核心，在于它能接入**真实的教材库、课标知识点库、期刊文献库、试题与认知证据库**——通用模型只能凭训练记忆泛泛而谈（"项目式学习很流行""核心素养很重要"），本技能能拉出**只有真实资源才能给的事实锚点**：某教材某单元的真实定位、某知识点的课标学业要求层级、某主题的近年真实文献与饱和度、某认知点的真实错因层级。深度就来自"每个维度都必须落到这类事实"，否则模块就会显得薄、与通用检索无异。

> **为什么是这六个维度：** 它们对应教师论文（无论策略 / 实证 / 理论 / 课例 / 叙事 / 非学科类）真正需要被核验的几类事实——教学内容是否真有课标与教材依据（①②）、论点是否站得住、是否与他人研究区分开（③⑥）、方法与理论是否真落地（④）、数据 / 认知类论断是否真有证据标尺（⑤）。其中 ①②⑤ 是通用文献检索给不了、本技能独有的"地基型"核对，必须写透；其余维度通用检索也能做一部分，但本技能要求落到条目级事实而非泛泛结论。

**六维度 × 必须产出的"资源硬事实"（每次实查该维度时对照，缺一项即视为未挖深）**

| 维度 | 通用模型给不了、本技能必须拉出的硬事实 | 弱写法（避免） | 强写法（目标） |
|---|---|---|---|
| ① 教材版本与单元核实 | 该教材版本的册次/单元真实定位、单元在教材中的真实目标与核心概念 | "教材引用无误" | "X 版必修X第X章确含'Y'，单元真实定位是'本单元侧重……'；本文项目以'Z'为情境，确实围绕该单元核心概念展开（一致），但在'W'环节拓展到单元外，需作者说明衔接" |
| ② **知识点与课标对应核实（第一增量）** | 稿列知识点/目标在课标中的**真实条目与学业要求层级**；稿称"掌握/重难点"对应的课标层级；稿用的素养名称与课标是否一致 | "知识点对应课标" | "稿以'创新意识'为培养目标，对照化学课标，其属'科学探究与创新意识'素养，学业要求强调'能提出有探究价值的质疑、设计实验方案'；本文项目触及'制备-探究'但未设'提出质疑/方案设计'环节，对'创新意识'的落实停留在'完成项目'，名实有间距" |
| ③ 同类研究现状与选题位置 | 同主题近年**真实文献按切入点聚成的 3–5 类**、本稿落点、相邻空档、绕不开的基准文献（仅指标题/纲要/奠基性权威文献）、领域证据标尺 | "主题已饱和" | 见第九节（景观地图 + 论点级比对 + 必对话文献） |
| ④ 研究方法/理论适配 | 该领域主流理论/方法框架（真实文献呈现的）、本稿主打理论是否真落到学科内容 | "理论运用恰当" | "同主题主流以'深度学习/核心素养'为框架，本文标题主打'项目式学习'但正文未给出项目设计的理论支点（如驱动性问题、持续探究、公开成果等设计要素），属贴标签" |
| ⑤ **关键论断的证据标尺与认知依据（第二增量）** | 稿涉及知识点在**认知与证据核对能力中的真实认知层级与典型错因**；检索到的同主题实证中常见的**证据标尺**（前后测/作品量规/对照组） | "缺乏实证数据" | "稿称'创新思维显著提升'，对照化学认知证据，'实验探究与创新意识'在高考属较高认知层级（综合应用），学生典型卡点在'方案设计与变量控制'；本文无前后测或作品证据，证据强度低于检索到的同主题实证常见的对照基准（多数提供前后测/作品量规）" |
| ⑥ 参考文献真实性与相关性 | 每条命中/对不上/未命中的**模式**；相关性分级（强/弱/装饰）；缺哪类基准文献；正文引文与文献是否张冠李戴 | "请核对参考文献" | "4 条中 3 条命中但均为 2020 前旧文，缺近 3 年项目式学习直接文献；[2] 正文用于支撑'培养高阶思维'但[2]实为单元教学文，疑似装饰性引用；核心论断直接相关的权威基准文献 Y(2026)未引（仅当 Y 为课标/奠基理论/权威期刊 seminal 时成立；硕士论文等同类近期文献称'同类最直接重叠文献，建议补引对话'）" |

**判断口径**：每个被实查的维度，结论里至少要出现一处"只有真实资源才能给"的事实锚点（具体篇名+年份 / 具体教材册次单元 / 具体课标条目或层级 / 具体认知错因层级）；否则视为该维度没挖深，回到本节补事实。①②⑤ 三项（教材核实、课标条目比对、认知证据标尺）是通用检索工具做不到、本技能独有的"地基型"核对——它们写透了，"资源核对要点"才是本技能真正的差异化优势。

## 十一（续）· 资源核对要点内嵌对照表模板（核心可视化优势）

通用大模型只能输出泛泛结论（"项目式学习很流行""核心素养很重要"），本技能接入真实资源后，能把"本稿说法 vs 真实资源结论"并置成表——这是相对通用模型最直观、最不可替代的呈现。表不是清单，是**证据锚点**：每一行都要落到具体篇名 / 真实单元 / 课标条目 / 认知层级。三张常用表样如下，按本稿实查维度择用，不必全放。

### 表 A · 选题位置对照表（维度③ 同类研究现状与选题位置）

## 十二、资源核对要点的深度收束（以审稿人视角拓开思路，而非只做核对清单）

"资源核对要点"要成为本技能相对通用模型的核心优势，不能只停留在"查到了、对上了、没对上"的核对清单——通用模型也能泛泛地说"文献需补充"。它的不可替代性在于：用真实资源把**作者没看见的研究格局、没想到的方法论、用得上的差异化空档**摊开给他看，体现审稿人一针见血又深入浅出的判断力。为此，对照表之后必须写一段有判断力的"深度收束"分析（约 150–250 字），至少覆盖两点：

1. **差异化空档**：基于文献景观地图，明确指出本稿本可立足、却未利用的真实空档——如未被覆盖的学段 / 学校类型 / 情境（县域高中、农村校、薄弱校），或相邻学科 / 相邻理论的可迁移切口；这是作者自己改不动、但一看就有方向的地方。
2. **可拓开的分析视角**：指出同源资源还能支撑的更深一层判断（如"若补入前后测，本文可落到'证据强度'而非'原则陈述'层""若把'创新思维'锚定到课标'创新意识'的具体行为指标，评价环节才有观测点"），帮作者把文章从"框架完整"推向"有实证支点"。

这段分析要直接给判断、给视角，不写"建议作者自行思考"之类的空话。**它也是整个模块"够深、够拓开思路"的最终落点。**
