# 中小学教师论文文体图谱

用于第 1 步"判断文体"。判断出文体后，用该文体的**结构骨架**做结构体检（逐项标 有/缺/太弱），再用该文体的**评审侧重**组织诊断理由。

核心原则：**文体决定结构，结构决定扣分点。** 用错文体是中小学教师论文最常见的结构性失误。

> 说明：课题申报书、开题/中期/结题报告及配套过程材料不在本技能范围内，本图谱不收录。

---

## 快速识别

| 看到这些特征 | 就是这一类 |
|---|---|
| 教学目标、学情分析、教学过程、板书设计、设计意图 | 教学设计 |
| 大段师生对话实录、教学片段 + 片段分析 | 课堂实录与案例分析 |
| 制度、机制、管理流程、办学理念、面上数据 | 教育管理论文 |
| 第一人称"我班上""那天"、单一事件、情感叙事 | 教育叙事 / 教学反思 |
| 问卷、样本量、百分比、信效度、统计表 | 调查报告 / 实验报告 |
| 发现问题→找原因→定方案→实施→观察→再改（两轮以上） | 行动研究报告 |
| 课程纲要、目标-内容-实施-评价闭环 | 校本课程与教材分析 |
| 平台、工具、数据看板、线上线下融合 | 教育信息化 |
| 分层任务、题型设计、难度梯度、作答样例、错因分析 | 作业设计与试题命制 |

## 1. 教学设计

- **篇幅**：2000-5000 字
- **骨架**：教材分析 → 学情分析 → 教学目标 → 教学重难点 → 教学过程（含设计意图）→ 板书/作业设计 → 教学反思
- **评审侧重**：设计意图跟课标、核心素养对不对得上；环节之间是不是层层递进；别人能不能照着上
- **常见问题**：只有流程没有设计意图；目标写成"了解""掌握"这种没法检验的词；学情分析是套话；反思只写"学生参与度高"
- **重要提醒**：教学设计**不是论文**。投期刊或参加论文评比会被判"缺文献综述、缺研究性"，这是高频的文体用错

## 2. 教学策略 / 教学法论文

- **篇幅**：3000-6000 字
- **骨架**：问题的提出 → 理论依据（课标、教育学/心理学）→ 策略分点阐述（3-5 条）→ 课堂实施与例子 → 成效分析（要有证据）→ 结论与反思
- **评审侧重**：策略成不成体系（不是零散妙招罗列）；有没有实际证据支撑；理论是否真正支撑做法
- **常见问题**：**这一类最容易出问题。** 只讲做法没讲依据，被评"经验总结、学理性不足"；几条策略是并列堆着而不是层层递进；成效只说"效果好"没有前后对比
- **提升方向**：引 5-10 篇近五年的文献；给自己的做法起个名字（比如"三阶追问法"）远胜泛泛说"提高兴趣"

## 3. 课堂实录与案例分析

- **篇幅**：3000-8000 字
- **骨架**：案例背景 → 教学片段实录（含师生对话）→ 片段分析 → 用理论照一照 → 改进建议
- **评审侧重**：实录真不真实（对话是不是像真的课堂）；分析有没有深度（不能停在"学生很活跃"）；理论用得贴不贴切
- **常见问题**：实录像剧本，学生发言全是标准答案；分析只有感受没有理论；改进建议跟前文脱节
- **提升方向**：同一个片段用两种理论视角各分析一次

## 4. 教育叙事 / 教学反思 / 教育随笔

- **篇幅**：1000-3000 字
- **骨架**：没有固定骨架，常见"事—思—理"三段：真实情境 → 困惑与处理 → 感悟与提炼
- **评审侧重**：真不真、细节够不够、反思深不深
- **明确豁免**：**不要求文献综述、不要求参考文献、不要求数据。** 拿学术标准去评教育叙事，是典型的评审出错
- **常见问题**：只有事没有思（流水账）；感悟拔高到"教育的本质就是爱"这种没法验证的话；细节失真
- **评审关键**：细节的真实感 + 反思的转折点。有"我原本以为……后来发现……"这种认知转变的，更容易被认可

## 5. 德育与班主任工作论文

- **篇幅**：3000-5000 字
- **骨架**：问题呈现 → 找原因（学生层面 / 家庭层面 / 班级层面）→ 带班策略 → 典型案例 → 成效
- **评审侧重**：情感分寸对不对（不能写成说教）；个案有没有说服力；别人能不能借鉴
- **常见问题**：把学生真实姓名写出来（应该用化名并说明）；对策是"加强沟通、多鼓励"这种口号；没有成效证据
- **提醒**：涉及学生个人信息必须脱敏，这一点现在越来越被看重

## 6. 教育管理论文

- **篇幅**：3000-6000 字
- **骨架**：背景与问题 → 管理理念或政策依据 → 机制设计 → 实施过程 → 成效（面上数据）→ 反思
- **评审侧重**：制度设计合不合理；证据必须是**全校或全年级的数据**，单个班的情况撑不起管理类的结论
- **常见问题**：拿一个班的经验推全校结论；制度描述像工作汇报；只讲成效不讲代价和风险
- **提醒**：政策文件名和年份必须准确

## 7. 调查报告 / 实验报告

- **篇幅**：4000-8000 字
- **骨架**：调查背景与目的 → 对象与方法（样本量、怎么抽样、工具、信效度）→ 结果（图表）→ 分析讨论 → 对策建议
- **评审侧重**：样本有没有代表性；数据真不真；统计方法对不对
- **常见问题**：样本很小却下普遍结论；只有百分比没有基数；问卷题目没附在文后；图表没编号没标题
- **提升方向**：这一类在期刊审稿里通过率明显高于纯经验类，因为"有数据"是硬通货

## 8. 行动研究报告

- **篇幅**：5000-10000 字
- **骨架**：发现问题 → 找原因 → 定行动方案 → 第一轮"实施—观察—改" → 第二轮 → …… → 成效评估 → 结论
- **评审侧重**：改进的链条完不完整；每一轮为什么这么改有没有交代
- **常见问题**：只做一轮就下结论；看不出"改了什么、为什么改"
- **硬性判断**：**少于两轮循环的行动研究，结构上就不成立**，这是最硬的扣分点

## 9. 教学案例 / 课例研究

- **篇幅**：2000-4000 字
- **骨架**：主题 → 背景 → 设计 → 实施 → 多角度分析（多人观察记录）→ 结论
- **评审侧重**："切口小、挖得深"；同一节课打磨多轮的痕迹
- **常见问题**：切口太大（"小学语文阅读教学研究"不是案例研究）；只有一稿没有迭代
- **提升方向**：附上观察量表、课堂观察原始记录

## 10. 校本课程开发 / 教材分析

- **篇幅**：4000-8000 字
- **骨架**：课程纲要（目标、内容、怎么上、怎么评）→ 开发过程 → 实施案例 → 评价方案与结果
- **评审侧重**：目标、内容、评价三者对不对得上；有没有课程意识（不是活动罗列）
- **常见问题**：把社团活动记录当成课程开发；没有评价方案

## 11. 教育信息化 / 数字化转型

- **篇幅**：3000-6000 字
- **骨架**：应用背景 → 技术方案（平台/工具/资源）→ 教学模式怎么重构 → 数据成效 → 反思与风险
- **评审侧重**：技术和教学融合得深不深（不能停在"用了某平台"）；有没有平台数据佐证
- **常见问题**：写成产品使用说明；把工具的功能当成教学成效；数据只取平台活跃度

## 12. 各类专题论文（综合实践、劳动教育、心理健康、家校共育、思政一体化等）

- **篇幅**：3000-6000 字
- **骨架**：同教学策略类，但必须有**对应专题的理论依据**（如劳动教育纲要、积极心理学、协同育人理论）
- **评审侧重**：跟最新政策对不对得上；活动设计专不专业
- **常见问题**：引的政策文件是旧版；活动设计没有专业依据

---

## 13. 作业设计与试题命制

- **篇幅**：2500-5000 字
- **骨架**：设计理念与依据（课标、减负政策）→ 目标与能力指向 → 题型 / 任务设计（分层、差异化）→ 实施说明（怎么用、用时、反馈方式）→ 评价与改进
- **评审侧重**：设计有没有课标或政策依据，不是凭经验出题；分层和差异化是不是真落地；有没有说明如何批改与反馈、怎么根据结果调整教学
- **常见问题**：只给题目没有设计说明；分层只是"基础题 + 提高题"标签，难度梯度没讲清；缺少评价反馈环节；题型与目标对不上（练了识记却说培养思维）
- **提升方向**：附一组学生作答样例与典型错因分析；说明设计如何呼应单元目标或核心素养

## 三条通用判断

1. **有没有"想解决什么问题"**——第一段就开始讲做法的，是问题；先讲清"要解决什么具体问题"的，更好。
2. **有没有"证据链"**——说了做法，有没有东西证明它有效？前后对比、原始材料、别人的观察，有一样算一样。
3. **文体跟投递渠道配不配**——不配的时候，优先建议换渠道，而不是硬改文章（换渠道成本低得多）。

## 文体用错了怎么处理

发现文体跟目标不匹配时，在报告最前面醒目提示，并给出两个选择：

| 情况 | 建议 |
|---|---|
| 教学设计 → 投期刊/参评论文 | 改投教学设计评比或优质课配套材料；或者补写文献综述和成效数据，扩写成教学策略论文 |
| 教育叙事 → 参评学术类论文评比 | 改投师德征文、教育叙事专项评比；或者补理论框架，改写成案例分析 |
| 经验总结 → 投核心期刊 | 改投普刊或教育类报纸；或者补数据补文献，升级成调查报告 |
| 教学案例 → 当论文参评 | 补上多轮打磨过程和理论分析，否则只能参加案例类评比 |
