# 格式与体例：常见问题与改法

用于第 2 步，看格式上的常见问题。

**使用方式**：发现问题后按本技能报告结构分别落位——问题本身写进「不足」（问题是什么、在原文哪、为什么是个问题），对应的改法写进「建议」（写清改在哪一小节、补哪类内容、参考哪类成熟做法，用审稿人自然、有判断力的口吻展开）。**严禁套用"打开第几节、引入/补入"之类统一话术起手**（详见 SKILL 硬性约束与模板"四、建议"）；**不要单独做一张打钩的规范核查表**。报告里要写"你的摘要只有两句话，评委看不出你做了什么"，不要写"摘要：不合格"。

---

## 一、体例上的常见问题

| 问题 | 怎么看出来 | 怎么改 |
|---|---|---|
| 标题太长或太虚 | 超过 25 字；用"浅谈""初探"开头 | 压到 25 字内，把研究的具体对象写进去 |
| 摘要不像摘要 | 写成"本文分三部分…"；太短（少于 100 字）或太长（超过 400 字）；带"我认为" | 改成 150-300 字，说清"什么问题—怎么做的—得出什么"，用第三人称 |
| 关键词不合适 | 不到 3 个或超过 5 个；用"教学""教育""研究"这类泛词 | 取 3-5 个能区分的词，把泛词换掉 |
| 层级乱 | 一、（一）1. (1) 层级跳级；同名的标题出现两次；标题写成一句话 | 层级统一；标题体例一致（都是名词短语或都是句子） |
| 图表不规范 | 没有编号和标题；没有数据来源；用截图代替表格；表格没有表头线 | 编号（图 1 / 表 1）+ 标题 + 数据来源；换成能编辑的表格 |
| 作者信息缺 | 只有姓名没有单位；或者匿名投稿却把信息留在正文里 | 按渠道要求补全 |
| 字数不对 | 跟目标场合要求差得明显 | 超了就删重复论证；不够就补证据和文献 |
| 中英文标点混用 | 中文句子里出现英文逗号、引号 | 全文统一 |

## 二、参考文献规范（GB/T 7714-2015 顺序编码制）

**基本规则**：正文引用处用上标 [1][2][3] 标注，文后按引用顺序编号排列。**正文引的和文后列的必须一条条对应上。**

### 各类型该长什么样

**期刊 [J]**
```
李志强, 张明. 深度学习视域下初中数学单元教学设计[J]. 中国数学教育, 2023, 50(3): 145-153.
```
顺序：作者. 题名[J]. 刊名, 年, 卷(期): 起止页码.

**专著 [M]**
```
王建民. 学术论文写作指导[M]. 3版. 北京: 高等教育出版社, 2022: 45-67.
```
顺序：作者. 书名[M]. 版本（第一版不写）. 出版地: 出版者, 出版年: 引文页码.

**学位论文 [D]**
```
陈思远. 基于知识图谱的学业评价方法研究[D]. 北京: 清华大学, 2023.
```

**会议论文集 [C]**
```
陈芳, 李强. 面向智慧课堂的数据治理模型[C]//第28届教育技术学术会议论文集. 北京: 科学出版社, 2023: 88-95.
```

**电子文献 [EB/OL]**
```
教育部. 关于加强新时代教育科学研究工作的意见[EB/OL]. (2019-10-30)[2026-10-05]. http://www.moe.gov.cn/.
```
顺序：作者. 题名[EB/OL]. (发布日期)[引用日期]. 网址.

**报纸 [N]**
```
张慧. 人工智能伦理框架亟待建立[N]. 科技日报, 2024-03-15(5).
```
顺序：作者. 题名[N]. 报纸名, 出版日期(版次).

**标准 [S]**
```
国家标准化管理委员会. 信息与文献 参考文献著录规则: GB/T 7714-2015[S]. 北京: 中国标准出版社, 2015.
```

### 最常见的六种错

1. 忘了写文献类型标识（[J]/[M]/[D] 这些）
2. 期刊条目缺卷期或页码
3. 年份写成汉字（"二〇二三年"），要用阿拉伯数字
4. 页码写成"第 145-153 页"，直接写起止页码就行
5. 作者超过三个没用"等"（中文）/"et al."（英文）
6. 正文引的编号跟文后对不上

### 还有一个隐性问题

引教材、教参、网络文库占比太高（超过四成），会被认为"没读过真正的研究文献"。这种情况建议补几篇近三年的期刊论文。

## 三、政策文件引用准不准（很容易被忽视）

1. 文件名要写全称，跟官方一致（比如《义务教育课程方案和课程标准（2022年版）》）
2. 发布年份要对
3. **不能引用已经废止的旧版文件**——评比里这是常见淘汰原因
4. 引用政策原文要加引号并注明出处

**做法**：把文稿里引到的政策文件逐条列出来，标"现行有效 / 需要核实 / 疑似已废止"。拿不准的标"需要核实"，不要武断下结论。

---

## 四、报告里怎么呈现这些

**不要在交付给作者的报告正文里单独做一张打钩的规范核查表。**（模板末尾的"写报告前的自检清单"是评审者内部对照用的质量检查，同样不得出现在交付正文——它不属于报告内容，只是写完后给自己核对用的。）格式与体例问题按本技能结构分别落位：问题本身写进「不足」（问题是什么、在原文哪、为什么是个问题），对应的改法写进「建议」（写清改在哪一小节、补哪类内容、参考哪类成熟做法，用审稿人自然、有判断力的口吻展开，**不套用"打开第几节、引入/补入"之类统一话术**），用正常的连贯说法写，不要压缩成"条目：结论"的打分标签：

- ❌ "摘要：不合格"、"参考文献格式：0 分"（把判断压成一条标签，既无位置也无理由）
- ✅ 不足写："摘要现在只有两句话，评委看不到你具体做了什么"；建议对应写："把摘要补到 150–300 字，把'调查了哪个年级、用了什么方法、得出什么结论'写进去"
- ✅ 不足写："文后第 4 条参考文献在正文里找不到对应位置，第 7、9 条则是正文引了但文后没列"；建议对应写："这几条要一条条对上，正文引用与文后列表逐条核对一致"
