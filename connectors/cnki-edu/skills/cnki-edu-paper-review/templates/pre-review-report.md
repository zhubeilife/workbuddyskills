# 预审报告模板

> 这是结构，不是填空题。删掉用不上的部分。
> 带【】的是要填内容的占位符。
> 报告核心是诊断分析：把稿子的问题摆清楚、指到具体位置、给修改方向与依据。
> 报告由「总体评价 + 资源核对要点（仅当本次实际做了资源核对时出现）+ 优势 / 不足 / 建议」构成。资源核对要点只在本次实际做了资源核对时出现，平时按四节正常写。都用连贯的段落写，不拆成表格或"现状 / 问题 / 位置 / 方向"标签（资源核对要点中允许嵌入少量针对性对照表，见下文）。**三模块（资源核对要点 / 不足 / 建议）之间不得把同一事实用相近篇幅各讲一遍**：资源核对要点讲"核实结论"、不足讲"问题 + 原文依据"、建议讲"具体怎么动手"，各自只讲本模块该讲的那一层。已写入资源核对要点的核实事实（如教材已核实、主题饱和指名），在优势 / 不足 / 建议中只做一句话简引（如"教材知识点已核实，见资源核对要点"），不重述整段验证过程，避免跨模块重复。
> 优势、不足、建议的每条都要编号（1. 2. 3.）。
> 文献与主题的研究现状、参考文献真实性与相关性，按下面的落点写进优势 / 不足 / 建议。
> 不写作者姓名、单位、职称等个人信息；不写"为投稿 / 评级 / 评职称而写"之类的用途判断。

# 《【论文标题】》预审报告

> 顶部标题固定格式：一律为 `# 《<论文标题>》预审报告`——"预审报告"必须置于论文标题（含书名号）之后。禁止使用 `预审报告 · 学段学科 ·《标题》` 或 `教研论文预审报告` 等变体（前者把"预审报告"放在前面、后者丢失论文标题）。文件名统一为 `<标题简称>-预审报告-<日期>.md`，同样把"预审报告"放在标题简称之后。

## 一、总体评价

【一段或两段连贯的话。说清：这是一篇什么文体的稿子、主要写了什么、整体处于什么状态（已经比较成型 / 偏经验总结 / 还有明显短板）。可点出最突出的一个特点。若文稿带发表痕迹，可在段落中点明"这看起来已经发表过，预审主要帮你判断它能否复用到要求更高的场合"，但仍要把文体、内容、状态写清楚，不能只写这一句。语气温和、客观，不写个人信息，不写用途。段末用一句话给出"核心判断"：本文最关键的一个问题是什么，为后面"不足"第 1 条做铺垫。】

## 资源核对要点（仅当本次实际做了资源核对时出现）

【工具无关、结论导向的小模块，紧接"总体评价"，只在本稿实际做了资源核对时出现；本次实际查了哪几个维度就写哪几个，不要为凑数硬写没查的维度，也不要把一项拆成多项充数。不出现任何工具名或"经XX检索"字样，把对照到的事实写成结论性语言，每个维度写透、指名道姓，不止报问题也报"核实一致"项。本模块允许嵌入少量紧凑对照表（选题位置对照、课标术语比对、文献相关性分级），使"本稿说法 vs 真实资源结论"一目了然——这是本技能相对通用模型的核心可视化优势；表为证据锚点，不是清单。对照表的表头须用明确措辞（如"本文定位""一致性说明""核查结论与处置建议"），**不得使用"差在哪""差距"等模糊表述**；凡涉及文献的条目，须给出完整出处（作者·题名·刊物 / 学位 / 会议·年份，卷期页码若可知一并注明），不能只写"作者（年份）"，否则"应补引"无从查找。整个资源核对要点应达到审稿人视角的深度——在对照表之后用一段有判断力的"深度收束"分析，点明本稿真正可差异化的空档（如未被覆盖的学段 / 情境、可迁移的方法论）与可拓开的分析视角，帮作者打开思路，这是通用模型给不了的判断。按论文实际投的能力，常见可写的维度（择适用者）：
(1) 教材版本与单元核实——写出稿中"以 X 版 X 册 Y 单元为例"的版本 / 册次 / 单元是否真实、是否如稿所述的具体事实（如"X 版 X 册 Unit Y 确含该内容"或"稿称 Unit 5，实际该内容在 Unit 6"）；核实一致也要明说"一致"。
(2) 知识点与课标对应核实（本技能区别于通用文献检索的核心增量）——核实稿中列出的核心知识点 / 教学目标 / 重难点是否对应真实课标知识点体系：名称是否准确、是否遗漏关键知识点、是否把低层级内容拔高为重难点（如课标属"了解"稿称"掌握"）、是否有张冠李戴；写出真实知识点名称或数量（如"稿中'XX'确属课标核心知识点，但把'YY'列为难点而课标更强调'ZZ'""稿称的重难点在课标中实属'了解'层级而非'掌握'"）。稿未列知识点则本项不写。对于德育、教育管理、专题（劳动 / 心理 / 家校 / 思政等）等非学科类论文，本维度相应核对其引用的政策、纲要、文件依据是否准确且为最新版（如"双减"意见、劳动教育指导纲要、中小学德育工作指南等的名称、年份、条款），名称或年份有误、引用旧版或已废止文件即列入不足；本库未收录的政策文件只评适用性、并建议作者核对来源，不对其存在性下判断。稿未列知识点且非学科类未引政策依据的，本项不写。
(3) 同类研究现状与选题位置——不写"已饱和"，画文献景观地图：同主题文献按切入点归 3–5 类、本文落哪类、该类是否最挤、相邻空档在哪，指名 3–5 篇绕不开的基准文献及与本文差异（"基准文献"仅指标题/纲要等权威规范、或被反复引用的奠基性权威文献；硕士论文、普通期刊、教辅普教类刊物、会议摘要等同类近期文献，只称"同类最直接重叠文献"，不得称"基准文献"或"绕不开"），必要时给该领域的"证据标尺"（同行做到什么证据量级）。代表文献须从多个切入点类别中选取至少 3 篇、分属不同类别，指名并写明与本文的具体重叠 / 差异 / 证据量级，不把单篇当唯一缺引项，也不浅尝辄止只列题名。
(4) 研究方法 / 理论适配——该领域主流理论框架 / 研究方法是什么，本稿主打的理论 / 方法真用到学科内容里了还是贴标签（名实不符）。
(5) 关键论断的证据标尺与认知依据（实证 / 数据 / 认知类论文）——对有"学生易错点 / 认知层级 / 难点在于"等论断的，对照实测情况看该知识点学生通常卡在哪一层级、典型错因是什么，判断论断有无依据；对实证类，用检索到的同主题实证给"证据强度"定标尺，把本稿证据摆到标尺上（如检索到的同主题实证多以前后测对照为常见做法，本文仅陈述"大幅提升"而无对比数据，证据强度低于该 corpus 常见的对照基准——注意是"检索到的 N 篇中常见的做法"，不作全称判断）。
(6) 参考文献真实性与相关性——写清命中 / 对不上 / 未命中分别有哪些、有无雷同或转录错误模式、缺哪类文献；未命中的条目只说明其未命中本库、不写"不存在"。
本次完全没做核对（工具不可用、只做了体例检查）则不写本块。示例与落点见 `references/05-resource-verification.md` 第九节落点对照表与第十节价值可见原则。】

## 二、优势

【连贯段落，3-5 条真实优点，每条编号（1. 2. 3.），**与不足同等深度**——每条写成完整连贯段落，点出文中具体章节 / 案例 / 原句 / 数据作为佐证，不写一句话概括、不空泛、不硬夸。先列真正成立的亮点。文献与主题类落点：若这个主题讨论已经很多，但作者从另一个新角度深入分析、带来了有依据的新思考，把这一点写在这里，并说清"新在哪、依据是什么"。凡资源核对核实过"教材定位一致 / 框架贴合主流"等，作为优势时要带上具体事实。】

例如：
1. 选题贴着教学实际，谈的是真问题，不是空泛喊口号。
2. 案例真实可感，举的例子来自自己的课堂，有说服力。
3. 在"传统文化育人"已有大量研究的背景下，本文以"三塑造"为统摄框架切入，并落到具体的教学环节，角度有一定新意。

## 三、不足

【连贯段落，按对稿子质量的影响从大到小排，每条编号。每段讲一个方面的问题，把"问题是什么、在原文哪、为什么是个问题"揉进同一段话，不要拆成"现状 / 问题 / 位置 / 方向"四个标签，也不要用表格。位置信息用"第二节研究设计""第三部分阅读兴趣分析"这类说法自然嵌进句子，既不破坏连贯又能精准定位到章节与段落。语言平实。

文献与主题类落点写在这里（只评文献库能查到的条目，查不到的不对其真实性下判断）：
- 参考文献某条信息对不上 → 写明哪条、差在哪，说清"为什么影响可信度"。
- 参考文献某条未能核实到确切出处 → 写"此条来源未能核实"，不写"不存在"。
- 所列文献与论题相关度不高、缺直接支撑本文核心观点的文献 → 指明缺哪一类。
- 这个主题已有大量同题研究、本稿内容与主流框架大差不差 → 须指名具体文献或类别，写明本稿与已有研究在哪一框架 / 例证 / 结论上具体雷同（不得只写"主题已饱和"一句收场）；若命中 ≥10 条且高度雷同，按 `references/05-resource-verification.md` 第九节做切入点聚类、论点级比对与差异化判断。
- 研究方法 / 理论只贴标签、与学科内容脱节（名实不符）→ 写明"标题/开头主打的 X，在正文没真展开、只当标签"，点出脱节在哪。
- 稿子以具体教材版本 / 单元 / 知识点为例，核实与真实课标内容对不上或夸大 → 写明差在哪，说清"为什么论据站不住"。】

## 四、建议

【连贯段落，按影响从大到小排，**与不足一一对应、深度稳定**——每条都是一个完整连贯段落，用审稿人自然、有判断力的口吻写，不套统一句式。不要每一条都以"打开第几节""引入/补入"起手；不同建议用不同句式展开：可先点"问题的根源在哪、顺着它该怎么调"，或"如果保留这一写法，更稳妥的处理是……"，或"与其声称 X，不如把笔墨落到 Y"。把改向、补什么、为何这样改、依据是什么揉进同一段，把理由讲透、落点指实。每条建议都要有具体落点（改在哪一节、补哪类内容、参考哪类成熟做法），但表达方式要多样、自然，不要千篇一律。不要提供套用写法、替换写法或可套用示例（即不给现成句子、改写片段或"旧句→新句"的代写式示范）；只把修改方向写清楚，让作者自己落笔。与"不足"对应但不重复——不足讲"为什么是个问题"，建议讲"具体怎么动手"。深度靠把理由讲透、把落点指实来体现，不靠列清单或统一话术。】

文献与主题类落点写在这里：
- 主题已饱和、内容雷同 → 指明可拉开差异的具体切口（如换研究对象、换理论框架、补实证对比），让本文与已有研究区隔开来。
- 缺某类文献 → 建议补哪一类、大概补几篇、补在哪一节。
- 某条文献需核对 → 建议作者核对该条原始出处。
- 理论 / 方法只贴标签 → 建议把它和学科内容真正结合起来（落到具体教学环节，并示范一句"这一做法对应理论的哪一点、为什么有效"），或把标题改贴切，别让标题比内容高半截。
- 教学内容与真实课标 / 教材对不上 → 建议核对原版教材 / 课标后修正表述，把论据落到真实内容。】

## 写报告前的自检清单（仅评审者内部使用，交付报告时整段删除）

本清单仅供评审者在写完报告后自我对照，**不得出现在交付给作者的报告正文中**。对照检查一遍，有一项不合格就改：

- [ ] 开头总体评价是描述性的，没有个人信息，没有用途判断
- [ ] 主体为"总体评价 + 资源核对要点（仅当本次实际做了资源核对时出现）+ 优势 / 不足 / 建议"；资源核对要点仅在本稿实际做了资源核对时出现，未做则不写、不留空块；除该条件块外没有多出来的独立小节
- [ ] 优势、不足、建议的每条都编了号，且是连贯段落，没有拆成"现状 / 问题 / 位置 / 方向"标签，没有表格（资源核对要点中允许嵌入的少量对照表除外）
- [ ] 不足和建议都是连贯段落，没有强弱自评表、没有结构骨架对照表（资源核对要点中允许嵌入的少量对照表除外）
- [ ] 框架合理、专业，不堆砌生僻术语，也没有把专业问题讲浅讲虚
- [ ] 每条问题都能落到具体的章节与修改动作（而非浮空诊断）
- [ ] 没有出现"加强论证""学术性不足"这类没法落地的说法
- [ ] 没有整段改写示范、没有打钩式规范核查表
- [ ] 没有推荐投哪家刊物、参加哪个评比
- [ ] 没有出现查重率、重复比例之类的说法
- [ ] 文献 / 主题的发现（不真实、不相关、主题雷同、有新角度）已分别写进不足或优势或建议，没有单独成节
- [ ] 没有出现"经XX检索 / 借助XX检索 / 本次未借助文献库"等过程性、工具性表述
- [ ] 没有对文献库查不到的条目（如通用教材、非本库书）随意评价"真实性"，只评相关性，并说明该条目未命中本库、未在报告中对其真实性下判断
- [ ] 是否已先还原核心论断、判定最关键缺陷，并在不足第 1 条说明它为何最关键、其他几条如何由它派生（级联），且报告未使用"承重缺陷"等内部标签（直接写"不足"）
- [ ] 每条不足是否锚定到原文具体句子并点出了推理断点（不是浮空诊断）
- [ ] 是否已对关键论断的证据做强弱定性（而非笼统说"缺证据"）
- [ ] 若做了资源核对，其结论（主题饱和 / 文献模式 / 教材核实）是否反哺进了不足或建议，而非只当确认附录
- [ ] 每条建议是否落到了具体的章节与修改方向（有可执行落点），且没有提供套用写法 / 改写片段 / 现成句子（评审只给方向，不做代写式示范）
- [ ] 用语是否客观中性：没有质问式、挑战式或主观臆断的表述（如"你凭什么判断"），每条诊断都有原文锚点或核实事实支撑
- [ ] 每条建议是否为一个完整、连贯的段落，论述有据、逻辑推进（把"为什么改、改在哪、补什么"自然揉进同一段，而非拆成"为何改／改在哪／补什么"等标签短句），且不草草带过
- [ ] 优势每条是否写成完整连贯段落、与不足同等深度，均点出文中章节 / 原句 / 数据佐证，无一句话概括、无空泛罗列
- [ ] 建议是否与不足一一对应、每条深度稳定（均为完整段落、不因篇幅忽长忽短），无突然过短或过长；且句式多样、未套用"打开第几节 / 引入补入"之类统一话术，读来像审稿人的自然判断而非模板填空
- [ ] 若主题检索命中很大（≥10 条且高度雷同），是否已做切入点聚类 / 论点级比对 / 必对话文献锚定，而非只写"主题已饱和"（见 `references/05-resource-verification.md` 第九节）
