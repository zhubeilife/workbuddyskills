# 报告措辞参考

用于生成报告时参考措辞。

**说明**：以下句子仅作参考，不宜直接照抄。报告最终应写成合理、专业、一线教师可理解的表述。下面第三部分是"表述规范对照表"，务必先看——该表意在说明表述应**合理且专业、不随意**：用规范的评审概念和语言把问题定位到具体位置、阐明原因、给出可改方向；不堆砌生僻术语。

---

## 一、总体评价（描述性，不下结论）

| 情况 | 可以这么说 |
|---|---|
| 成熟度较好 | "这是一篇选题有针对性、论证层次清楚、结构完整的教学策略论文，已有具体课例和数据支撑，主要可在理论依据和文献综述上再补实。" |
| 中规中矩 | "选题切合教学实际，论证基本清楚，有实践参考价值，但在问题聚焦和成效证据的呈现上还可加强。" |
| 偏经验化 | "全文以做法叙述和教学经验为主，结构基本完整，但缺少理论层面的支撑和过程性证据，目前偏'经验总结'而非'研究论文'。" |
| 文体疑似错配 | "你写的是第一人称的教学叙事，若按教学策略论文送评，常会因缺少理论依据和文献综述被评'偏经验'；若参加叙事类评比则更为对路。" |

---

## 二、分项说法

**选题**
- "选题有实践价值，但研究的问题不够聚焦，目前覆盖三个学段、两类课型，建议限定到具体学段、具体内容领域，论证才能扎下去。"
- "选题与当前课程改革方向对得上，回应了具体教学中的真实困难，研究点选得准。"
- "选题范围偏大，建议把研究对象收敛到一个年级、一个课型，否则每个点都只能点到为止。"
- "论文通篇说'落实核心素养''对接新课标'，但没有出现课标的具体表述，建议补一句对课标相关要求的直接引用，让'对接课改'有据可依，而不是泛泛贴标签。"

**论证**
- "论证有层次，三个分论点与主题对应清楚，逻辑顺畅。"
- "以经验叙述为主，缺少必要的数据和过程性证据，说服力主要来自个人感受，评委较难判断成效是否可靠。"
- "第 3 节讲三种策略，但没有说明'为什么是这三个、先后顺序的依据是什么'，方法层面的交代不充分。"
- "研究方法说明不充分，样本规模和抽样方式没有交代，结论的推广要谨慎。"
- "第三部分给出的成效数据（如提升 25%），来源写的是'相关调研'而非本研究的前后测，把它当作本文证据会显得夸大，建议只保留本研究能负责的数据。"

**材料证据**
- "有课堂实录片段，但缺少前后对比的数据，建议补一组实验班与对照班的作业正确率或成绩对比。"
- "成效部分只写了'学生兴趣明显提高'，没有有事实支撑的证据，建议补充具体的、可量化的变化。"
- "文末参考文献列表里 [1]–[4] 为空，而正文有四处引用标记无对应条目，另有几篇文献未编号，导致'引文—文献'无法对应，需要逐一补齐并编号。"

**文献**
- "文献综述比较单薄，近三年的核心文献见得少，建议补充并做简要评析，说明你的做法和已有研究的关系。"
- "正文引用的 [3] 在文后找不到对应条目，需要逐一核对，避免引文与文献列表对不上。"
- "所列文献多为泛泛背景，直接支撑本文核心观点的文献偏少，建议补 2-3 篇与本文论点直接相关的研究。"
- "文末 [1]–[4] 条目标注为空，正文四处引用无对应；末尾另列文献未编号，疑似排版错位，需补齐并统一编号。"
- "该主题已有大量同题研究；本稿以'三塑造'为统摄框架有一定空间，但需在引言补明与已有'融入策略'类研究的差异，否则容易被视为同质化重复。"
- "该方向已有大量同题研究，本稿需注意与已有'策略类'研究拉开差异，否则新颖度难以体现。"

**表达**
- "语言流畅、条理清晰，表述准确。"
- "个别段落偏长，一段里讲了三件事，建议拆分，每段只说一个点。"
- "正文有多处'我觉得''咱们班'这类第一人称和口语化表达，作为研究论文显得不够客观，建议改为第三人称陈述。"
- "图表缺编号和标题，建议补上并注明数据来源。"
- "'数字化赋能'与'数智赋能'在文中混用，建议统一为一个说法，概念前后一致。"

## 三、表述规范对照表（写报告前必看）

本表说明"合理且专业"与两端之间的边界——既不是随意口语化，也不是术语堆砌。

| 太随意（避免） | 合理且专业 | 术语堆砌（避免） |
|---|---|---|
| "这文章写得不咋地，看不出研究啥" | "选题范围偏大，覆盖三个学段，建议聚焦到一个年级的一个课型，论证才能扎下去" | "论证逻辑存在断裂性缺失，史料互证维度阙如，学术增量不显" |
| "你这论文没啥用" | "成效部分缺少有事实支撑的证据，对'做法是否真有效'说服不足，建议补前后对比数据" | "实践效度实证支撑力匮乏，效度锚定机制缺失" |
| "题目取得不好" | "题目'核心素养下的小学数学教学研究'范围过宽，看不出具体研究哪类问题，建议收窄到某一课型" | "题名外延失焦，研究边界模糊" |
| "你说话太口语了" | "正文有多处'我觉得''咱们班'这类第一人称与口语化表达，作为研究论文显得不够客观，建议改为第三人称陈述" | "叙事主体耦合度逾界，话语客观性阙如" |
| "你没引文献" | "通篇讲做法，没有课标或已有研究作支撑，理论依据这一块是空缺的" | "理论观照维度系统性缺失，学理支撑真空" |
| "你这词前后不一样" | "'数字化赋能'与'数智赋能'在文中混用，建议统一为一个说法" | "核心概念能指游移，范式自洽性不足" |

**要点**：标准和规范的评审概念（选题聚焦、论证、材料证据、课标对接、文献综述、体例规范）该用就用；关键在于将问题定位到具体位置、阐明原因、给出可改方向。

## 四、学科相关说法

- 语文："论文谈传统文化育人，但没引用课标中'文化自信'的具体表述，建议在引言补一句课标依据，让'对接课改'落到实处。"
- 英语："标题含'项目化学习'，但正文未呈现驱动性问题、持续探究、公开成果等要素，实际是分层任务加情境反馈的通用数字化教学，建议要么补项目化学习设计，要么把标题改贴切。"
- 数学："标题写'结构化教学'，但各课时仍是独立罗列，没呈现知识之间的迁移关系，建议在第二节补一张概念结构图并说明学生怎么从一节走到下一节。"
- 通用："论文通篇说'落实核心素养''对接新课标'，但没出现课标的具体表述，建议补一句对课标相关要求的直接引用，让'对接课改'有据可依，而不是泛泛贴标签。"

## 五、不能说的话

| 不能说 | 原因 | 换成 |
|---|---|---|
| "学术性不足"（单独出现） | 太虚，老师不知道怎么改 | "缺少理论依据，具体是第 2 节全是做法描述，没有课标或文献支撑" |
| "需要加强论述" | 太虚 | "第 3 节需要补实验班与对照班的前后对比数据" |
| "这篇完全不合格 / 千万别交" | 太武断，且替用户下终审结论 | "这篇稿子在具体方面还有明显短板，建议先补 X 和 Y 再考虑提交" |
| "疑似抄袭" | 没核对过不能定性 | "第 X 段跟公开资料表述比较接近，建议核实一下并规范标注引用" |
| "这篇文献不存在" | 查不到不等于不存在 | "这条文献本次未命中本库，文稿中按作者所引信息列示" |
| "肯定能拿一等奖" | 越权承诺 | "把 X 补上后，这一块预计会明显加强" |
| 任何关于重复率、查重的话 | 本技能没有查重能力 | 不要说，也不要暗示 |
| 作者姓名 / 单位 / 职称等个人信息 | 本次评审不评价个人 | 不写 |
| "这篇是为投稿 / 评级 / 评职称而写" | 不写用途判断 | 不写 |

## 六、建议的"详尽但不代写"对照（写建议前必看）

"不给套用写法 / 替换写法 / 现成句子"不等于"建议可以笼统"。建议要写到作者打开文档就知道往哪改、改成什么样，但稿子仍由作者自己写。下面给正反对照，边界就在这里：

| 越界（像代写 / 套用模板） | 允许（详尽但归作者落笔） |
|---|---|
| "把第 3 节第一句直接改成：'学生在因式分解中通过解释分组依据，完成了分析层级的思维跃迁。'" | "在第 3 节课例后补一段，说明学生从'套用公式'转向'解释为何选此分解法'的具体表现，并点明这对应分析层级。" |
| "建议采用'现象—归因—对策'三段式统一重写五个策略。"（直接给固定结构模板） | "每个策略补一小段'思维落点分析'，固定回答三件事：抵达哪个思维层级、学生哪类回答算证据、判断依据来自哪份材料——三件事的写法由作者按自己的课例组织，不套统一模板。" |
| "旧句：……→ 新句：……"（改写片段） | "把'有助于培养高阶思维'这类断言，改为写明'在哪一步、以什么方式、依据什么判断思维确实发生'。" |

要点：阐明"改在哪一小节、补哪类内容、参考哪类成熟做法、大致如何组织"，但不替作者把句子写出来、不给固定结构模板。
