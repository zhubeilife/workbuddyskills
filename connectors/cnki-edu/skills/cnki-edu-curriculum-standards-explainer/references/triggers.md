# 触发关键词（Triggers）

## 一、强触发（命中即进入「课标解读」场景）

### 1. 通用解读类

课标解读、解读课标、帮我解读课标、课程标准解读、课标要求解读、课标原文解读、查课标原文、课标第几页、课标章节、课标里怎么写的、课标原文怎么说。

### 2. 版本对比类

新旧课标对比、课标变化、课标2022版和2025版区别、课标2017版和2025版区别、课标修订变化、课标演变。

### 3. 七个方面的专用说法

| 方面 | 强触发词 |
|---|---|
| 核心素养 | 核心素养解读、本学科核心素养、核心素养内涵、核心素养落点、核心素养课堂体现 |
| 课程性质 | 课程性质解读、这门课是什么、课程定位、课程育人价值、学科本质 |
| 课程理念 | 课程理念解读、课程基本理念、为什么教 |
| 课程目标 | 课程目标解读、学段目标、课标总目标、课标目标分解、目标与核心素养对应 |
| 课程内容 | 课程内容解读、课程内容要求、课程学业要求、课程教学提示、课程内容框架、学习任务群 |
| 学业质量 | 学业质量解读、学业质量标准、课程水平划分、课程达标要求、课程评价标准 |
| 课程实施 | 课程实施解读、课程教学建议、课程评价建议、资源开发建议、课程教研建议 |

### 4. 「学段 + 学科 + 方面」组合说法

小学语文课标解读、初中数学课标要求、高中物理核心素养、义教英语课程内容等。

### 5. 文献检索类（进入本流程并启用知网检索）

查课标解读文献、知网检索课标、搜课标相关论文、课标解读有哪些文献、课标解读文献综述、专家怎么解读课标、权威怎么解读、学界怎么看课标、课标修订依据是什么、课标为什么这么改、课标变化的研究、有没有相关研究支撑、有没有参考资料/文献依据、给我文献依据、教研文献、最新解读文章、2025年修订版解读文献、课标解读研究现状。

## 二、弱触发（先确认一句再用）

课标、课程标准、新课标、义教课标、高中课标、学科核心素养、学习任务群、跨学科主题、课标怎么落地、课标怎么教、课标怎么评、课标要求怎么分解到单元、课标与备课、以前课标怎么要求、课标变化、课标修订、新老教材对比、课标评价建议、学业质量与命题、课标资源建议、教材编写建议、课程资源开发、课标与教研、教师课标理解、课标培训等。

**确认话术**：`你是想解读课标原文与要求，还是只想聊聊教学思路？`

- 回答倾向"原文 / 要求 / 依据 / 章节" → 进入本流程。
- 回答倾向"教学思路 / 活动设计" → 走常规教学设计，不启动本技能。

## 三、边界：不要触发本技能

| 用户意图 | 应走什么 |
|---|---|
| 聊教学思路、设计一节课 | 常规教学设计 |
| 出题、组卷、设计作业 | 命题/作业设计流程 |
| 讲教材知识点、答疑一道题 | 学科答疑 |
| 高校 / 职教 / 成人教育课程标准 | 不在覆盖范围 |
| "把语文课标全文发给我" | 提示上传原文或查阅官方渠道，本包不含课标全文 |
| 纯文献综述、只要论文列表不要课标解读 | 常规文献检索，本技能的知网能力只服务课标解读 |
| 要知网全文 / PDF 下载 | 本技能提供「🔗 跳转到知网阅读/下载」链接，由知网负责在线阅读与全文/PDF 下载；本技能本身不托管全文 |

## 四、使用建议

- 直接把上面这些词写进技能的 `description` 与「触发判断」段落，检索召回最好。
- 强弱分层要保留：强触发直接进入，弱触发先确认一句，可以显著降低误触发。
- 新增触发词时，同时补进本文件与 `SKILL.md` 的「触发判断」，两处保持一致。
- 文献检索类触发只是"进入本流程+启用知网"，**不代表必须给出文献**；检索无果时按 [cnki-retrieval.md](cnki-retrieval.md) 第七节降级。
