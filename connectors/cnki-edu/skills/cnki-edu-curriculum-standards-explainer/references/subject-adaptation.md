# 学段适配与学科适配

## 一、学段适配表

输出时必须先判断学段，再选择匹配的行为动词与要求层级。

| 学段 | 侧重 | 常用行为动词 | 反面示例（不要出现） |
|---|---|---|---|
| 小学1-2年级 | 感受、认读、说出、复述 | 感受、认读、说出、复述、借助……初步…… | "分析""论证""建构" |
| 小学3-4年级 | 理解、概括、初步运用 | 理解、概括、初步运用、尝试、体会 | "系统梳理""深度批判" |
| 小学5-6年级 | 理解、概括、初步运用（要求提升） | 理解、概括、比较、初步运用、有条理地表达 | "鉴赏评价""形成体系" |
| 初中7-9年级 | 理解、概括、品味、初步分析 | 理解、概括、品味、初步分析、体会、说明 | "建构理论体系""独立研究" |
| 高中必修 | 鉴赏、评价、比较、梳理、探究 | 鉴赏、评价、比较、梳理、探究、建构 | 小学化表述（"认读""说说看"） |
| 高中选择性必修 | 同高中必修，选择性深化 | 同上 + 专题化、专题探究 | — |
| 高中选修 | 同高中必修，个性化拓展 | 同上 + 个性化、拓展性探究 | — |

**学段适配的两个方向都要防**：既不能把高中要求下放到小学（拔高），也不能把小学的稚化表述用在高中（降格）。

## 二、学科适配表

不同学科按课标自身的组织方式呈现内容，不要用一个学科的组织框架去套另一个学科。

| 学科 | 课标的内容组织方式 |
|---|---|
| 语文 | 学习任务群（基础型 / 发展型 / 拓展型） |
| 数学 | 领域（数与代数、图形与几何、统计与概率、综合与实践） |
| 英语 | 级别（分级目标体系） |
| 科学 | 核心概念（学科核心概念 + 跨学科概念） |
| 艺术 | 艺术实践（表现、创造、欣赏、融合等） |
| 道德与法治 / 思想政治 | 主题（政治认同、道德修养、法治观念等素养主题） |
| 历史 | 时序 + 主题（中国古代史、中国近现代史、世界史等） |
| 地理 | 人地关系主题 + 区域认知框架 |
| 物理 / 化学 / 生物学 | 核心概念 + 主题（物质、运动与相互作用、能量等） |
| 信息科技 | 逻辑主线（数据、算法、网络、信息处理、信息安全、人工智能） |
| 体育与健康 | 运动能力 + 健康行为 + 体育品德 |
| 劳动 | 劳动任务群 / 劳动项目 |

> 若某学科的组织方式不确定，宁可写"该学科课标按……组织（⚠请核对具体章节名称）"，也不要硬套其他学科的框架。

## 三、适配自检清单

- [ ] 通篇只有本学段的要求？
- [ ] 行为动词与本学段匹配？
- [ ] 用的框架是本学科自己的组织方式？
- [ ] 没有出现其他学科的核心素养名称？
- [ ] 没有出现课标中不存在的术语？

## 四、跨学段要求的衔接表达

当需要说明"与前后学段的递进关系"时（课程内容方面要求此项），统一用下表口径：

```
上一学段：……（已有基础）
本学段：……（当前要求）
下一学段：……（后续走向）
```

只做客观衔接描述，不对其他学段做完整解读。
