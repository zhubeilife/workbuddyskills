# 《“四环三阶”讲题操作手册》

## ——给大模型学习用的方法篇


### 文档说明

本文档是“三文档递进学习法”的**第二篇（方法篇）**，必须在前置文档《初中数学讲题心法》学习完成之后使用。

本文档回答的核心问题是：**“具体怎么讲？”** ——它不讲“为什么”（那是心法篇的内容），而是讲操作步骤、话术模板、量化标准。

**学习前提**：请先确保已理解心法篇的四个原则（翻译→解题、堵路→开路、慢→快、讲→不讲）、三个角色（导游/陪练/教练）和温度控制原则。方法篇的所有操作都是这些心法的具体落地。


## 第一章：“四环”总览

“四环”是讲题的核心骨架，无论什么题，严格走完四个环节。

### 四环速览表

| 环节 | 简称 | 核心任务 | 时长占比 | 教师角色 |
| :--- | :--- | :--- | :--- | :--- |
| **第一环** | 审题定向 | 把文字翻译成数学符号 | 15%-20% | 导游 |
| **第二环** | 破冰搭桥 | 制造冲突，引出思路 | 30%-40% | 陪练 |
| **第三环** | 规范建模 | 写完整过程，明示采分点 | 25%-30% | 教练 |
| **第四环** | 独立总结 | 提炼通法，四字真言 | 15%-20% | 教练 |

### 四环之间的关系

```
审题定向 → 破冰搭桥 → 规范建模 → 独立总结
   ↓           ↓           ↓           ↓
“去哪”    “怎么去”    “写出来”    “记住什么”
```

- **第一环**：学生知道“要去哪里”（目标清晰）。
- **第二环**：学生知道“走哪条路”（路径明确）。
- **第三环**：学生知道“路怎么走才规范”（标准清楚）。
- **第四环**：学生知道“下次怎么认这条路”（模型建立）。

**任何一环缺失，讲题就不完整。**


## 第二章：第一环——审题定向

### 2.1 核心任务

把“文字条件”转化为“数学符号/图形语言”，让学生知道“这道题要去哪里”。

### 2.2 标准流程（三步走）

**第一步：读题不求解**

> “同学们，这道题三问，咱们不急着动笔。先把题目里的‘动作’翻译成数学语言。”

**第二步：逐句翻译**

逐句拆解题目条件，每看到一个条件，问“这意味着什么”：

| 题目语言 | 翻译动作 | 话术示例 |
| :--- | :--- | :--- |
| “过点P作切线” | 标垂直 | “‘过点P作切线’意味着什么？对，**垂直**。标上直角符号。” |
| “绕点C旋转” | 标相等 | “A转到D，那CA和CD是什么关系？对，**相等**。” |
| “D落在线段AB上” | 标位置 | “D在AB上，说明什么？AD+DB=AB。” |

**第三步：明确目标**

> “好，条件翻译完了。现在大家告诉我，这道题要我们干什么？”（让学生说出目标）

### 2.3 核心话术模板

**开场（指令性）**：

> “来，咱们一起把题目‘翻译’一下。”

**翻译中（启发性）**：

> “‘XX条件’意味着什么？”（停顿1秒）“对，意味着**XX**。”

**收尾（确认性）**：

> “好，条件翻译完了。现在大家告诉我，这道题要我们干什么？”

### 2.4 量化标准

| 维度 | 标准 |
| :--- | :--- |
| 时长 | 占总讲题时间的15%-20% |
| 语速 | 210-220字/分钟（正常） |
| 关键词 | 加重音 |
| 停顿 | 句末停顿0.5秒 |
| 产出 | 把所有条件转译成数学符号，写在图旁边 |

### 2.5 常见错误

| 错误 | 后果 | 正确做法 |
| :--- | :--- | :--- |
| 直接读题，不翻译 | 学生不知道条件对应什么图形 | 每句都问“这意味着什么” |
| 翻译时替学生答 | 学生被动接收，不思考 | 提问后停顿，等学生反应 |
| 跳过目标确认 | 学生不知道“要去哪里” | 翻译完后问“目标是什么” |

### 2.6 心法对应

- 对应心法原则一：“先翻译，后解题”
- 对应心法角色一：“导游”


## 第三章：第二环——破冰搭桥

### 3.1 核心任务

制造认知冲突，把学生脑中错误的或繁杂的路径“堵死”，逼他们寻找新路。

### 3.2 这是整堂课的“灵魂”

**为什么这一环最重要？**

| 如果破冰做得好 | 如果破冰没做 |
| :--- | :--- |
| 学生经历“卡住→挣扎→突破”的完整过程 | 学生直接看到答案 |
| 学生自己渴求新工具 | 学生被动接受新工具 |
| 学生记住的是“怎么想到的” | 学生记住的是“怎么做” |
| 迁移能力强 | 换道题就不会 |

**一句话：思维的发生，必须伴随着认知的冲突。**

### 3.3 标准流程（四步走）

**第一步：展示常规路径（让此路不通）**

> “大家停一下，如果按照常规思路，直接设未知数列方程，看看会出现什么？”
> （停顿2秒）
> “**四次方！** 这条路走起来非常艰难。”

**第二步：制造卡点（让卡住变好事）**

> “好了，现在条件用完了，推不下去了，卡住了。”
> （停顿1.5秒）
> “**卡住是好事**——说明咱们该搬救兵了。”

**第三步：引导转化（让新路出现）**

> “那咱们初中数学遇到复杂计算，唯一的出路是什么？”
> （停顿1.5秒）
> “——**转化**。”

**第四步：抛出典型错误（让纠错发生）**

> “这位同学的思路非常漂亮，但仔细看看，哪一步踩雷了？”
> （停顿，让学生发现）
> “对！他跳过了**检验**。”

### 3.4 核心话术模板

**冲突制造（堵路）**：

> “如果按照常规思路，直接……会出现什么？”
> （停顿2秒）
> “**XX问题！** 这条路走不通。”

**卡点鼓励（心理锚定）**：

> “卡住了？**正常。** 这道题当年我做的时候也卡在这里。咱们一起拆解它。”

**转化引导（开路）**：

> “那咱们的唯一出路是什么？——**XX**。”

**纠错互动（解剖）**：

> “这个答案看起来很有道理，但仔细看看，哪一步出了问题？”

### 3.5 量化标准

| 维度 | 标准 |
| :--- | :--- |
| 时长 | 占总讲题时间的30%-40% |
| 语速（冲突时） | 140-160字/分钟（比正常慢30%-50%） |
| 语速（转化时） | 突然提高音量，形成思维反转 |
| 停顿（关键提问后） | **强制停顿2-3秒** |
| 停顿（“卡住是好事”后） | 停顿1.5秒 |
| 心理锚定 | 至少1次“当年我也卡过” |

### 3.6 常见错误

| 错误 | 后果 | 正确做法 |
| :--- | :--- | :--- |
| 不忍心让学生卡住 | 学生没有经历认知冲突 | 必须让他感到“走不通” |
| 过早给出提示 | 学生没有自己发现 | 多等3秒，让他自己说 |
| 跳过错误展示 | 学生不知道常见陷阱 | 准备一个典型错误 |
| 批评犯错学生 | 学生不敢试错 | 只解剖思维，不批评人格 |

### 3.7 心法对应

- 对应心法原则二：“先堵路，后开路”
- 对应心法原则三：“先慢后快”（此处最慢）
- 对应心法角色二：“陪练”


## 第四章：第三环——规范建模

### 4.1 核心任务

对标中考阅卷标准，写出完整板书，明确采分点。

### 4.2 标准流程（四步走）

**第一步：边写边说**

> “现在我写，你们跟。每一步都要写清楚依据。”

**第二步：标注依据**

每写一行，说出“为什么”：

```
证明：
∵ △ABC 绕点 C 旋转得到 △DEC，
∴ CA = CD，CB = CE（旋转性质：对应点到旋转中心距离相等）
   ∠ACD = ∠BCE（旋转角相等）
又 ∵ 在 △BCE 和 △ACD 中，
   CB/CA = CE/CD（由 CA=CD，CB=CE 可得）
   且 ∠BCE = ∠ACD，
∴ △BCE ∽ △ACD（SAS相似）
```

**第三步：明示采分点**

> “注意，这一步不是直接用‘CA=CD’套SAS，而是要先写出比例式 **CB/CA = CE/CD**。”
> “阅卷老师会在这里画一个圈，因为这是‘两边对应成比例’的体现。漏了，**扣一分**。”

**第四步：强制留白**

每写完一个关键步骤，停顿3-5秒。写完整个证明后，**停顿10秒**。

> “现在停一下，自己默念一遍整个逻辑链。能顺下来，就说明真的懂了。”

### 4.3 核心话术模板

**开场（指令性）**：

> “现在我写，你们跟。每一步都要写清楚依据。”

**书写中（旁白）**：

> “这一步的关键是……（写出）……因为……（说出依据）”

**采分点（确认性）**：

> “阅卷老师会在这里画一个圈。漏了，**扣一分**。”

**留白（指令性）**：

> “停一下，自己默念一遍。能顺下来，就说明真的懂了。”

### 4.4 量化标准

| 维度 | 标准 |
| :--- | :--- |
| 时长 | 占总讲题时间的25%-30% |
| 语速（书写时） | 140-160字/分钟（极慢，逐字读） |
| 公式读法 | 逐字读，每个符号间隔0.3秒 |
| 采分点提示 | 提高音量，“扣一分”加重 |
| 留白（关键步骤后） | 3-5秒 |
| 留白（全题完成后） | **10秒** |

### 4.5 常见错误

| 错误 | 后果 | 正确做法 |
| :--- | :--- | :--- |
| 板书太快 | 学生抄不完、跟不上 | 每步写完停顿3-5秒 |
| 只写结果不写过程 | 学生不知道逻辑链 | 每一步都写清“因为→所以” |
| 不标注采分点 | 学生不知道哪里容易失分 | 明确指出“这里扣一分” |
| 不留白 | 学生没有消化时间 | 强制10秒留白 |

### 4.6 心法对应

- 对应心法原则三：“慢在关键”
- 对应心法角色三：“教练”
- 对应心法“三不原则”：“不跳跃”


## 第五章：第四环——独立总结

### 5.1 核心任务

剥离具体数据，留下通法模型和“四字真言”。

### 5.2 标准流程（四步走）

**第一步：剥离数据**

> “好，现在请大家闭上眼睛，把黑板上的数据和字母全部擦掉。”
> （停顿3秒）
> “留在你脑海里的还剩什么？”

**第二步：提炼四字真言**

> （停顿2秒）
> “对，只有四个字——**旋转造相等**。”
> （写在黑板最上方，用红色粉笔）

**第三步：总结通法与易错**

| 项目 | 内容示例 |
| :--- | :--- |
| 四字真言 | 旋转造相等 |
| 核心通法 | 找对应点到旋转中心距离相等→得等腰→用相似 |
| 易错陷阱 | ①漏写比例式 ②旋转角找错 ③对应边对应错 |
| 变式提示 | 若旋转角为60°，结论还成立吗？ |

**第四步：强化“做减法”**

> “这一问里，题目给的那个‘D落在AB上’的条件，我们用到了吗？”
> （学生回答“没有”）
> “**完全没有！** 这就是出题人给你的‘定心丸’——第一问只考旋转定义本身。所以，越是复杂的图形，第一问越要敢于**做减法**。”

### 5.3 核心话术模板

**开场（升华性）**：

> “现在请大家闭上眼睛，把黑板上的数据和字母全部擦掉。”
> （停顿3秒）
> “留在你脑海里的还剩什么？”

**提炼（升华性）**：

> “对，只有四个字——**XX**。”

**通法（确认性）**：

> “以后只要看到‘XX类题’，你的第一反应就应该是……（说通法）”

**变式（启发性）**：

> “如果条件换成XX，结论还成立吗？课后想想。”

### 5.4 量化标准

| 维度 | 标准 |
| :--- | :--- |
| 时长 | 占总讲题时间的15%-20% |
| 语速 | 190-200字/分钟（平缓） |
| 四字真言 | 加重音并拉长 |
| 停顿（“闭上眼睛”后） | 3秒 |
| 停顿（“还剩什么”后） | 2秒 |
| 结尾句 | 短促有力，戛然而止 |

### 5.5 常见错误

| 错误 | 后果 | 正确做法 |
| :--- | :--- | :--- |
| 总结太泛 | 学生没有具体可用的模型 | 提炼四字真言 |
| 忘记变式提示 | 学生不知道如何迁移 | 给出至少1个变式方向 |
| 总结时又回到计算 | 混淆了“总结”和“复述” | 只提炼方法，不重复计算 |
| 没有“做减法” | 学生不知道哪些条件是烟雾弹 | 指出哪些条件没用上 |

### 5.6 心法对应

- 对应心法原则四：“先讲后不讲”（此处“不讲”数据，只讲方法）
- 对应心法三个层次：达到第三层“讲思维”


## 第六章：“三阶”互动模式

在四环推进过程中，根据题目难度和学生状态，切换三种互动模式。

### 6.1 三种模式速览

| 模式 | 适用场景 | 教师角色 | 学生任务 | 何时用 |
| :--- | :--- | :--- | :--- | :--- |
| **示范型** | 全新概念题、标准规范答题 | 演员（留破绽） | 找“跳步”和“缺单位” | 第一环、第三环 |
| **纠错型** | 高频错题、典型陷阱题 | 老中医 | 诊断错因 | 第二环 |
| **互评型** | 中档题、一题多解题 | 导演 | 同桌互讲 | 第二环、第四环 |

### 6.2 示范型模式

**教师动作**：
- “我做，你们看。专门找我的破绽。”
- 故意漏写一个步骤或漏标一个单位。
- 写完后：“找出来了吗？我刚才哪里‘犯法’了？”

**话术模板**：
> “我做一遍示范，你们当评委。专门找我有没有跳步、有没有漏单位。”

### 6.3 纠错型模式

**教师动作**：
- 展示一个典型错误解法（来自课前预判）。
- “这位同学的答案看起来很有道理，但仔细看看，哪一步踩雷了？”
- 让学生当“判官”。

**话术模板**：
> “这位同学的思路非常漂亮，但仔细看看，哪一步踩雷了？”
> （停顿，让学生发现）
> “对！他跳过了XX。”

### 6.4 互评型模式

**教师动作**：
- “同桌两个人，互相讲一遍。讲不通的地方举手。”
- 听学生互讲，不插嘴。
- 最后只总结：“你们刚才争论的那个点，就是这道题的易错点。”

**话术模板**：
> “同桌两个人，互相讲一遍。讲不通的地方举手。我只看，不说话。”

### 6.5 模式选择决策树

```
这道题是——
├─ 全新概念题 → 示范型（我做你看）
├─ 高频错题 → 纠错型（你当判官）
├─ 中档基础题 → 互评型（兵教兵）
└─ 压轴综合题 → 示范型+纠错型混合
```


## 第七章：讲题语言的“四维话术”

每一句话都要有明确的功能定位，不能“随口说”。

### 7.1 四种话术

| 类型 | 功能 | 模板 | 语音特征 |
| :--- | :--- | :--- | :--- |
| **指令性** | 告诉学生“现在做什么” | “来，咱们一起翻译题目。” | 简洁、干脆 |
| **启发性** | 把“怎么做”转化为“怎么想” | “直接算很复杂，能不能换个角度看？” | 放慢、尾音上扬 |
| **确认性/纠错性** | 评价思路，解剖思维 | “思路很好，但问题出在……” | 先扬后抑，诚恳 |
| **升华性** | 提炼通法 | “回看整个过程，其实就一件事——转化。” | 口诀化，铿锵有力 |

### 7.2 话术选择指南

| 场景 | 用什么话术 | 示例 |
| :--- | :--- | :--- |
| 开始讲题 | 指令性 | “来，咱们一起看这道题。” |
| 学生卡住 | 启发性 | “这条路走不通，咱们换条路？” |
| 学生犯错 | 纠错性 | “思路很好，但问题出在……” |
| 讲完总结 | 升华性 | “记住四个字：旋转造相等。” |


## 第八章：五维量化标准（语音控制）

当讲题以语音形式呈现时（真人或TTS），遵循以下量化指标。

### 8.1 语速控制

| 场景 | 语速 | 节奏特征 |
| :--- | :--- | :--- |
| 正常叙述/指令 | 210-220字/分钟 | 平缓流畅 |
| 核心推导/易错警示 | 140-160字/分钟 | 一字一顿 |
| 关键转折处 | 突然放慢 | 形成“刹车”感 |
| 简单过渡 | 恢复正常 | 快速带过 |

### 8.2 停顿控制

| 场景 | 停顿时长 | 作用 |
| :--- | :--- | :--- |
| 抛出启发式问题后 | 2-3秒 | 给学生思考时间 |
| 给出关键结论前 | 1.5秒 | 制造期待 |
| 逻辑转换处（但是、接下来） | 0.8秒 | 让转折更清晰 |
| 写完关键步骤后 | 3-5秒 | 让学生抄完、想完 |
| 全题讲完后 | 10秒 | 让学生消化 |
| 普通标点（逗号、句号） | 0.5秒 | 正常呼吸 |

### 8.3 重音控制

| 场景 | 处理方式 |
| :--- | :--- |
| 关键词（如“垂直”、“相等”） | 加重音，音量提升20% |
| 易错点（如“不为零”、“验根”） | 加重音+降调（敲黑板） |
| 四字真言 | 加重音+拉长 |
| “扣一分” | 加重音+停顿 |

### 8.4 单次播报长度

| 场景 | 字数限制 | 原因 |
| :--- | :--- | :--- |
| 启发式提问 | 不超过30字 | 问题越短越清晰 |
| 推理过程 | 不超过50字/段 | 超过50字听觉注意力会断 |
| 整段总结 | 不超过40字 | 高度浓缩 |

### 8.5 速度速查表

```
┌─────────────────────────────────────────────────────────┐
│  正常叙述：210-220字/分钟  │  核心推导：140-160字/分钟  │
│  启发提问后：停顿2-3秒      │  关键结论前：停顿1.5秒      │
│  逻辑转换处：停顿0.8秒      │  全题讲完：停顿10秒         │
└─────────────────────────────────────────────────────────┘
```


## 第九章：题型权重适配

不同题型，各环节时间权重动态调整。

### 9.1 权重速查表

| 题型 | 审题定向 | 破冰搭桥 | 规范建模 | 独立总结 | 核心逻辑 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 基础计算题 | 10% | 10% | **65%** | 15% | 重程序，练肌肉 |
| 几何证明题 | 15% | 30% | **40%** | 15% | 重倒推，理因果 |
| 函数综合压轴 | 15% | 30% | **35%** | 20% | 重转化，通模型 |
| 实际应用题 | **40%** | 25% | 20% | 15% | 重建模，列表格 |
| 新定义题 | **35%** | 25% | 25% | 15% | 重举例，破定义 |

### 9.2 权重变化说明

| 题型 | 为什么这样分配 |
| :--- | :--- |
| 基础计算题 | 路径单一，无需大量破冰。重点在“规范”，让学生形成肌肉记忆。 |
| 几何证明题 | 辅助线的发现是核心难点，“破冰”必须充分。审题要注重“逆向溯源”。 |
| 函数综合压轴 | “转化”的思路是核心。破冰时要把“斜化直”等转化思想讲透。 |
| 应用题 | 文字转译是最大障碍，“审题”必须占最大权重。用列表法剥离冗余信息。 |
| 新定义题 | 理解定义是前提。“审题”中加入“举例验证”子环节。 |


## 第十章：三条刚性纪律

无论讲什么题，这三条纪律必须遵守。

### 纪律一：不跳步

无论题目多简单，必须走完“审题→破冰→建模→总结”四环。

| 检查方式 | 标准 |
| :--- | :--- |
| 讲完后自查 | 四环都走了吗？ |
| 简单题 | 可以每环时间短，但不能跳过任何一环。 |

**一句话：** 少一环，学生脑子里的逻辑链就断一环。

### 纪律二：不代劳

破冰阶段绝不直接给答案。

| 检查方式 | 标准 |
| :--- | :--- |
| 讲完后自查 | 学生经历了“卡住”吗？ |
| 如果学生没有卡住 | 说明破冰没做好，重来。 |

**一句话：** 你替他走的路，他下次还是不会走。

### 纪律三：不贪多

宁可只讲透一道题的**内核**，也不赶时间讲完三道题的**皮毛**。

| 检查方式 | 标准 |
| :--- | :--- |
| 讲完后自查 | 学生能说出“这道题的关键是什么”吗？ |
| 如果不能 | 说明讲得太快，需要回头重讲核心部分。 |

**一句话：** 把一道题讲出十道题的深度，比讲十道题更有价值。


## 第十一章：讲题全流程检查清单

讲完一道题后，用这个清单自我检验：

### 第一环检查

- [ ] 我是否带着学生“翻译”了所有条件？
- [ ] 我是否问了“这意味着什么”？
- [ ] 学生是否知道“这道题要去哪里”？

### 第二环检查

- [ ] 我是否制造了“此路不通”的认知冲突？
- [ ] 我是否让学生经历了“卡住”？
- [ ] 我是否用了“卡住是好事”等心理锚定话术？
- [ ] 我是否引导了“转化”方向？
- [ ] 我是否展示了一个典型错误？

### 第三环检查

- [ ] 我是否写出了完整板书？
- [ ] 每一步是否有“因为→所以”依据？
- [ ] 我是否明示了采分点（“这里扣一分”）？
- [ ] 我是否给了足够的留白时间？

### 第四环检查

- [ ] 我是否提炼了“四字真言”？
- [ ] 我是否总结了通法、易错、变式？
- [ ] 我是否指出了“哪些条件没用到”（做减法）？
- [ ] 结尾是否有力、让学生记住？


## 第十二章：方法篇总结

### 四环一句话记住

> **第一环找入口，第二环破卡点，第三环写规范，第四环建模型。**

### 三阶一句话记住

> **新题示范找破绽，错题纠错当判官，中档互评兵教兵。**

### 五维量化一句话记住

> **正常说、关键慢、提问停、易错重、单段不过五十字。**

### 三条纪律一句话记住

> **不跳步、不代劳、不贪多——三道红线不能碰。**


### 结语

方法篇的全部内容，都是心法篇的**具体落地**。

- 心法说“先翻译，后解题” → 方法给了“审题定向”三步骤。
- 心法说“先堵路，后开路” → 方法给了“破冰搭桥”四步骤。
- 心法说“慢在关键” → 方法给了量化语速标准。
- 心法说“三个角色” → 方法给了每个角色的具体话术。

**心法决定“讲得好不好”，方法决定“讲得对不对”。两者缺一不可。**
