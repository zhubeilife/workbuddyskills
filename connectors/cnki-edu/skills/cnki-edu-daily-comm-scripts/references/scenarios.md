# 场景库 · 六类场景的判定、目标与策略

> 本文件为技能执行时的补充知识上下文。执行时先在此定位场景编号，再取 @templates.md 的句式，最后过 @redlines.md 与 `scripts/check_tone.py`；**含建议 / 请求的文本另须过 `scripts/check_advice.py`**（见文末「建议的依据要求」）。
>
> **⚠️ 政策边界**：以下场景涉及政策——**A2 费用与缴费**（收费政策 / 教辅征订）、**涉及名次与作业量的应答**、**手机管理**、**选科 / 升学**。这些场景**只讲原则与做法，不给政策数值**，一律"以学校 / 上级正式通知为准"；无依据时写 `<待核：需政策依据>`，并跑 `scripts/check_policy.py`。见 `SKILL.md` §5.5。

## 用法

1. 读用户描述 → 在下表匹配最接近的场景编号。
2. 取该场景的「默认目标」与「常用策略」。
3. 目标若被用户明确改写，以用户为准（多数时候家长/老师的真实目标是"要信息"而非"要改变"）。
4. 进入 @templates.md 取话术骨架。

---

## A. 通知发布类

| 编号 | 场景 | 判定特征 | 默认目标 | 常用策略 |
|---|---|---|---|---|
| A1 | 群公告 / 班级通知 | 活动、放假、作息、携带物品等全员事项 | 要改变（让家长照做） | 结论先行 + 三要素（时间/地点/要带什么）+ 截止位置放句尾 |
| A2 | 费用与缴费通知 | 涉及金额、代收、自愿 | 要改变 | 金额 + 用途 + 规则来源（自愿/代收/退费）+ 截止方式，一句不多一字不少 |
| A3 | 作业 / 任务布置与提醒 | 布置、提交、提醒 | 要改变 | 任务 + 提交方式 + 一次性时间点 |

**共性要求**：群发只面向全员事项；涉及个别学生一律转私聊。

---

## B. 学生反馈类

| 编号 | 场景 | 判定特征 | 默认目标 | 常用策略 |
|---|---|---|---|---|
| B1 | 学习情况 / 成绩反馈 | 阶段反馈、单元测 | 要信息 + 要改变 | 进步先行 → 具体问题 → 两条建议 → 约定下次反馈时间；**两条建议须由前面的具体问题推出** |
| B2 | 进步表扬 | 报喜、优点、进步 | 维护关系 | 具体事实（有名有姓）+ 对孩子的观察 + 感谢家长配合 |
| B3 | 成绩波动 / 下滑 | 分数下降、状态退步 | 要信息 + 要改变 | **先排除非学习因素**（情绪、睡眠、家庭、身体），再谈方法；**归因必须先摆对应观察**，不得凭空提作息 / 情绪（见文末「建议的依据要求」） |

**共性要求**：先给具体进步（不说"最近不错"），再谈需要关注的问题。

## C. 问题沟通类

| 编号 | 场景 | 判定特征 | 默认目标 | 常用策略 |
|---|---|---|---|---|
| C1 | 行为 / 纪律问题 | 打闹、冲突、扰乱课堂 | 要改变 | **先给态度（对行为本身，如"动手打人这件事肯定不对"）→ 只陈述事实经过 → 说明影响 → 请家长配合的方向**（**配合方向须由前面的事实推出**，不得另起"作息""情绪"这类无观察的新话题）；处理方案由学校统一流程给出。**禁止写"我不做评价""我不私下定性"这类态度声明**——边界写在程序上，不写在自己的态度上（见文末「边界的表述要求」） |
| C2 | 作业态度 / 完成度 | 未交、敷衍、抄袭 | 要改变 | 数据化事实（几次、哪几次）→ 影响 → 两条可执行建议（**建议须由这些数据化事实推出**） |
| C3 | 出勤 / 迟到 | 迟到、请假 | 要信息 + 要改变 | 询问原因先于要求，避免质问口吻 |
| C4 | 家长诉求类 | 想调座位、换座位、换班 | 要信息 + 要改变 | 先接住诉求 → 说明规则与影响 → 给可行方案；不承诺结果 |

## D. 质疑与冲突类

| 编号 | 场景 | 判定特征 | 默认目标 | 常用策略 |
|---|---|---|---|---|
| D1 | 家长质疑老师 | 质疑教学、处理方式 | 要信息 + 维护关系 | 先听完不打断 → 复述诉求确认 → 能解决的当场给时间点 |
| D2 | 家长投诉 | 投诉、要求处理 | 要信息 + 要改变 | 先共情 → 再事实 → 后渠道（建议单独电话沟通） |
| D3 | 群里冲突苗头 | 群内出现争论、情绪 | 降温 | 私聊优先原则 + 拆弹话术；绝不在群里辩论 |
| D4 | 家长之间矛盾 | 家长互相指责 | 降温 | 不站队、不评判、分别私聊，把双方拉回事实 |

## E. 敏感话题类

| 编号 | 场景 | 判定特征 | 默认目标 | 常用策略 |
|---|---|---|---|---|
| E1 | 心理健康 / 情绪 | 情绪低落、自我否定、异常 | 要信息 + 转交 | 表达关心 → 只陈述观察到的行为 → **立即转交学校既定流程**，不自行处置 |
| E2 | 安全事件 | 受伤、冲突升级、安全隐患 | 要信息 + 转交 | 事实 + 已采取措施 + 转交学校处理，不擅自承诺；**事件涉及学生之间冲突时，先在事实前给一句对行为本身的态度**（"动手打人这件事肯定不对"），边界写在程序上——**不写"我不做评价""我不私下定性"**（见文末「边界的表述要求」） |
| E3 | 家庭变故 | 离异、经济困难、亲人离世 | 维护关系 | 不追问隐私、不传播；表达支持与"随时联系我" |
| E4 | 身体健康 / 隐私 | 生病、身高体重、证件信息 | 维护关系 | 一律私聊，绝不群内提及；不引用他人隐私 |

## F. 关系维护类

| 编号 | 场景 | 判定特征 | 默认目标 | 常用策略 |
|---|---|---|---|---|
| F1 | 主动表扬 / 感谢 | 感谢家长配合 | 维护关系 | 具体事件 + 具体的人 + 真诚，不泛泛 |
| F2 | 失误说明 / 道歉 | 校方或老师失误 | 维护关系 | 承认具体事实 → 不推诿 → 说明补救措施 |
| F3 | 约谈 / 面谈 / 家访邀约 | 邀请沟通 | 要改变 | 事由 + 时间选项（给 2 个）+ 预计时长，不带压力 |
| F4 | 阶段性小结 | 学期、月度反馈 | 要信息 | 进步 → 待提升 → 下一阶段计划 → 需要家长配合什么 |

**共性要求**：关系维护类的核心是"具体"——具体的人在、具体的事、具体的时间；不泛泛而谈、不带任务压力。

## 建议的依据要求（六类通用 · 场景层执行口径）

> 与 @redlines.md 第 11 类、@templates.md「通用规则」同源；含建议 / 请求的文本成稿后**必跑** `scripts/check_advice.py`（见 `SKILL.md` §8.1 步骤 5d）。

1. **建议从事实出**：给出的每条建议 / 请求，必须能追溯到前文**已陈述的观察事实**。**"最多两条"是上限，不是配额**——不足两条就给一条，**严禁凑数**。
2. **先归因、后建议，不得跳步**：要借睡眠 / 情绪 / 家庭 / 身体 / 电子产品归因时，**先摆出对应观察**（"我发现他这两天早读会打瞌睡"），再提建议；没有观察，该条要么删，要么改为**了解式提问**（"想先跟您了解一下他最近在家的作息安排"）。
3. **高危场景**（最容易凭空塞建议）：**B1 成绩反馈、B3 成绩波动、C1 行为纪律、C2 作业态度**——这四类的建议必须逐条对得上事实。
4. **不得用"如果…"包装**：把"如果他最近睡得比较晚"当成事实来说，家长读完仍不知道依据是什么——要么补观察，要么改成提问。
5. **自检问句**：每条建议问一句「**前面哪句事实在支撑它？**」——答不上来的，删。

## 边界的表述要求（六类通用 · 场景层执行口径）

> 与 @redlines.md 第 12 类、@templates.md「通用规则」同源；由 `scripts/check_tone.py`（v1.3 起）的「元话语免责」类自动扫描，见 `SKILL.md` §8.1 步骤 5a。

1. **边界写在程序上，不写在态度上**。要表达"不代学校定责 / 不擅自处理"时，用**处理程序**表述：
   - ✅ "具体怎么处理，学校有统一的流程，我按流程走，有结果第一时间告诉您。"
   - ❌ "我不做评价。" / "我不私下定性。" / "我不站队。"
   后者是**元话语**——解释自己这句话的性质，不传递信息，且把说话人从"当事人"挪到"旁观者"，家长读成回避。

2. **态度给足、程序守住**（涉学生冲突类必守）。对被动手方家长**必须**给出对**行为本身**的价值判断（"动手打人这件事肯定不对"）——**不给，家长会认定你在和稀泥**；**不能**给的是具体责任认定与处分结果。
   > 关键区分：**对行为表态 ≠ 认定责任**。"打人不对"是学校一致立场，给双方家长都可说；"谁的责任、怎么处分"归学校程序。

3. **三层顺序固定，不得写反**：**事实层（讲经过）→ 态度层（表态）→ 程序层（讲归属）**。写反成"先免责、再讲事实"，是这类沟通里读起来最冷的排法。

4. **高危场景**（最易出现元话语）：**C1 行为纪律、E2 安全事件、D1 家长质疑、D2 家长投诉**——这四类都是"家长在等一个说法"的时刻，最容易被"我不做评价"顶回去。

5. **自检问句**：每句话问一句「**这句是在讲"我"（态度/免责），还是在讲"事"（流程/责任）？**」——指向"我"的，改成指向"事"；指向"我"的**态度判断**若要保留，只留"对行为本身"的判断。
