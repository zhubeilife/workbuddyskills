# 路由判定细则 · 日常沟通话术形态

本文件是「日常家校沟通话术」技能的分流中枢。**每次接到用户输入，先在此完成两级路由，再进入成稿。**

---

## 一、先确认：这个活归本技能吗？（越界转交，硬性）

本技能**只做消息 / 对话类沟通**。以下情况**不属于本技能**，应提示用户改用 **`cnki-edu-parent-meeting-speech`（家长会发言稿）**：

| 用户实际要的是 | 判据 | 转交 |
|---|---|---|
| 家长会 / 班会上**现场念**的整篇稿子 | 交付物落在**家长的耳朵**，不是对话框 | → 发言稿技能 |
| 要 PPT 大纲 / 五段式 / 时长分配 | 结构是口播稿的骨架 | → 发言稿技能 |
| "家长会发言稿" | 明确是稿 | → 发言稿技能 |

**转交话术（直接用）**：

> 这个看起来是**要在会上念的整篇稿子**，不是发消息——我这边是专门写日常沟通话术的。要发言稿的话，请改用「家长会发言稿」技能，我把需求说明给你：〔简述用户需求〕。

---

## 二、第一级路由 · 任务形态判定

**按顺序判，命中即停。** ③④ 是**状态事实**（草稿已在手上 / 消息已发来），有就是有，优先于 ②的意图猜测。

| 步 | 形态 | 判定信号 | 典型表述 | 后续路径 |
|---|---|---|---|---|
| 1 | **③ 草稿把关** | 用户**已贴出成段文本**，动词是 改 / 润色 / 看看行不行 / 有没有不合适 / 把把关 | "这样写行吗""帮我改改" | → 红线检查（§四） |
| 2 | **④ 应答 / 降温** | 用户**已贴出家长的原话**求回复；或群里已出现争论 | "家长这么问我怎么回""群里吵起来了" | → 应答 / 降温模式（§五） |
| 3 | **② 日常话术（本技能主营）** | 面向个别家长 / 家长群的**短消息 / 对话** | "给家长发个通知""催一下缴费""发条微信" | → 场景路由（第三节） |

### 2.1 强信号词表（互斥）

| ✅ 归本技能（话术） | ❌ 归发言稿技能 |
|---|---|
| 通知 / 群公告 / 发一条 / 发个微信 / 私信 | 发言稿 / 讲话稿 / 讲稿 / 逐字稿 |
| 怎么回复 / 回家长 / 措辞怎么说 | 家长会**上讲** / 上台讲 / 说点什么 / 讲 20 分钟 |
| 催 / 提醒 / 接龙 / 收款 / 报名 | PPT 大纲 / 幻灯片 / 分几页 |
| 约谈 / 家访邀约 / 私信怎么说 | 开场 / 结尾 / 五段式 / 时间分配 |

### 2.2 高频误判对照（**逐条记住**）

| 用户原话 | ❌ 易误判成 | ✅ 实际归属 | 判据 |
|---|---|---|---|
| "写个**家长会通知**" / "通知家长开家长会" | 发言稿技能 | **本技能 A1** | 有"家长会"三字，但交付物是**消息** |
| "家长会上我想**说说**手机管理" | 本技能 | **发言稿技能** | "会上说"= 口播 |
| "我这样写行吗"+ 贴了一段话 | 重写一份 | **③ 草稿把关**（本技能） | 已有文本 + 求判断 → 先跑红线检查 |
| "家长说我没照顾他孩子，怎么回" | ② 主动沟通 | **④ 应答降温**（本技能） | 消息**已发来** → 双版回复 |
| "帮我写个**家访**后的小结发群里" | 发言稿 | **本技能 F4** | 落点是"发群里" |
| "把上次那份**发言稿**改一改" | ③ 草稿把关 | **发言稿技能** | 用户既给草稿又要发言稿 → 归那边 |

> **一句话判据**：交付物最终落在**家长的对话框里** → 本技能；落在**家长的耳朵里** → 发言稿技能。

## 三、第二级路由 · 场景路由

先读用户描述 → 在下表匹配最接近的场景编号 → 取该场景的「默认目标」与「常用策略」→ 进入 `templates.md` 取话术骨架 → 过 `redlines.md` 与 `check_tone.py`。

| 类 | 编号 | 场景 | 判定特征 |
|---|---|---|---|
| **A 通知发布** | A1 | 群公告 / 班级通知 | 活动、放假、作息、携带物品等**全员事项** |
| | A2 | 费用与缴费通知 | 涉及金额、代收、自愿 |
| | A3 | 作业 / 任务布置与提醒 | 布置、提交、提醒 |
| **B 学生反馈** | B1 | 学习情况 / 成绩反馈 | 阶段反馈、单元测 |
| | B2 | 进步表扬 | 报喜、优点、进步 |
| | B3 | 成绩波动 / 下滑 | 分数下降、状态退步 |
| **C 问题沟通** | C1 | 行为 / 纪律问题 | 打闹、冲突、扰乱课堂 |
| | C2 | 作业态度 / 完成度 | 未交、敷衍、抄袭 |
| | C3 | 出勤 / 迟到 | 迟到、请假 |
| | C4 | 家长诉求类 | 想调座位、换座位、换班 |
| **D 质疑冲突** | D1 | 家长质疑老师 | 质疑教学、处理方式 |
| | D2 | 家长投诉 | 投诉、要求处理 |
| | D3 | 群里冲突苗头 | 群内出现争论、情绪 |
| | D4 | 家长之间矛盾 | 家长互相指责 |
| **E 敏感话题** | E1 | 心理健康 / 情绪 | 情绪低落、自我否定、异常 |
| | E2 | 安全事件 | 受伤、冲突升级、安全隐患 |
| | E3 | 家庭变故 | 离异、经济困难、亲人离世 |
| | E4 | 身体健康 / 隐私 | 生病、身高体重、证件信息 |
| **F 关系维护** | F1 | 主动表扬 / 感谢 | 感谢家长配合 |
| | F2 | 失误说明 / 道歉 | 校方或老师失误 |
| | F3 | 约谈 / 面谈 / 家访邀约 | 邀请沟通 |
| | F4 | 阶段性小结 | 学期、月度反馈 |

**共性要求**：群发只面向全员事项，**涉及个别学生一律转私聊**；反馈类一律**正面先行**；关系维护类的核心是"**具体**"。

**政策相关场景**：A2 费用与缴费通知、E4 健康隐私、涉及名次 / 作业量 / 手机 / 选科的应答，**均触发政策数据须有据**——不解释政策、不给政策数值，一律"以学校 / 上级正式通知为准"（家委尤其如此，见 `redlines.md` 第 5 类）。

各类的默认目标与常用策略详见 `scenarios.md`。

### 3.1 附加通用能力

- **温和催办**：各场景通用，默认附一版（句式见 `templates.md` 末尾）。
- **家委版**：身份为家委时并列输出，只做转发与统计，不越权。

---

## 四、③ 草稿把关的执行要点

- 先跑 `scripts/check_tone.py`，输出命中项；再人工层按 `references/redlines.md` 改写。
- 交付「**原句 → 修正**」对照表。
- **同批检查**：政策数值是否有来源（跑 `check_policy.py`）、建议是否脱离事实（跑 `check_advice.py`）。

---

## 五、④ 应答 / 降温的执行要点

- **应答**：先共情结构（复述诉求 → 确认理解 → 给事实 / 时间点），再给 **2 版回复（克制版 / 推进版）**。
- **降温**：群冲突走「**私聊优先 + 拆弹话术**」——不在群里辩论；先给结论止住话题；把个别情况引到私聊；不站队、不评判。
