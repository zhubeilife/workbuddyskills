# 数据格式 / params.json / narrative.json 完整规范

## 一、输入数据（一个 xlsx，最多 3 个工作表）

### 1. 主表（默认取第一个工作表；CSV 则为文件本身）

宽表，一行一个学生：

```
学号 | 姓名 | 班级(可选) | 语文 | 数学 | 英语 | 物理 | ...
```

- 学科列名 = 学科名（引擎按 `--subjects` 匹配，匹配不到的学科跳过并记入 `data_notes`）
- 学科别名：列名「道法」「德法」≡「道德与法治」，仅用于**匹配列**，输出仍用用户给定的学科名
- **学号 / 姓名 / 班级 三列都可缺**：缺学号用行号代替，缺姓名用学号，缺班级则按同一群体处理
  （维度 5 的平行班对比随之不可用）。不要因为缺列就要求用户补列
- 空值/「缺考」/「-」按缺失剔除（不计 0 分），并逐个写入 `data_excluded` + data_notes
- 超出 [0, 满分] 的值视为异常值剔除并列出
- 有「班级」列且存在多个班级时，引擎自动分组；`--focus-class` 指定主分析班级
- **表头前有合并大标题行会自动跳过**；第一个工作表若只是封面/说明页，会自动改用下一个有数据的表
- 「总分/排名/备注/序号」等列不会被误认为学科
- **满分不在主表里**：主表只存分数，满分靠 `--full` / params.json / 数据反推（见「二·五 满分怎么确定」）
- 卡住了先跑 `--list-sheets` 看有哪些工作表、各有多少行

### 2. 逐题表（可选，工作表名含「逐题」即可被自动识别）

长表，一行 = 一个学生一道题：

```
学号 | 学科 | 题号 | 满分 | 得分 | 知识点(可选)
20260001 | 数学 | 1 | 5 | 3.0 | 集合与逻辑
```

- 必需列：学科 / 题号 / 满分 / 得分
- **「学号」列是分层与个体统计的开关**（用户要求 2026-10-10）：
  - **有** → 逐题统计出**两层**（班级层 = 主分析班级、年级层 = 全部样本），
    还能**逐班**给出每道小题的得分率（报告维度 3 的「各班 · 逐题得分率」矩阵、
    Excel「04 逐题得分率」末尾的各班得分率列）
  - **没有** → 两层数字相同（都是全部样本），各班逐题对比**不生成**；
    班级 / 年级层的逐题得分率不受影响
  - 学号与主表**格式对不上**时个体矩阵同样不生成（`no_match`，会在 `data_notes` 里点名）——
    注意前导零与文本/数字格式两端要一致
- **没有此表 → 维度 3、4 与 Excel「04/05/09/10」整块不生成**（不摆"数据缺失"空板块），
  只在章节小字里交代一句。**不要虚构逐题数据**
- 只有部分学科有逐题数据时，只对这些学科生成；其余学科的维度 3/4 不出现
- **没有知识点列（或整列为空、或整列只填了 `-`「/」「—」「N/A」「无」「未标注」「待定」这类占位符）
  → 维度 4 与 Excel「05 知识点优先级」都不生成**，逐题表也不留空白「知识点」列，
  Excel 的「01 阅读说明」工作表导航里也不出现 05。**占位符不算知识点数据**——
  列在、每行都有字，也可能一个真知识点都没有（认不出来的话会造出名字叫「-」的假知识点）。
  引擎**绝不编造「未标注」这类知识点**（那是假教学结论）。可由 AI 根据题目内容推断后补一列，并在该列单元格里写明"AI 推断"，交付时交代需复核
- 部分题有知识点、部分没有：只聚合有归属的题，并在 `data_notes` 里说明有多少题未被统计（逐题得分率不受影响）
- 同一「学号 + 题号」重复出现时**取最后一条**，不重复计数
- **该生该题没有记录 = 缺答**：个体矩阵与「09」长表都**留空**，不按 0 分计入（0 分是有作答但一分没得，两者不同）

### 3. 历次表（可选，工作表名含「历次」即可被自动识别）

长表，一行 = 一个学生一次考试：

```
学号 | 姓名 | 考试 | 总分 | 排名(可选) | 序号 | 日期
20260001 | 赵一 | 第1次月考 | 612 | 12 | 1 | 2026-03-15
20260001 | 赵一 | 期中考试 | 640 | 8  | 2 | 2026-04-25
```

- 必需列：学号 / 考试 / 总分；姓名、排名可选
- **先后顺序的判定**，优先级：`--history-order` > 「序号」列 > 「日期」列 > 考试名称里的序号
  （「第2次」<「第10次」；中文数字「第一次」「二模」同样解析）。
  名称里只要有一个**既不含数字、又没有「序号/日期」列**（如「期中考试 / 期末考试」），
  引擎就判不出先后 → **只警告不阻断**：打印 `[警告]`、写进 `data_notes`，报告摘要与维度 6、
  Excel「07」都显著标注，报告**照常产出**（其余 5 个维度不受影响）。建议补「序号」或「日期」列，或用
  `--history-order "第1次月考,期中考试,第2次月考,期末考试"` 显式指定后重跑（此时不再告警）
- 判不出时**不会硬排**吗？会按名称估算，所以趋势判定、进步榜、需关注名单**可能整体反向**——
  这正是要显著警告的原因；顺序可靠时（`explicit`/`seq`/`single`）不会出现告警
- 同一「学号 + 考试」重复出现时**取最后一条**
- 只有 1 次考试时谈不上趋势：维度 6 自动退回横截面分层，并在 `data_notes` 里交代
- 没有此表 → 维度 6 自动改为横截面分层

## 二、params.json 模板（可选，覆盖默认设定）

```json
{
  "exam_name": "高二期中考试",
  "class_name": "高二(3)班",
  "teacher": "张老师",
  "date": "2026-11-10",
  "history_order": ["第1次月考", "期中考试", "第2次月考", "期末考试"],
  "subjects": {
    "语文":   { "full": 150, "pass": 90,  "excellent": 127.5, "low": 60 },
    "数学":   { "full": 150, "pass": 90,  "excellent": 127.5, "low": 60 },
    "英语":   { "full": 120, "pass": 72,  "excellent": 102,   "low": 48 },
    "物理":   { "full": 100, "pass": 60,  "excellent": 85,    "low": 40 }
  },
  "benchmarks": {
    "年级均分": { "语文": 105.2, "数学": 98.6, "英语": 88.4, "物理": 61.3 },
    "区市均分": { "语文": 101.5, "数学": 95.1 }
  }
}
```

- `class_name` 一旦写了视为**显式指定班级**，维度 3/4/6 会同步收敛到该班（与 `--focus-class` 等效）
- `history_order`：历次考试的先后顺序；等价于 `--history-order`。历次表没有「序号/日期」列、
  名称又排不出先后时**强烈建议给**：不给只打印 `[警告]` 并在报告里显著标注（不阻断），趋势结论需自行核对
- `subjects` 的键支持别名（列名「道法」时写「道德与法治」也能对上）
- `full_policy`：`"ask"`（默认，见下方「满分怎么确定」）/ `"default"`（一律按常规 100 分制继续）

## 二·五、满分怎么确定（**最不能猜的一项**）

满分决定及格线/优秀线/低分线，进而决定四率（优秀/良好/合格/不合格）、及格率、低分率、分数段、形态判定与分层名单。

**分制分布（2026-10）：常规分制为 100 分；其次是 150 分、10 分、5 分；120/200/750 等较少见。**
「常规」只描述常见程度，**不是任何一科的默认值**——语文数学可能是 100 也可能是 150，
英语可能是 100/120，小学科常见 10 分制、5 分制，所以引擎不按学科名硬猜。解析顺序：

| 优先级 | 来源 | 行为 |
|--------|------|------|
| ① | `params.json` → `subjects.<学科>.full` | 采用，`full_source = user`，不提示 |
| ② | 命令行 `--full "语文=150,数学=100,物理=10"` | 采用，`full_source = user`，不提示 |
| ③ | 由该列成绩反推，且**只有唯一候选** | 采用，`full_source = inferred`，登记到 `meta.full_to_confirm`（各学科章首小字标「待确认」+ Excel「01 阅读说明」置顶点名；**满分与三条分数线另逐列写在 Excel「02 学科总览」**） |
| ④ | 推断不出 / 多个候选都说得通 | **停止分析，退出码 3**，打印清单与补救命令，请用户给出 |

反推规则：取「最小的 ≥ 该列最高分的常见满分」，且要求最高分 ≥ 该满分的 85%。
常见满分集 = 5 / 10 / 15 / 20 / 30 / 40 / 50 / 60 / 70 / 75 / 80 / 100 / 120 / 150 / 200 / 250 / 300 / 750
（展示给用户时按常见度排序：**100（标注「常规」）→ 150 → 10 → 5 → 其余升序**）。
反推前会先剔除负数与超过 750 的脏值（一个 999 不会把最高分抬到无法判断）。

| 该列最高分 | 反推结果 |
|-----------|---------|
| 150 | 150 分制（唯一） |
| 145 | 150 分制（145 ≥ 127.5，120 分制已被排除） |
| 95 / 88 | 100 分制（唯一，常规分制） |
| 10 / 9 | 10 分制（唯一） |
| 5 / 4.5 | 5 分制（唯一） |
| 68 | 70 / 75 / 80 都说得通 → **停下来问用户** |
| 45 | 无候选（45 < 0.85×50）→ **停下来问用户** |

退出码 3 的提示里会附「常见满分：100 分（常规）、150 分、10 分、5 分」，
并把该科数据支持的候选按常见度排出（100 排首位并标「常规」），直接转达给用户即可。

只有在用户明确表示「不用问，没给的就按常规分制」时，才可加 `--full-policy default`：
**一律按常规 100 分制兜底**（汇总列 总分/总成绩 按 750，其他学科一律 100）。
此时不阻断，但仍写入「待确认」提示——**默认值只是参考，不是事实**。
若某科实际是 150/120/10/5 分制，必须用 `--full` 或 params.json 改正后重跑。

及格线/优秀线/低分线默认 = 满分 ×60% / 85% / 40%，可用 `pass` / `excellent` / `low` 单独覆盖。

## 三、narrative.json 模板（AI 撰写的教学解读，可选但推荐）

```json
{
  "summary": [
    "本次数学均分 95.4（得分率 63.6%），低于年级均分 3.2 分，属本次最薄弱学科。",
    "…"
  ],
  "subject_notes": {
    "数学": {
      "stats": "对维度1的解读：均值/中位数关系、离散度、与满分的距离…",
      "bands": "对维度2的解读：形态归因、哪个段最该抓…",
      "questions": "对维度3的解读：共性错题集中在哪些能力点…",
      "kp": "对维度4的解读：薄弱知识点的教学归因…",
      "comparison": "对维度5的解读：与年级/平行班的差距在哪里…",
      "individual": "对维度6的解读：临界生怎么抓、学困生怎么帮…"
    }
  },
  "cross_note": "学科间均衡性、排名一致性、跨学科共性短板…",
  "improvement": {
    "common": ["共性问题 1", "共性问题 2"],
    "kp_priority": { "数学": ["P1 解析几何：…", "P2 函数与导数：…"] },
    "students": { "数学": ["临界及格：张三、李四…（具体到人）"] },
    "actions": ["本周内完成解析几何专题讲评", "…"]
  }
}
```

写作要求：
- 每条结论必须带数字（来自 analysis.json），禁止"成绩不理想"这类空话
- 讲评建议落到**具体题号/知识点**；学生名单**直接点名**
- `summary` 3–5 条；`improvement` 按"共性问题 → 知识点 → 学生 → 行动清单"四层组织
- **`data_notes_extra` 已废弃**（用户要求 2026-10-08）：报告与 Excel 结果册都不再承载"数据说明"，
  写了也会被忽略；需要补充的数据质量交代请在**对话交付说明**里讲

## 四、analysis.json 关键字段（供追问与二次加工）

| 字段 | 含义 |
|------|------|
| `meta.individual_scope` | 维度 3 **班级层**的范围（班级名或「全部样本」）；也是维度 4/6 的范围 |
| `meta.individual_scope_is_focus` | 是否为「本班范围」 |
| `meta.grade_scope` / `grade_scope_count` | 维度 3 **年级层**的范围（恒为「全部样本」）与人数 |
| `meta.two_level_questions` | 逐题统计是否真的分了两层（逐题表有「学号」且存在主分析班级时为 `true`；否则两层数字相同） |
| `meta.has_class_question_detail` | 是否逐班给出了每道小题的得分率（逐题表带学号 + 多班样本时为 `true`） |
| `meta.multi_class` | 样本是否含多个班级（决定「年级层 · 班级排名」章节与 Excel 09 是否生成） |
| `meta.has_history_summary` | 是否有可用的历次对比数据（决定「历次成绩对比」章节与 Excel 10 是否生成） |
| `meta.has_student_id` | 数据里是否有**真学号**（主表识别到学号/考号列且至少一人有值时为 `true`）。为假时报告与结果册的**「学号」列整列不出现**——内部仍用 `#N` 兜底做主键，但那是内部编号，**不能当学号对外显示**（用户要求 2026-10-11） |
| `meta.focus_class` / `focus_class_explicit` | 主分析班级 / 是否由用户显式指定（指定的班不存在时 `focus_class` 会改成「全部样本」） |
| `meta.focus_class_requested` | 用户原本指定的班级名（用于解释为什么回退到全部样本） |
| `meta.source_sheet` | 实际读取的主表所在工作表名（内部字段，只在 analysis.json 里） |
| `meta.partial_subjects` / `meta.total_label` | 是否只分析了部分学科 / 合计列的称谓（`全科总分` 或 `所选学科总分`） |
| `meta.has_knowledge_points` | 逐题数据里是否有**真实**的知识点归属（否 → 不生成维度 4 与 Excel 05）。判据在引擎的 `norm_kp()`：空值、`-`「/」「—」等 NULL 记号、`无`「未标注」「待定」等占位符一律归空 |
| `meta.history_order_source` / `history_order_reliable` | 历次顺序来源 `explicit`/`seq`/`single`/`natural`/`unknown` / 是否可信（`natural` 时报告附一行提醒；`unknown` 时**只警告不阻断**，摘要、维度 6 与 Excel 07 都显著标注） |
| `meta.duplicate_sids` | 被合并的重复学号 `[{sid,kept,dropped}]`（合并规则：**保留最后一条**） |
| `meta.full_summary` | 各科满分与其来源（用户指定 / 数据推断 / 常规100分制默认）。**报告封面与结果册都不列**，仅作分析底稿与交付说明用 |
| `meta.full_to_confirm` | **未由用户确认的满分清单** `[{subject,full,source,basis,candidates}]`，非空时必须向用户复述 |
| `results[学科].full_source` | 该科满分来源：`user` / `inferred` / `default` |
| `results[学科].questions[]` | 逐题数据：`q/full/kp/level` + **班级层** `mean/rate/n` + **年级层** `mean_all/rate_all/n_all/level_all` + `two_scope`（两层是否不同源） |
| `results[学科].stats` / `stats_all` | 本班 / 全年级的基础统计量，含四率 `excellent_rate` / `good_rate` / `qualified_rate` / `fail_rate`（互斥四档）与累计的 `pass_rate`（及格率 ≥60%） |
| `results[学科].bands` / `bands_all` | 本班 / 全年级的分数段分布 |
| `results[学科].questions[]` | 逐题：`q / full / mean / rate / n / level`（班级层）+ `mean_all / rate_all / n_all / level_all`（年级层）+ `by_class[{cls,mean,rate,n}]`（各班层） |
| `grade_overview` | 年级层总览：`{by_total[], by_subject{学科:[…]}, grade_stats{学科:{…}}, class_count}`；单班样本为 `{}` |
| `history_summary` | 历次对比：`{exams[], has_subject_detail, grade:{total[], subjects{}}, by_class{班级:{total[], subjects{}}}}`；无历次表时为 `{}` |
| `data_notes` | 全部数据质量交代（缺失、统计范围、排序、重复学号、满分待确认等）。**报告与 Excel 结果册都不渲染**，只在 analysis.json 与命令行输出里，交付时必须在对话中复述 |
| `data_excluded[学科]` | 被剔除学生 `[{sid,name,cls,raw,reason}]`，**逐个点名** |
| `results[学科].stats` / `stats_all` | 本班范围 / 全部样本的基础统计 |
| `results[学科].questions[].kp` | 该题的知识点归属；**没有归属就是空串，不会出现「未标注」** |
| `results[学科].knowledge_points` | 知识点聚合（只含真实有归属的题）；为空 → 维度 4 与 Excel 05 不生成 |
| `results[学科].individuals.ranking` | 该范围下的完整排名 `[{rank,sid,name,cls,score}]`（Excel 06/08 由此还原学生成绩；报告排名表用 `sid` 出「学号」列，`meta.has_student_id` 为假时不显示） |
| `results[学科].individuals.history` | 历次追踪（`exams` 顺序已按真实时间序排好）；只有 1 次考试时为空、`mode` 退回 `cross-section` |

## 五、命令速查

```bash
PY="$HOME/.workbuddy/binaries/python/envs/default/Scripts/python.exe"   # 受管 venv，含 openpyxl（$HOME = 用户主目录，不写死用户名）

# 0) 环境/链路自测（48 个回归用例）
"$PY" scripts/selftest.py
"$PY" scripts/make_sample_data.py --out 示例成绩.xlsx

# 0.5) 不确定用哪个工作表时
"$PY" scripts/exam_analysis.py --data 成绩.xlsx --list-sheets

# 1) 分析（多科）—— --full 显式给满分最稳；缺了会按成绩反推，反推不出会退出码 3 让你回头问用户
"$PY" scripts/exam_analysis.py --data 成绩.xlsx --exam-name "高二期中考试" \
  --subjects "数学,语文,英语,物理,政治" \
  --full "数学=150,语文=150,英语=120,物理=100,政治=100" \
  --focus-class "高二(3)班" \
  --history-order "第1次月考,期中考试,第2次月考,期末考试" \
  --params params.json --out analysis.json

# 1b) 用户明确说「不用问满分，按常规分制」时
"$PY" scripts/exam_analysis.py --data 成绩.xlsx --exam-name "…" --subjects "…" \
  --full-policy default --out analysis.json

# 2) 渲染（HTML + PDF + Excel 三件套）
"$PY" scripts/report_builder.py --analysis analysis.json \
  --narrative narrative.json \
  --out "高二期中考试_数语英物政_成绩分析报告.html" --pdf

# 单科：--subjects "英语"；全学科：--subjects ""
```
