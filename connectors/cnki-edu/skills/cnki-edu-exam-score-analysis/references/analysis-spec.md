# 6 大分析维度：计算方式与图表要求

所有比率以**该学科满分**为基准。多科模式下，每个维度按学科分别计算，图表标题统一加学科名前缀
（如「【数学】分数段分布」）。

> **报告里的层级序号**（用户要求 2026-10-11）：`一、` → `（一）` → `1.`（见 report-spec「标题序号体系」）。
> 下面各维度小节的报告标题**不再重复写「维度 N ·」**（会与新序号重复、维度缺失时错位成「（四）维度 5」），
> 只写小节名，如「（三）逐题得分率」「（四）对比分析」。本文档保留「维度 N」作为规格编号，便于文档内互相引用。

## 满分设定（一切比率的基准）

满分错了，及格率 / 优秀率 / 分数段 / 形态判定 / 分层名单**全部作废**，所以它必须先被确认：

- 分制分布（2026-10）：**常规分制为 100 分**，其次 150 分、10 分、5 分；120/200/750 等较少见。
  「常规」只表示常见程度，**不等于任何一科的默认值**
- 优先用用户给的（`params.json` 的 `subjects.<学科>.full` 或 `--full "语文=150,数学=100"`）
- 用户没给时，按该列成绩反推（取「最小的 ≥ 最高分的常见满分」，且最高分 ≥ 该满分的 85%）
- **反推不出唯一结果就停止分析（退出码 3）请用户给出**，不得按学科名硬猜——
  语文/数学都可能是 100 分制或 150 分制，英语可能是 100 或 120，小学科常见 10 分制、5 分制。
  给用户的清单里，候选分制按「常见度」排列（100 排首位并标「常规」），并列出常见分制供用户挑
- 凡是非用户指定的满分，一律落到 `meta.full_to_confirm`，各学科章首小字标「待确认」、Excel「01 阅读说明」置顶红色提示、
  **交付时必须向用户复述**
- 反推出来的满分若**不属常见分制**（120/200/250/300…），`data_notes` 里会额外加一条提示（只在 `analysis.json`
  与命令行输出里，报告与结果册都不展示），请重点复核
- 各科满分与及格/优秀/低分三条分数线**已逐列写在 Excel「02 学科总览」**，结果册里不再重复一遍。

| 3 逐题得分率 | **班级层 = 主分析班级；年级层 = 全部样本；各班层 = 每个班**（三层同时给） |
| 年级层总览（新增章节） | **全年级（全部样本）**：班级总分排名、各学科班级排名、全年级各科四率与分数段 |

`analysis.json` 用 `meta.individual_scope` / `meta.individual_scope_is_focus` 记录实际统计范围；

**不要把全年级排名当"班内排名"**——曾经维度 1/2/5 用本班、维度 3/4/6 用全年级，同一份报告两套范围。

两点必须同步（否则标签与实际统计范围自相矛盾）：
- `--focus-class` 指定的班级**不在主表里** → 范围回退为全部样本，**封面「分析班级」也改成「全部样本」**
  （原班级名留在 `meta.focus_class_requested`），不能封面写一个不存在的班
- 只分析了**部分学科**（主表里还有别的学科列没算进来）→ 结果册合计列写「**所选学科总分**」
  （`meta.partial_subjects` / `meta.total_label`），不能写「全科总分」——那会被当成学校层面的整份总分

## 维度 1 · 基础统计量

计算并列出：平均分、最高分、最低分、标准差、中位数、极差、得分率，以及
**四率（优秀 ≥85%｜良好 70–85%｜合格 60–70%｜不合格 <60%，互斥分档、相加 100%）**、
**及格率（≥60%，累计值）** 与 **低分率（<40%）**。

多班样本另附「年级层对照」一行（本班 vs 全年级，同一套分数线，直接看出重心偏高还是偏低）。

| 指标 | 公式 / 计算方式 |
|------|------------|
| 优秀率 | 得分 ≥ 满分×85% 人数 ÷ 有效人数 |
| 良好率 | 满分×70% ≤ 得分 < 满分×85% 人数 ÷ 有效人数 |
| 合格率 | 满分×60% ≤ 得分 < 满分×70% 人数 ÷ 有效人数 |
| 不合格率 | 得分 < 满分×60% 人数 ÷ 有效人数 |
| 及格率 | 得分 ≥ 满分×60% 人数 ÷ 有效人数（**累计值**，与上面四率不在同一层） |
| 低分率 | 得分 < 满分×40% 人数 ÷ 有效人数 |
| 标准差 | 总体标准差 √(Σ(x−x̄)²/n)，衡量班内离散度 |
| 得分率 | 平均分 ÷ 满分（跨学科比较统一用得分率） |

颜色标注规则（报告自动执行）：标准差/满分 ≥20% 标红（离散度过大）、≥16% 标橙；及格率 <80% 标红、<90% 标橙；低分率 >10% 标红、>5% 标橙。
（`auto_stats` 的兜底正文也用 20% 这一阈值，不要改回 18%——否则同一份报告里表格预警与正文结论会打架。）
多科模式在本维度末尾附「学科间基础指标对比表」（含变异系数 = 标准差/满分）作预告。

## 维度 2 · 分数段分布

按满分比例分 5 段：不及格 <60%、60–70%、70–80%、80–90%、优秀 ≥90%。
表格的**「分数段」列直接显示具体分数区间**（按本学科满分换算，如「0 – 90 分」「135 – 150 分」），
再给人数 / 占比 / 累计占比——分数段一律落到具体成绩，不用百分数表示（用户要求 2026-10-11）。

**形态判定规则**（`detect_shape`）：
- 两极分化：优秀段 ≥20% 且 不及格段 ≥20%
- 尾部沉重：不及格 ≥30%，或（不及格+60–70%）≥50% 且 得分率 <70%
- 高分偏态：优秀段+80–90% 段 ≥55%，或得分率 ≥80%
- 正态集中：其余（**文案里「哪一段人数最多」必须由实际数据算出**，不许写死 70–80%——
  否则会和表格里的「人数最多的是 XX 段」自相矛盾）

**多班样本另附「年级层 · 分数段分布」**（全部样本，同一套分数线），与本班分布并排，
用来判断本班的结构是否偏离年级整体（例如年级两极分化、本班尾部更沉）。
两张表的「分数段」列都按本学科满分换算成**实际分数区间**。

## 维度 3 · 逐题得分率（按学科统计 · 用户要求 2026-10-10 / 11）

**前置条件：必须有逐题得分数据。** 没有数据时**本节整节不生成**（标题、表格、图表都不出现），
Excel 的「04 逐题得分率」也不生成。**报告里不写任何「本节未生成」的说明小字**——
"哪一节 / 哪张表没生成、为什么"只在**对话交付说明**里讲（用户要求 2026-10-11），正文保持干净。
**不要**留一个「数据缺失」的空板块，也不要虚构题目数据。

**每个学科独立成节**，节内固定四块，**绝不把多科混在一起统计**（用户明确要求按学科分别统计）；
**小题分只到班级与年级层，不下到每个学生**（用户要求 2026-10-11）：

### 3.1 班级层 · 逐题得分率
- 范围 = 主分析班级（`--focus-class`；未指定则样本中的第一个班）
- 字段：题号 / 满分 / 平均得分 / 得分率 / （知识点）/ 判定 / **讲评优先级 P1…** / 作答人数
- 得分率 = 该题平均得分 ÷ 该题满分；**行按题号升序**，讲评优先级按**本班得分率**升序**单独标注**，
  P1 最需先讲（用户要求 2026-10-11：行序是题号序，P 值另算，不能用行号当 P）
- 判定：共性错题 <60%（红）｜薄弱题 60–75%（橙）｜达标题 75–85%（绿）｜优势题 ≥85%（蓝）

### 3.2 年级层 · 逐题得分率
- 范围 = **全部样本（含各班）**
- 字段同 3.1（含判定与作答人数，不给讲评优先级），**按题号升序**排列
  （用户要求 2026-10-11：便于与试卷题序一一对照；纯数字题号按数值排，如 1 → 2 → 10）
- 用途：判断本班哪些题**明显低于年级水平**——这是区分「本班问题」与「全年级共性难点」的分水岭
- 两层范围相同时（单班样本、或逐题表没有「学号」列）**只呈现一套**，不摆两份一模一样的数字

📊 图表：题号 × 得分率**双系列分组柱状图**（左柱 = 本班、右柱 = 全年级）；
两层相同时退回单系列柱状图 + 60%（共性错题线）/ 80%（掌握线）两条虚线警戒线

### 3.3 各班层 · 逐题得分率
- 前置：逐题表带「学号」且能与主表对应；样本有 ≥2 个班（`meta.has_class_question_detail`）
- 形态：**行 = 题号，列 = 每个班级（末列为全年级）**，格内 = 该班在该题上的平均得分率（热力着色）
- 用途：一眼看出「哪道题哪个班塌了」——同一道题在 A 班是优势题、在 B 班是共性错题，讲评要分班施策
- 空白 = 该班在该题没有作答记录（缺答，不是 0 分）
- 无处/单班 → 这块整块不生成，不摆只有一列的空表

### 3.4 得分最低 / 得分最高的试题清单
- **按本学科分别给出**：得分率升序取前 5 道（优先讲评）与降序取前 5 道（已掌握）
  —— 这两张清单按**得分率**排（语义如此），是「含题号列一律题号升序」的唯一例外
- 每条列出：题号、判定等级、得分率（两层时同时给本班与全年级）、涉及知识点（有归属时）
- 清单项**不套 `<b>`**（用户要求 2026-10-11）：直接写「第6题（共性错题）：得分率 55.1%，…」

## 维度 4 · 知识点掌握热力图

**前置条件：逐题表里有「知识点」列且该列有**真值**。** 「空单元格」、「-」「/」「—」「N/A」
以及「无」「暂无」「未标注」「待定」这类**占位符都不算知识点数据**（列在、每行都有字，却一个真知识点都
没有，是最容易骗过判据的一种输入——会被造出名字叫「-」的假知识点）。没有真值时，
**凡是涉及知识点的地方一律不显示那一列 / 那一节**
（用户要求 2026-10-11），具体分四处：

- 维度 4 **整节不生成**（标题、表格、图表全不出现），也不生成 Excel「05 知识点优先级」；
  **报告里连一句「未生成」的说明小字都不写**——缺失原因只在**对话交付说明**里讲
- 逐题得分率表、得分最低/最高试题清单里**不摆空白的「知识点」列**（空列本身也是占位）
- 跨学科「各学科 TOP3 薄弱知识点」**不整块消失**，退回按**每题得分率**给出「各学科 · 薄弱试题 TOP3」；
  「各学科 TOP3 共性错题」只保留 学科 / 题号 / 得分率
- 教学建议的「知识点薄弱点（讲评优先级）」**改按小题得分数据来分析**：标题换成
  「薄弱题讲评优先级（按小题得分率）」，按每题得分率升序列出最薄弱的题

若逐题数据存在但缺知识点列，可由 AI 按题目内容推断补列，并在逐题表的「知识点 / 模块」单元格里
写明"AI 推断"，交付时交代需教师复核。

> ⚠️ **绝不编造「未标注」这类知识点**。引擎曾用 `kp or "未标注"` 兜底，导致摘要写出
> 「共性薄弱知识点集中：数学→未标注（65.0%）」——那是凭空造出的假教学结论，老师照着讲评会出事。
> 现在：没有归属的题**不参与**知识点聚合；一道题都没有归属时 `knowledge_points = []`，维度 4 整节不生成。
> 部分题有归属时只聚合有归属的，并在 `data_notes` 里说明有多少题没被统计。

- 知识点得分率 = 该知识点下所有题目得分率的平均
- 等级：优秀 ≥85%（深蓝）｜良好 75–85%（绿）｜薄弱 60–75%（黄）｜危险 <60%（红）
- 输出「知识点 × 掌握等级」矩阵 + 讲评优先级 P1、P2…（按得分率升序）
- 找出"高投入低掌握"的知识点 → 单独列「讲评排序」清单
- 📊 图表：热力矩阵（行=知识点，列=4 个等级，命中格高亮，右侧标得分率）

## 维度 5 · 对比分析

对比对象：平行班（数据含「班级」列时自动分组）、年级均分、区市均分（params 提供）。
每个对象完整输出：平均分、中位数、得分率、最高分、最低分、极差、标准差、分数段分布，
以及**四率（优秀率 / 良好率 / 合格率 / 不合格率，互斥分档）**、**及格率（≥60%，累计值）**、低分率。

**逐班分数段分布表**（每个班一张，标题「XX班 分数段分布」）的「分数段」列
直接显示**具体分数区间**，不用百分比（用户要求 2026-10-11）。

**超均率** = (本班均分 − 基准均分) ÷ 基准均分 × 100%。

📊 图表①：分组柱状图（各班平均分/最高分/最低分并列）
📊 图表②：雷达图，6 轴 = **得分率**、及格率、优秀率、低分率、标准差(稳定性)、超均率；归一化规则：低分率与标准差取反（越外圈越优），超均率以 ±10% 线性映射到 0–1
（轴名必须是「得分率」——该轴放的是 0–1 的得分率，不是原始平均分。）

## 维度 6 · 个体追踪

统计范围：显式指定 `--focus-class` 时为该班，否则全部样本；标注写在名单表标题上。

**有历次成绩**（工作表 `历次`）：
- 考试先后顺序：`--history-order` 显式指定 > 「序号」列 > 「日期」列 > 考试名称里的序号
  （第2次 < 第10次；「第一次」等中文数字与「二模」同样解析）。
  **禁止用裸字典序**——会把「第10次月考」排到「第1次月考」前，使趋势判定整体反转、进步榜点错人
- **排不出顺序（有名称既不含序号、也无「序号」/「日期」列）→ 只警告不阻断**：报告照常产出
  （维度 6 不因顺序存疑就废掉其余 5 个维度），但把告警写进 `data_notes`、在「核心结论摘要」置顶、
  维度 6 用醒目样式标注，Excel「07」也标注。判定结果写在 `meta.history_order_source`
  （`explicit` / `seq` / `single` / `natural` / `unknown`）与 `meta.history_order_reliable`；
  `natural`（全靠名称里的序号）时在报告维度 6 附一行提醒
- **历次表只有 1 次考试**（每个学生只有 1 条记录）→ 谈不上趋势，自动退回横截面分层
  （`individuals.mode = "cross-section"`），并在 `data_notes` 里交代原因
- 对每个学生计算总分序列与名次序列
- 趋势判定：持续进步（逐次不降且总提升>0）｜持续下滑（逐次不升且总下降<0）｜波动（极差 ≥ max(3, |总变化|×1.5)）｜平稳（其余）
- 名单：进步榜（名次提升 ≥3 或总分持续进步）、需关注名单（名次下滑 ≥3 或总分下降）
- 📊 图表：折线图（横轴考试次序；总分与名次各一张，示范前 6 人）

**无历次成绩** → 横截面分层：
- 尖子生：≥ 优秀线
- 临界优秀：优秀线 − 5%满分 ≤ 得分 < 优秀线
- 临界及格：及格线 − 5%满分 ≤ 得分 < 及格线
- 学困生：< 低分线
- 📊 图表：分层人数柱状图 + 班内排名表（前 20）

## 年级层 · 班级排名与全年级指标（用户要求 2026-10-11，仅多班样本）

独立成章，位于「核心结论摘要」之后、各学科章节之前：

1. **班级总分排名**：班级 / 人数 / 总分平均 / 得分率 / 名次（按**总分平均**降序）——并列柱状图
2. **各学科 · 班级整体排名**：行 = 班级，列 = 各学科**平均分**（括号内为该班在该科的名次），
   末列 = 该班平均名次（越小越好，用来一眼看出「哪班哪科是短板」）
   - 格内一律显示**平均分（分数）**，不用百分数（用户要求 2026-10-11）
   - 各科满分可能不同 → **名次统一按得分率排定**，平均分不可直接跨科横比（表下小字说明）
3. **全年级各学科四率**：均分 / 得分率 / 优秀率 / 良好率 / 合格率 / 不合格率
4. **全年级各学科分数段分布**：**按学科分别成表**（用户要求 2026-10-11）——
   每个学科一张独立统计表，**表的正上方用小标题写出学科名称**（如「【数学】分数段分布（全年级 · 满分 150 分 · 135 人）」）；
   表内「分数段」列直接显示**实际分数区间**（如「0 – 90 分」「135 – 150 分」），列为 分数段 / 人数 / 占比 / 累计占比，
   **不用百分数**；各科满分不同，故不做矩阵横排

`grade_overview` 为空（单班样本）时整章不生成。

## 历次成绩对比（用户要求 2026-10-11，有历次表才生成）

1. **历次年级总分对比**：逐次的总分平均、得分率 + 折线走势
2. **历次年级 · 各学科四率**：**按学科分别成表**（用户要求 2026-10-11），每个学科一张表、
   表上方标学科名称，表内为 考试 / 人数 / 平均分 / 得分率 / 优秀率 / 良好率 / 合格率 / 不合格率
3. **历次班级 · 总分与各学科**：总分**单独一张表**（班级 / 考试 / 人数 / 平均分 / 得分率）；
   各学科**分别成表**、表上方标学科名称，再给各班总分折线（看班级间差距的此消彼长）

- 历次表**只有「总分」列**时 `has_subject_detail = False`：本节只给总分层面的对比，
  并在节首如实说明「只对比总分维度」——**绝不编造学科历次数据**
- 班级归属优先取历次表的「班级」列，没有则用主表的学号→班级映射
- 考试次序沿用「历次成绩顺序」的判定规则（`--history-order` > 序号 > 日期 > 名称序号）

## 跨学科横向对比（仅多科模式）

位于所有学科章节之后、教学建议之前：
1. 各学科关键指标横向对比表：平均分（得分率）、四率（优秀率 / 良好率 / 合格率 / 不合格率）、及格率（累计）、低分率、标准差、形态
2. 各学科 TOP3 共性错题 & TOP3 薄弱知识点汇总——**两块都按学科分别成表**（用户要求 2026-10-11），
   每个学科一张表、表上方标学科名称
   - **逐题表没有知识点归属时**：「TOP3 薄弱知识点」退回按**每题得分率**
     给出「各学科 · 薄弱试题 TOP3」（题号/满分/得分率/等级），只是不再有「知识点」这一列；
     「TOP3 共性错题」只保留 题号 / 得分率。两块都**不整块消失**
3. 各学科薄弱知识点数量堆积柱状图（危险/薄弱两层）——没有知识点数据时**不生成**
4. 班级在各学科上的排名一致性：每班各科得分率名次、平均名次、最强/最弱学科、是否"各科均在前 3"
5. 📊 分组柱状图（横轴学科、纵轴得分率、班级分组并列）　📊 雷达图（轴=学科得分率，每班一个多边形）

## 数据剔除与可追溯（不得静默丢人）

缺考/空值/非数值/超满分/负分的学生会被剔除统计，但**必须逐个点名**：
- `analysis.json` 的 `data_excluded[学科]` = `[{sid, name, cls, raw, reason}]`
- Excel「01 阅读说明」渲染出「未纳入统计的学生（逐科剔除名单）」表（**报告正文里不再展示**），
  并注明"未参与任何统计，不是 0 分"
- 这是结果册里**唯一**保留的数据质量交代（班主任对名单要用）；其余 `data_notes` 只在
  `analysis.json` 与对话交付说明里出现

只写一句「已剔除 N 条」是不够的——班主任对名单时会发现少人却查不到是谁。

**重复学号**（同一学号出现多行）按**同一人合并、保留最后一条**，明细落在 `meta.duplicate_sids`
（`[{sid, kept, dropped}]`）与 `data_notes`。过去会被当成两个学生：人数虚高、均分失真、排名表里同一人出现两次。
逐题表与历次表里同一「学号+题号 / 学号+考试」的重复行同样取最后一条，避免重复计数。

**整列缺考/非数值的学科**（表头像学科但整列一个可解析分数都没有）不得静默丢弃：
该科退出分析并在 `data_notes` 里点名；若用户显式 `--subjects` 要求该科，则直接报错说清"整列没有分数"。
（过去这种列连"学科"都算不上，会一声不响地消失。）
