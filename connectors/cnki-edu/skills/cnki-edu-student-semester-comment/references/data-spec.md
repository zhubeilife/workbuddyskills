# 数据规范

六类输入表的字段口径、识别规则，以及两个中间产物的完整 schema。

> **图片（截图 / 照片）不在"六类"之内**——它是**录入通道**，不是新的一类材料：
> 图片先由 AI 读图转写成一份标准表，再按本文件的口径进来。转写规范见
> `references/image-intake.md`。脚本收到图片会友好拒绝。

## 一、六类输入表

主键按「**有学号用学号、没学号用姓名**」生成；姓名与学号**一起参与匹配校验**。
列名以用户原表为准，脚本按关键词模糊识别，**不会改写用户表**。

| 情形 | 主键 | 例子 |
|---|---|---|
| 有学号列（且至少一行有值） | 学号 | `20240301` |
| 无学号列 / 学号列整列为空 | 姓名 | `陈雨欣` |
| 无学号且同名学生 | 姓名 + 序号 | 排前面的 `陈雨欣1号`、后面的 `陈雨欣2号` |

`roster.json` 每生的 `学号` 字段存的就是**这份主键**（不是原表学号），`meta.主键` 注明走的是
「学号」还是「姓名」，`主键来源` 逐人标明（`学号` / `姓名` / `姓名序号`）。
`comments.json` 直接抄这一字段即可与名单对上。

### 1. 成绩表（必需）

宽表，一行一个学生。

| 类别 | 常见列名 | 说明 |
|---|---|---|
| 主键 | 学号 / 考号 / 学籍号 | 没有也能跑，此时以姓名为主键；**「学号」优先于「考号」**（不取"先出现"的那列） |
| 姓名 | 姓名 / 学生姓名 | 强烈建议有 |
| 性别 | 性别 | 有则用于判断代词 |
| 学科 | 语文 / 数学 / … | **列名里含学科名即可**：「语文成绩」「期末语文」「语文(150分)」都能识别；词表与同义归一见 `scripts/subjects.py`（四个脚本共用的唯一来源，不要在各脚本里另建一份） |
| 总分 | 总分 / 总成绩 | 缺省时按各科求和；优先精确匹配，避免「语文总分」被当全局总分；**含「期中/上次」的总分列不会被当成本次总分** |
| 排名 | 班级排名 / 排名 / 名次 | 缺省时不做排名类分析；**「年级排名/校排名」不会当班级排名用**，只做提示 |
| 期中对比 | 期中总分 / 期中排名 / 上次排名 | 有则生成「总分变化」「排名变化」；与本次总分/排名必须是**不同的列** |
| 统计行 | 姓名列写「班级平均」「年级最高」 | 按「无学号 + 姓名含统计词」自动剔除，不会变成学生 |

**学科列识别的三条保护**

- 含「期中/上次/历次/上学期」的列视为**历史列**，不参与本次学科统计；
  若某科只有历史列、没有当前列，会退回当本次用并在提示里说明
- 整列是**文本等级**的列（如「语文等级」A/B/C，一个分数都解析不出）会被判掉并提示——
  否则全班都会被误判成缺考
- **有分数但人数明显偏少**（不足全班一半）的列**保留**，判为**选考/走班科目**：
  整列不再被当等级列丢弃；未参加的同学不计该科缺考（只记 `未选考科目`），
  该科也不计入总分（否则选考与未选考的同学总分不可比）。`meta.选考科目` 会列出这些科
- 含**次数标记**的列（「第1次-数学」「平时3-语文」「周测2-英语」）不进本次学科统计，
  而是整理成 `平时趋势`——否则同一门课会被 6 个平时列算成 6 门，班均直接失真

**成绩册的"脏"表头怎么读（`scripts/read_workbook.py`）**

| 现实里的写法 | 脚本行为 |
|---|---|
| 第 1 行是合并的大标题（「初一3班 平时成绩表（六次）」） | 跳过标题行，第 2 行当表头，并在「机器提示」里说明跳了几行 |
| 双行表头：「第1次」横向跨 7 科 + 下一行「数学/语文/…」 | 拼成「第1次-数学」；**只有下格是学科名时才拼**，「总分」这类单行表头不会被拼坏 |
| 横向合并单元格（openpyxl 只在左上角留值） | 按合并范围向右补齐；上界由整个表头块决定，最后一块不会因为自己的字短就被截断 |
| 一个工作簿多张表：平时 / 期中 / 期末 | 按考试先后自动分流：最靠后的一次 = **本次成绩**，之前最近一次 = **上次对比**，全是第N次的 = **平时趋势** |
| **成绩分在多个文件里**：`期末.xlsx` / `期中.xlsx` / `平时.xlsx`，而且每个文件的工作表名都是「Sheet1」 | **一起传给 `--scores`**（空格或逗号分隔，1 个文件照旧）即可：脚本按**文件名**给通用表名贴标签（「初一3班期末考试成绩」），再照上面同一套规则分流。**不要先手工合并工作簿**——只传期末表不会报错，但期中进退与平时序列会整体缺席，脚本检测到同目录还有像成绩表的文件时会在控制台打 `[重要提示]` |
| 两张成绩表且名字看不出先后（「表一」「表二」） | **报错**，列出可选值请你用 `--scores-sheet` 指定（不猜） |
| 某一行整行以数字为主 | 判为数据行，不会误当成第二行表头 |

可用 `--scores-sheet` / `--prev-sheet` / `--trend-sheet` 覆盖任意一个自动决定。
自检：`python scripts/test_workbook_layout.py`（40 个断言）。

**口径约定**

- `总分变化 = 本次总分 − 上次总分`，正数 = 上升
- `排名变化 = 上次排名 − 本次排名`，**正数 = 进步**（名次数字变小是进步，容易搞反）
- 本次总分/排名取的是**非历史列**（「总分」「期末总分」「班级排名」「期末排名」），
  上次取「期中总分」「期中排名」——两者必须是不同的列，命中同一列会直接报错
- 本次没有总分列（总分由各科求和得出）时，与「上次总分」不同源，**不产出「总分变化」**，
  并在提示里说明原因（避免拿两套口径相减、算出一个恒为 0 的"变化"）
- 空白单元格 = **无数据**，不按 0 分计；但原表总分若已把缺考算进去，排名会失真 → 脚本会标记「缺考学生」并禁用排名类表述
- **选考/走班科目**不计入自动求和的总分；未选考的同学只记 `未选考科目`，不算缺考、不触发排名类禁用
- **平时序列的成文口径**（用户口径 2026-10-09）：`平时趋势` 只给序列、不给均值，成文一律写成
  **「学科 + 第X次平时成绩 + NN分」**，如「语文从第一次平时成绩74分提升到第六次平时成绩的87分」；
  这是评语里**唯一**允许出现「NN分」的写法，省略式「第1次的 74 涨到第6次的 87」会被
  `export_comments.py` 的 `seq_style_flags()` 提示改写

### 2. 作业统计表（可选）

| 标准字段 | 识别关键词 | 归一化 |
|---|---|---|
| 应交次数 | 应交 / 应完成 | 整数 |
| 实交次数 | 实交 / 已交 | 整数 |
| 提交率 | 提交率 / 交作业率 | → 0~1 小数（93 或 93% 都识别） |
| 按时提交率 | 按时 / 准时 | → 0~1 小数 |
| 订正完成率 | 订正 | → 0~1 小数 |
| 作业质量等级 | 质量等级 / 等级 | 原样保留（A/B/C） |
| 作业备注 | 备注 / 说明 | 原样保留，评语素材 |

额外派生：`欠交次数 = 应交 − 实交`

### 3. 课堂表现统计表（可选）

| 标准字段 | 识别关键词 | 归一化 |
|---|---|---|
| 发言次数 | 发言 / 举手 | 整数 |
| 专注度 | 专注 | 原样（通常 1~5） |
| 小组合作 | 合作 / 协作 | 原样 |
| 课堂纪律 | 纪律 / 守纪 | 原样 |
| 课堂任务完成率 | 任务完成 / 完成率 | → 0~1 小数 |

### 4. 教师个别描述表（可选，但决定评语质量上限）

| 列 | 说明 |
|---|---|
| 学号 / 姓名 | 主键（没有学号列时姓名即主键） |
| 描述列 | 自动识别（教师描述/描述/观察/备注/情况），或用 `--note-col` 指定；都识别不到时取最长文本列 |

**这是评语血肉的来源。** 一个学生可以有多条描述（班主任 + 科任），会自动合并；完全重复的会去重。

### 5. 往年评语表（可选）

上学期/往年写过的学生评语，作用**相当于教师对学生的个性化描述**——但只是**参考**。

| 列 | 说明 |
|---|---|
| 学号 / 姓名 | 主键（没有学号列时姓名即主键） |
| 评语列 | 自动识别（往年评语/上学期评语/期末评语/教师评语/评语/寄语/评价），或用 `--past-comment-col` 指定；都识别不到时取最长文本列 |

- 传参：`--past-comments 上学期期末评语.xlsx`
- 落进 `roster.json` 每生的 **`往年评语`** 字段（与 `教师描述` 并列，互不覆盖）
- 匹配口径与教师个别描述表**逐字相同**（同一套 `NameMatcher`，学号优先、名单外不兜底）——
  两张表在 `prepare_roster.py` 里由**同一个** `ingest_text_table()` 处理，口径只有一处
- 可以有多行（上学期 + 上上学期），按给定顺序合并、完全重复的自动去重

**它和「教师个别描述」的语义差别（成文时必须区分）：**

| | 教师个别描述 | 往年评语 |
|---|---|---|
| 是什么 | 本学期、班主任或科任写的观察 | 上学期/往年写过的评语 |
| 成文时怎么用 | 直接作为本学期的**证据**引用 | 只作**参考**（找稳定特点、做连贯） |
| 能否直接搬进新评语 | 可以 | **不可以**（与去年雷同 / 与本学期变化脱节） |
| 与今年材料冲突时 | 以教师描述为准 | **以本学期材料为准** |

成文细则见 `writing-rules.md` 规则 5；机检闸门：`similarity_check.py --past`。

`roster.json` 里每生的 `往年评语` 是**原文字符串**（与 `教师描述` 同形），
`对齐说明.覆盖人数["往年评语表"]` 记命中人数。

### 6. 荣誉材料表（可选）—— 奖状 / 证书 / 荣誉榜

**最常见来源是用户拍的照片或截图**（奖状、荣誉证书、班级荣誉榜），先按
`image-intake.md` 读图转写成表；也可以直接给一份德育处导出的获奖名单。

| 列 | 说明 |
|---|---|
| 学号 / 姓名 | 主键。**奖状上没有学号是常态**，只有姓名列也行（重名时脚本会请用户确认） |
| 荣誉列 | 自动识别（荣誉奖项/荣誉/奖项/获奖/奖状/证书/称号/表彰/奖励/所获荣誉），或用 `--award-col` 指定；都识别不到时取最长文本列 |

- 传参：`--awards 奖状荣誉清单.csv`（图片请先转写成表）
- 落进 `roster.json` 每生的 **`荣誉奖项`** 字段
- 一条一行（一个学生可能有多条），按给定顺序合并、完全重复的自动去重；
  **级别与时间并入同一格**，如 `校级三好学生（校级，2026年6月）`——
  分成三列时脚本只会取最长的那一列，级别和时间会安静地丢掉
- 匹配口径同上：与教师描述/往年评语由**同一个** `ingest_text_table()` 处理

**它是「可以直接引用的证据」**，也是「竞赛获奖 / 担任职务」这类内容能合法进评语的**唯一来源**
（此前属"材料没提就不许写"）。三条成文口径：

| | 要求 |
|---|---|
| 忠于原文 | 奖项名称、级别、时间照抄；**级别不得夸大**（校级不写市级，三等奖不写一等奖） |
| 时间久远的（小学时期、往年） | 只当**稳定特点**的佐证，不写成本学期新发生的事 |
| 别的照旧 | 材料里没有的竞赛/职务仍然不许写（规则 2 不变）；荣誉与成绩不得互相"证明" |

机检闸门：`export_comments.py` 的 `award_flags()`——评语里写了奖项/称号、而该生材料
（`教师描述` + `荣誉奖项`）里找不到出处 → 预警疑似虚构。「往年评语」刻意不算出处。

## 二、姓名匹配规则（防串人的关键防线）

**这套规则由 `prepare_roster.py` 里的 `NameMatcher` 执行，作业表、课堂表、教师描述表、
往年评语表、荣誉材料表五张附表全部走它**，不存在"某张表宽松一点"：

```
有学号 且 学号在名单内  → 采用（姓名不一致只提示，不改动）
有学号 但 学号不在名单  → 判「名单外」，绝不用姓名兜底（仅当名单本身没有学号时才退回按姓名接）
学号列为空 且 姓名精确命中（且该姓名不是重名）→ 采用
学号列为空 且 姓名近似  → 要求等长 + 相似度 ≥0.8 + 不是重名，且列「疑似同一人」待人工确认
同名多人 且 本表没有学号 → 按本表出现顺序依次对应 1号、2号，并提示人工核对（不静默猜完就算）
都不命中               → 判「未匹配记录」，不纳入
```

主表（成绩表）另有一条**硬中止**规则：

- 出现**重复学号** → 报错停止（无法判断哪一行是本人，取哪条都是错的）
- 有学号列、但**只有部分行填了学号** → 报错停止（一次对齐里混用「学号 / 姓名」两种主键，
  `meta.主键` 只记得下一种，附表匹配口径也会跟着漂移）。
  请补齐学号，或把学号整列删掉、改以姓名为主键

**重名**本身合法，脚本保留全部学生：
- 有学号时优先靠学号匹配，重名清单会在「对齐说明」里点名列出；
- 无学号时直接编成「陈雨欣1号」「陈雨欣2号」，顺序即成绩表里的顺序。

姓名归一化：去半角/全角空格、去括号备注；**只用于比对，不回写用户表**。

> 曾经踩过的坑：早期版本对"名单外学号"也做姓名模糊匹配，结果把名单外学生"王浩然"
> 匹配到了名单内的"孙浩然"头上。**有学号就必须以学号为准**，这条不能松。
>
> 同一个坑在作业表/课堂表上重现过：名单外学号 + 与名单内某生同名时，脏数据会静默顶替
> 名单内学生的真实记录，且不进「未匹配记录」。所以现在三张附表统一只认 `NameMatcher`。

```jsonc
    "姓名冲突":   [ { "学号": "...", "主表姓名": "...", "描述表姓名": "...", "性质": "..." } ],
    "疑似同一人": [ { "学号": "...", "名单姓名": "...", "描述表姓名": "..." } ],
    "名单外记录": [ { "来源": "...", "学号": "...", "姓名": "...", "原因": "..." } ],
    "未匹配记录": [ { "...": "...", "描述预览": "..." } ],
    "字段口径":   [ "..." ],
    "机器提示":   [ "..." ]
  }
}
```

**`分层建议` 是规则初判，不是结论。** 初判规则：

| 条件 | 结果 |
|---|---|
| 全班 < 10 人 | `待人工确认（全班不足 10 人，分位规则失效）`——一律人工分层 |
| 有缺考科目 | `待人工确认（有缺考科目，排名不可比）` |
| 没有班级排名（如表里只有年级排名） | `待定` |
| 排名前 25% 且排名未大跌 | `A 优秀稳定` |
| 排名后 25% | `D 需重点帮扶` |
| 排名下降 ≥ 班额的 15%（下限 3 位） | `C 波动待稳` |
| 其余 | `B 踏实平稳` |

C 层阈值随班额缩放（40 人班即排名下降 ≥6 位），不再对所有班型用一个固定数字。

## 四、`comments.json`（第三段产物）

```jsonc
{
  "meta": {
    "班级": "初二(3)班", "考试": "初二上学期期末考试",
    "版本": "学生版", "人称": "第二人称", "字数口径": "120~180 字",
    "规则遵循": "双证据原则 / 禁虚构 / 反雷同 / 分层策略 / 不出现分数名次 / 不点名其他学生"
  },
  "comments": [
    {
      "学号": "20240301",
      "姓名": "陈雨欣",
      "核心印象标签": "解题快手",
      "分层": "A 优秀稳定",
      "评语正文": "……",
      "证据来源": ["成绩表-数学 94", "教师描述-八百米递水", "荣誉-校级三好学生"]
    }
  ]
}
```

约束：

- `comments` 条数与 `roster` **完全一致**，学号一一对应（`export_comments.py` 会对账）
- **每条必须写 `姓名`，且与 `roster` 里该主键对应的姓名一致**：不一致（且都非空）时
  `export_comments.py` 会**拒绝配对并报硬错误**——这是交付端防串人的最后一道闸门
  （学号抄错一位、或从别的班文件复制粘贴就会踩到）
- `核心印象标签` 建议 2~4 字，全班同一标签最多 2 人（`similarity_check.py` 会统计复用次数）
- `证据来源` 必填，用于回溯"这句话的依据是什么"，也是审稿时最有用的字段
- `分层` 可写 `待人工确认（缺考，排名不可比）` 等说明性值

> **诚实说明**：`证据来源` 目前只由成文阶段（Step 3/4）写、由人工或 AI 复核，
> **脚本不校验它与正文是否真对应、也不校验其中引用的材料是否真实存在**。
> 「双证据 / 禁虚构」这两条铁律的执行靠的是第二段画像卡留痕 + 人工过一遍，
> 不要误以为跑完脚本就等于校验过了。

## 五、常见输入缺陷与应对

| 缺陷 | 应对 |
|---|---|
| **用户发来图片**（成绩截图、奖状照片、手写描述照片、PDF） | 图片是**录入通道**不是一类材料：先由 AI 读图转写成标准表再进来。三条硬口径（回读确认 / 读不出留空 / 图上没标注的数字不当分数用）见 `image-intake.md`。把 `.png/.jpg/.pdf` 直接传给 `prepare_roster.py` 会被**友好拒绝**并给出转写指引 |
| 图片是**成绩趋势图**（柱状/折线） | 只能得出趋势，不能得出分数；只有图上直接标了数值标签才可以转写，且仍要回读确认 |
| 奖状照片**没有学号** | 正常。只有姓名列即可；重名或姓名写法不一致时脚本进「疑似同一人 / 姓名冲突」，**必须问用户** |
| 荣誉表把**级别/时间分成单独列** | 脚本只会取最长的那一列，级别与时间会丢掉；转写时**并入同一格**（`校级三好学生（校级，2026年6月）`） |
| 旧版 `.xls` 当 `--scores` | 脚本**友好拒绝并提示**「请先另存为 .xlsx 或 .csv」（不再抛 openpyxl 异常） |
| `.csv` 当 `--scores` | **已支持**（与 .xlsx 同一条链路）；`.txt` 也按 csv 读 |
| 学科列名不带标准写法（「期末语文」「语文(150分)」） | 无需处理，识别规则是「列名含学科名」；含「期中/上次」的列会自动归为历史列 |
| 学科列名完全认不出 | 用 `--subjects` 明确指定；指定的列名不存在时脚本报错并列出该表实际列名 |
| 同一门课有简写与全称两种列（「道法」＋「道德与法治」） | 按学科本体归一去重，只取前一处并在提示里列出被剔除的列；`--subjects` 传简写也能对到全称列 |
| 同一学科出现两列（「语文」+「语文等级」） | 等级列整列解析不出分数，会被**先**判掉（提示写「整列是文本等级」），不参与同门去重——不会再报成"同一门课的另一种写法" |
| **选考/走班**（物理/历史二选一，某科只有一半人考） | **已支持**：该科**保留**并标进 `meta.选考科目`；未选考的同学不计缺考（记 `未选考科目`），该科不计入总分 |
| 成绩表底部有「班级平均」「年级最高」统计行 | 按「无学号 + 姓名含统计词」自动剔除，不进名单（旧版会变成"学生"并报「漏写」） |
| 表里只有「年级排名」没有「班级排名」 | 本次不做排名分位与排名变化（年级排名的位次基数不同），只提示；不要拿它当班级排名 |
| 成绩表重复学号 | 脚本**报错停止**，要求先修表（不静默取一条） |
| 学号列**只有部分行**填了学号 | 脚本**报错停止**：主键必须全班统一，绝不混用「学号 / 姓名」 |
| 成绩表没有学号列 / 学号列整列为空 | 不报错：忽略学号，以姓名为主键；`meta.主键` 会注明 |
| 班里有同名学生 | 有学号→正常处理并列出清单，优先靠学号匹配；**无学号→按出现顺序编「张三1号」「张三2号」**，并要求人工核对 |
| 传了路径但文件不存在 | 脚本**报错**，不再静默跳过（静默跳过会让小贴士误报成「你没提供材料」） |
| 附表（作业/课堂/描述）一个文件里有多张工作表 | 自动挑「有姓名/学号列、数据行最多」的那张（不再死认第一张），并在提示里写明改选了哪张 |
| 只有教师描述、没有统计表 | `--scores 教师描述.xlsx --notes 教师描述.xlsx`；**降级路径已跑通**，按「没有成绩数据」处理，评语中不得出现任何数字 |
| 上传了**往年（上学期）学生评语** | 走 `--past-comments`，落进 `往年评语` 字段（**与 `教师描述` 分开存**）。它是**参考**、不是本学期证据：不得照搬措辞（`similarity_check.py --past` 机检）、其中的事实须以本学期材料为准、不得转述其中的分数名次 |
| 往年评语里的旧结论与今年材料冲突 | **以本学期材料为准**，旧结论不写——参考材料越位比没有材料更糟 |
| 往年评语表的评语列名认不出 | 用 `--past-comment-col` 指定；都认不出时取最长文本列（与教师描述表同规则） |
| 往年评语只覆盖部分学生 | 缺的人记进「缺失项」（往年评语），不静默当作没有；`对齐说明.覆盖人数` 会体现 |
| 写**竞赛获奖 / 担任职务** | 只有 `荣誉奖项`（`--awards`）或教师描述里有出处才能写；没有材料就是虚构。写了必须忠于原文、级别不夸大，`export_comments.py` 的 `award_flags()` 会预警无出处的荣誉表述 |
| 荣誉材料只覆盖部分学生 | 正常（不是人人有奖）。缺的人记进「缺失项」；**不要因为某人没奖就给他"补"一个班内荣誉** |
| 荣誉表的荣誉列名认不出 | 用 `--award-col` 指定；都认不出时取最长文本列（与教师描述表同规则） |
| 表头有合并单元格 / 前几行是标题 / 有多个工作表 | **已支持**：自动跳过标题行、拼双行表头、按考试先后选表；歧义（两张成绩表名字无先后）时报错要求 `--scores-sheet` |
| **期末 / 期中 / 平时是三个独立文件** | **已支持**：`--scores 期末.xlsx 期中.xlsx 平时.xlsx` 一起传，按文件名分辨考试先后（文件名看不出先后时仍报错，用 `--scores-sheet` 指到文件名标签）。只传一个文件时控制台打 `[重要提示]` 列出同目录其他成绩文件——**这条必须读给用户**，否则期中进退与平时序列会静默缺席 |
| 多个班级混在一张表 | 主表加「班级」列先拆分，或分次运行，`--class-name` 标注本次班级 |
| 只有一段粘贴文本 | 整理成 csv（学号,姓名,描述）后走 `--notes` |
| 学生姓名有生僻字 | 不影响；脚本按 Unicode 处理，仅需保证各表写法能通过归一对上 |
| 姓名恰好是常用词（如「安静」「许多」） | 不影响对齐（内部用学号）；但成文阶段要留意「安静下来」这类行文会被自检提示为疑似点名，属误报，自查即可 |
