# 评语写作规则

本文件是 `SKILL.md` Step 4 的细则。动笔前必读，写完后用它逐条自查。

---

## 零、语气基调（先定调，再谈规则）

写的人是老师，读的人是学生本人。这一层**不因"活泼一点/严肃一点/存档版"改动**，
下面几条硬规则都是在这条基调上展开的。

| 项 | 要求 | 反面长什么样 |
|---|---|---|
| **视角** | 老师对学生说话，默认第二人称"你"；存档版全篇改"该生"，不得混用 | "该生表现良好，望继续努力"式的公文体旁白 |
| **优点：表扬到位** | 落到材料里的**一件具体的事或一个数字**上；把这一条写足，优点段是全篇最长的部分 | "学习认真，表现优秀，望继续努力" |
| **缺点：委婉给建议** | 转成**可执行的下一步**（时间 + 数量 + 动作），只给方法不给分数；先认下他的好，再商量下一步 | "上课不专心，作业潦草，成绩很差" |

**唯一判据：这句话贴到教室里公示，学生本人看了会不会难受？会，就重写。**

三条最容易搞反的地方：

- **表扬不是点缀。** 优点段写足，缺点通常一到两句就够。反过来（优点一句、缺点三条）
  就不是老师在跟学生说话，是在念问题清单。
- **委婉 ≠ 含糊。** 该点到的事要点到（"这学期有八次作业没能交上来，我们来定个约定"），
  只是不贴标签、不下定性判断；也不是把问题绕开不谈。
- **别用"虽然…但是…"把优点吃掉。** 先讲足优点，再另起一句给建议。
  "你其实很聪明，但是太粗心"——学生记住的只有"但是"后面那句。

语气样张（同一件事的两种写法）：

| ❌ 不这么写 | ✅ 这么写 |
|---|---|
| 该生学习态度端正，成绩优秀，望继续努力 | 这六次数学你一次比一次稳，从七十几一路爬上来；讲台上讲题那次，思路比答案更让人记住 |
| 上课不专心，爱说话，作业潦草 | 这股劲在教室里没地方使，就变成了接话；你的内容本来就好，别让潦草替你打了折扣 |
| 数学成绩很差，需加强 | 数学的断层老师看出来了——从那一章重新过一遍，把根接上，下学期的题就顺了 |

> 样张只是**语气示范**，句子本身不可复用：成文时每一句都必须换成该生材料里的真实证据
> （否则会同时踩规则 2 和规则 4）。

机检闸门：`scripts/export_comments.py` 的 `NEG_WORDS` 会在交付前逐条预警定性贬义词
（带否定语境识别，"不是笨""没有退步"不算问题）。**预警清零才算过。**
加词或改词表后，先拿 `references/comments.json`（40 条优质评语）复验，必须仍为 0 命中。

## 一、五条硬规则（违反即不合格）

### 规则 1 · 双证据原则

每条评语至少落到 **1 个量化事实 + 1 个具体行为细节**。

| | 示例 | 判定 |
|---|---|---|
| ✅ | 数学作业连续 12 周按时提交，讲台上讲题时思路清晰 | 有数字，有画面 |
| ✅ | 这学期你的作业一次没落下，虽然大部分是第二天早自习赶出来的 | 有数字，有场景，且诚实 |
| ❌ | 学习认真，尊敬师长，是个好学生 | 只有形容词，换谁都能用 |
| ❌ | 你是一个聪明懂事的学生，课堂上能够认真听讲 | 模板句，零信息量 |

量化事实必须是材料里真实存在的，**不许换算成更漂亮的说法**。
"提交率 93.8%" 可以说"作业几乎一次没落下"，不能说"作业从来都按时交"。

**`平时趋势` 是最容易被浪费的一份证据。** 它是某一科的一整条序列
（`逐次: [70,72,74,80,82,84]` + 首/末/最高/最低/跨度/方向），脚本按用户口径
**只保留序列、不产出均值**，占位如下：

| | 示例 | 判定 |
|---|---|---|
| ✅ | 语文从第一次平时成绩74分提升到第六次平时成绩的87分 | 标准式：学科＋第X次＋平时成绩＋NN分 |
| ✅ | 数学从第一次平时成绩89分一路升到第六次平时成绩的100分 | 同上，动词可换（提升/升到/抬到） |
| ❌ | 数学那条平时线从第1次的 74 一直涨到第6次的 87 | **省略式**：家长会当成期末分，也看不出哪一科 |
| ❌ | 地理第4次摸到 96、第5次冲到 99 | 同样要写成「第X次平时成绩NN分」，旧写法已不再推荐 |
| ❌ | 数学平时平均 78 分 | 均值把所有起伏抹平，等于没写 |
| ❌ | 学习一直很稳定 | 序列明明在动，这句与证据冲突 |

**引用平时序列，一律用标准式（唯一推荐写法）**

> **学科 + 第X次平时成绩 + NN分**
> 例：**语文从第一次平时成绩74分提升到第六次平时成绩的87分。**

三件事必须一次说清：**哪一科**、**第几次**、以及这是**平时成绩**（过程性成绩，不是本次期末分）。
序数写「第一次 / 第六次」（中文），分数写「74分 / 87分」（阿拉伯数字 + 分）。
说清这三件事，是让家长看懂"这是过程里的进步"的唯一办法。

要点：
- **不许省略**：不写「第1次的 74 一直涨到第6次的 87」，不写「那条线」「六次记录」这类自造指代，
  也不许不点学科。`export_comments.py` 的 `seq_style_flags()` 会逐条提示这三类不达标写法
  （省略式 / 自造指代 / 没写学科），命中只提示、给出改法
- 引用**第几次**和**序列形状**（一路爬升 / 高位横盘 / 大起大落 / 中段塌过一次再追回来），
  不要自己把 `逐次` 平均一下再写——均值抹掉的正是趋势本身
- 标准式必然让「平时成绩」高频复现（40 人实测 21~30 处），这是**口径要求、不算口头禅**；
  但**句式**仍要打散：前导词（这门课 / 这六次 / 这一科）、动词（提升 / 升到 / 抬到 / 推到）、
  结尾不要成套，`similarity_check.py` 的「高频区别性词」栏里出现「的平 / 次平」属正常，
  出现「一次…又一次」这类整句模板才算问题
- `方向` 只是辅助判断（上行/下行/基本持平），成文要用**序列本身**说话，不要直接抄这两个字
- `缺次` 不为空时，**不许**说"每次都考了"——缺的那次按无数据算，不提即可
- 序列跨度大 ≠ 差：可说"起伏大、还没稳住"，但不能说"退步了"（除非 `首末差` 为负且幅度明显）
- **只有标准式里的「NN分」允许出现**（用户口径 2026-10-09，`PLAIN_SEQ_RES`）。
  「第3次冲到96分」「期末考了87分」照旧报「含分数」——没写「平时成绩」，读者无法判断
  这是过程分还是本次考试分

### 规则 2 · 禁止虚构

**绝对不能写**（材料没提就是没有）：

- 未出现的学科成绩、竞赛奖项、职务头衔
- 家庭情况、身体条件、性格诊断（"性格内向"要谨慎，除非教师描述里明确写了）
- 学生之间的比较（"比某某同学进步大"）
- 材料缺失项：某生没有作业/课堂数据时，评语里不能提他的作业提交率

**可以写**：材料里的短板学科 → 只给方法，不给分数。
> ✅"数学的断层老师看出来了，从那一章重新过一遍，把根接上"
> ❌"你的数学只考了 63 分"

#### 例外：奖状 / 证书 / 荣誉材料（`荣誉奖项`）

用户发来奖状、证书、荣誉榜时（走 `--awards`；**图片需先按 `image-intake.md` 读图转写成表**），
`荣誉奖项` 就是**可以直接引用的证据**——**这是"竞赛获奖 / 担任职务"能合法进评语的唯一途径**，
否则它们永远属于上面那条"绝对不能写"。

开了这个口子，就有两条必须守住的线：

| | 要求 |
|---|---|
| **忠于原文** | 奖项名称、级别、时间照抄。**级别不得夸大**：校级不写成市级，三等奖不写成一等奖，入选不写成名次。改一个字就是虚构 |
| **时间要对得上** | 小学时期、往年的奖 → 只当"**稳定特点**"的佐证（"这个兴趣你从小学就一直在做"），**不写成本学期新发生的事** |
| 其余照旧 | 材料里没有的竞赛/职务**仍然不许写**（有奖状的是这件事，不是这类事）；荣誉与成绩不得互相"证明"（"因为拿了奖所以成绩好"是推断，不是材料） |

> **不是人人都有奖**，而评语里人人都是"进步"。所以荣誉只解决"能不能写"，
> 不解决"值不值得当主线"——**全班都有的达标证书不构成区别性**，别把它写成核心印象，
> 不然二十条评语会从"看成绩"变成"念奖状"。

机检闸门：`export_comments.py` 的 `award_flags()` —— 正文出现明确的奖项/称号，
而该生材料（`教师描述` + `荣誉奖项`）里找不到出处 → 预警疑似虚构。
**「往年评语」刻意不算出处**（规则 5 要求往年的事在今年材料里能对上）。

### 规则 3 · 发展性表述

不下定性负面判断。所有"问题"都要转译成"可执行的下一步"。
（这是「零、语气基调」里**缺点那一半**的展开；另一半——优点必须表扬到位——见规则 1 与「零」。）

| ❌ 不能写 | ✅ 转译后 |
|---|---|
| 成绩很差 | 基础环节还有较大提升空间 |
| 学习态度不端正 | 你的能力其实一直都在，只是还没找到发力的地方 |
| 作业拖欠严重 | 这学期有八次作业没能交上来，我们来定个约定 |
| 上课不专心，爱说话 | 这股劲在教室里没地方使，就变成了接话 |
| 性格孤僻 | 你的朋友不算多，但相处的时间都很长，这种长久比热闹难得 |
| 太粗心 | 你缺的从来不是聪明，是愿意慢下来的那三秒 |
| 退步明显 | 这学期的名次往后滑了，老师看下来，问题不在脑子 |
| 不爱回答问题 | 老师不打算劝你变得外向，只想跟你商量一件事 |

判断标准：**这句话如果贴到教室里公示，学生本人看了会不会难受？** 会，就重写。

### 规则 4 · 反雷同

- 全班任意两条评语，**开头句式不得相同**
- **结尾期待句必须两两不同**，禁止"希望你下学期再接再厉"这类万能收尾
- 同一 `核心印象标签` 全班最多用于 **2 人**，且两人的证据细节必须完全不同
- 区别性相似度 < 0.24（看实词是否重复）
- 骨架相似度 < 0.18（抹掉学科/时间/数字/姓名后仍不得相似）
- 同句式句对 0 组（逐句比句法骨架，专治"同一句式换内容"）
  —— 这三项均由 `similarity_check.py` 判定，任一项报警都要改

### 规则 5 · 往年评语只作参考（有往年材料时才适用）

用户上传的往年（上学期）评语收在 `roster.json` 的 `往年评语` 字段。它的作用是
**相当于教师对学生的个性化描述**，帮你找到"这个人身上稳定的、只属于他的特点"，
也让今年的评语与去年提过的期待接得上。但它**不是本学期的事实证据**。

| 能做什么 | 不能做什么 |
|---|---|
| **找稳定特点**：去年点过、今年材料里又出现的事，是最可信的素材 | **不得照搬去年措辞**——`similarity_check.py --past` 逐句比句式骨架，命中就要换骨架重写 |
| **做连贯**：去年建议"多开口"，今年材料印证了 → 可以点出来 | 拿往年事实当今年事实：去年写过竞赛/职务/性格，今年材料没印证就不写（违反规则 2） |
| 参考它的口吻（老师对学生说话） | 转述其中的分数、名次（与现行口径冲突） |
| | 沿用已经过时的判断：去年"不爱发言"、今年发言 15 次 → 写"开始举手了"，不写"一直不爱说话" |

判断标准只有一句：**这句话今年材料里有依据吗？**
有 → 可以写；只有去年有 → 不写。参考材料越位，比没有材料更糟——家长会发现老师写的是去年的孩子。

> 跨年检测的覆盖面与批内「同句式句对」一致：**不足 8 个汉字的短句不参与比对**
> （短句鉴别力太弱，"希望继续努力"这类撞上也不说明问题）。所以它抓的是**长句照搬**；
> 短句层面仍要靠人工扫一眼开头与结尾。

没有本学期教师描述、只有往年评语时：可以写"延续性"评语，但**不要假装这是本学期的观察**；
在交付说明里点出"这次只有往年材料"，并提示补一份本学期的教师描述
（`export_comments.py` 表下小贴士第 1 条会自动改成这个口径）。

## 二、三段式结构

```
肯定（具体） → 建议（可执行） → 期待（有画面感）
```

- **肯定**：从教师描述里挑的那一个专属动作切入，不要从"你是一个……的学生"起手。
  **要写足**——两三件具体的事比一句"表现优秀"有力，优点不允许被一句形容词带过
- **建议**：必须可执行——给出时间（"明天开始"）、数量（"一天十个词"）、动作（"把手机放在客厅充电"）。
  用商量的口吻（"老师想跟你商量一件事""我们来定个约定"），不用命令句，不写"你必须/你要改正"
- **期待**：与本人证据挂钩，有画面。不要抽象祝福。

结尾句示例（每句都绑定了本人材料）：

| 学生特征 | 结尾句 |
|---|---|
| 解题快但书写乱 | 先把步骤一行行写清楚，你的答案会更有说服力 |
| 会写作文但考场写不完 | 你已经把好内容写出来了，剩下的只是让它完整地站住 |
| 从不举手但听力满分 | 你的答案值得被全班听见，这是老师这学期最想跟你说的一句话 |
| 作业潦草 | 你的内容本来就好，别让潦草替你打了折扣 |
| 慢热型 | 把那一个月的吃力挪到假期，你会走得更轻松 |

## 三、分层写作策略

| 层 | 特征 | 写作重点 | 陷阱 |
|---|---|---|---|
| **A 优秀稳定** | 名次前列、指标稳定 | 防"捧杀"：写"从优秀到卓越"的具体路径 + 带动力 | 只夸不导，写成颁奖词 |
| **B 踏实平稳** | 中上游、无大起落 | 写"稳定背后的坚持"，给一个可量化的跃升目标 | 写不出差异，全班一个味儿 |
| **C 波动待稳** | 曾验证过能力、最近起伏 | 写"能力已验证 + 稳定性的具体抓手"，突出某次亮点 | 只提退步，伤士气 |
| **D 需重点帮扶** | 排名靠后 | **先找真实闪光点**（哪怕只是"值日从不缺席"），再给**一个**最小可行动作 | 罗列一堆问题；闪光点写虚 |

> D 层最容易翻车。规则是：**闪光点必须真实且具体，建议只给一个。**
> 给三个建议等于没给建议。

## 四、称谓与代词

- 默认第二人称"你"，对话感更强，适合学生自读
- 学校要求第三方存档时改第三人称"该生"（全篇统一，不得混用）；
  **换的只是人称，语气基调一条不动**——别把"该生"顺手写成公文体
- 需要"他/她"时按 `roster.json` 的性别字段判断；性别缺失时统一用"你"规避
- 家长版开头加"XX家长："，落点改为"家里可以怎么配合"
- 全文的"老师"指任课教师视角，不要写成第三人称的"班主任老师认为"

## 五、句式复用陷阱（实测教训）

最典型的雷同不是"写错了人"，而是**同一个句式换了内容**：
40 人实测中，初稿有 20 条用"这学期你的……"起手式，字面各不相同但骨架完全一样，
家长翻几份就能看出是同一支笔写的——而两两相似度只有 0.027，实词层面干净得挑不出毛病。

这正是 `similarity_check.py` 里「骨架相似度」和「同句式句对」两项存在的原因：
主指标看的是实词，一旦内容被整体换掉它就瞎了；后两项分别从"抹掉可替换槽位再看"
和"逐句比对句法骨架"两个角度把它捞回来。**三项指标任何一项报警都要改。**

一组实测对照（句式完全一致、只有学科/事迹/评价词不同的 6 条，
见 `references/盲区用例_同骨架换词.json`）：
主指标最大 0.252（只有 1 对勉强进「需检查」，无一对「高度雷同」）；骨架最大 0.191，
平均 0.191、9 对进「同骨架」；靠「同句式句对」抓出 47 组，并给出模板 `○把○你会更○`
（「下学期把标注写全一点你会更拔尖」vs「往后把脉络串细一点你会更清晰」）。
**只跑主指标就会把这一整组放过去。**

机器之外，「高频区别性词」那一栏仍要人工过一遍（它兜的是三项指标都还没敏感到的习惯）：

- 出现次数 > 全班人数 × 15% 的 bigram，就要警惕是不是自己的口头禅
- 优先处理**结构性短语**（"这学期你的""在……方面""希望你能"），不要只盯着形容词
- 处理办法是**换骨架**，不是换词：
  - ❌"这学期你的名次往前走了一截" → ✅"名次往前走了一截"
  - ❌"这学期你的物理成绩一直不错" → ✅"物理成绩一直不错"
  - ❌"这学期你和老师聊过一次之后" → ✅"这一学期，你和老师聊过一次之后"
- 改写后重跑自检，直到三项指标清空、该栏不再出现结构性短语
