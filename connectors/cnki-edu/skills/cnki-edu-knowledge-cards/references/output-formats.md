# 输出格式规范

六种形态：Markdown（默认）、图片、PDF、文档、网页、**思维导图**。思维导图属本技能支持的卡片形态，用于知识体系梳理。
**所有格式不得改变知识内容，安全提示必须保留。**

---

## ① Markdown（默认）

- 结构清晰，便于复制到备课文档、班级群、学习平台。
- 必含：卡片类型、适用学段/学科、知识点、使用场景、教师提示、分层/安全标注。
- 卡片之间用 `---` 分隔；批量任务在开头放卡片组封面块（见 [card-templates.md](card-templates.md) 第三节）。
- 数理符号用可读写法（`a²+b²=c²`、`H₂O`），不要留裸 LaTeX；需要排版公式时明确说明并改用 HTML 输出。

## ② 图片

- 格式：PNG、JPG、SVG、长图。
- 版式：单卡、双面卡、多卡拼图、A4 海报、手机长图。
- 尺寸建议：
  - 手机长图：1080×1920
  - 方形卡：1080×1080
  - A4 打印图：2480×3508（300 dpi）
- 学段适配：低段大字号、配拼音、用图标、高对比；中高段简洁、逻辑化。
- 学科适配：公式、实验示意、时间线、地图、音标等可嵌入。

**做法**：先产出 HTML 卡片页（用 [../references/card-page-template.html](../references/card-page-template.html) 改写），设置好尺寸与字号，预览确认后再转图片。不要跳过预览直接出图。

**HTML → PNG 无浏览器依赖方案（Windows 实测）**：本机已装 Chrome/Edge 时，不必安装 puppeteer/playwright：

```sh
chrome.exe --headless=new --disable-gpu --no-sandbox --hide-scrollbars \
  --window-size=<宽>,<高+200余量> --user-data-dir=<临时目录> \
  --screenshot=out.png "file:///<绝对路径>.html"
```

- `--screenshot` 截的是**视口**不是整页：窗口高度必须 ≥ 内容高度，否则底部被裁。
- 输出倍率受系统 DPI 影响（150% 屏常得 1.5×），`--force-device-scale-factor` 可能被忽略；交付前先读 PNG 实际宽高确认清晰度。
- 裁掉底部空白：pymupdf 读像素 + numpy 按背景色找最后一行内容，再补回海报底边距。
- pymupdf 重存 PNG 可能膨胀到十几 MB：用「逐行自适应滤波(0–4) + zlib level 9」手写 PNG，2400×2150 可压到 ~1MB。

## ③ PDF

- 格式：A4 打印版、A4 多卡裁切版、A5、名片卡、折叠卡、双面卡。
- **必须包含**：裁切线、页边距、双面校准、打印说明。
- 用途：课堂分发、家庭打印、复习册、考前速查。

**做法**：由 HTML 打印样式产出（`@page { size: A4; margin: ... }` + `page-break-inside: avoid`），或按用户已提供的排版要求生成文档后导出。交付时提示打印设置（"实际大小"、关闭页面缩放）。

## ④ 文档

- 格式：DOCX、Word、txt 纯文本。
- 特点：可编辑，保留样式、表格、文本框、占位符；教师可自行修改内容、增删卡片。
- 适合需要二次加工的教研与备课场景。

**做法**：走 WorkBuddy 的 Word 文档生成路径产出 `.docx`，保留标题层级与表格结构；不要只丢一段纯文本冒充文档。

## ⑤ 网页

- 格式：完整 HTML/CSS/JS，响应式。
- 功能：点击翻卡、显示/隐藏答案、随机抽卡、计时、收藏、错题标记、搜索、打印。
- 支持数学公式渲染、化学式、图片嵌入、离线使用。
- 可分享链接、嵌入班级平台、生成二维码。
- 无障碍：字体可调、高对比、键盘操作。

**做法**：复制 `references/card-page-template.html` 为起点，把卡片数据填进模板的数据数组，不要另起炉灶重写一套交互。模板特性：纯静态、零外部依赖、可离线打开、键盘可操作、打印样式已内建。生成后用浏览器预览面板打开确认交互可用。

**配色（学科主题色，可选）**：在 `const DECK = { ... }` 内可设 `theme` / `theme2`（hex，如化学用 `#1aa179` 绿、历史用 `#b5713a` 赭），整页页头渐变、按钮、层级徽章会跟随该学科色；单卡还可设可选 `color` 字段做点缀色。不设则默认蓝紫渐变，已适配低段高对比与打印。

## ⑥ 思维导图（本技能支持的卡片形态）

- 形态：中心节点 + 彩色分支的可视化知识体系梳理；可产出 HTML/SVG 交互图，或 Markdown 树状文本。
- 结构约定：
  - **中心节点** = 篇目 / 专题 / 单元主题（如《田忌赛马》）。
  - **主分支** = 按知识维度拆分，如：文学常识 / 人物介绍 / 故事背景 / 经过 / 结果 / 道理启示 / 重点词句（依学科与篇目灵活调整，不强行统一数量）。
  - **子节点** = 每个维度下的要点，力求"一卡一点"式的短句，不展开成长篇。
- 学段适配：小学低段大字号、配图标、高对比；中高段可加密逻辑层级。
- 用途：单元/篇目复习、课前导学、知识速览，可贴墙、可打印、可导出 PDF。
- 标注：版本/册次不确定时在图角注明「请按所用教材版本核对」；出处可随分支标注。

**做法**：用纯 HTML/CSS（或 SVG）画中心节点 + 分支卡片，配色区分主分支，带打印样式（横向 A4 导出 PDF）；或输出 Markdown 缩进树状结构便于复制进备课文档。无需另装依赖，可离线打开。

## ⑦ 视觉风格指南（贴纸·手帐·生动化）——**所有 K-12 卡片/图谱/导图通用**

> 用户明确要求：**中小学的知识卡片 / 图谱 / 导图 / 思维外化图应当是生动有趣的，页面元素要丰富多彩，不能"一个方框一个方框"地堆砌**。本指南约束 ⑤ 网页、⑥ 思维导图 与图片/PDF 形态的视觉呈现，默认生效；学段越低的任务，越要活泼、留白、高对比。

### 7.1 设计原则（四不四要）

- **不**用大片白底 + 等距方框网格；**要**有主题色块、渐变、圆角与投影层次。
- **不**让中心节点是"方框"；**要**做成发光的"星球 / 主角气泡 / 卡通徽标"（见 §⑥ 做法）。
- **不**用直线硬连线；**要**用曲线 / 胶带 / 虚线等有机连线，带轻微弧度与配色。
- **不**把重点写成普通小字；**要**用金色"★重点"星标贴纸、彩色 keyline 高亮，让重点"跳"出来。

### 7.2 通用视觉元素（建议件件落地）

| 元素 | 做法 | 适用 |
|---|---|---|
| 主题色 | 学科主题色（地理星空蓝 `#3b6fd4`、化学绿 `#1aa179`、历史赭 `#b5713a` 等）贯穿页头渐变、连线、徽章、横幅 | 全部 |
| 中心节点 | 发光球体 / 气泡徽标（SVG 径向渐变 + 描边 + emoji），不是矩形框 | 导图 / 图谱 / 知识地图 |
| 分支节点 | 绕中心均匀分布的**圆角彩色贴纸**（emoji + 短标题），曲线胶带连线 | 导图 / 图谱 |
| 贴纸卡 | 手帐风：**彩色横幅标题（左切角）+ 凸起 emoji 徽章 + 胶带角 + 轻微旋转**；hover 抬升、入场 pop 动画 | 卡片 / 详细分支卡 |
| ★重点 | 金色"★重点"星标贴纸（`key:true` 触发），配浅金底 keyline | 全部 |
| 背景涂鸦 | 星点 / 圆点 / 小星（CSS `radial-gradient` 或 SVG 散点）做底纹，活泼不抢内容 | 网页 / 图片 |
| 漂浮装饰 | 若干 ✶✦✺★❀✸ 漂浮在页边（低透明度、轻微浮动动画，打印时隐藏） | 网页 |
| 学段适配 | 低段：大字号、拼音可选、图标多、高对比；中高段：加密逻辑层级、保持轻装饰 | 全部 |

### 7.3 复用模板（不要另造轮子）

- **思维导图 / 知识图谱 / 思维外化图**：直接复制 `references/knowledge-graph-template.html` 改写 `const GRAPH = {...}`（中心节点 + 彩色贴纸分支 + 手帐贴纸卡，已内置贴纸/手帐/星标/涂鸦全套元素与学科主题色、A4 横向打印样式）。
- **翻卡 / 抽卡 / 自测网页**：复制 `references/card-page-template.html`（温暖渐变 + 学科主题色 `DECK.theme` + 三级徽章 + 翻卡交互，可在卡片 `color` 字段加点缀色）。
- 图片 / PDF 形态：先以上述 HTML 模板出图 / 打印，再转 PNG 或导 PDF，保证视觉语言一致。

### 7.4 学科主题色速查

| 学科 | 主色 theme | 辅色 theme2 | 中心节点意象 |
|---|---|---|---|
| 地理 | `#3b6fd4` 星空蓝 | `#1f3c7a` 深蓝 | 地球 / 星球 |
| 化学 | `#1aa179` 绿 | `#0f7d63` 深绿 | 烧瓶 / 分子 |
| 历史 | `#b5713a` 赭 | `#8a4f24` 深赭 | 卷轴 / 印章 |
| 物理 / 生物 / 通用 | `#5b7cfa` 蓝紫（默认） | `#8a6cf0` 紫 | 原子 / 细胞 / 问号 |

## 质量要求（逐项核对）

| 维度 | 要求 |
|---|---|
| 内容 | 一卡一核心，语言简洁，准确无误，符合课标，不超纲，不杜撰；涉实验必写安全提示；不生成与课堂场景无关的长篇内容 |
| 图片 | 清晰、无错位、字体可读；小学低段用大字号 |
| PDF | 边距合理、裁切线准确、双面可校准 |
| 文档 | 样式统一、可编辑、占位符明确 |
| 网页 | 响应式、可离线、交互可用、无外部依赖（如有依赖必须说明） |
| 思维导图 | 中心节点清晰、分支不交叉错乱、配色区分维度、低段大字号高对比、可打印/可导出 PDF |

## 格式选择决策

```text
用户要什么？
├─ 没说 / "给我卡片"           → Markdown（默认）
├─ 要打印、要裁切、要分发       → PDF（A4 裁切版 + 裁切线）
├─ 要贴教室、要发群、要图片     → 图片（HTML 先预览再出图）
├─ 要自己改内容、要教研留档     → 文档（DOCX，可编辑）
├─ 要翻卡/抽卡/自测/收藏       → 网页（自带可翻卡模板）
├─ 要体系梳理/知识速览/贴墙   → 思维导图（HTML/SVG 或 Markdown 树状）
└─ 要导入 Anki/Quizlet        → Markdown 三列（正/背/标签）或 CSV
```
