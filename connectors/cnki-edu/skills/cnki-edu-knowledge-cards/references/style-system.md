# 输出样式系统（详解与速查）

本文件是 `SKILL.md`「输出样式系统」节的配套详解：给出**决策流程、样式拾取表、图标锚点、变量清单、模板套用方法**，供生成时快速照表执行，避免自由发挥。

> 总原则：**先决策 → 再声明 → 后生成**。每次生成前必须输出一行声明：
> `本次样式：学科风格=？；学段密度=？；图形结构=？；配色方案=？`

---

## 一、决策流程（四步）

1. **定学科风格**：看学科（文科/理科/跨学科）→ 选图形结构大类；再看 `{{样式偏好}}` 是否指定（指定即从之）。
2. **定学段密度**：小学=图多字少；初中=逻辑+考点；高中=网络+题型。
3. **定图形结构**：学科大类 + 内容类型（时间/因果/对比/分类/公式/实验）交叉决定（见 SKILL.md 第二、四节表）。
4. **定配色方案**：与所选风格绑定，颜色总数 ≤6。

未指定样式时默认：**手绘笔记风 + 经典思维导图结构 + 按学段自动调字号**。

---

## 二、样式拾取速查表

| 用户意图 / 场景 | 推荐风格（data-style） | 图形结构 | 学段密度 |
|---|---|---|---|
| 预习、课堂笔记、低段 | `handdrawn` 手绘笔记风 | 概念树 / 时间轴 | 按学段 |
| 知识点卡、复习卡 | `collage` 卡片拼贴风 | 卡片网格 / 对比表 | 按学段 |
| 初高中复习、速查 | `magazine` 极简杂志风 | 对比表 / 公式网络 | 初中/高中 |
| 理科公式推导、实验流程 | `blackboard` 黑板粉笔风 | 流程图 / 鱼骨图 / 模型图 | 初中/高中 |
| 单元整体梳理、导图 | `mindmap` 经典思维导图风 | 中心图+彩色分支 | 按学段 |

## 四、变量清单（切换风格即整体换肤）

`references/style-library.css` 为每种风格定义了以下变量（与两个 HTML 模板共用同名变量）：

- 背景/面板：`--bg-1 --bg-2 --panel`
- 文字：`--text --muted --line`
- 主题色：`--deck --deck-2`（卡片模板）/ `--theme --theme-2`（导图模板，二者同设）
- 高亮/警示：`--key --key-soft --warn --warn-soft`
- 等级色：`--lv-base(/soft) --lv-up(/soft) --lv-chal(/soft)`
- 圆角/阴影：`--radius --radius-sm --shadow --shadow-hover --shadow-pop`
- 字体：`--font-head --font-body`（标题/正文同族，避免混乱）

---

## 五、模板套用方法

1. 样式库 CSS 已**内联**进两个 HTML 模板（在 `<style>` 内），交付的 HTML 单文件即可离线渲染、支持 5 种风格切换；**生成交付物时严禁把 `style-library.css` 单独输出/复制到用户目录**。
2. 给 `<html>` 加 `data-style`（模板已内置默认值，生成时按样式声明改键即可）：
   ```html
   <html lang="zh-CN" data-style="mindmap">
   ```
3. 若需高对比无障碍模式，保留模板原有 `data-contrast="high"` 即可（样式库已用 `:not([data-contrast="high"])` 避让，不会冲突）。
4. 颜色/字体/背景由变量驱动，无需重写渲染逻辑；如需局部强调，叠加 `.hl-*` / `.chalk` / `.anchor-*` / 形状类。

---

## 六、强制约束与避坑（与 SKILL.md 第七、八节一致）

- 一级分支 5–7 个；层级 ≤4；节点关键词 ≤7 字（小学 ≤5 字）。
- 颜色 ≤6、一色一义；同主题同色系，不同主题不同色。
- 字体统一（标题/正文不混用衬线+非衬线）。
- 留白 ≥30%（高中 ≥25%）；可打印、可黑白辨认；重要分支用形状区分。
- 文科必含：主题、考点、迁移区；理科必含：公式框、适用条件、单位、易错点。
- 不文字堆砌、不只抄目录、不字体混乱、小学不密、高中不无留白。
