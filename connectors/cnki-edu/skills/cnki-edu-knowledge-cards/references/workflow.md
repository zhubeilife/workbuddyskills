# 工作流程详解与输入模板

---

## 一、五步工作流

### Step 1：意图识别与信息确认

从用户输入中识别四项：

| 识别项 | 取值 |
|---|---|
| 学科 | 语文 / 数学 / 英语 / 物理 / 化学 / 生物 / 道法·政治 / 历史 / 地理 / 科学 / 音乐 / 美术 / 体育 |
| 学段 | 小学低段(1–2) / 小学中段(3–4) / 小学高段(5–6) / 初中(7–9) / 高中 |
| 卡片类型 | 知识点卡片 / 复习卡片 / 教研卡片（口语形态见 [card-templates.md](card-templates.md) 第五节） |
| 具体内容 | 知识点名称 / 单元名称 / 篇目 / 章节 / 教研主题 |

信息不完整时**主动询问**，一次问齐，不要挤牙膏：

> "请问您需要为哪个学科、哪个学段制作知识卡片？是关于什么知识点的？您希望是单知识点卡片还是单元复习卡片？"

追问话术库：

- 缺学段：「这个知识点在小学、初中还是高中？方便的话告诉我年级和册次，卡片会更贴合教材。」
- 缺学科：「您做的是哪个学科的卡片？」
- 缺范围：「这次是一个知识点、一个单元，还是一册/一个专题？」
- 缺用途（弱触发）：「要不要做成简练知识卡片？3—5 个要点，可速查、可背诵、可导出。」
- 缺格式：「默认给您 Markdown，方便复制到备课文档；需要图片、PDF、Word 还是可翻卡的网页版？」

> 学段与学科**不允许自行假设**；教材版本缺失可默认并按规则标注。

### Step 2：内容检索与生成

1. 按学科加载 [prompt-library.md](prompt-library.md) 对应系统提示词，叠加总控提示词。
2. 按优先级检索知识来源：用户上传的教材/课标原文 → 课标与教材通用知识 → 模型知识。
3. 生成卡片核心内容，**标注课标/教材出处**。
4. 批量任务（>5 张）先输出卡片清单（编号 + 标题 + 学科 + 学段）供用户确认，确认后逐卡生成。
5. 无法确认的事实标注"待核实"或"⚠请按所用教材版本核对"，宁缺毋滥。

### Step 3：卡片格式化输出

按用户选择的卡片类型套模板，默认输出结构化 Markdown，含：卡片类型、适用学段/学科、知识点、使用场景、教师提示、分层/安全标注。
结构骨架见 [card-templates.md](card-templates.md)。

### Step 4：交互式追问与迭代

输出后**主动引导**追问（不要说"还需要什么吗"这种空话，给具体选项）：

- "是否需要调整卡片的内容详略程度？"
- "是否需要为这个知识点再生成一张对比辨析卡片？"
- "是否需要生成同一单元的分层复习卡片？"
- "要不要补一张易错点专项卡？"
- "要不要把答案折叠起来，做成可自测的抽卡版？"

### Step 5：选择卡片导出格式

- 支持 Markdown / 图片 / PDF / 文档 / 网页 / 思维导图 六种形态（思维导图规范见 [output-formats.md](output-formats.md)，属本技能支持的卡片形态）。
- 多张卡片可批量导出，或打包为压缩包。
- 导出完成后**提示文件名、保存路径和打开方式**。
- 导出后知识内容不得改变，安全提示必须保留。

## 二、三大使用场景

### 场景一：课堂 / 课前（预习 · 分层 · 实验流程）

- 典型触发：预习卡（图）、导学卡（图）、课前预习卡、分层练习卡、分层任务卡、实验流程卡、操作流程卡、安全核对卡、课堂互测卡、随堂卡、课堂卡片。
- 生成侧重：**正面是引导性问句**，背面是要点提示；分层卡需用 `分层标注` 明确标注基础/提升/挑战；实验类必须显式成块写安全核对项。
- 默认输出：Markdown；要求"（图）"或可打印时输出 HTML 卡片页（A6 或 16:9）。

### 场景二：课后 / 碎片（打卡 · 数字卡 · 自测）

- 典型触发：课后自测卡、复习卡、打卡卡、口袋卡、碎片卡、数字卡、纸质卡、手机翻卡、Anki 卡、Quizlet 卡、错题纠错卡、单元过卡、期末过卡。
- 生成侧重：卡面极简（正面问题 + 背面答案 + 标签），便于导入背诵软件或随身翻；答案默认折叠。
- 默认输出：Markdown（三列：正 / 背 / 标签）或可翻卡网页。

### 通用场景（汇总 · 速查 · 知识清单）

- 典型触发：思维导图、知识汇总卡、速查卡、简练汇总、知识清单卡、问答卡、概念卡、对比卡、时间线卡、篇目知识卡、章节知识卡、文学常识卡。
- 生成侧重：3—5 个要点，可速查、可背诵、可导出；一卡一事，不展开成长篇。
- 默认输出：Markdown。

## 三、场景判定与转交

1. **显式场景词优先**：命中"预习 / 分层 / 实验流程"走场景一；命中"课后 / 碎片 / 打卡 / 数字卡"走场景二；命中"汇总 / 速查 / 简练 / 知识清单"走通用场景。
2. **多场景命中**：按用户原词中最具体的场景进入；无法判断时先问一句："要做成课堂用、课后自测，还是通用速查卡片？"
3. **不触发本技能时**：按边界转交备课、出题、作业、错题本等对应技能（思维导图已纳入本技能范畴，不再转出）。
4. **全学段全学科通用**：以上规则不限小学 / 初中 / 高中，不限语文、数学、英语、物理、化学、生物、道德与法治·思想政治、历史、地理、科学、信息、音体美等学科。

## 四、用户输入模板（可直接让用户填空）

```text
请生成课堂内知识卡片：
- 学段：
- 年级：
- 学科：
- 教材版本/单元：
- 知识点/篇目/章节：
- 课型：
- 学生水平：
- 卡片类型：
- 实验/操作名称：
- 输出格式：Markdown / 图片 / PDF / 文档 / 网页
- 图片尺寸或打印版式：
- 网页功能需求：
- 其他要求：
```

用户只填一部分也可以开始；缺失的按 [SKILL.md](../SKILL.md)「输入四要素」处理——学段与学科缺失必问，其余可默认并标注。

## 五、交付话术模板

Markdown 交付：

```text
已完成〈初中·物理〉《浮力》卡片组，共 8 张（公式与定理卡 3 张、易混概念辨析卡 2 张、基础概念卡 3 张）。
- 教材版本：人教版八年级下册（如与所用教材不一致，请告诉我，我按实际版本重做）
- 文件：浮力知识卡片.md
- 可直接复制到备课文档；需要我导出成可翻卡的网页版或 A4 打印 PDF 吗？
```

文件交付：

```text
已导出至 <保存路径>/浮力知识卡片.pdf
- 版式：A4 打印版，4 张/页，含裁切线与打印说明
- 打开方式：双击用 PDF 阅读器打开；打印时选择"实际大小"、关闭"缩放以适应"
- 如需双面卡，请告诉我，我改成双面校准版
```
