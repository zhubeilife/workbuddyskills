## 二、弱触发（先确认一句再用）

用户**只给范围、没说"xx 知识卡片"**时的典型输入：

- "帮我准备一下《观沧海》的预习"
- "七年级生物显微镜使用注意事项"
- "数学公式分层练习题"
- "把这些单词做成能随身背的"
- "辛亥革命怎么回事"
- "《红楼梦》主要人物"
- "浮力知识点"

处理方式：**先问一句**

> "要不要做成简练知识卡片？3—5 个要点，可速查、可背诵、可导出。"

用户确认后再进入；用户其实就是想要一个普通回答时，直接回答即可，不强行套卡片。

## 三、触发优先级与转交建议

1. **显式场景词优先**
   - 命中"预习 / 分层 / 实验流程" → 走**场景一**（课堂 / 课前）
   - 命中"课后 / 碎片 / 打卡 / 数字卡" → 走**场景二**（课后 / 碎片）
   - 命中"汇总 / 速查 / 简练 / 知识清单" → 走**通用场景**
   （场景定义见 [workflow.md](workflow.md) 第二节）
2. **多场景命中**：按用户原词中最具体的场景进入；若无法判断，先问一句："要做成课堂用、课后自测，还是通用速查卡片？"
3. **不触发本技能时**：按边界转交**备课、出题、作业、错题本**等对应技能（思维导图已纳入本技能范畴，不再转出）。
4. **全学段全学科通用**：以上触发词不限小学、初中、高中，不限语文、数学、英语、物理、化学、生物、道德与法治/思想政治、历史、地理、科学、信息、音体美等学科。

## 四、不触发（容易误判的边界）

| 用户意图 | 应转交 |
|---|---|
| 写教案 / 教学设计 / 课件 | 备课类技能 |
| 出一套试卷 / 作业布置 | 出题、作业类技能 |
| 错题本整理与统计 | 错题本类技能 |
| 画完整思维导图/知识图谱 | 思维导图已纳入本技能范畴（见形态词"思维导图"），按"思维导图卡"产出，不必转出 |
| 纯知识点查询（不需要卡片形态） | 直接作答 |
