# 内容准确性规范

教育内容出错比不好看更严重。生成前过四问，生成后按学科核对。

## 一、生成前四问

1. 知识点在教材里的标准表述是什么（定义 / 公式 / 结论 / 原文）？
2. 有没有必须引用的原文（语文课文、史实记载）？原文一字不差。
3. 数值 / 单位 / 符号按哪个标准（人教版 / 课标）？**权威常量先查 `references/_facts.json`**（黄赤交角 23.44°、重力加速度 9.8、电解水 2:1 等），生成时用 `<span data-fact="名称">数值</span>` 标记，交给 `scripts/lint_facts.py` 机械核对。
4. 哪些文字必须精确——它们必须进 HTML 文字层，不能靠生图。

## 二、文字层分离（硬性）

AI 生图只负责"美"，精确文字必须 HTML 叠加：

- 课文原句、公式、标签、读数、按钮文字 → 用绝对定位的 HTML 元素叠在图上，带半透明底衬保证后排可读。
- 生图提示词里写「无文字、无字母、无坐标轴、无数据标注」。
- 绝不用生图里的文字承载精确信息（会糊、会错、会侵权风险）。

## 三、教材原文优先（语文 / 英语 / 道法 / 历史）

- 引用原文，一字不差，并标注出处（如「出自巴金《海上日出》」）。
- 原文用引文样式（左侧色条 / 引号），与讲解文字区分。
- 不篡改、不"意译"原文去凑动画；讲解释放在原文之外。

## 四、分学科核对表

| 学科 | 必核 |
|---|---|
| 数学 | 公式符号、定义域、单位、图像象限与渐近、计算数值 |
| 物理 | 物理量符号与单位、矢量方向、公式适用条件、常数（g=9.8） |
| 化学 | 化学式配平、反应条件、物质状态符号、颜色现象 |
| 生物 | 结构名称、生理过程顺序、专有名词（不口语化错用） |
| 地理 | 方位（上北下南）、比例尺含义、气候/洋流事实、中国疆域规范 |
| 历史 | 年代、人物、事件因果、疆域变迁（按教材地图） |
| 语文/英语 | 原文一字不差、作者与出处、释义不偏离教材 |

## 五、交付前自检

- 所有公式 / 数值 / 原文与教材一致？
- 精确文字都在 HTML 文字层，未烤进生图？
- 无事实错误、无误导性简化？
- `data-fact` 标记的常量经 `scripts/lint_facts.py` 一致？
- 跑 `scripts/validate_html.py` + `scripts/verify_render.py` 通过？
