# 学科硬约束单一真相源（_facts）

> 本文件是 cnki 动画里**权威数字**的唯一出处。生成前查这里，生成后用 `scripts/lint_facts.py` 机械化比对，杜绝「23.5° / 23.44°」「黄赤交角写反」之类长尾错误。

## 一、为什么需要它

studio / v2 两个 skill 都证明了一件事：**不把常量集中成单一源 + 不机械校验，数值类错误会反复出现**。cnki 原本只有 `05-subject-specs.md` 的「内容红线」文字要求，没有可被程序核对的真值库。本文件补上这一层。

- 机器可读真值：同目录 `_facts.json`（生成工具与 lint 都读它）。
- 人类可读说明：本 `.md`。

## 二、标记约定（生成时必须这样写权威数字）

动画里任何「会被教师拿教材对一遍」的精确数字，用 `data-fact` 包起来：

```html
<!-- 标量 -->
<p>黄赤交角约为 <span data-fact="黄赤交角">23.44°</span>。</p>

<!-- 比值（电解水） -->
<p>生成气体体积比 <span data-fact="电解水体积比">2 : 1</span>（氢:氧）。</p>

<!-- 公式结果也可标 -->
<div>像距 <span data-fact="凸透镜像距">30</span> cm</div>
```

`lint_facts.py` 会：
1. 读出 `data-fact="名称"`；
2. 从元素文本里抽出数字（支持 `23.44°`、`:` 比值、`×10⁸`、上标数字等写法）；
3. 与 `_facts.json` 同名条目比较，超出 `tol` 容差即**报错**。

> 没标 `data-fact` 的数字不会被查（也不报错）——标记是「请帮我核对」的显式请求，不是强制。凡是你拿不准、或会被教材对质的数字，都加上标记。

## 四、扩充约定

加常量只改 `_facts.json` 一处（机器读），并在本 `.md` 第三节补一行（人读）。lint 自动生效，无需改脚本。`kind` 支持：`"scalar"`（默认，标量）、`"ratio"`（a:b 比值）、`"flag"`（仅参考，不参与自动校验）。

## 五、与 v2 / studio 的差异

- v2 把常量散在 `subjects/_facts.md` 且靠 `subject-lint.mjs` 做「黑名单词法级」回归；我们改为**结构化 JSON + 数值级容差比对**，更准、更少误报。
- studio 用 `catalog.json` 的 `routes/families/stages` 契约；我们保留更轻的 `data-cnki-*` 声明（见 `SKILL.md`「生成契约」节），不引入重型目录。
