# 分学科专项规范

本技能区别于"通用大模型套壳"的关键：每个学科有各自的强动画需求、**具体的生成规则**、内容红线与视觉惯例。**生成前必须先判学科，按本节加载该学科的专属要求**，再套用 `01` 的形态与 `02` 的画质策略。通用要求覆盖不到学科特性时，以本节为准。

> 强可视化 / 交互动画需求最强的学科（优先打磨、示例最全）：**物理、化学、生物、地理、数学、语文**。其余学科列基础要求。

通用原则（全部学科共用，但下面各学科有更具体的要求）：精确文字（公式、符号、原文、标签）一律 HTML 文字层，绝不让生图把字"烤"进画面；数值、单位、名称与教材一致；每个作品含"引入问题 → 操作探究 → 即时反馈 → 小结迁移"的最小学习闭环。

## 一、语文学科

**强需求**：课文情境活化、古诗词意境、叙事场面、人物与文言文场景，是纯文字或 PPT 最薄弱、却最出效果的部分。

**首选形态**：情境切换（同一课文的不同时空 / 状态对比）、剧情对话（角色推进理解）、过程演示（叙事 / 意象展开）、知识游戏（字词积累）。

**生成规则（具体怎么做）**
- 先定位课文的"画面支点"：哪一段可直接转为场景？哪个人物 / 意象是视觉核心？不要整篇铺开，挑 1–3 个最关键的画面点做深。
- 情境切换类：用 2–3 张插画帧表现课文推进（如《海上日出》黎明→日出→正午），帧间用**交叉淡入**，并随画面叠加**课文原句**（HTML 文字层），让学生"看画读句"。
- 剧情对话类：角色立绘 + 对话框，对话内容须出自课文或教材合理推断，**不擅自改写人物台词**；分支选项应是课文内的真实抉择（如《司马光》"砸缸还是喊人"）。
- 古诗词：优先做"意境还原"——把诗句逐句变成可看的画面，并标注诗题 / 作者 / 朝代。

**内容红线（最严）**
- 课文原句、古诗文**一字不差**，标注出处（篇名 / 作者 / 朝代）；不掐头去尾、不改写为白话充当原文。
- 作者、朝代、生平、课下注释与**教材一致**。
- 古诗须用教材选定版本（如"海日生残夜，江春入旧年"不可错植、不可张冠李戴）。
- 人物称谓、时代背景符合课文与史实；文言文场景不戏说、不穿越。

**视觉惯例**：插画底图优先（人物、场景、意象）；古风 / 现代风按课文定；原句、注释、作者一律 HTML 文字层。

**易错点与正确做法**

| 易错 | 正确做法 |
|---|---|
| 把原文烤进生图，出现错字、漏字 | 原文用 HTML 文字层叠加，生图只负责画面 |
| 古诗版本与教材不符 | 生成前查教材选定版本，原句一字不差 |
| 用现代服饰演古代课文 | 服饰、器物、场景符合课文时代 |
| 整篇课文平铺，没有画面支点 | 只挑 1–3 个关键画面点做深 |

**典型教学点（具体要画什么）**：《海上日出》日出全过程（三帧 + 原句叠加）；《静夜思》月夜意境；《司马光》砸缸施救（情境 + 分支）；《少年闰土》月下刺猹；古诗意象组合；文言文人物对白。

## 二、数学学科

**强需求**：数形结合、几何变换、函数图像、立体几何是"看不懂就永远不懂"的典型，动态演示价值极高。

**首选形态**：几何变换（平移 / 旋转 / 对称 / 位似）、参数探究（函数系数联动）、数据可视化、过程演示（定理推导）、课堂工具（作图 / 计算）。

**生成规则（具体怎么做）**
- 几何变换类：图形用 SVG 矢量绘制（缩放不糊）；变换过程**动画过渡**（顶点平滑移动到新位置），不是瞬间跳变；变换前后图形同屏对比或叠加半透明"残影"帮助对照。
- 参数探究类：滑块改变 a/b/c 等参数，**函数图像实时重绘**（不是重画坐标轴）；同时显示当前参数值与关键点（顶点、交点、渐近线）。
- 立体几何类：用真 3D 或规范透视画几何体；**必须展示剖面 / 高 / 底面半径**等推导要素（如圆锥体积推导要见"等底等高的圆柱"对照与剖面）；旋转体要能转视角。
- 坐标系：坐标轴方向、单位长度、网格线规范；刻度真实。

**内容红线**
- 符号严格：π、√、坐标 (x,y)、集合、逻辑符号不可错写；上下标、分数线清晰。
- 几何证明 / 推导步骤无误；"约等于"不乱用，该精确处不给近似。
- 单位统一（长度 cm、面积 cm²、角度 °、体积 cm³）。

**视觉惯例**：SVG 矢量优先；图形元素用色区分（已知边 / 未知边 / 辅助线 / 变换前后）；立体图形用真 3D 或规范透视。

**易错点与正确做法**

| 易错 | 正确做法 |
|---|---|
| 函数图像不随参数实时重绘 | 滑块一动，曲线立刻重算重绘 |
| 几何变换瞬间跳变，看不出过程 | 顶点动画过渡 + 残影对照 |
| 圆锥体积推导只给公式不给剖面 | 画等底等高圆柱对照 + 剖面 + 高 |
| 坐标轴刻度随意 | 单位长度一致、刻度真实、含原点 |

**典型教学点（具体要画什么）**：二次函数图像与 a/b/c 关系（滑块联动曲线 + 顶点）；三角形全等判定（叠合动画）；圆锥体积推导（剖面 + 圆柱对照）；平移旋转对称（残影对照）；概率树状图；勾股定理动态证明。

## 三、英语学科

**强需求**：词汇情境化、对话操练、游戏化记忆是语言习得刚需，静态单词表效果差。

**首选形态**：情境切换（场景 + 单词 / 短语）、剧情对话（角色对话操练）、知识游戏（配对 / 闯关 / 听音选图）、课堂工具。

**生成规则（具体怎么做）**
- 词汇情境类：每个目标词配一个**生活化场景插画** + 可点读的发音提示；点词出图、点图出词，建立音形义联结。
- 对话类：场景插画 + 角色对话框，对话为教材句式；可点"角色"播放对应一句，训练跟读。
- 游戏类：配对 / 闯关 / 听音选图，即时反馈（对 / 错），计分与鼓励语按学段（`02` 设计系统）。

**内容红线**：拼写、音标、词义与**教材一致**；例句地道、语法点正确；时态 / 单复数 / 介词用法无误；避免中式英语。英文文本务必拼写准确。

**视觉惯例**：生活化情境插画（食物、动物、场所、动作）；图标辅助理解；游戏化反馈。

**易错点与正确做法**

| 易错 | 正确做法 |
|---|---|
| 英文拼写 / 大小写错误 | 生成后逐词核对教材拼写 |
| 例句语法错误、中式英语 | 用教材句式，避免杜撰 |
| 只给单词不给情境 | 每个词配场景插画 + 可点读 |

**典型教学点**：食物 / 动物词汇情境；日常对话情景；时态对比（现在 / 过去）；介词 on/in/under 空间关系；字母发音规律。

## 四、物理学科（最强需求之一）

**强需求**：力学、电磁、电路、光学、热学、波，几乎全部需要"可操作的探究"与"矢量 / 场"的可视化，是通用大模型最做不好的部分。

**首选形态**：虚拟实验（器材操作 + 读数）、参数探究（变量联动）、过程演示（机制分步）、空间探索（场线 / 受力）、几何变换（光路）。

**生成规则（具体怎么做）**
- 虚拟实验类：器材用**规范示意图**（弹簧测力计、电表、光具座、电源符号）；学生可拖拽改变条件（如移动蜡烛、调电阻），**现象 / 读数实时变化**；读数取真实合理值。
- 场 / 矢量类：用真 3D 或规范矢量图；场线（电场线、磁感线）用**带箭头的疏密线**表示方向与强弱；受力图标作用点、方向、大小比例。
- 光路类：实线表实际光线、虚线表反向延长线；箭头表传播方向；透镜成像要标物距 / 像距 / 焦距与像的性质。
- 参数探究类：滑块改变变量（如物距、电阻），图像 / 读数联动，并给出符合规律的结论。

**内容红线**
- 常量与公式准确：g≈9.8 m/s²、c=3×10⁸ m/s、水的比热容 4.2×10³ J/(kg·℃)；单位规范（N、V、A、Ω、J、W、Pa）。
- 矢量方向正确（力、速度、场）；参照系 / 正方向标注清晰。
- 电路符号符合国标；串并联判断、读数真实。
- **不违背物理定律**（能量守恒、楞次定律方向等）；不编造不存在的现象。

**视觉惯例**：真 3D / 矢量场（地磁场、电场线含箭头与疏密）；规范器材图；光路图标准（实线虚线、箭头方向）；受力图规范。

**易错点与正确做法**

| 易错 | 正确做法 |
|---|---|
| 磁感线无箭头、无疏密 | 带箭头 + 疏密表强弱，闭合不交叉 |
| 电路符号不国标 | 用教材标准电源 / 电阻 / 电表符号 |
| 受力图方向错、漏作用点 | 标作用点、方向、大小比例 |
| 编造不存在的现象 | 结论严格符合物理定律 |

**典型教学点**：地磁场与指南针；串并联电路；凸透镜成像（拖物距看像变）；牛顿第二定律；单摆周期；焦耳定律；波的叠加与干涉。

## 五、化学学科

**强需求**：微观粒子、分子结构、反应过程、实验现象肉眼不可见，动态 3D 与微观宏观对照价值极大。

**首选形态**：虚拟实验（仪器操作 + 现象）、过程演示（反应机理）、空间探索（分子 3D 结构）、参数探究（浓度 / 温度 / 催化剂）、数据可视化。

**生成规则（具体怎么做）**
- 分子结构类：用**球棍模型或比例模型**画 3D 分子；原子用标准色（C 灰、O 红、H 白、N 蓝、Cl 绿）；键角、比例合理；可旋转查看。
- 反应过程类：微观（粒子重新组合）与宏观（现象）**双视图对照**；用动画表现"旧键断裂、新键形成"，并标反应条件（△、催化剂）。
- 实验类：规范仪器（试管、烧杯、酒精灯、导管）；现象（颜色、气体、沉淀）按真实呈现；危险操作（易燃易爆、腐蚀）有**安全提示**。

**内容红线**
- 化学式、方程式**配平正确**，状态符号（↑↓）、反应条件准确。
- 元素符号大小写严格（Co 与 CO、Ca 与 Cu 区分）。
- 不编造不存在的物质或反应；分子 / 晶体结构键角、比例合理。

**视觉惯例**：分子 3D 结构（标准原子色）；规范仪器；微观与宏观对照；反应前后物质的量守恒可视化。

**易错点与正确做法**

| 易错 | 正确做法 |
|---|---|
| 方程式不配平、漏状态符号 | 配平 + 标 ↑↓ 与条件 |
| 元素大小写混淆（CO/Co） | 严格区分大小写 |
| 原子球颜色随手给 | 用标准原子色 |
| 危险实验无安全提示 | 加"模拟，真实实验按实验室规范" |

**典型教学点**：电解水；CO₂ 实验室制取；分子运动；酸碱中和；元素周期律；质量守恒定律微观解释。

## 六、生物学科

**强需求**：细胞、分裂、光合、生态、人体、遗传，结构精细、过程连续，宜动画不宜静态图。

**首选形态**：虚拟实验、过程演示（分裂 / 光合 / 呼吸）、空间探索（细胞器 / 人体系统）、分类配对、数据可视化（种群）。

**生成规则（具体怎么做）**
- 结构类：细胞 / 器官用插画或 3D；**结构与名称标签一一对应**，点击结构高亮并显示功能（如点线粒体出"呼吸作用场所"）。
- 过程类（分裂 / 光合）：分步动画，每步标注发生了什么（如"中期：染色体排赤道板"）；箭头方向表物质 / 信号流向。
- 生态类：食物链 / 食物网用节点 + 箭头，标能量流动方向；种群变化用曲线。

**内容红线**
- 结构名称与功能准确（细胞器、组织、器官）；**不拟人化误导**（比喻须注明，如"线粒体像动力车间"仅为比喻）。
- 有丝分裂 / 减数分裂各期特征、染色体行为无误；分类阶元正确（界门纲目科属种）。
- 人体解剖术语规范；箭头方向表示物质 / 信号流向须正确。

**视觉惯例**：细胞 / 器官结构插画或 3D；生态场景；流程图箭头方向规范；必要时标比例尺。

**易错点与正确做法**

| 易错 | 正确做法 |
|---|---|
| 分裂各期特征混淆 | 按"前中后末"逐步标清染色体行为 |
| 拟人化当事实讲 | 比喻注明"仅为比喻" |
| 结构名与功能不对应 | 点击结构出名称 + 功能 |
| 流程图箭头方向错 | 物质 / 信号流向标对 |

**典型教学点**：植物细胞结构（点击看功能）；有丝分裂；光合作用过程；食物链与食物网；人体血液循环；DNA 双螺旋与复制。

## 七、地理学科

**强需求**：地球运动、地形地貌、气候、地图方位，空间性强，需 3D 与动态对照；其中**地球运动（自转 / 公转 / 昼夜 / 四季 / 五带）**是最典型、最该做好的交互动画。

**首选形态**：空间探索（地球 / 地图漫游）、过程演示（自转公转 / 板块 / 水循环）、情境切换（景观对比）、数据可视化（气候图表）。

**生成规则——地球运动类（具体怎么做，重点）**
- **必须画地轴**，并标注 **23.5° 黄赤交角**；地轴一端指北（可标"指向北极星方向"）。
- **公转时地轴保持平行**（指向不变），这是最易错处——动画里地球走到轨道不同位置，地轴方向必须一致，不能随位置乱转。
- 太阳光线用**一组平行箭头**表示（太阳极远，光线平行），从太阳一侧射向地球。
- **昼夜用受光面亮、背光面暗**表示；亮暗交界即**晨昏线**，要画出来并随节气变化。
- 必须画并标注：**赤道、北回归线 23.5°N、南回归线 23.5°S、北极圈 66.5°N、南极圈 66.5°S**。
- 节气要点：**夏至**太阳直射北回归线 → 北半球昼最长、北极圈极昼、南极圈极夜；**冬至**相反（直射南回归线、北极圈极夜）；**春分 / 秋分**直射赤道、全球昼夜平分。
- 交互：用按钮 / 播放切换节气（地球沿轨道移动到对应位置、地轴保持平行、太阳相对方向变），让学生观察直射点移动与极昼极夜范围变化；可拖拽旋转视角、播放自转看昼夜更替。
- 五带：在侧视图中标出热带、北温带、南温带、北寒带、南寒带及其界线（回归线 / 极圈）。

**生成规则——地图类**
- **中国地图必须用标准地图底图**（含台湾省、南海诸岛、九段线等要素完整），不得随手绘制、不得缺失领土、不得错画国界省界。
- 经线纬线、方位、比例尺正确；地形区、气候类型名称规范。

**内容红线**
- 地球运动方向：自转**自西向东**、公转**自西向东**；黄赤交角 23.5°、回归线 23.5°、极圈 66.5° 准确。
- 中国地图要素完整、画法规范（见上）。
- 气候类型与分布、地形区名称与教材一致。

**视觉惯例**：规范地图底图（用标准地图，不可随意画）；地球真 3D（自转 / 公转 / 昼夜）；地形剖面、罗盘 / 方位标；气候数据用规范图表。

**易错点与正确做法**

| 易错 | 正确做法 |
|---|---|
| 公转时地轴方向乱转 | 地轴始终平行，指向不变 |
| 把黄赤交角画成"地轴与公转轨道面夹角" | 黄赤交角是地轴与公转轨道面垂线的夹角=23.5°；地轴与轨道面夹角=66.5° |
| 昼夜不画晨昏线、极昼极夜缺失 | 画晨昏线，夏至北极圈全亮、南极圈全暗，冬至相反 |
| 中国地图漏台湾 / 南海 | 用标准地图底图，要素完整 |

**典型教学点（具体要画什么）**：地球自转与公转（地轴 + 轨道 + 太阳光线 + 晨昏线 + 节气切换）；气压带风带；中国地形三级阶梯；气候类型分布；等高线判读；板块运动。

## 八、历史学科

**强需求**：时间顺序、因果链条、场景复原，适合时间线与情境重现。

**首选形态**：时间线 / 流程线、剧情对话（人物 / 抉择）、情境切换（古今 / 对比）、空间探索（疆域演变地图）、分类配对。

**生成规则（具体怎么做）**
- 时间线类：横轴标朝代 / 世纪刻度，**事件按真实年代落点**；可点事件出详情卡（时间、人物、意义）。
- 场景复原类：用考据风插画还原时代场景（服饰、器物、建筑符合时代）；人物对话贴合史实语气。
- 疆域演变类：用标准历史地图底图，不随手画边界。

**内容红线**：年代、人物、事件、因果准确；**不戏说、不穿越**；文物、服饰、建筑符合时代；疆域图参照标准历史地图。

**视觉惯例**：时代场景插画（考据风）、时间轴（朝代 / 世纪刻度）、地图演变动画。

**易错点与正确做法**

| 易错 | 正确做法 |
|---|---|
| 年代 / 因果错乱 | 事件按真实年代落点，因果不乱 |
| 服饰器物穿越 | 符合对应时代 |
| 疆域随手画 | 用标准历史地图底图 |

**典型教学点**：丝绸之路；朝代更替时间线；重大事件因果；文物辨识；改革与变法。

## 九、道德与法治 / 政治

**首选形态**：情境对话（两难 / 选择）、剧情对话、对比双栏（观点 / 权利与义务）、过程演示（流程 / 程序）。

**生成规则**：用贴近学生生活的情境插画；选择分支清晰，每个选项导向明确结论；结论符合主流价值观。

**内容红线**：法律概念、条文精神准确；案例符合现实与主流价值观；不虚构法律条文；国旗国徽等须规范。

**典型教学点**：规则情境判断；权利与义务；宪法常识；网络安全与法治；情绪管理。

## 十、小学科学 / 初中科学

**首选形态**：虚拟实验、过程演示（自然现象）、情境切换、知识游戏、空间探索。

**生成规则**：拟物卡通、一次一件事、鼓励式反馈；现象对比清晰（如三态变化前后对照）；实验有安全提示。

**内容红线**：现象描述准确、**不超纲**（按小学 / 初中课标）；生活化、可观察。

**典型教学点**：水的三态；磁铁与磁性；植物生长条件；简单电路；天气与气象；力的作用。

## 十一、信息科技

**首选形态**：过程演示（算法步骤）、数据可视化、参数探究、课堂工具。

**生成规则**：算法用流程动画（高亮当前步）；数据结构可视化（栈 / 队列 / 树）；对比不同算法效率（步数 / 时间）。

**内容红线**：算法逻辑正确；流程图符号规范（起止、判断、处理）；二进制 / 编码概念准确。

**典型教学点**：排序算法演示；流程图绘制；二进制与十进制；循环与分支；数据与编码。

## 十二、音乐 / 美术 / 体育（基础要求）

- **音乐**：节奏 / 节拍可视化、音符时值、波形与频率；可配听音互动。
- **美术**：色彩 / 构图原理动画、名画鉴赏对比、技法分解。
- **体育**：动作分解（慢放 / 分步）、规则示意、体能数据。
- 红线：专业术语准确（音符名称、运动术语）；不出现错误示范动作。

## 使用约定

1. 一个教学点若跨学科（如"密度"偏物理、"统计图"偏数学），以**主学科**加载规则，相关学科规则可叠加。
2. 学科红线与 `03` 的通用准确性规则冲突时，**以学科红线为准**（更具体）。
3. 内容生成后，按该学科"内容红线 + 易错点"逐条核对，再交付。
