# 需求澄清与默认值（不阻塞推进）

信息缺失时按下表直接推进，不要停下追问。生成前先过一遍该知识点的教材标准表述（定义、公式、结论、原文）。

| 缺失项 | 默认值 | 说明 |
|---|---|---|
| 学段 | 初中 | 多数课堂场景；小学用拟物、高中加公式框 |
| 学科 | 由教学点推断 | 一眼可判则直接定，不必问 |
| 教材版本 | 人教版 | 公式/结论跨版本通用；特有篇目才需确认 |
| 用途 | 课堂投屏讲解 | 也兼容插 PPT / 希沃 / 发学生 |
| 深度 | 按学段默认 | 小学具象、初中规律、高中精确 |
| 风格 | 按学段设计系统 | 见 `references/02` 三学段变量 |

**启动语示例**：「要讲解《海上日出》的日出过程，做成语文情境动画，能插 PPT。」→ 直接定：语文 / 小学高或初中 / 情境切换 + 过程演示 / AI 生图底图。

**唯一可停的情形**：涉及具体篇目且跨版本差异大（如某课文不同教材取舍不同），先用"人教版"假设并在交付说明注明，不阻塞。
