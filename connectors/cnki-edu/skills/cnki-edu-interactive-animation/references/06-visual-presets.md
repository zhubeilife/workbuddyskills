# 06 · 视觉与交互预设（P0 / P1 改进基线）

本文件沉淀「弥补代差」的两类预设：**P0 视觉代差**（3D 引擎、AI 插画）、**P1 交互代差**（游戏化、容错叙事、统一组件库）。生成新动画时优先套用，避免每次从零写样式。

---

## P0-1 · 轻量 3D 引擎预设（手绘投影，离线零依赖）

适用：分子结构、晶体、几何、太阳系、磁场等需要"真 3D 立体感"的教学点。

**两种实现，按需求取舍：**
- **手绘 3D 投影（首选，零体积）**：用下列投影函数把 3D 点投到 2D Canvas，配合 `requestAnimationFrame` 自转 + 拖拽。优点：单文件、无依赖、体积小（<10KB）；已验证样例 `高中化学水分子3D结构交互动画.html`、模板 `geomagnetic-3d.html` `earth-solstice.html`。
- **内联 Three.js（强 3D 时）**：当需要真实光照/材质/复杂几何体时，把 `three.min.js`（MIT 许可）压缩源码内联进 `<script>`（约 600KB，仍是单文件离线）。仅在对"真实 3D 质感"要求高时用，且**必须保留其 MIT 许可头与版权声明**（见 SKILL.md 版权红线"开源库可嵌但须署名"）。

**可复用投影函数（复制即用）：**
```js
// 绕 Y 轴 ay、绕 X 轴 ax 旋转后透视投影到画布
function project(p, ay, ax, W, H){
  var ca=Math.cos(ay), sa=Math.sin(ay);
  var x1=p.x*ca + p.z*sa, z1=-p.x*sa + p.z*ca;
  var cb=Math.cos(ax), sb=Math.sin(ax);
  var y1=p.y*cb - z1*sb, z2=p.y*sb + z1*cb;
  var f=420/(420+z2);
  return {sx:W/2 + x1*f, sy:H/2 + y1*f, z:z2, f:f};
}
```
要点：按 `z` 升序绘制（远→近）保证遮挡正确；原子用径向渐变加高光显材质；键角用 `arc` 标注并随旋转更新。

## P0-2 · AI 插画底图预设（高保真插画质感）

适用：语文情境、历史场面、地理景观、生物生态、小学拟物故事、低龄认知类。

**生成规范（务必遵守，否则触版权/红线）：**
1. 提示词加 `NO text, NO letters, NO words, NO numbers anywhere`——**绝不让 AI 把文字烤进图**（教材原文、标签、读数一律放 HTML 文字层）。
2. 学科配色：小学糖果色 + 圆角；初中清新蓝绿；高中深色科技感。
3. 尺寸：横幅底图 `1536x1024`（再压缩到宽 ≤1000 内嵌，单文件控制在 ~1.2MB 便于投屏/PPT）。
4. 内嵌：`base64` 写入 `background-image` 或 `<img src>`，**无外链**。
5. **版权红线**：只生"自绘风格"插画，不模仿特定 IP（如某动画角色）；不抓取网络第三方图片当素材。已验证样例 `小学科学水的三态插画版交互动画.html`、模板 `illustrated-scene-demo.html`。
6. 成本：ImageGen 单张约 5–10 credits，生成前告知用户。

## P1-1 · 游戏化模板（目标 + 即时反馈 + 成功态）

适用：规律探究类（电路、光路、化学方程式配平、分类）。

结构（最小可玩闭环）：
- **任务条**：明确目标（如"让两盏灯都亮"），用醒目色块。
- **操作区**：开关/按钮带 `on` 选中态；点击即改状态并重绘。
- **反馈区**：实时文字——未达成给"具体哪步错"（如"L2 不亮：检查 S2 是否闭合"）；达成切绿色成功态 + 小结。
- **提示按钮**：不剧透答案，只给排查方向。
- **重置**：回到初始。
已验证样例 `初中物理电路闯关交互动画.html`。

## P1-2 · 容错叙事模板（学生常错对比）

每个易错点配一张对比表，把"错误认知 vs 正确规律"并排，比单纯讲解更易纠错：

| 维度 | 内容 |
|---|---|
| 错误认知 | 学生最常见的误解（如"关 S1 另一盏也灭"） |
| 正确规律 | 教材口径的正确表述 |
| 判断方法 | 可操作的小窍门（如看是否"分叉又汇合"） |
| 数据/公式 | 关键数值或关系 |

## P1-3 · 统一交互组件库（跨动画一致）

- **按钮**：`font-size≥13px`、圆角 `10px`、选中态 `.on`（实心主色）；hover 改边框色。
- **滑块**：`accent-color` 主色；左/右标注端点。
- **开关**：绿=闭合、红=断开，画"闸刀"角度区分。
- **全屏 / 选中态 / 操作提示 / 即时反馈 / 重置 / 触屏** 为每条动画的必带六件套（见硬标准 4）。
- 字号底线 **12px**（自检脚本会拦）。

## Edu 对齐结论（实测，2026-10-09）

> ⚠️ **使用本技能时即应先查权益**（`ToolSearch` 精确查 `mcp__<SERVER>__userState`，无参数调用，只看返回 `data`；一次会话查一次）：
> `data:true` → edu 数据可用；`data:false` → **edu 链路整体不可用**，提示用户前往 **e.cnki.net** 购买 / 开通权益，**不得改用网络搜索或自编内容顶替**（详见 `references/09` §零）。

真实调用 `mcp__<SERVER>__tkSubject / mcp__<SERVER>__tkPoint / mcp__<SERVER>__tkBook`：**工具可用、返回结构化 CNKI 真数据**（知识点含"知识点认识/命题方向/解题方法"三层；教材含版本与章节树）。
**但不可用内联进 Skill 生成链**：① `mcp__<SERVER>__tkPoint` 只接受 `subjectCode`、**无关键词过滤**，单学科（如初中物理）返回 **6.2 MB**；② 直接塞进生成提示会爆上下文+延迟+成本。
→ **Skill 层不接 edu**；课标对齐默认靠 LLM 通用知识兜底，高严谨场景在 **Dify Web 产品层**用检索/向量过滤节点（先按关键词筛 `mcp__<SERVER>__tkPoint/mcp__<SERVER>__tkBook` 再喂生成器）实现。
