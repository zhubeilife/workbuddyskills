# 形态库与交互设计

把教学点映射到 10 类形态之一（可叠加 1 个辅助类型），再按学段定深度与界面形态。渲染介质见 `SKILL.md` 画质策略，红线见 `references/02` 与 `references/05`（**分学科内容红线以 `05` 为准**）。

> 每个学科的强动画需求、首选形态、内容红线与视觉惯例，见 `references/05-subject-specs.md`。生成前先判学科并加载对应规范，是本技能区别于通用大模型的核心。

---

## 一、10 类形态（主类型选 1）

| 类型 | 是什么 | 标准界面结构 | 必备控件 | 典型学科 |
|---|---|---|---|---|
| **情境切换** | 同一主体不同时空/状态对比 | 场景底图 + 状态标签 + 切换条 | 切换按钮/滑块、状态说明卡 | 语文、地理、生物、历史 |
| **剧情对话** | 角色对话推进理解 | 角色立绘 + 对话框 + 分支选项 | 选项按钮、对话进度 | 语文、英语、历史、道法 |
| **空间探索** | 在场景里漫游/观察方位 | 场景 + 八方向/缩放 + 信息点 | 拖拽移动、信息卡、复位 | 地理、历史、生物、科学 |
| **虚拟实验** | 可操作的探究实验 | 器材 + 操作区 + 读数/现象 | 拖拽放置、滑块、复位、读数 | 物理、化学、生物、科学 |
| **参数探究** | 调参看规律 | 参数面板 + 实时图像 | 滑块×1–3、实时曲线/读数 | 数学、物理 |
| **过程演示** | 分步展示发生机制 | 步骤条 + 当前步动画 | 上一步/下一步、自动播放 | 生物、化学、地理、物理 |
| **几何变换** | 图形变换/构造 | 图形 + 变换控件 | 拖拽顶点、选择变换、复位 | 数学 |
| **数据可视化** | 统计/关系呈现 | 图表 + 交互筛选 | 筛选/高亮、tooltip | 数学、地理、科学 |
| **知识游戏** | 玩中学 | 游戏场景 + 计分 | 操作、即时反馈、重玩 | 全学科（尤其英语/小学） |
| **课堂工具** | 教学小工具 | 极简输入/输出 | 输入、执行、清屏 | 全学科 |

## 二、交互形态库（按学科选，勿千篇一律"讲解卡+选择题"）

| 交互形态 | 用途 | 适用学科 |
|---|---|---|
| 拖拽排序 | 时序 / 流程 / 结构关系 | 历史、生物、化学、信息 |
| 分类配对 | 区分概念 / 词义 / 现象 | 语文、英语、生物、地理 |
| 图像 / 地图标注 | 强化视觉识别与空间理解 | 数学、地理、生物 |
| 文本批注 | 聚焦语言细节与证据 | 语文、英语、历史 |
| 参数调节器 | 观察变量变化的结果 | 数学、物理 |
| 分步推导 / 操作 | 建立完整过程感 | 数学、化学、信息 |
| 情境对话卡 | 训练表达与输出 | 英语、语文 |
| 实验预测卡 | 先预测再验证 | 物理、化学、生物 |
| 时间线 / 流程线 | 线性顺序感 | 历史、生物、化学 |
| 对比双栏 | 并列两种观点 / 版本 | 历史、语文、地理 |

**最小学习闭环**（每作品内含）：引入问题 → 操作探究 → 即时反馈 → 小结迁移。

## 三、学段适配矩阵

| 类型 | 小学 | 初中 | 高中 |
|---|---|---|---|
| 虚拟实验 | 拟物卡通器材、一次一件事、拖一拖看现象 | 规范器材、多步操作、读数记录 | 精确数据、误差意识、参数联动 |
| 参数探究 | 1 个滑块、大数字、生活类比 | 2 滑块、规范单位 | 3 参数、公式联动、图像精确 |
| 剧情对话 | 角色可爱、选项图文 | 选项文字、分支简单 | 信息密度高、开放式 |
| 知识游戏 | 闯关、鼓励语、慢节奏 | 计分、限时友好 | 竞技、快节奏、少装饰 |
| 过程演示 | 拟人化、分步少 | 规范术语、步骤清 | 机理深、符号严谨 |

适配不是"改字号"：配色/圆角/语气/练习结构整体按 `references/02` 三学段变量重设计。
