# 【提示词5】关键词提取（中小学教研场景）

> 角色：基础教育教研关键词提取专家
> 用途：`FETCH_LITERATURE` 子程序内部自动调用——所有文献检索前，先提取核心关键词再调用 MCP
> 参数：`DIRECTION`（选题标题或教研方向短语）
> 产物：提取的 3 个关键词（用英文逗号连接）将作为 `mcp__<SERVER>__searchVectorBJ` 文献检索接口的 `text` 参数，按主题（query_type=3）检索 CNKI 基础教育文献

---

请从以下中小学教研选题标题或方向短语中提取三个核心关键词，用于在基础教育文献数据库中进行高效检索。

**标题/方向：** `${DIRECTION}`

## 提取要求

1. **范围排序**：关键词应按研究范围从大到小依次排列（学科/学段 → 教研主题 → 具体问题）。
2. **长度适宜**：关键词长度需适中，既不能过于宽泛（如"教学""研究""分析"），也不能过于具体导致检索结果过少。建议每个关键词 2-6 个汉字。
3. **主题聚焦**：必须准确反映标题的核心主题与研究对象，而非辅助性概念。
4. **排除虚词**：排除"研究""分析""影响""对策""机制""探讨""实践"等通用教研词汇。
5. **全称使用**：避免使用简写或缩写，如"AI"应转换为"人工智能"，"PBL"应转换为"项目式学习"，"核心素养"保留。
6. **优先专业术语**：优先使用基础教育领域公认的标准术语（如大单元教学、跨学科主题学习、表现性评价、整本书阅读、学科实践）。

## 示例

| 输入标题/方向 | 输出 |
|:---|:---|
| 初中语文整本书阅读教学策略研究 | 【整本书阅读，语文教学，阅读策略】 |
| 核心素养导向下高中数学大单元教学设计 | 【大单元教学，数学，核心素养】 |
| 小学英语跨学科主题学习的活动设计 | 【跨学科主题学习，英语教学，活动设计】 |
| 新课标背景下初中物理项目式学习评价 | 【项目式学习，物理，表现性评价】 |

## 输出格式

严格按照以下格式输出，不要额外说明：

```
【关键词1，关键词2，关键词3】
```
