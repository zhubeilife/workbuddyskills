# 组卷会话状态模型（支持 S8 再编辑）

> 这是支撑**换题 / 换序 / 改分 / 相似题替换**的关键：成卷后必须保留一份**可寻址**的题目清单。
> **仅存活于当前会话，不落盘试题内容（合规）。**

```jsonc
{
  "paper_id": "zujuan-20261008-xxxx",
  "meta": {
    "stage": "初中", "subject": "数学", "subjectCode": 20,
    "title": "九年级（上）数学期中测试卷",
    "totalScore": 120, "examMinutes": 120,
    "difficultyRatio": "易:中:难≈3:5:2",
    "scenario": "a"                       // a–f，见 SKILL.md S1
  },
  "blueprint": {
    "kind": "per_question | summary | inferred",
    "rows": [
      { "no": 1, "module": "一元二次方程", "point": "一元二次方程的定义",
        "ct": 1, "dg": 11, "level": "了解", "score": 2 }
    ]
  },
  "questions": [
    {
      "no": 1,                              // 寻址键（全局题号）
      "ref": "s01",                         // 会话内**短引用**；不写题库内部 ID(SID)
      "ct": 1, "dg": 11, "score": 2,
      "stem_html": "…", "options": ["…", "…"],
      "images": ["<题库图片地址>/…"],
      "answer": "B", "analysis": "…"
    }
  ],
  "ops_log": [
    { "op": "replace", "no": 6, "reason": "用户要求换应用题", "ts": "…" }
  ]
}
```

## 使用约定

- **寻址键**：`no`（全局题号）→ 定位题目、换题、换序、改分。
- **一致性校验**：`sum(score)` 必须等于 `meta.totalScore`；题型结构与蓝图的认知层次/难度分布需可核对。
- **元数据不外显**：本状态仅**会话内**存在；其中只留**会话内短引用**（`ref`）与**归一后的五档难度**。题库接口的**元数据字段值**（`SID` / `Label` / `SourceReports` / `Degree` 原值等）**一律不写入本状态、不回流到对外输出**。
- **生命周期**：会话结束即释放；不缓存试题内容（合规）。
- **多学科**：一次请求含多个学段学科 → 拆成 N 个独立 `paper_id`，**逐学科串行**执行（避免并发限流），各自独立成套。

## 再编辑指令 → 状态操作映射

| 用户指令 | 操作 |
|---|---|
| 「第 6 题换个题」 | 按 `no=6` 定位 → 用同 `point/ct/dg` 重拉 → 替换 `questions[6]`，记 `ops_log` |
| 「把第 25 题改 10 分」 | 改 `score` → 重算总分 → 校验 = totalScore |
| 「解答题放到选择题前面」 | 重排 `questions` 顺序 → **重编 `no`** |
| 「给我几道第 6 题的相似题」 | 走「题找题」降级（标准搜题），返回候选供选 → 替换 |
| 「只要期中题重换第 10 题」 | 重拉时加 `so=7`（期中） |
