# 场景 g：题找题 · 相似题巩固（独立规范）

> 本规范与「标准组卷」并列，是**另一条产物链路**：产物必须**包含用户给的那道原题**。
> 实测日期：2026-10-08。

---

## 1. 触发判定（唯一口径：4 条全中才走本规范）

1. 用户**明确给出**了一道或几道试题的**原题文本或图片**（截图 / 拍照 / 粘贴题干）；
2. **没有**明确要求"按知识点组卷 / 按章节出题 / 按双向细目表组卷"；
3. 意图词属下列之一：**巩固 / 练习 / 练一练 / 专项 / 错题 / 查漏补缺 / 针对这几道再来几道 / 给孩子练**；
4. 用户**没有**要求"讲解这道题"（那是讲题链路，不是组卷）。

### 分水岭（一句话判别）
> **产物里是否必须出现"用户给的那道原题"？**
> - 必须出现（原题是锚点，相似题是附属）→ **走本规范（场景 g）**
> - 不必出现（知识点才是锚点，用户原题只是提问素材）→ **走标准组卷 S2–S7**

### 正例 / 反例
| 用户输入 | 走哪条 |
|---|---|
| 给 1 张题图 + "我想让孩子巩固这几道试题" | ✅ 场景 g |
| 给 3 道错题文本 + "这几道总错，想专门练练" | ✅ 场景 g |
| 给 2 张卷面照片 + "相似题各来两道" | ✅ 场景 g |
| "围绕复式折线统计图出 5 道题" | ❌ 标准组卷（无原题输入） |
| "按这份双向细目表组一份九年级数学期中卷" | ❌ 标准组卷 |
| 给原题 + "再围绕这个知识点补充几道难度递进的" | ❌ 标准组卷（用户明确指向知识点/难度体系） |
| 给原题 + "讲讲这道题" | ❌ 讲题链路 |

> 界限只在**锚点**上，不在"用户是否给了题"上。给了题但同时指了知识点体系，仍走标准组卷。

## 2. 流程（S1g → S5g → S6g → S7g）

### S1g 拆题（识别）
- **图片** → 逐题识别为文本，**保留结构化信息**：数据表格（转 `<table class="tbl">`）、图形描述、空位（`（　　）`）、小问编号。
- **文本** → 按题号 / 分值 / 段落切分。
- 产出：`[{原题文本, 参考来源(若有，仅内部比对用、不对外呈现), 猜测学科}]`
- 一道题 = 一组的锚点；N 道题 = N 组。

### S2g 定位原题（全学科搜题）
- 用识别出的**题眼特征词**调 `mcp__<SERVER>__tkSearchQuestion`，**不传 `subjectCode`**（= 全学科），`ps=10`。
- 取返回**第 1 条**（系统默认最接近该原题者），记下 `SID` / `Subject` / `Label` / `Degree` / `Points`。
- **命中判定**（与用户原题逐项比对：情境主体、数据、小问结构）：
  - 一致 → 采纳**题库版**作为试卷中的"原题"（数据更规范、且能取到解析）；
  - 不一致 / 0 命中 → 以**用户原文**为准呈现原题，并标注"题库未收录原题"，相似题改按考点召回。
- ⚠️ `mcp__<SERVER>__tkSearchQuestion` 的 keyword 不宜含空格与特殊符号（`∠ = °` 等），否则易 400；用 2–6 字的判别性词。

### S3g 取相似题

**首选路径（已于 2026-10-09 恢复可用）**：`mcp__<SERVER>__tkQuestionSame(SID, subjectCode, num)`（num ≤ 5）
- 调用前须先经 S2g 拿到**合法 SID**（`mcp__<SERVER>__tkSearchQuestion` 返回的 SID 可直接用）。
- 返回结构与 `mcp__<SERVER>__tkSearchQuestion` 一致：`{"data":[{SID, Subject, Cate, CateName, Label, Content, Degree, …}], "code":200}`。
- 实测（2026-10-09）：小学数学 num=2 / num=5、初中物理 num=2 —— 均 `code:200`，返回结构相同、题目高度同型（同题型 + 同考查结构 + Degree 邻近）✅
- `num` 传 5 就返回 5 条；返回顺序即系统相似度排序，**直接取前 N 条**即可，无需二次排序。

**主备切换规则（重要 · 先降级、降级后仍败才中止）**：
1. 首次调用若返回 `"系统繁忙，请稍后再试。"`（纯字符串、无 `code`）→ **退避重试 1 次**；
2. **仍失败 → 不走默认 fail-fast，而是先执行本链路的文档化等价降级**（下方「备选路径」关键词召回）；切换时**必须在输出显式标注「相似题接口连续失败，已降级为关键词召回」**，**不得静默切换**；
3. **降级路径（`mcp__<SERVER>__tkSearchQuestion`）自身也连续 2 次失败**（服务级）→ **此时才按 `fault-tolerance.md §6` 中止任务并返回结构化错误**；
4. 计数分开：`mcp__<SERVER>__tkQuestionSame` 与 `mcp__<SERVER>__tkSearchQuestion` 的失败计数**各自独立**，切到降级后**从 0 重新计数**；每次组卷最多探测 2 次，避免反复无效调用。

> 历史记录：2026-10-08 该接口全天不可用（跨学科 17+ 次全返回"系统繁忙"，同期其他 tk* 均 `code:200`）；2026-10-09 复测恢复正常。属**服务端偶发故障**，故主备两条路径都必须保留。

**备选路径（降级，产物等价）**：
1. 取原题考点：`mcp__<SERVER>__tkQuestionAnalysis(SID, subjectCode)` → `Points`（考点）+ `Topics`（主题）；
2. 用**题眼关键词**走 `mcp__<SERVER>__tkSearchQuestion(keyword, subjectCode, ps=10)`（优先同科；必要时不传 subjectCode 跨科）；
3. **过滤**：剔除原题自身（同 SID）、剔除题型明显不符者（原题是解答题却混入判断题/选择题）；
4. **相似度排序**（优先级从高到低）：
   ① 同题型 → ② 同考查结构（小问数量与落点一致）→ ③ 考点重合数多 → ④ `|Degree − 原题 Degree|` 最小；
5. 取前 **2** 道；不足 2 道 → 用 `mcp__<SERVER>__tkSearchSubjectQuestion(point=[原题 Points], subjectCode)` 补齐；仍不足 → 去掉修饰词放宽关键词再搜；最终不足则**如实报告**"该知识点下可召回相似题仅 N 道"。

**数量规则**：用户未指定 → 每道原题默认 **2 道**相似题；用户指定 → 按其数量（首选路径直接传 `num`；降级路径按数从备选召回中取）。

### S4g 取解析
对**原题 + 每道相似题**逐题调 `mcp__<SERVER>__tkQuestionAnalysis(SID, subjectCode)`，取 `Points / Analyse / Method / Answers / DisplayAnswer`。

### S5g 编排（分组）
- 分组：**一组 = 一道用户原题**（含其识别结果）。
- 组内顺序固定：**原题 → 相似练习 1 → 相似练习 2 ……**
- 组号连续：`一、第 1 组` / `二、第 2 组` ……
- **不做全程题号重排**（组内用「原题 / 相似练习 N」角色标签定位，不用数字题号）。

### S6g / S7g 产物（与标准组卷的差异）
| | 标准组卷 | **场景 g（本规范）** |
|---|---|---|
| 试卷结构 | 题型分节（选择/填空/解答） | **分组**（每组 = 原题 + 相似练习） |
| 双向细目表 | 产出 | **不产出** |
| 产物份数 | 三份独立文件（试卷 docx + 解析 docx + 细目表 html） | **两份独立文件：试卷 docx（不含解析）+ 解析 docx** |
| 解析位置 | 独立文件 | **独立文件（不再与试卷合卷）** |
| 锚点 | 知识点 | 用户原题 |

> ⚠️ **强制：试卷与解析必须是两个独立文件**（用户硬性要求）。渲染器用
> `--part paper` / `--part analysis` 分别产出两个 HTML，再各自转 docx。
> **禁止**再把二者合并成单份「合卷」交付（`--part both` 仅为兼容旧用法保留）。

- 渲染（第一份 · 试卷）：`python3 scripts/render_similar.py <groups.json> --part paper -o <paper.html>`
- 渲染（第二份 · 解析）：`python3 scripts/render_similar.py <groups.json> --part analysis -o <analysis.html>`
- 导出：`bash scripts/to_docx.sh <paper.html> <试卷.docx>`；`bash scripts/to_docx.sh <analysis.html> <解析.docx>`
  （页边距、图内嵌、悬挂缩进、解析区分页等硬约束同标准；两份各自转档）

## 3. 输出结构（硬性）

**试卷区（第一份 docx，不含解析）**
```
{卷名}
{说明行：共 N 组 | 每组 = 1 道原题 + M 道相似练习}

一、第 1 组
  考点：…（可选，来自原题 Points/Topics）
  【原题】（10分）{题干 + 表格 + 题干图 + 小题}
  【相似练习 1】（10分）{题干 + …}
  【相似练习 2】（10分）{题干 + …}

二、第 2 组
  …
```

**解析区（第二份 docx，独立成篇）**
```
{卷名}
参考答案与试题解析

一、第 1 组
  【原题】{重列题干}
  【考点】…
  【分析】…
  【解答】解：…
  {答案图}
  故答案为：…
  【相似练习 1】{重列题干 + 考点/分析/解答}
  【相似练习 2】…
  …
```

> 解析独立成篇后**无需卷内分页**；`fix_page_break.py` 已能识别「锚段在文首」并自动跳过，不会在解析文档开头多出空白页。

排版一律遵循 `layout-standard.md`（v1.2）：正文 10.5pt / 行距 1.5 / 小问分行 / 题图 `https://` + `no-referrer` + `lazy` / 选项无边框表格绝不折行 / 转换时页边距显式传参。

## 5. 已实测案例（2026-10-08 初版 / 2026-10-09 接口版）

- **输入**：1 张小学数学题截图 —— 阳光小学五（2）班"环境保护周"收集废旧电池 / 废弃塑料瓶，复式折线统计图（制图 + 读取最多 + 比较最大差值）。
- **S1g**：识别为 1 道解答题（含 2 行 × 8 列数据表 + 1 张空白统计图 + 3 个小问）。
- **S2g**：`mcp__<SERVER>__tkSearchQuestion(keyword="废旧电池")`（不传 subjectCode）→ **第 1 条正是该题**（学科码/题源标注/原始难度系数已按「不外显」口径脱敏，此处不再列具体值）✅

### 路径 A（2026-10-09，走 `mcp__<SERVER>__tkQuestionSame` 首选路径）✅
- `mcp__<SERVER>__tkQuestionSame(SID, 10, num=2)` → `code:200`，返回 2 道同型题（题源标注与难度系数略）：
  - 某网店下半年毛衣/短袖销量（图例补充 + 增长最快月 + 备货建议），难度与原题相邻；
  - 家电超市 9～12 月彩电/空调销量（补图 + 差距最大月 + 上升最快区间），难度与原题相邻；
- 两题与原题**同题型、同考查结构（补图 + 读图比较 + 开放建议）、难度相邻**，质量优于关键词召回 ✅
- 产物：`小学五年级数学_复式折线统计图_题找题巩固练习_相似题接口版_含答案解析.docx`
  - 1 组 / 3 题；9 张图内嵌、2 张数据表；页边距 2.5/2.0cm；行距 `line=360`（1.5 倍）；悬挂缩进 6 段；`warnings: []`

### 路径 B（2026-10-08，降级路径，接口故障期间的产物）
- **S3g**：`mcp__<SERVER>__tkQuestionSame` ×5 → 全部"系统繁忙" ❌ → 降级：
  - 考点 `统计图表的填补 / 从统计图表中获取信息 / 复式折线统计图`，主题 `应用题 / 应用意识`；
  - 关键词 `复式折线统计图` → 10 条结果，剔除原题与判断题/选择题后，取同型解答题 2 道：**大竹县"五一"最高最低气温**、**品牌电器上半年销量**（难度与原题相邻）✅
- 产物：`小学五年级数学_复式折线统计图_题找题巩固练习_含答案解析.docx`

> 两条路径均为 1 组 / 3 题（原题 + 相似练习 1 + 相似练习 2）；**路径 A 的相似题与考查结构贴合度更高**（接口返回的就是系统判定的相似题），故接口可用时优先走 A。

## 6. 本次新增的坑（已修复）

- `split_subq()` 原先无条件把 `（N）` 换成换行 → 会把题干正文里的**校园称谓**"阳光小学五**（2）**班"误拆成新行。
- **修复口径**：仅在下列位置才认作小问边界——① 段首；② 前一字符是 `。；！？：`；③ 前一字符是 HTML 标签结束符 `>`（如 `</table>（1）…`）。
- 已回填 `scripts/render_paper.py`（`render_similar.py` 复用同一函数，自动受益），并对已交付的两份卷子做了回归验证。

## 7. 与标准组卷的关系（给编排层的一句话）

> **标准组卷**：以「知识点」为轴，产物不含用户原题。
> **场景 g**：以「用户原题」为轴，产物必须包含用户原题 —— 走 `similar-question.md` 这条独立链路。
