# 国家中小学智慧教育平台教材数据核实指南

平台入口：https://basic.smartedu.cn（国家中小学智慧教育教育平台），教材资源位于"课程教学"板块下的"教材"频道（/tchMaterial）。

## 级联结构

教材数据按以下层级组织，与技能的级联选择一一对应：

```
学段（小学 / 初中 / 高中）
└── 年级（一年级 ~ 高三）
    └── 学科（语文、数学、英语、物理、化学、生物学、道德与法治、历史、地理、科学、音乐、美术、体育与健康、信息科技、劳动 …）
        └── 教材版本（人教版、统编版/部编版、北师大版、苏教版、沪科版、外研版、译林版、教科版、粤教版 …）
            └── 分册（一年级上册 / 下册；高中为 必修第一册、选择性必修第二册 …）
                └── 目录（单元 → 课文/章节/课时）
```

## 常见版本简称对照

| 用户说法 | 平台/正式名称 |
|---|---|
| 部编版、统编版 | 统编（教育部组织编写），目前语文、道德与法治、历史为统编教材 |
| 人教版 | 人民教育出版社（注意区分"人教A版/人教B版"高中数学） |
| 北师大版 | 北京师范大学出版社 |
| 苏教版 | 江苏凤凰教育出版社 |

## 核实步骤

1. **优先用平台检索**：对"版本 + 分册 + 课文名"组合使用 WebSearch（可加 site:basic.smartedu.cn 或直接搜教材目录关键词），或用 WebFetch 打开平台教材页获取目录信息。
2. **平台无法访问或页面为动态渲染时**：改用 WebSearch 搜索"《教材版本 年级 学科 上册》目录"等关键词，与权威来源（出版社官网、地方教育资源平台）交叉验证。
3. **仍无法确认时**：依靠模型内置知识给出最可能的目录，向用户标注"以下目录基于已有知识整理，请核对是否与您手头教材一致"，列出该单元前后相邻课文帮助用户确认位置。**该提示只出现在对话正文，不得写入 Word 文档**（文档内零编写说明，见 SKILL.md 铁律 R1）。

## 注意事项

- 同名课文可能出现在多个版本/学段（如《背影》在人教版八年级上册，也可能出现在其他选本），必须让用户确认具体版本。
- 教材近年有修订（如 2024 年秋季起统编语文、历史等新修订教材陆续使用），同一课文的单元位置可能变化；核实到目录后以用户手头教材为准。
- 高中教材区分"必修"与"选择性必修"，分册名称与初中"上/下册"不同。
- 不得虚构平台接口返回值；凡网络核实失败，必须降级为"知识推断 + 用户确认"。**核实结论与假设只写在对话正文**，文档内只体现最终确定的教材信息（写在"基本信息"栏），不写任何假设说明或核实过程。
