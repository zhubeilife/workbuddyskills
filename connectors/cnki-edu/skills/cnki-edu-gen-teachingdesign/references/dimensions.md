# 教学设计维度写作规范

默认七个一级维度：**教材分析、学情分析、教学目标、教学重难点、教学过程、板书设计、教学反思**。下面给出各维度的写作定位、内容要求与篇幅基准（篇幅以中文正文字数计，用户有明确篇幅要求时以用户为准）。

## 写作红线（先读这一节）

以下内容**一律不得写入教案正文**（对应 SKILL.md 铁律 R1/R2/R3），违者视为成稿不合格：

1. **不写编写说明类文字**：如"本维度依据…""以下内容参考…""此处可结合…""（待补充）""说明：…""注：…"——直接写教案内容本身，不做自我解释。
   - **判定口径（防误删）**：看"这句话是否在解释文档自身"。**学科正文中的同形词必须保留**——`说明文`/`说明方法`/`说明顺序`/`说明性文字`、`示例`/`示例题`、`温馨提示`/`提示语`、`注释`/`注解` 等属教学内容，**禁止**按关键词字面删除。
2. **不写来源与工具**：正文中不标注文献出处、检索工具、生成方式、模型名称。
3. **不写占位与承诺**：不留 `{}`、`XXX`、TBD、待填、待定；不写"具体情况视学情而定"之类的免责式空话。
4. **不写署名与说明块**：文首文末不加作者、日期、版本号、编写说明、附注、修订记录。
5. **不写文档外板块**：不含"参考文献""参考资料""知网推荐"等任何独立于教学设计的板块。
6. **不凑字数**：反复述句、空泛口号、无信息量的排比句一律删除；宁可写短，不写虚。

## 一、教材分析（约 200–400 字）
- **课标要求**：说明本课对应的课程标准条目（注明学段/模块）。
- **教材地位**：本课在单元中的地位、与前后课的逻辑联系、知识类型（事实/概念/原理/方法/价值）。
- **知识脉络**：本课知识点在上位知识体系中的位置与前后衔接。
- 常见误区：只复述课文提要，不谈"地位与联系"。

## 二、学情分析（约 200–400 字）
- **已有基础**：本课前的学习起点。
- **认知特点**：该学段思维水平（如"具体形象→抽象逻辑"）。
- **学习困难**：可能的困难与前概念冲突。
- 避免套话；困难点要与"教学难点"呼应。

## 三、教学目标（3–5 条，每条 1–2 句）
- **核心素养目标**：对应 2022 版义教课标 / 2017 版修订高中课标的学科核心素养。
- **目标表述**：行为主体（学生）+ 行为动词（可观测）+ 条件 + 程度。
- 避免把"三维目标"作为标题框架写出，可融入素养表述；目标不交叉、不重复。

## 四、教学重难点
- **教学重点**：来自教材与课标（核心知识/关键能力），1–2 条，说明依据。
- **教学难点**：来自学情（抽象度高、易混淆处），1–2 条，简述为何难及突破路径。
- 重点≠难点，可重合但分别表述。

## 五、教学过程（主体，篇幅占比最大）
按环节展开，默认结构：**导入新课 → 探究新知 → 巩固练习 → 课堂小结 → 布置作业**。每个环节必须含三要素：
- **教师活动**：关键提问原话、讲解要点、组织方式。
- **学生活动**：预设行为（独立思考、讨论、实验、汇报），重要提问附预设回答。
- **设计意图**：对应哪条目标、如何突破重难点。
用户指定课时数时按课时拆分，每课时独立成节，均含完整环节链；未指定默认 1 课时。

## 六、板书设计
- **主板书**：文本/结构图，体现知识主线，与小结一致。
- **副板书**：易错点、生成性内容。避免罗列碎词。

## 七、教学反思（约 150–300 字）
- **目标达成**：可能达成的目标、潜在风险（时间/组织/差异）。
- **改进设想**：用"若…可…"预判语气，不写空泛总结。

## 可扩展维度（用户可加选，作为补充或新增一级）

| 维度 | 内容要点 |
|---|---|
| 教学准备 | 教具、实验器材、多媒体、学具清单 |
| 作业设计 | 分层作业（基础/提升/拓展），设计意图与时长；呼应"双减" |
| 课后拓展 | 实践活动、阅读书目、跨学科任务 |
| 德育/思政渗透 | 思想价值点及融入方式 |
| 信息技术融合 | 数字化工具及具体用途 |
| 跨学科主题 | 跨的学科、真实情境任务、评价方式 |
| 评价设计 | 形成性评价任务、量规 |
| 单元整体说明 | 大概念、任务群位置 |

## 自定义维度

用户提出清单外维度时，按名称与描述组织内容，遵循同一文档体例，插入位置按逻辑顺序（一般放在教学过程之前或之后）。
