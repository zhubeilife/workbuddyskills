# 知网推荐（紧接 PPT 卡片下方 · 仅三项 · 零元数据 · 文献名带链接一次点击直达知网研学研读页面 · 不进入 PPT）

本文件定义"知网推荐"的检索策略、**禁止暴露的元数据清单**、**跳转链接取值规则（直接取用接口返回的文献链接 · 一次点击直达 · 地址只作跳转目标、不以明文外显）**、**链接写法（保点击跳转）**与输出格式。

四条硬约束：

1. **位置**：知网推荐**不进入 PPT 文件**，而是**紧接 PPT 卡片下方直接展示**（PPT 总结文字之后，中间不插入任何其它区块），不折叠、不分页、不另起独立区域。
2. **展示内容**：每条**只展示三项文字**——**文献名 / 作者 / 来源**。
3. **一次点击直达知网研学研读页面**：**仅「文献名」可点击**，点击后**一次即直达该文献在知网研学平台的研读页面**（在线阅读全文）——跳转目标**直接取用检索接口返回的 `url` 字段**，**原样使用、不自行拼接**（规则见第三节）。
4. **零元数据 + 文献名带链接 + 未登录可登后查看**：**严禁以任何方式展示、复述、暗示来自知网或检索接口的任何元数据**；链接作为「**文献名**」的**跳转目标**存在，**不得以明文形式进入可见文案**；**《文献名》必须带跳转链接，点击一次即直达该篇在知网研学平台的研读页面**（**不要求、也不附带悬停提示**）；**若用户未登录，点击后由研学平台弹出登录框，登录完成后自动校验阅读权限——有权限即在线阅读全文**，**链接保留、不删改**。作者、来源为**纯文本、不可点击**。

篇数**不超过 6 篇**。

## 一、检索策略（唯一入口：edu MCP，明确写在 skill 中）

- **检索接口（写在 skill 中）**：知网推荐**必须调用名称为 `edu` 的 MCP 提供的文献检索接口**：
  - 工具全名：`mcp__<SERVER>__searchVectorBJ`
  - 调用方式：以 PPT **主题 + 类型**为检索词传入（如"光合作用 初中生物 教学"）。
  - 若运行时发现该工具实际名称与 `mcp__<SERVER>__searchVectorBJ` 不一致，则以 `edu` MCP 当前暴露的文献检索接口为准（功能等价即可，不要改用其它非 edu MCP 来源）。
- **选取标准**：与主题**高度相关、近 10 年优先、来源可信**的文献，最多 **6 篇**。
- **补检**：若单次检索结果不足，可换同义检索词补检；仍不足则少列，不虚构。
- **领域偏好**：教研/教学类 PPT 优先《中小学XX教学》《XX教育》等学科教学期刊；工作汇报类优先行业白皮书/研究报告。
- **取用字段（内部）**：题录中取**文献名**（`篇名` / `Title`）、**作者**（`Author`）、**来源**（`Source` / `JournalName`）三项用于展示；**文献名同时挂上第三节"接口返回的研读页链接"**。
- **实际返回字段（2026-10-13 实调复核）**：`mcp__<SERVER>__searchVectorBJ` 实际返回——`相关度`、`resource`、`小标题`、**`篇名`/`Title`**、`正文`、`Summary`、`Author`、`JournalName`/`Source`、`JournalName_EN`、`AuthorAffiliation`、`ResourceType`、`Year`、`PubDate`、`Keyword`、`Fund`、`DownloadedTimes`、`CitedTimes`、**`url`**（段落接口另有 `章节序号`、`当前小标题`）。
  - ✅ **接口直接返回 `url` 字段**——该字段即该篇在**知网研学平台的研读页地址**（形如 `https://ix.cnki.net/read/article/readonline?dbcode=…&tablename=…&filename=…&fileSourceType=1`）。**文献名的跳转目标直接取用它，原样使用。**
  - ⚠️ **不再自行构造链接**：旧版本"以完整篇名拼接知网官网检索页地址（`kns.cnki.net/kns8s/defaultresult/index?kw=…`）"的做法**已整体废弃**。
  - ⚠️ **`篇名` 是文献标题，不是知网的文件标识**——**严禁把篇名当 `filename` 去拼任何地址**（旧版本曾如此，实测落到错误页，已废弃）。

## 二、禁止暴露的元数据清单（强约束 · 违反即不合格）

接口返回的原始字段**只用于内部取用**（内部据其取「文献名、作者、来源」并取用 `url` 作跳转链接），**一律不得外显**：

| 类别 | 禁止暴露的内容 |
|---|---|
| 时间/出处元数据 | **发表时间**、年卷期、页码、出版/收录日期 |
| 标识类元数据 | **doi**、**内部 id**、`filePath`、记录号、分类号、ISSN/CN 号 |
| 来源链路元数据 | 数据库名、来源链路、检索语句、查询语句、命中数 |
| 链接元数据 | **可见文案中的 URL / 域名明文**（如 `ix.cnki.net`、`kns.cnki.net`、`www.cnki.net`、`oversea.cnki.net`、`x.cnki.net`、`doi.org` 等写成文字的地址） |
| 其它元数据 | 被引量、下载量、关键词、摘要全文、基金信息、作者单位 |

> 唯一例外：跳转链接作为「文献名」的**跳转目标**存在（Markdown 链接 / 内联锚点的地址），**渲染后的可见文案中必须完全不可见**。

### 2.1 链接写法（保点击跳转 · 不附带悬停提示）

**目标只有一个：保证"点击《文献名》一次即直达该篇在知网研学平台的研读页面"**；**不要求、也不附加悬停提示**——`title` / 链接标题在对话渲染环境中不呈现，写了也无效，属冗余信息。

- **默认首选写法 —— Markdown 链接（兼容性最好）**：

  ```
  [《文献名》](<接口返回的研读页链接>)，作者，来源
  ```

- **次选写法 —— 内联 HTML 锚点（仅在已确认"渲染环境会执行内联 HTML"时使用）**：

  ```html
  <a href="<接口返回的研读页链接>" target="_blank" rel="noopener noreferrer">《文献名》</a>，作者，来源
  ```

  > ⚠️ **实测（2026-10-13）**：**对话 / 卡片类渲染环境会剥离内联 HTML 锚点**——HTML 写法落地后会被剥成**纯文本、点不动**。因此**默认不要用内联 HTML**；一旦发现落地后"点不动"，**立即改回首选写法（Markdown 链接）**。

- **兜底写法 —— 无链接纯文本**（**仅当链接完全无法渲染时**）：只写《文献名》，不挂任何链接。

> 判定顺序：**默认用 Markdown 链接**；**只有在确知环境会执行内联 HTML 时才改用内联锚点**；只有链接完全无法渲染才用纯文本兜底。三种写法的共同底线：锚文本**只含《文献名》**，作者与来源为**纯文本、不可点击**，**一律不写 `title` / 链接标题**，可见文案中不出现任何域名或地址明文。

## 三、跳转链接取值规则（直接取用接口返回的文献链接 · 一次点击直达 · 地址只作跳转目标、不以明文外显）

**目标（硬性）**：每条「文献名」挂一个**跳转链接**，用户**点击一次即落在该篇在知网研学平台的研读页面**（在线阅读全文）。**链接 = 直接取用检索接口返回的 `url` 字段**，**原样使用、不做任何拼接或解析**。

**取值规则（唯一）**：

- **直接取用 `url` 字段**：`mcp__<SERVER>__searchVectorBJ` 返回的每条题录自带 **`url`** 字段，该字段即该篇在**知网研学平台的研读页地址**，形如 `https://ix.cnki.net/read/article/readonline?dbcode=…&tablename=…&filename=…&fileSourceType=1`。
- **原样使用**：**不改写、不精简参数、不替换字段值、不自行拼接、不解析**；直接把该值作为《文献名》的跳转目标（内联锚点的 `href` / Markdown 链接的地址）。
- ⚠️ **已废弃的旧做法**：旧版本"以完整篇名拼接知网官网检索页地址（`kns.cnki.net/kns8s/defaultresult/index?kw=<URL编码后的篇名>`）"**已整体废弃**，不再采用。
- ⚠️ **跳转目标固定为「研学研读页面」**：**不得**改用知网官网检索页（`kns.cnki.net/kns8s/...`）、知网节 / 文献详情页（`kcms/detail/detail.aspx?...`、`kcms2/article/abstract?v=...`）等其它地址，**也不得自行拼接任何地址**。
- ⚠️ **不得用非浏览器请求去抓该地址**：本流程**只取接口返回值**，**不发起任何额外网络请求**。
- ✅ 取到的链接**只作「文献名」的跳转目标**，**任何情况下都不得以明文出现在可见文案里**（条目文本、列表、卡片、幻灯片皆然）。

### 3.1 未登录 / 无阅读权益：点击后登录即可（硬约束）

点击后进入知网研学研读页。

- **已登录且有阅读权益**（机构授权、个人／团队会员、文献流量包等）→ **直接在线阅读全文**。
- **未登录** → 由研学平台**弹出登录框**（账号登录、扫码、微信/QQ 等），**登录完成后平台自动校验该篇阅读权限**——有权限即展示全文，无权限则给出平台自身的获取指引。
- **这是预期行为，不是链接错误**：**链接照挂**——**不预先拦截、不改写、不删除、不降级为纯文本**（仅"渲染环境不支持链接"时的纯文本兜底除外）。
- **可见文案**：只允许一句**中立**提示——固定为「**点击文献名可在线阅读全文；未登录时登录知网账号后即可查看**」，**严禁**出现任何登录网址、接口名、服务名、域名、字段名。
- **默认附提示**：知网推荐列表**下方统一附上该句**；**不依赖**内部权益探测即可直接附上。

### 3.2 取值过程的失败与降级（保证不中断、不暴露）

- 若某篇**未返回 `url`**，该篇**不挂链接、退为无链接纯文本**（此时无跳转目标），**流程继续**，不得中断知网推荐的产出；**不得臆造地址**。
- 全程属内部流程：**不得**在用户可见处出现"取值 / 拼接 / 解析 / 抓取 / 检索页 / 验证码"等字样；对用户只呈现最终列表。
- 取到的原地址**不以明文展示**——只作为「文献名」的跳转目标存在。

- **写法 C（兜底 · 无链接纯文本）**——**仅当连链接都无法渲染时**才用：`《文献名》，作者，来源`（此时无跳转目标）。

- **不写 `title` / 链接标题**：**需求口径 = 保点击跳转、放弃悬停提示**；`title` 在对话渲染环境中不呈现，一律不写。

- ❌ 禁止写法：

  - 把内联 HTML 交给会**原样转义展示**的渲染环境（用户会看到含地址的 HTML 源码）；
  - 以表格、脚注、代码块、括号注释等任何形式夹带元数据。

## 五、合规与保密要求（关键）

- **不编造**：作者、来源须可核验；检索不到则少列，不虚构。**跳转链接同理**——**只用接口返回的 `url` 字段**，**不臆造、不伪造、不自行拼接**。

- **不进入 PPT**：知网推荐仅作 PPT 卡片下方的拓展阅读，绝不写入幻灯片。
- 若确无直接相关文献，可列"相近主题"文献并说明偏差，但仍只展示三项文案。
