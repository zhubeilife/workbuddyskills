# Organization 术语与概念辨析

本文件是 Organization Domain 的术语与概念辨析唯一维护入口。它把用户表达映射到正式组织业务概念，并解释名称相似但不能互相替代的概念；不维护命令参数或组织对象的完整属性。

## 使用规则

- 只有定义、身份、适用范围和结果含义相同的叫法，才记录为同义表达。
- 输出优先使用正式名称；用户使用简称时，首次回答可注明正式名称。
- “当前”“历史”“生效日期”等是关系或查询时点限定，不固化到部门、职位或职级等对象名称中。
- 同一个词在部门层级和员工关系中含义不同，属于歧义表达，不是同义词。

## 已确认的同义表达

| 正式名称 | 同义表达 | 对应主题/对象 | 定义与识别条件 | 不等于 |
| --- | --- | --- | --- | --- |
| 部门 | 组织部门 | 组织结构 / 部门 | 企业组织结构中的业务单元，以 `departmentId` 定位 | 组织树展示节点、员工汇报关系 |
| 组织树 | 部门树 | 组织结构 / 组织节点 | 展示部门节点及其父子层级的树形结果 | 员工汇报树 |
| 职位 | 岗位 | 职位与职务 / 职位 | 组织范围内可被员工任职的具体岗位实例，以 `positionId` 定位 | 职务、职务类型 |
| 职务 | 工作职务 | 职位与职务 / 职务 | 对工作性质或专业角色的定义，以 `jobTitleId` 定位 | 职位实例、职务类型 |
| 汇报关系 | 汇报线 | 员工关系 / 员工汇报关系 | 明确员工上下级关系上下文时，指指定汇报类型下的员工关系事实 | 部门父子层级 |
| 工作地点 | 办公地点 | 地点与成本中心 / 工作地点 | 企业可引用的办公地点定义，以 `companySiteId` 定位 | 考勤打卡地点、行政区域 |

## 相近但不等价的概念

| 概念 A | 概念 B | 关键差异 | 禁止替代 |
| --- | --- | --- | --- |
| 部门 | 组织节点 | 部门是业务组织单元；组织节点是组织树中的展示节点，可能使用不同 ID | 组织节点 `id/nodeId` 不能直接当作 `departmentId` |
| 职位 | 职务 | 职位是可被任职的岗位实例；职务是工作性质或专业角色定义 | 职务不能替代职位实例 |
| 组织树 | 员工汇报关系树 | 前者表达部门父子层级；后者表达指定类型下的员工关系 | 部门父子关系不能推出员工上级 |
| 单层职级 | 薪资等级/绩效等级 | 单层职级是 Organization 的职位引用定义；薪资和绩效等级属于其他业务语境 | 不能用职级结果解释薪资或绩效等级 |
| 部门编制记录 | 部门 | 编制记录属于方案周期上下文，有独立记录 ID；部门是组织结构对象 | `hcDepartmentId` 不能当作 `departmentId` |
| 计划编制 | 占编结果 | 计划编制是方案配置；占编结果是指定维度条件下的服务端计算结果 | 计划数不能替代占编数 |
| 工作地点 | 考勤打卡地点 | 工作地点是 Organization 可引用定义；打卡地点是 Attendance 事实 | 工作地点不能证明实际打卡地点 |

## 条件性表达与歧义表达

| 用户表达 | 可能指向 | 判断规则 |
| --- | --- | --- |
| 职级、级别 | 职级体系、序列、职层、职级分组或单层职级 | 只有明确 Organization 职级上下文时，才将“级别”作为职级的口语表达；不能映射到薪资或绩效等级 |
| 上级、下属 | 部门父子关系或员工汇报关系 | 有“部门/组织树”上下文时走组织结构；有员工和汇报类型时走汇报关系；否则先澄清 |
| 编制 | 编制方案/周期、部门编制记录、计划编制数、控编维度或占编结果 | 必须先确认要查询哪个对象或数量口径，不能把“编制”作为单一对象 |
| 组织 | 组织树、部门、组织节点或整个 Organization 模块 | 根据“有哪些部门”“组织节点”“组织架构”等上下文区分 |
| 岗位 | 职位或职务 | 在本 Domain 通常映射为职位；出现“职责/角色定义”时不能直接替代职务，需澄清 |

术语不能唯一映射时，只追问一个会改变对象、命令或结果口径的问题；不能根据字段名、名称相似或历史 code 猜测。
