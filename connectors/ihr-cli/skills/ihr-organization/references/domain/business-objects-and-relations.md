# Organization 业务对象与关系

本文件详细定义 Organization 中会改变对象识别、查询选择、关联和结果判断的业务对象、关键属性与关系。各对象的固定字段与关键字段解释随对象维护在组织结构、职位职务、职级、汇报关系、地点成本中心和编制管理 Reference 中；本文件不复制命令完整字段，参数必填性、默认值和返回路径仍以命令契约为准。

## 1. 组织结构对象

### 部门/组织节点

**定义**：部门是企业组织结构中的业务单元；组织节点是组织树中的返回节点。节点通常引用部门，但节点 `id/nodeId` 与 `departmentId` 不是同一个标识概念。

**身份与定位**：业务部门使用 `departmentId`；树节点使用当前树结果中的 `id/nodeId`。按名称查询时必须先得到唯一部门候选。

| 关键属性 | 业务含义 | 值/状态/时间解释 | 使用约束 |
| --- | --- | --- | --- |
| `parentDepartmentId` | 直接父部门 | 当前或指定生效日期下的结构关系 | 不能解释为员工直属上级 |
| `departmentStatus` | 部门状态 | 状态 code 只对当前组织结果成立 | 不与职位或员工状态互换 |
| `isVirtual` | 是否虚拟组织 | 决定是否纳入组织树范围 | 不表示部门是否停用 |
| `organizationChartNodeType/type` | 组织节点类型 | 解释树节点业务类别 | 不根据显示文本猜类型 |
| `principalId/principalName` | 部门负责人引用和名称 | 受负责人查看权限影响 | 负责人不等于员工汇报上级 |
| `establishDate/effectiveDate` | 设立与生效日期 | 两个日期回答不同问题 | 生效日期按命令参数过滤，不等于完整历史还原 |
| `capacity/totalCapacity` | 节点自身/含下级的容量摘要 | 以组织树当前返回口径为准 | 不等于编制模块计划数或占编数 |
| `onJobHeadCount/onJobTotalHeadCount` | 节点自身/含下级的在职人数摘要 | 查询时点和权限范围内结果 | 不代替 Staff 花名册去重统计 |

## 2. 职位与职务对象

### 职位

**定义**：职位是一个组织范围内可被员工任职的具体岗位实例。它可以引用部门、职务和单层职级，并包含岗位说明、容量和启停信息。

**身份与定位**：使用 `positionId`；名称和编码只用于筛选或消歧，不保证全公司唯一。

| 关键属性 | 业务含义 | 值/状态/时间解释 | 使用约束 |
| --- | --- | --- | --- |
| `positionName/positionCode` | 职位名称与编码 | 当前职位定义 | 名称相同不代表同一职位 |
| `departmentId` | 所属部门引用 | 职位记录有效时的组织归属 | 不证明某员工在该部门任职 |
| `jobTitleId` | 职务引用 | 返回非空时才建立关系 | 不用职务名称猜引用 |
| `positionGradeId` | 单层职级引用 | 返回非空时才建立关系 | 不代表薪资或绩效等级 |
| `positionState` | 职位启停状态 | `ENABLE/DISABLE/ALL` 用于查询范围 | `ALL` 不表示全部历史职位 |
| `effectiveDate` | 职位生效日期 | 职位定义的时间属性 | 不表示员工任职生效时间 |
| `capacity` | 职位容量/编制人数 | 按职位记录返回解释 | 不等于实际任职人数或部门占编 |
| `parentId` | 父级职位引用 | 仅在返回非空且契约支持时使用 | 不代替部门层级或汇报关系 |
| `appliedRange/appliedRangeMap` | 职位适用组织范围 | 可能包含行政或多维组织范围 | 不自动解释为职位所属部门 |

### 职务与职务类型

**定义**：职务描述工作性质或专业角色；职务类型对职务进行分类。职务不是某个部门中的职位实例。

**身份与定位**：职务使用 `jobTitleId`，职务类型使用 `jobCategoryId`；名称或编码相似不能替代 ID 关系。

| 对象 | 关键属性 | 业务含义 | 使用约束 |
| --- | --- | --- | --- |
| 职务 | `jobTitleName/jobTitleCode` | 职务名称与编码 | 不当作职位名称或职位 ID |
| 职务 | `jobCategoryId` | 所属职务类型引用 | 只有字段真实返回时建立关系 |
| 职务 | `minPositionGradeId/maxPositionGradeId` | 允许的职级范围引用 | 不是员工当前职级 |
| 职务 | `effectiveDate` | 职务定义生效日期 | 不表示职位或员工生效 |
| 职务类型 | 名称、编码 | 职务分类定义 | 不替代具体职务或职位 |

## 3. 职级体系对象

### 职级体系对象

**定义**：职级体系、职级序列、职层、职级分组和单层职级是五类独立定义。它们共同描述租户的职级架构，但不能仅凭名称推断固定父子层级。

**身份与定位**：分别使用命令返回的体系 ID、序列 ID、职层 ID、分组 ID 和 `positionGradeId`。当前部分返回为 `PARTIAL`，只有实际返回的字段才能用于关联。

| 对象 | 主要作用 | 关键属性 | 使用约束 |
| --- | --- | --- | --- |
| 职级体系 | 表示一套职级制度及其配置范围 | 体系 ID、名称、设置、树节点 | 不把空设置解释为没有体系 |
| 职级序列 | 表示体系中的业务序列 | 序列 ID、名称、排序 | 与职层、职级分组分别查询 |
| 职层 | 表示层级过滤或排序对象 | 职层 ID、名称、排序 | `page/size` carrier 不证明可分页 |
| 职级分组 | 对单层职级进行分组展示 | 分组 ID、名称、状态、嵌套职级 | 嵌套关系只按实际返回解释 |
| 单层职级 | 可被职位引用的具体职级定义 | `positionGradeId`、名称、分组、序列条件 | 不等于薪资等级或绩效等级 |

当前没有公开的职位职级切换操作。不能用未公开定义的存在作为可执行或新旧体系判定证据。

## 4. 员工关系对象

### 员工汇报关系

**定义**：员工汇报关系是在指定汇报类型下，一个员工与上级或下级员工之间的关系事实。它不是部门组织结构。

**身份与定位**：当前没有公开独立关系 ID；以唯一 `staffId`、当前租户有效 `reportToType`、查询时点和展示层级共同定位。

| 关键属性 | 业务含义 | 值/状态/时间解释 | 使用约束 |
| --- | --- | --- | --- |
| `reportToType` | 汇报关系类型 | 必须是当前租户 `Enum.DirectManagerType` 的有效协议值 | 不直接传显示名称或猜测历史 code |
| `showLevel` | 向下展开员工层级 | 默认/显式值以 Help 为准 | 不是部门树深度 |
| `showParentLevel` | 向上展开员工层级 | 默认/显式值以 Help 为准 | 不是部门 ancestors 数量 |
| `hasAuth` | 当前节点可见性 | 受当前用户数据权限影响 | `false` 不证明员工不存在 |
| `children` | 当前关系类型下的下级节点 | 递归 TREE，完整度 `PARTIAL` | 不自动继续扩大层级 |

## 5. 地点与成本归集对象

### 工作地点

**定义**：工作地点是企业可被部门等组织对象引用的办公地点定义，不是考勤打卡结果。

**身份与定位**：使用 `companySiteId`；按名称、地区和类型查询时，地区值使用已确认 code。

| 关键属性 | 业务含义 | 值/状态/时间解释 | 使用约束 |
| --- | --- | --- | --- |
| `siteName` | 地点名称 | 当前地点定义 | 同名不保证同一 ID |
| `country/province/city/district` | 地区层级 code | 按地区层级解释 | 不直接把自然语言名称当 code |
| `siteType` | 地点类型 | 当前租户协议值 | 不猜测未公开 label 到 code 映射 |

### 成本中心与分组

**定义**：成本中心是财务归集定义；系统另有成本中心分组列表。当前公开返回未完整声明二者的关联字段，因此不能只凭名称建立分组关系。二者都不是部门或编制方案。

**身份与定位**：成本中心使用 `costCenterId`；分组使用实际返回的分组标识。当前分组字段完整度为 `PARTIAL`。

| 关键属性 | 业务含义 | 值/状态/时间解释 | 使用约束 |
| --- | --- | --- | --- |
| `costName/costCode` | 成本中心名称与编码 | 当前业务定义 | 名称或编码不替代部门 ID |
| `isValid` | 成本中心有效状态 | 只解释成本中心本身 | 不推出引用它的部门/职位状态 |
| 分组标识与名称 | 成本中心分组 | 以实际返回为准 | 分组不是成本中心记录 |

## 6. 编制对象

### 编制方案与部门编制记录

**定义**：编制方案/周期规定计划事实的适用区间和管控方式；部门编制记录是在该上下文中对应一个组织部门的计划记录。

**身份与定位**：方案/年度/周期分别使用真实返回的 `hcYearId`、`hcYearPlanId` 或周期 ID；部门编制记录使用 `id/hcDepartmentId`。普通 `departmentId` 只能作为被引用部门，不能作为编制记录 ID。

| 关键属性 | 业务含义 | 值/状态/时间解释 | 使用约束 |
| --- | --- | --- | --- |
| `departmentId/departmentPathName` | 记录对应的组织部门 | 指定方案周期中的部门引用 | 不把它当编制记录 ID |
| `planName` | 编制方案名称 | 展示字段 | 名称不能替代方案 ID |
| `hcPlanPeriod/hcPlanPeriodId` | 编制周期及标识 | 计划事实的适用区间 | 不等于查询执行时间 |
| `totalHcCount/directHcCount` | 总计划编制/直属计划编制 | 指定周期下的计划数 | 两者不可直接相加 |
| `totalHcBudget/directHcBudget` | 总预算/直属预算 | 指定周期下的预算 | 不是已发薪资成本 |
| `publishStatus` | 编制记录发布状态 | 当前已确认值中 `0/1` 分别表示未发布/已发布 | 发布不等于审批完成或员工已占编 |
| `isIndependentCalculate` | 是否独立核算 | 决定与上级汇总关系 | 不据此改写组织树 |
| `isDimension` | 是否允许细化维度 | 决定能否查看/使用维度详情 | `true` 不代表已有维度数据 |
| `overHcType` 等超额字段 | 编制或预算与父子部门约束的结果 | 只按返回 code 解释 | 不推断具体超编原因以外的业务结论 |

### 控编维度与占编结果

**定义**：控编维度描述部门编制可按哪些字段和值细分；占编结果是在一个编制记录和一组维度条件下由服务端计算的数量。

**身份与定位**：维度以已确认 `hcDepartmentId` 下返回的列键/字段和值定位；占编结果以 `hcDepartmentId + controlDimensions + 查询时点` 定位，没有独立结果 ID。

| 关键属性 | 业务含义 | 值/状态/时间解释 | 使用约束 |
| --- | --- | --- | --- |
| `dataIndex/key/title` | 维度字段 code、稳定键和展示名 | 来自当前编制记录的维度定义 | 不根据标题猜 `fieldName` |
| `filter/filterConfig` | 是否可过滤及过滤配置 | 当前维度定义 | 开放对象只使用已确认字段 |
| `searchMode` | 条件组合方式 | 当前公开值 `AND/OR` | 不自动重排用户条件 |
| `operator` | 单个字段匹配方式 | 当前公开值 `IN/EQUALS` | 不构造未公开比较操作符 |
| `fieldName/fieldValue` | 参与计算的维度字段和值 | 必须来自维度定义或用户确认协议值 | 空值不能自行补默认业务含义 |
| `dimensionOccupyCount` | 维度占编数量 | 指定条件和查询时点的计算结果 | 空维度返回不能解释为部门总人数 |

## 7. 关系清单

| 来源对象 | 关系 | 目标对象 | 数量 | 成立条件/时点 | 事实来源 | 禁止推断 |
| --- | --- | --- | --- | --- | --- | --- |
| 部门 | 直属包含 | 子部门 | 1:N | 当前或指定生效日期 | 组织树、直属子部门结果 | 不推出员工汇报关系 |
| 部门 | 上级链包含 | 父部门 | N:1 链 | 当前查询结构 | 部门 ancestors 结果 | 不推出员工上级 |
| 职位 | 归属于 | 部门 | N:1 | 职位记录有效时 | 职位 `departmentId` | 不推出员工任职 |
| 职位 | 引用 | 职务 | N:1，可空 | 返回 `jobTitleId` 时 | 职位结果 | 同名不构成关系 |
| 职位 | 引用 | 单层职级 | N:1，可空 | 返回 `positionGradeId` 时 | 职位结果 | 不推出薪资/绩效等级 |
| 职务 | 归类为 | 职务类型 | N:1，可空 | 返回 `jobCategoryId` 时 | 职务结果 | 类型不替代职务 |
| 职务 | 允许的职级范围为 | 单层职级 | 未声明 | 返回最小/最大职级引用时 | 职务结果 | 不表示员工当前职级 |
| 部门 | 引用 | 工作地点 | N:1，可空 | 组织节点当前返回 | `companySiteId` | 不表示实际打卡地点 |
| 部门 | 引用 | 成本中心 | N:1，可空 | 组织节点当前返回 | 组织节点返回的 `costCenterCode`/名称摘要 | 不表示薪资成本结果 |
| 员工 | 在指定类型下汇报给 | 员工 | 未声明 | 有效汇报类型和查询时点 | 汇报关系树 | 不从部门结构推导 |
| 部门编制记录 | 对应 | 部门 | N:1 | 指定方案周期 | 编制部门搜索结果 | 两种 ID 不互换 |
| 部门编制记录 | 属于 | 编制方案/周期 | N:1 | 方案周期有效范围 | 方案/周期字段 | 不推出审批完成 |
| 部门编制记录 | 具有 | 控编维度 | 1:N，实际为空时以返回为准 | `isDimension` 和维度详情可用时 | `by-id` 结果 | 允许细分不等于已有维度 |
| 占编结果 | 按维度计算自 | 部门编制记录 | N:1 | 指定条件和查询时点 | `occupy-count` 结果 | 不替代计划编制或在职人数 |

## 8. 自然语言映射中的高风险词

| 用户表达 | 必须先区分 | 进入的业务内容 |
| --- | --- | --- |
| 上级、下属 | 部门层级还是员工汇报关系 | 组织结构或汇报关系 |
| 岗位、职位、职务 | 职位实例还是职务定义 | 职位与职务 |
| 级别、职级 | 体系、序列、职层、分组还是单层职级 | 职级架构 |
| 人数 | 在职人数、职位容量、计划编制还是占编数量 | 组织结构、职位或编制 |
| 某时间的组织 | 要按生效日期过滤，还是要还原那天的完整结构 | 有 `--effective-date` 就按参数查；没有公开的历史快照导出 |

对象、关系类型、时点和范围不能唯一时，只询问一个会改变命令选择或结果口径的问题。无法映射到公开命令或真实返回证据时按能力缺口停止。
