# 薪资公式

薪资公式描述公司薪资项目之间的计算关系。当前 Domain 提供函数发现、校验和样例试算；保存到已有公司薪资模板进入[公式编辑 Use Case](../use-cases/formula-edit/guide.md)。

## 1. 三种公式表达

| 表达 | 用途 | 约束 |
| --- | --- | --- |
| 编辑器名称公式 | 用户按薪资项目名称编写和确认 | 使用 `formula-format=IDEOGRAPHIC` 校验 |
| 内部 code 公式 | CLI/后端按薪资项目 code 计算 | 使用 `formula-format=CODE`；通常来自校验结果的 `exprItems` |
| Excel 单元格公式 | 工作簿中的单元格引用和 Excel 函数 | 只能作为输入来源，不能直接保存为薪资系统公式 |

三者不可直接等同。具体运算符、函数和 Excel 差异读取[公式语言](../commands/formula-language.md)。

## 2. 函数发现

- `formula +functions` 返回当前公司公式引擎提供的函数名称。
- 只使用动态返回集合与公式语言 Reference 中静态语义的交集。
- 函数同名不证明参数、缺省值或错误行为与 Excel 完全相同。

## 3. 校验

- 公式必须以 `=` 开头，并明确当前字段名称/code及其他可引用字段。
- `formula +validate` 用于校验语法、引用、函数和循环依赖，并产生后续可用的规范化表达。
- 字段名称多候选、缺少可引用字段或函数不受支持时停止，不猜 code、不删除公式片段绕过。
- 校验成功不证明业务规则正确，也不授权模板写入。

## 4. 试算

- `formula +calc` 使用明确的样例字段值、进位规则和小数位计算一个结果。
- 优先使用校验返回的内部 code 公式，字段值必须与引用 code 一一对应。
- 试算结果只适用于当前样例输入，不能表述为员工实际工资、某期台账值或模板保存结果。

## 5. 保存边界

用户只问“公式是否正确”或“给定样例算多少”时，本 Domain 在校验/试算完成后结束。用户最终目标是修改已有模板时，转入公式编辑 Use Case，重新读取模板快照、展示业务名称、取得保存确认，并以 `companyTemplate +save-rules` 的回读证据判断完成。
