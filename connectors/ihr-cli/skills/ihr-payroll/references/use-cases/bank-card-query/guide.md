# Use Case：查询人员银行卡

## 目标定义

对用户明确指定的一个员工，在 Staff 花名册权限范围内完成身份校验后，读取 Payroll 返回的银行卡记录。该目标只支持单员工详情，不支持列表、反查或批量。

## 业务判断

1. 无论用户给姓名、工号还是直接 staffId，都必须先通过 `ihr-cli staff +search` 校验目标员工在当前花名册范围内可见。
2. 银行卡员工解析不得改用 `salaryProfile +list` 或 Master Data。
3. 多个员工候选按姓名、工号和部门确认；不能选择第一项或逐个尝试 ID。
4. 用户要求按银行卡号、银行、多员工或全公司查询时，当前能力不支持。

## 执行与验证

1. 读取 `ihr-staff` 中 `staff +search` 的公开命令契约，以最小字段查询并取得唯一真实 `staffId`。
2. 在[公开命令导航](../../domain/commands.md)定位 `bankCard +detail`，读取 Help 和[银行卡契约](../../commands/bank-card.md)。
3. 用户确认唯一员工业务身份和查询范围后执行一次详情，不自动重试。
4. 返回 `summary/staffId/cards` 且 staffId 与前序唯一员工一致，才算完成。银行卡业务字段按返回值原样呈现，员工手机号、证件号等基础身份字段仍按共享规则处理。

## 停止条件

- Staff 查询零候选、ID 不一致或多候选未确认；
- 用户要求列表、批量、反查、自动重试或未公开字段；
- 鉴权、权限、业务、网络或响应解释失败。不得枚举其他 staffId 或使用 raw 接口。
