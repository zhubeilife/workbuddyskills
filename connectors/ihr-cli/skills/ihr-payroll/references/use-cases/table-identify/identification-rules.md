# 薪资表识别规则

## 物理表格切分

先依据结构切分，再判断业务角色。工作表名称或标题文本不能替代结构证据。

1. 以有原始值、显示值或公式的单元格作为内容占用点；样式、行高、列宽或合并信息只作为辅助边界证据。
2. 优先使用 Excel Table、命名区域、连续内容区域、完整空行/空列、合并标题、样式边缘和筛选范围确定候选边界。
3. 只有样式而没有值或公式的长尾区域不进入表格范围。工作表 `dimension` 可能被这类单元格放大，不能直接作为表格边界。
4. 标题、说明或合计行与数据区域相邻且共享列结构时可以纳入同一物理表格，并在 `headerRange`、`dataRange` 或 evidence 中区分。
5. 两个区域即使互有公式引用，仍保持两个物理表格；引用记录为 relationship。
6. 每个范围使用最小包围矩形的标准 A1 表示。`tableId` 固定为 `sheet-<三位工作表序号>:<范围>`，例如 `sheet-001:A1:AT5`。

每个边界至少记录一个 evidence code：

- `EXCEL_TABLE`：Excel Table 明确定义；
- `NAMED_RANGE`：命名区域与内容边界一致；
- `EMPTY_SEPARATOR`：完整空行或空列分隔；
- `CONTIGUOUS_CONTENT`：内容单元格形成连续区域；
- `MERGED_HEADER`：合并标题覆盖候选列；
- `STYLE_EDGE`：边框或样式在边缘发生稳定变化；
- `FILTER_RANGE`：自动筛选范围；
- `FORMULA_PATTERN`：连续公式结构支持数据区域边界。

## 角色判断

### 薪资主表候选

综合判断以下独立信号，避免只依赖中文关键词：

- `PERSON_RECORD_AXIS`：存在姓名、工号、部门、岗位等人员识别列，且下面是按行排列的人员记录；
- `PAYROLL_MEASURE_COLUMNS`：同一行轴上存在多组考勤、收入、扣款、统计或实发类度量列；
- `MULTI_LEVEL_HEADER`：合并表头与末级列形成稳定的多层列结构；
- `ROW_FORMULA_PATTERN`：公式主要在人员行内引用同一行字段；
- `PAYROLL_TOTAL_PATTERN`：存在收入、扣款或结果列之间的汇总关系。

同时具备明确物理边界、人员记录轴和多类薪资度量列，且没有证据相近的竞争表格时，可以标记 `HIGH` 并自动选择。只有标题关键词、只有一行说明或只有金额列时不能自动选择。

### 辅助表

辅助表通常具备以下信号：

- `LOOKUP_SHAPE`：键、区间、等级、条件与结果组成小型查找表；
- `REFERENCED_BY_MAIN`：薪资主表候选的公式引用该范围；
- `NON_PERSON_AXIS`：记录轴不是员工；
- `RULE_OR_STANDARD_VALUES`：内容表现为标准、费率、阈值或映射关系。

同一工作簿或同一工作表中的辅助表仍属于薪资主表之外的业务外部引用，relationship 的 `businessScope` 使用 `INTRA_WORKBOOK_EXTERNAL`。

### 其他和未分类

- `OTHER`：说明区、打印区、工资单展示或与本次薪资计算无关的独立表格。
- `UNCLASSIFIED`：证据不足或相互冲突。保留范围与问题，不强行归类。

## 主表选择

- 唯一 `HIGH` 候选且无竞争证据：`auto_selected`。
- 两个及以上候选均具备人员记录轴和薪资度量：`needs_confirmation`。
- 没有候选满足最低结构：`needs_confirmation`，请用户指定工作表和范围。
- 用户选择只确认表格身份，不等于确认末级表头、薪资项目或公式规则。

询问用户时只展示工作表、范围、行列规模、置信度和证据的中文摘要（例如“连续公式结构”“合并表头边界”）；内部 evidence code 不展示，不展示员工姓名、工资值、公式文本或辅助表原始内容。

## 引用关系

遍历全部公式引用、定义名称和 Excel Table 结构，按引用坐标定位目标表格：

- `FORMULA_REFERENCE`：公式单元格引用另一个表格或范围；
- `DEFINED_NAME_REFERENCE`：定义名称指向某个表格或范围；
- `TABLE_REFERENCE`：结构化引用指向 Excel Table；
- `EXTERNAL_WORKBOOK_REFERENCE`：指向其他工作簿或外部连接。

关系记录来源表格、来源单元格、目标表格、目标范围和解析状态。目标落在提取产物之外、引用语法无法解析或目标范围不完整时，记录 `UNRESOLVED_REFERENCE`；不能根据缓存值反推目标规则。已选主表实际依赖且无法读取的引用是阻断问题；仅在工作簿元数据中登记、没有主表使用证据的孤立外部链接只记录 warning。

## 不属于本 Use Case 的判断

- 末级表头最终确认、重复列处理和标准化名称；
- 公司薪资项目候选查询、复用、新建或 ID 映射；
- 有效员工数据行确认和逐行公式画像；
- Excel 公式到系统公式的转换、校验和试算；
- 模板创建、字段保存或默认步骤写入。
