# `ihr-cli smart-kpi unit +list`

查询当前公司已启用的计量单位。指标模板导入和单位管理共用本命令。

## 输入

本命令没有业务参数，不接受 `--json` 或 `--stdin`。

```bash
ihr-cli smart-kpi unit +list
```

## 输出与共用规则

- 返回当前公司已启用计量单位，主要使用单位名称完成唯一解析。
- 停用单位本期不可见，不得改调分页接口。
- 不接受公司或用户字段；只读失败不自动重试。

## 指标模板导入

- 仅在文件请求新增或修改指标单位时调用；未改单位的更新直接保留完整详情中的值。
- 来源单位必须在当前列表中唯一确认。不存在或有歧义时阻止预览确认，不能自行创建单位或直接保存未知文本。
- 权重字段的单位固定为 `%`，不能套用其他指标数值字段的单位。
- 导入只使用本命令解析单位，不得调用 `unit +save`。

## 单位管理

- 查询已启用单位、新建前定位名称，或更新前取 ID，都使用本命令。
- 更新时 ID 必须来自本会话本命令结果。
