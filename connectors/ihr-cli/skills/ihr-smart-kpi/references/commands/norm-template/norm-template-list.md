# `ihr-cli smart-kpi norm-template +list`

分页查询指定考核模板下的指标模板。指标模板导入流程在客户确认考核模板和来源范围后，用它读取全部现有指标模板并辅助客户判断新增或更新。

## 输入

分项参数与 `--json/--stdin` 二选一，不能混用。

| 参数 | 类型 | 必填状态 | 默认值 | 枚举/格式/单位 | 条件依赖 | 公开 JSON 映射 | 业务说明 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| `--template-basic-id` | string | REQUIRED | 无 | 正整数 ID | 导入流程中应使用客户已确认的考核模板 ID | `templateBasicId` | 指定指标模板所属的考核模板。 |
| `--page` | int | OPTIONAL | `1` | 大于等于 `1` | 无 | `page` | 指定需要查询的指标模板页码。 |
| `--page-size` | int | OPTIONAL | `20` | `1-100`，单位：条 | 无 | `pageSize` | 限制当前页返回的指标模板数量。 |
| `--norm-template-name` | string | OPTIONAL | 无 | 无 | 无 | `normTemplateName` | 按指标模板名称模糊查询。 |
| `--enabled` | bool | OPTIONAL | 无 | `true`、`false` | 使用 `--enabled=true/false` 传值 | `enabled` | 按启用状态过滤。 |

```bash
ihr-cli smart-kpi norm-template +list --template-basic-id 1001 --page 1 --page-size 100
```

## 输出与 Agent 规则

- 返回 `pageData` 分页业务结果。名称模糊命中多个模板时必须让客户确认目标，不能自行选择。
- 命令直接查询指定考核模板下的指标模板，不会先查询考核模板列表；权限或对象校验失败时停止。
- 每次命令只返回一页。普通查询仅在用户确有需要时继续翻页；指标模板导入流程会在考核模板和来源范围已确认后，从第 1 页开始按分页信息串行读取全部页，用于完整比对。
- 导入比对时不传名称或启用状态过滤，使用 `--page-size 100`；不得并发翻页或自动重试。任一页失败时停止新增/更新建议，不能把部分列表描述为全部指标模板。
- 完整列表只用于提供新增/更新建议。名称、项目或指标内容相似不能替代客户确认；更新时必须由客户选择确切指标模板。
- 选择更新目标后必须继续读取完整详情，不能用列表项直接构造保存载荷。
- 不接受公司、用户、token、权限或其他身份字段；只读失败不自动重试。
