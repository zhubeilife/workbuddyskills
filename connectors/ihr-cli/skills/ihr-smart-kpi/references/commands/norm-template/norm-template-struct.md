# `ihr-cli smart-kpi norm-template +struct`

读取新建指标模板所需的完整结构底稿，包括维度、项目、项目字段及字段配置。

## 输入

| 参数 | 类型 | 必填状态 | 默认值 | 枚举/格式/单位 | 条件依赖 | 公开 JSON 映射 | 业务说明 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| `--template-basic-id` | string | REQUIRED | 无 | 正整数 ID | 导入流程中应使用客户已确认的考核模板 ID | `templateBasicId` | 指定需要读取新建结构底稿的考核模板。 |

支持分项参数、JSON 对象或 stdin JSON 对象，三者不能混用。

```bash
ihr-cli smart-kpi norm-template +struct --template-basic-id 1001
```

## 输出与 Agent 规则

- 返回新建模板的完整维度、项目、`columnField`、权重和分值范围底稿。
- 命令直接读取指定考核模板的结构，不会先查询考核模板列表；权限或对象校验失败时使用 SMART-KPI 返回的错误并停止。
- 只有客户已确认新建目标考核模板后才能调用。构造指标时必须逐项目复制全部当前字段元数据，只替换客户确认的值。
- 不从文件列名猜测字段 ID、字段属性、录入规则、额外配置或公式配置。
- 只读命令不自动重试；底稿变化或后续映射变化时重新读取并重新预览。
