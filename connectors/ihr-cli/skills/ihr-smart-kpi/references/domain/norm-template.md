# 指标模板

## 业务内容

| 内容 | 业务含义 | 关键边界 |
| --- | --- | --- |
| 考核模板 | 指标模板所属的员工或组织考核配置范围 | 必须由当前可见结果和用户共同确认 |
| 指标模板列表 | 指定考核模板下已有指标模板的分页摘要 | 只能辅助新增或更新判断，不能作为更新底稿 |
| 新建结构 | 当前考核模板允许配置的项目、字段和元数据结构 | 只用于新建，不能替代现有模板详情 |
| 指标模板详情 | 已有指标模板的完整项目、指标、字段和配置 | 是全量更新的唯一底稿 |
| 指标分类与单位 | 当前租户可用的分类树和计量单位 | 名称或编码多候选时必须确认，不能猜 ID |
| 指标库引用 | 按编码或名称批量匹配可引用指标 | 每项必须唯一匹配或由用户选择 |
| 公式 | 指标评分公式或字段计算公式 | 单公式与字段公式集合分别校验，结果仍需业务语义判断 |

## 新建与更新

### 新建

1. 确认考核模板和来源范围。
2. 完整读取该考核模板下的指标模板列表，辅助判断是否新建。
3. 用户确认新建后，读取当前新建结构。
4. 按当前项目字段和业务规则构造一个完整新状态。

### 更新

1. 确认考核模板和来源范围。
2. 完整读取该考核模板下的指标模板列表，用户选择确切更新目标。
3. 读取目标指标模板完整详情。
4. 从完整详情投影保存白名单，修改已确认内容，保留未提及内容；只有明确确认的删除才移除。

列表项、来源文件和用户输入都不能注入已有模板、指标或字段 ID。已有 ID 必须来自本次公开命令的当前可见结构或详情。

## 字段与公式

- 保存字段只使用命令契约允许的白名单；展示字段、临时字段和身份字段不进入载荷。
- 附件、员工自选和数据引用不能由来源文件独立创建或修改；更新时只保留详情允许的既有关系。
- 字段从手工录入或数据引用切换为公式时，必须清理旧值和旧数据引用，并构造完整公式配置。
- 单条公式先完成本地函数、参数、引用、映射和结果类型判断，再调用 `ihr-cli smart-kpi formula +check`。
- 同一指标包含多个字段公式时，在单条校验全部通过后调用 `ihr-cli smart-kpi formula +field-check` 检查目标字段完整性和循环依赖。
- 后端校验通过不证明来源 Excel 公式与业务意图等价；歧义、未知函数、不支持引用或非数值结果必须停止或由用户明确放弃导入。

详细转换规则只在文件导入目标中读取[字段转换](../use-cases/norm-template-import/field-conversion.md)和[公式转换](../use-cases/norm-template-import/formula-conversion.md)。

## 保存与完成边界

- `ihr-cli smart-kpi norm-template +save` 提交一个完整指标模板，新建和更新都不是局部 patch。
- 真实写入前必须对同一不可变 JSON 执行 UTF-8 stdin dry-run，并完整比较返回的 `request` 与原载荷。
- 最终确认绑定一个模板和一个不可变载荷；任何目标、底稿、字段、值、公式、顺序或传输变化都使原确认失效。
- 多个模板逐个预览、逐个确认、逐个保存。不能把汇总确认扇出为多次写入。
- 命令没有幂等键，保存失败不自动重试。
- 保存命令返回成功后，先记录返回的 `normTemplateId`，再统一调用 `ihr-cli smart-kpi norm-template +detail --norm-template-id <normTemplateId>` 回读；新建和更新都不得用名称模糊列表定位替代该详情入口。更新时返回 ID 可能是后端新建版本的 ID，必须使用返回值。
- 详情回读成功后直接作为实际保存结果展示，不执行确认载荷与详情的业务字段一致性比较。
- 只有取得有效 ID 且详情回读成功，才能把来源标记为 `SAVED`，向客户展示实际落库内容并进入下一个模板。保存响应缺少/返回无效 ID 或详情回读失败时，记录“保存请求成功，但保存结果回读失败”，不得报告完成、自动重试或继续后续模板。

## 导入过程状态

文件导入的过程状态按 [导入过程状态](../use-cases/norm-template-import/session-state.md) 维护：

- 每个 Agent Session 同时只允许一个活动导入。
- 状态固定写入当前工作空间按 `sessionKey` 隔离的 `ihr-smart-kpi/norm-template-import/<sessionKey>/state.json`。
- 同一 Session 上下文压缩后必须先从当前工作空间的固定路径恢复；新 Session 不得读取旧状态。
- 当前运行环境不能提供当前工作空间、稳定 `sessionId`、SHA-256 或必要文件工具时停止，并向客户说明“当前工具暂时无法继续导入”及下一步；不能降级为对话记忆或不确定的共享路径，也不得展示内部实现术语或存储细节。
