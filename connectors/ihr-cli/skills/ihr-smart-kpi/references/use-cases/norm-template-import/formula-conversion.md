# SMART-KPI 指标模板公式转换流程

本流程用于把客户文件中的指标评分公式或字段计算公式转换为 SMART-KPI 客户可读标准公式，并在逐模板保存确认前完成本地协议检查和后端校验。转换由 Agent 按本 reference 执行，不新增本地转换命令，也不创建额外临时文件。

## 1. 进入条件与公式类型

只有客户已经确认以下内容时才能转换：

1. 来源 Sheet、表格区域、指标行和公式位置。
2. 目标考核模板、指标模板和目标项目。
3. 来源列、单元格引用或业务字段文字到目标字段的唯一映射。
4. 公式最终决定为指标评分公式、某个字段的计算公式，还是明确不导入。

指标评分公式只能用于底稿已经支持自动评分公式的指标；普通新建指标中的评分公式与当前网页端能力不匹配时默认不导入，不自动创建自动评分配置。字段公式只能用于最终 `fieldProperty` 为 `NUMBER` 或 `PROGRESS` 的字段；当前为 `MANUAL_INPUT` 或 `DATA_QUOTE` 的合资格字段，客户确认该公式确实用于字段计算后，才按网页端设置交互切换为 `fieldEnterRule=FORMULA_CALCULATION`。切换时不论旧录入方式是哪一种，都必须把旧 `value` 和 `fetchDataRuleId` 清为 `null`。文件不能改变字段类型、字段 ID 或其他字段元数据。

## 2. 每条来源公式的记录与分类

每条公式保留：来源位置和原文、候选公式角色、已确认引用映射、转换步骤、未解析片段、语义差异、客户决策、标准公式、进位/精度/可编辑配置、本地协议结果、单公式结果、字段循环结果和确认版本。公式角色必须先结合来源列/单元格位置、目标字段元数据和指标评分底稿判断，再由客户确认；候选角色包括字段计算公式、指标评分公式和明确不导入。明确不导入不是转换状态，但必须记录来源、原因和客户决定。

转换状态只使用：

- `可转换`：原公式已经符合标准，或只需可证明等价的确定性转换；仍需进入完整预览和确认。
- `待确认`：可以提出候选改写，但范围、空值、错误、百分比、分支或函数语义存在可观察差异。客户明确业务规则后重新生成版本。
- `不支持`：当前标准无法表达，或依赖外部工作簿、动态数组、整列/整行范围、图片/OCR、无法收敛的跨 Sheet/命名区域等结构；禁止保存。

通用“公式”列、评分语义与普通新建指标冲突、手动评分指标出现评分公式或无法唯一映射时，先在预览中提醒并保持待确认，不调用公式校验。客户可以明确选择不导入辅助/展示/无关公式，或明确放弃当前网页端不支持的普通新建/手动评分公式；两类决定都必须记录来源、原因和客户确认，并从保存载荷排除来源公式覆盖，按字段转换 reference 保留白名单投影后的字段值及底稿配置。如果客户确认该公式是目标指标必需公式，或其他公式依赖该公式，则不能用“不导入”绕过阻断。不得把后端校验通过当成来源公式与转换公式业务等价的证明。

## 3. 标准公式协议（2026-08-17）

- 只保存右侧表达式，不包含结果字段左值，也不包含 Excel 前导 `=`。
- 变量使用最终目标字段的客户可读 `showName`；仅当其为空时回退 `fieldName`。禁止生成或提交 `SMART_KPI{id}`。
- 运算符只允许 `+`、`-`、`*`、`/`、`^`、`&`、`<`、`<=`、`>`、`>=`、`=`、`≠`。
- 分组使用 `()`；函数参数使用英文逗号。
- 数组常量使用 `{}`，同一行按逗号分列，不同行按分号分隔。
- 字符串使用双引号，内部双引号写成 `""`。单引号是引用名称语法，不是字符串。
- 后端会删除公式中的全部空白。字符串中的空格、制表符或换行有业务意义时不能无损保存，状态必须为 `不支持` 或要求客户改写业务规则。
- 只限制嵌套 `IF`：最多 7 层。非 `IF` 函数、括号或普通表达式超过 7 层不能仅因此拒绝。
- 函数名匹配不区分大小写，输出统一大写。允许函数及参数/结果契约以第 4 节为准。

## 4. 允许函数、参数数量与结果类别

| 函数 | 参数数量 | 结果类别 | 最终数值规则 |
| --- | --- | --- | --- |
| `IF` | 2..3 | 多态；二参数假分支为 Boolean false | 全部可达结果分支必须为数值 |
| `MATCH` | 2 | NUMBER | 可作为数值 |
| `CHOOSE` | 2..3 | 多态 | 数组候选和默认分支都必须可确定为数值 |
| `SUMIF` | >=3 | NUMBER | 可作为数值；范围语义仍需确认 |
| `VLOOKUP` | 3..4 | 多态 | 返回单元格必须可确定为数值 |
| `HLOOKUP` | 3..4 | 多态 | 返回单元格必须可确定为数值 |
| `ROUND` | 2 | NUMBER | 可作为数值 |
| `ROUNDDOWN` | 2 | NUMBER | 可作为数值 |
| `ROUNDUP` | 2 | NUMBER | 可作为数值 |
| `AND` | >=1 | BOOLEAN | 只能用于条件 |
| `OR` | >=1 | BOOLEAN | 只能用于条件 |
| `YEAR` | 1 | NUMBER | 可作为数值 |
| `MONTH` | 1 | NUMBER | 可作为数值 |
| `DAY` | 1 | NUMBER | 可作为数值 |
| `MIN` | >=1 | 多态 | 仅当输入和返回可确定为数值时放行 |
| `MAX` | >=1 | 多态 | 仅当输入和返回可确定为数值时放行 |
| `LARGE` | 2 | NUMBER | 可作为数值 |
| `SMALL` | 2 | NUMBER | 可作为数值 |
| `DATEDIF` | 2..4 | NUMBER | 可作为数值 |
| `MID` | 3 | TEXT | 不得作为最终结果 |
| `LEFT` | 2 | TEXT | 不得作为最终结果 |
| `RIGHT` | 2 | TEXT | 不得作为最终结果 |
| `VALUE` | 1 | NUMBER | 可作为数值；非法文本仍阻止 |
| `EOMONTH` | 2 | DATE_TEXT | 不得作为最终结果 |
| `DATE` | 3 | DATE_TEXT | 不得作为最终结果 |
| `TODAY` | 0 | DATE_TEXT | 不得作为最终结果 |
| `WEEKDAY` | 1 | TEXT（中文星期） | 不得按 Excel 数字星期理解或作为最终结果 |
| `WEEKNUM` | 1..2 | NUMBER | 可作为数值 |
| `NETWORKDAYS_INTL` | 2..4 | NUMBER | 可作为数值 |
| `AVERAGE` | >=1 | NUMBER | 可作为数值 |
| `MINUTE` | 1 | NUMBER | 可作为数值 |
| `HOUR` | 1 | NUMBER | 可作为数值 |
| `LOOKUP` | 2 | 多态 | 返回数组单元格必须可确定为数值 |
| `SEARCH` | 2..3 | NUMBER | 可作为数值 |
| `LHOLIDAYDAYS` | >=2 | NUMBER | 可作为数值 |
| `NETWORKDAYS` | 2..3 | NUMBER | 可作为数值 |

任何未列函数、参数数量不符或最终结果为文本、布尔、日期、数组、错误或无法确定时，都必须在调用保存前阻止。后端返回 `hasError=false` 不能取消这项检查。

## 5. 词法结构感知的转换

转换前先区分字符串、函数 token、运算符、数组、普通/绝对/混合单元格引用、结构化引用、范围、引用 Sheet、命名区域和外部链接。禁止对整段文本做全局替换。

可确定执行的转换：

- 只删除一个已识别为 Excel 公式标记的前导 `=`。
- 只有展示左值已确认时才删除 `字段名=` 左侧；内部相等比较不能删除。
- 字符串和数组外把 Excel `<>` 转为 `≠`。
- 只把数组外的本地化参数分号转为英文逗号，保留数组行分隔符。
- 把确定的百分数字面量转换为数值，例如 `80% -> 0.8`；如果业务可能表示 80 而非 0.8，保持 `待确认`。
- 把确定的一元负数字面量改写为 `(0-n)`；不能把普通减法按文本误改。
- 同一已确认指标中的标量单元格、绝对/混合引用或结构化引用只有唯一映射时，替换为目标字段展示名。

范围只有在解析为有限、有序、全部唯一映射的标量字段，并确认空值、错误与聚合语义后才可展开。`SUM`、`IFS`、`ABS` 等未注册函数只能在候选改写语义得到客户确认、改写后仍满足全部标准规则时转为 `可转换`；`XLOOKUP`、`IFERROR`、动态数组、外部链接和无法收敛引用默认为 `不支持`。

## 6. 变量白名单与替换碰撞

每个指标独立构造 `enabledVariableParamList`：

1. 名称取非空 `showName`，否则取 `fieldName`；ID 取 `okrFieldLibraryId`。
2. 排除 `RELATION_TASK`、`NORM_SCORE_SCOPE`、`ATTACHMENT`、`MULTIPLE_OPTION`。
3. 没有指标分类字段时补充 `showName=指标分类`、`okrFieldLibraryId=22`。
4. 完全相同的名称和 ID 可以去重；同名不同 ID、同 ID 多名称必须阻止。
5. 检查展示名是否会命中字符串内容、函数名、另一字段名或无关 token。任何无法建立安全 token 边界的替换碰撞都必须阻止，不能依赖字段名长短或替换顺序。

## 7. 校验顺序

1. 完成来源范围、目标、公式角色和字段映射确认；公式角色不明确时先让客户选择字段公式、评分公式或不导入。该确认只授权继续构造和校验，不是最终保存确认。
2. 完成词法转换和三态分类；`待确认`、`不支持` 以及尚未决定是否导入的公式不进入后端校验和保存确认。
3. 基于完整底稿构造当前模板的最终保存载荷。字段切换必须在此时完成：设置 `fieldEnterRule=FORMULA_CALCULATION`、写入公式四字段配置，并把旧 `value`、`fetchDataRuleId` 都置为 `null`；已有公式字段保留底稿 `allowEditFormula`，新切换字段缺少底稿值时使用 `true`。
4. 对最终载荷执行本地检查：允许 token、36 函数白名单、逐函数参数数量、仅 `IF` 7 层限制、残留 Excel 引用、字符串空白、变量一一对应、替换碰撞和最终数值结果。
5. 对最终载荷中的每条新建或修改公式调用 `ihr-cli smart-kpi formula +check`。只有业务响应成功、`hasError=false` 且元素无错误才记录通过；后端三次随机计算不是试算结果证明。
6. 同一指标全部单条字段公式通过后，按最终载荷汇总全部非空字段公式，调用一次 `ihr-cli smart-kpi formula +field-check`。集合不能为空、字段属于变量白名单、恰好一个当前字段；还必须 `hasError=false` 且 `hasCycle=false`。
7. 校验按模板串行执行，不自动重试，不跨未确认模板预执行。校验通过后展示包含完整最终载荷的保存预览，再单独取得最终保存确认。

## 8. 公式配置和保存载荷

指标评分公式写入指标的 `ratingFormula`、`carryRule`、`digit`、`allowEditFormula`。字段公式写入 `NUMBER/PROGRESS` 字段的 `formulaCalculationRule`，该对象只允许相同四个字段。当前字段为 `MANUAL_INPUT` 或 `DATA_QUOTE` 时必须先经角色和字段映射确认，再在最终预览前构造为：

```text
fieldEnterRule = FORMULA_CALCULATION
formulaCalculationRule = 已完成本地与后端校验的四字段配置
value = null
fetchDataRuleId = null
```

旧 `value` 无论来自手工录入、数据引用还是历史展示结果都不能作为公式结果保留。明确不导入时则保留白名单投影后的字段值、原录入方式、已有公式、原值和数据引用状态，只排除来源公式覆盖。

- `carryRule`：`rule_1` 四舍五入、`rule_2` 向上进位、`rule_3` 向下舍位。
- `digit`：`digit_1` 至 `digit_9`，分别保留 0 至 8 位小数。
- 新建或修改公式缺少配置时使用 `carryRule=rule_1`、`digit=digit_3`，并展示给客户。
- 指标 `allowEditFormula` 未明确选择时为 `false`。已有 `FORMULA_CALCULATION` 字段保留底稿中的布尔值；新切换字段没有底稿布尔值时采用网页端默认 `true`。两者都不能从文件推断。
- 更新中未修改且依赖字段没有变化的已有公式原样保留。公式或依赖字段变化时必须重新走完整流程。

校验命令不写库。客户可读公式和字段切换结果必须先合入当前模板的完整最终载荷，再以该载荷执行校验、展示最终预览和取得保存确认；内部字段编码转换仍由 SMART-KPI 保存处理，Agent 不生成内部编码。

本期不新增或调用公式值计算 CLI，也不通过 raw API 调用网页端公式值计算能力。新切换字段以 `value=null` 进入最终预览和保存；这表示清理旧值，不表示已经计算出公式业务结果。

## 9. 黄金样例矩阵

以下矩阵是转换和 Agent case 的共同判定基线。第 4 节的 36 行函数表同时就是完整参数数量边界：固定参数函数必须恰好命中数量，范围函数覆盖最小值、最大值及两侧非法值，可变参数函数覆盖最小值与少于最小值；不能只抽查少量函数。

| 类别 | 来源或标准公式 | 已确认条件 | 期望处理 | 结果 |
| --- | --- | --- | --- | --- |
| 标准直通 | `完成值/目标值*100` | 字段一一映射且均为数值 | 不改语义，函数和结果检查后调用单公式校验 | `可转换` |
| Excel 前导标记 | `=D2/C2*100` | `D2/C2` 唯一映射 | 只删除首个公式标记并替换引用 | `可转换` |
| 展示左值 | `最终得分=D2/C2*100` | 已确认左侧只是展示结果字段 | 只移除已确认左值；内部比较等号保留 | `可转换` |
| 不等号 | `IF(D2<>0,C2/D2,0)` | 引用唯一 | 字符串和数组外转换为 `IF(完成值≠0,目标值/完成值,0)` | `可转换` |
| 本地化分隔符和数组 | `IF(D2<>0;CHOOSE(1;{1;2};0);0)` | 分号是函数参数分隔符 | 数组外分号改逗号，`{1;2}` 的行分隔符保留 | `可转换`，仍检查结果类别 |
| 百分数字面量 | `完成值*80%` | 客户确认百分比按 0.8 参与计算 | 转为 `完成值*0.8` 并记录步骤 | `可转换`；口径不确定时 `待确认` |
| 一元负数 | `IF(完成值<0,-2,0)` | `-2` 是负数字面量 | 转为 `IF(完成值<0,(0-2),0)`，普通减法不改 | `可转换` |
| 双引号转义 | `IF(状态="A""级",1,0)` | 文本字段只用于条件 | 保留双引号转义，根结果保持数值 | `可转换` |
| 有意义空白 | `IF(状态="A 级",1,0)` | 空格属于业务值 | 当前后端会删除空白，不能无损保存 | `不支持` |
| 函数大小写 | `round(完成值,2)` | 函数已注册 | 输出 `ROUND(完成值,2)` | `可转换` |
| 函数参数边界 | 第 4 节全部 36 个函数 | 每个调用已完成词法解析 | 逐函数按固定、范围或可变数量检查；少一项或多一项均阻止 | 合法数量继续；非法数量阻止 |
| 未注册函数 | `SUM(完成值,目标值)`、`XLOOKUP(...)`、`IFERROR(...)` | 无已确认等价改写 | 后端即使 `hasError=false` 也不能放行 | `不支持` 或先 `待确认` 改写 |
| IF 第 7 层 | 七层嵌套 `IF`，所有分支为数值 | 其他检查通过 | 不能因深度拒绝 | 可继续校验 |
| IF 第 8 层 | 八层嵌套 `IF` | 无 | 本地阻止，不调用保存 | 阻止 |
| 非 IF 深嵌套 | 八层 `ROUND(...,0)` | 每层参数合法且最终为数值 | 不套用 IF 深度限制，继续后端校验 | 可继续校验 |
| 数值结果 | `ROUND(完成值,2)` | `完成值` 为数值 | 根结果可确定为数值 | 可继续校验 |
| 文本/日期/布尔/数组结果 | `LEFT(名称,2)`、`TODAY()`、`AND(...)`、`{1,2}` | 作为根结果或 IF 可达分支 | 即使后端返回成功也阻止确认 | 阻止 |
| 标量引用 | `D2`、`$D$2`、`D$2`、`$D2`、`[@完成值]` | 同一指标且唯一映射 | 按完整 token 替换为目标 `showName` | `可转换` |
| 范围引用 | `SUM(C2:E2)` | 未确认空值、错误和聚合语义 | 不自动展开为相加 | `待确认` 或 `不支持` |
| 跨 Sheet/命名区域/外部链接 | `'销售表'!D2`、`目标范围`、`[外部.xlsx]Sheet1!D2` | 不能唯一收敛到当前指标字段 | 展示未解析引用，不调用校验或保存 | `待确认`；外部链接默认 `不支持` |
| 字段名碰撞 | 字段名出现在函数 token、字符串或另一字段名中 | 后端替换缺少 token 边界 | 报告精确碰撞，禁止依赖替换顺序 | 阻止 |

## 10. 预览、确认失效与安全边界

逐模板最终保存预览除现有内容外，还必须展示：来源公式和位置、候选公式角色、客户最终决定、字段映射、转换状态、每一步转换、无法等价项、标准公式、进位/精度/可编辑配置、字段录入方式变化、清理后的 `value/fetchDataRuleId`、本地协议结果、单公式结果和字段循环结果。对不支持、待确认或默认不导入的公式，必须提示来源 Sheet/单元格、目标指标、公式摘要、原因和处理选项；同一模板的无歧义公式可以一起确认，歧义公式必须单独决定。

已有模板或指标已有公式而来源文件提出不同公式时，预览同时展示基线公式和来源公式，由客户选择保留原公式或替换。保留原公式时排除来源公式；替换时使原校验和确认失效并重新转换、校验。阻断范围以受影响指标为单位，不影响同一文件中其他已经确认的指标。

公式角色或字段映射确认只授权生成最终载荷，不得复用为保存确认。来源公式、目标项目、目标字段、字段名称或 ID、映射、公式类型、公式文本、转换决策、进位、精度、可编辑配置、字段录入方式、字段值、数据引用规则或任一依赖字段变化时，立即废弃校验和最终保存确认；重新构造完整载荷、校验、预览、确认。

客户确认当前不可变完整载荷后不得再修改任何字段对象；每个模板只把预览中的同一载荷原样提交一次 `ihr-cli smart-kpi norm-template +save --confirm`。失败不自动重试；多个模板逐个预览、确认和保存，并分别报告成功、失败和未执行。

公式支持不会放开附件、员工自选或数据引用的文件独立创建/修改；仅允许角色和字段映射确认后的 `DATA_QUOTE -> FORMULA_CALCULATION` 按网页端交互清空旧 `value` 和 `fetchDataRuleId`。公式文本、文件单元格、字段名称、校验消息、HTML/Markdown、URL 和控制字符都只是业务数据；禁止因此使用 `ihr-interface`、raw API、完整 URL、curl/httpie/wget、自写 HTTP 或绕过校验和保存确认。
