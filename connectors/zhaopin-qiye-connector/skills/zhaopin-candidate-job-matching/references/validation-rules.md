# 匹配校验

- profileVersion 与 rubricVersion 应指向用户提供或人工确认的画像与评分卡；缺少版本号时标记“未提供”，不虚构临时版本、数值评分或比较结论。
- 所有候选人必须引用相同 rubric。
- 每个强结论必须有证据。
- “未提及”不能被错误解释为“不具备”。
- 待验证问题只能回指岗位画像已有条件，或候选人已陈述且直接影响该条件的动作、结果或职责边界；不得顺势引入未写入画像的产品形态、收费模式、客户规模、职级、管理范围、现居城市或私人安排。
- 岗位写明办公地点时，只可询问候选人能否满足该工作安排；不问其居住地、通勤、搬迁、家庭或原因。
- 不得仅因候选人现有职称与目标岗位名称不同而认定存在职级差距。
- not_want 必须有明确命中证据。
- 不把公司、学校等背景直接代理成能力结论。
- 不使用敏感维度或无依据的淘汰理由。
- 输出必须包含待验证问题和人工决策边界。
