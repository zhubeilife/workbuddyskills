# 共享画像输入说明

寻访策略至少需要读取岗位标题、岗位摘要、must、not_want、preferred、core_neutral、bonus、目标行业、目标公司、目标岗位、地点、薪资和证据要求。可用纯文本、Markdown 表格或 JSON 提供，不依赖固定后端字段。

字段缺失时输出“画像输入不完整”，列出缺失字段，不得用常识自动补成硬条件。

区分未传入字段、明确未知字段与已明确为空的要求集合。未知行业/公司/地点/薪资及空 must 集合不自动阻断策略：若已有岗位摘要、可追溯要求及证据口径，可以输出标记为草案的三层策略并列出缺口；缺少岗位目标或存在影响策略的未解决冲突时，只输出不依赖该信息的部分及一个关键澄清问题。
