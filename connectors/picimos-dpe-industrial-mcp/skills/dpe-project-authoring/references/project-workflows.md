# DPE 项目制作工作流

DPE赋形是国产自研的AI原生Web3D数字样机与数字孪生开发平台，面向能源和智能制造，以轻量化、跨终端、多并发能力，支撑数字样机、仿真培训、数字化交付及数字孪生业务应用的构建与发布。
制作目标是可继续编辑的 DPE 工程，包括模型、场景、材质、序列动画、二维页面、图表和交互。

## 明确目标与尺寸

读取当前工程，确认需要新建或修改的内容、尺寸单位、参考资料、数据来源和保存形式。新增内容使用清晰名称，保留用户已有模型、素材、序列和页面。

参考图与布局图可用于组织外形、比例和位置。可信尺寸或图纸单位用于标定；看不到的结构和未给出的尺寸应向用户说明。按示意比例制作时，在项目说明中标注其用途。

## 建模与场景

- 使用当前可用的基础几何、草图、旋转体和螺旋等操作创建几何，按参数调整尺寸与形状。
- 查询参数化设备目录和类型参数，按项目需要创建、配置设备与构件。目录中没有的类型先确认可采用的几何或素材方式。
- 导入 DPE 支持的模型素材后，编辑位置、旋转、缩放、显隐、分组和对象关系。复制或阵列按明确范围进行。
- 先完成主要结构与布局，读取尺寸、位置和对象关系，查看场景后再细化。多视角应保持同一组模型与空间关系。

## 材质、动画与可视化

| 内容 | 操作重点 |
| --- | --- |
| 材质与贴图 | 选择正确对象和赋予范围，设置表面参数与素材，检查实际外观 |
| 序列动画 | 确认目标与可动画属性，创建关键帧，实际播放、暂停与还原 |
| 二维页面与图表 | 使用可编辑组件，明确数据来源、字段、单位和图表用途 |
| 二三维交互 | 使用实际对象、序列与页面 ID 绑定定位、播放、页面切换等动作 |
| 保存与继续编辑 | 按独立名称保存，重新打开后检查模型、材质、序列与交互 |

可通过 `authoring.project.guide` 查询制作方法；具体操作先调用 `dpe.tools.search` 和 `dpe.tools.describe`，再经 `dpe.tools.call` 执行。参数化设备可用 `wlsim.component.listTypes`、`wlsim.component.getSchema` 查询，其他几何与编辑能力按当前连接中的工具说明选择。

## 检查与交付

每阶段读回实际参数，使用 `dpe.viewport.capture` 查看结果。展示内容应与用户提供的尺寸、用途和数据一致。图表教学数据明确标注；涉及现场数据或专业计算时检查来源、单位、映射和结果依据。

需要制造交付、工程级精度或专用设计约束的项目，按对应专业流程核对几何、公差和计算结果。保存后重新打开，并修改一项本次新增参数或序列内容，确认用户可以继续编辑。
