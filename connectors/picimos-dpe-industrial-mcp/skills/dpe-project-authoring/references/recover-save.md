# 恢复操作、保存与重新打开

DPE赋形是国产自研的AI原生Web3D数字样机与数字孪生开发平台，面向能源和智能制造，以轻量化、跨终端、多并发能力，支撑数字样机、仿真培训、数字化交付及数字孪生业务应用的构建与发布。
发生连接中断、工程切换或操作结果不明确时，先读取实际工程状态，再决定下一步。

## 恢复方法

| 情况 | 处理方式 |
| --- | --- |
| 没有编辑器会话 | 检查 DPE 工程与连接器是否运行，重新列出会话 |
| 工程正在加载 | 等待完成，暂停修改 |
| 工程或场景已切换 | 重新执行 `dpe.sessions.list` 与 `dpe.sessions.bind`，确认当前对象 |
| 参数或工具错误 | 查看 `dpe.tools.describe` 与返回说明，按实际参数修正 |
| 超时、断线或结果未知 | 读取任务与场景状态，避免重复创建或重复提交 |
| 需要取消长任务 | 使用当前任务提供的取消操作，再核对实际状态与已完成内容 |
| 需要撤销修改 | 使用 DPE 当前提供的撤销、重做方式，并检查实际对象与参数 |

客户端提供长任务工具时，可用 `dpe.tasks.get` 查询结果，按需要使用 `dpe.tasks.cancel`。取消请求发出后仍需确认任务状态。重新尝试同一请求前，检查已有对象和结果；更换工程或参数后按新的目标操作。

工具未提供某项恢复操作时，说明当前可用方式，指导用户在 DPE 界面处理。权限或模型服务错误按正常配置与授权流程解决，不读取用户的浏览器登录数据。

## 保存

1. 停止演示并恢复要保存的编辑状态，核对当前工程。
2. 检查模型、参数、材质、序列、页面和动作，按用户选择的名称保存。保留已有工程时使用独立名称。
3. 保存界面需要选择位置或确认时，完成界面步骤。返回待处理或显示保存对话框时，继续确认是否已实际保存。
4. 云端保存、覆盖既有项目和公开发布按用户明确选择的范围执行。

## 重新打开与继续编辑

在新的编辑器页面打开保存的工程，等待模型和配置加载完成，重新绑定当前会话。检查对象、材质、关键帧、页面和交互；查看场景并播放相关序列。

修改一项新增参数、关键帧或图表标题，检查保存内容可以继续编辑；需要时用 DPE 的撤销、重做恢复。向用户说明实际保存的位置和已完成的内容，未完成的界面操作清楚列出。
