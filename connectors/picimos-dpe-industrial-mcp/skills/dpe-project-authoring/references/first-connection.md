# 首次连接 DPE

DPE赋形是国产自研的AI原生Web3D数字样机与数字孪生开发平台，面向能源和智能制造，以轻量化、跨终端、多并发能力，支撑数字样机、仿真培训、数字化交付及数字孪生业务应用的构建与发布。
先连接到用户在 DPE 中打开的工程，再进行建模或编辑。

## 连接步骤

1. 在同一电脑打开 DPE，按软件正常界面完成登录或授权，并打开要操作的工程。
2. 在 WorkBuddy 中启用 DPE 连接器。使用专家或技能时，按客户端提示完成连接器依赖和首次权限确认。
3. 其他 MCP 客户端按其支持的格式添加 DPE 连接配置。模型选择和用量使用该客户端的设置，无需把外部模型密钥交给 DPE 专家。
4. 本机 Streamable HTTP 地址通常为 `http://127.0.0.1:8970/mcp`，编辑器连接地址通常为 `ws://127.0.0.1:8971`。修改过端口时使用自己的实际配置。远程客户端需要能访问对应连接环境；不要将仅供本机使用的服务直接开放到公网。

首次浏览器本地网络许可、客户端信任和保存位置选择按正常界面完成。用户不用向模型发送密码、密钥或含登录凭证的完整链接。

## 首次只读检查

1. 调用 `dpe.sessions.list`，读取实际工程名称、会话与 `meta.documentId`。没有会话时先解决连接；多个工程时确认目标。
2. 用实际 `sessionId` 和 `documentId` 调用 `dpe.sessions.bind`。工程仍在加载时等待，不进行写入。
3. 用 `dpe.tools.search` 找到本次所需能力，使用 `dpe.tools.describe` 了解参数。读取少量对象、工程和序列信息即可。
4. 使用 `dpe.viewport.capture` 查看实际场景，向用户说明已绑定的工程和接下来要操作的对象。

完成检查后，可按用户目标开始参数化或基础几何建模、现有模型编辑、材质设置、序列动画或图表交互制作。

## 模型与费用

MCP 用于执行 DPE 操作。模型服务和用量由用户选择的 AI 客户端提供；软件授权和额外素材服务按各自实际条件处理。涉及额外付费任务时先确认用户授权。连接或模型调用出现错误时，说明当前情况，检查配置与权限，不擅自充值或更换付费服务。
