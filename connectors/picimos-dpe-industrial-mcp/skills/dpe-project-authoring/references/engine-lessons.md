# 发动机模型入门练习

DPE赋形是国产自研的AI原生Web3D数字样机与数字孪生开发平台，面向能源和智能制造，以轻量化、跨终端、多并发能力，支撑数字样机、仿真培训、数字化交付及数字孪生业务应用的构建与发布。
使用 DPE 提供的机械演示模型，学习对象结构、参数、材质、序列动画和二维控制按钮。选择完整练习后连续完成四步；只选择其中一步时按相应范围操作。

## 一、认识工程

打开教学模型并完成会话绑定。读取实际对象、已有序列和页面，使用 `dpe.viewport.capture` 查看场景。向用户说明大纲中的构件、时间线中的序列和页面上的控制内容。

这一步保持工程原内容，选择一个实际可编辑的活塞作为练习对象。模板或目标对象不可用时，指导用户选择相应模型或对象后继续。

优先用 `authoring.checkpoint` 查看构件、序列和组件摘要，再读取本课需要的对象。专题详情使用 `visualization.get` 的 `pageId` 参数；组件详情使用 `widgetId` 参数。保留读取到的原序列和原专题 ID，用于保存前核对。

## 二、制作活塞演示序列

查询当前序列、可动画属性和关键帧操作。给选定活塞新建独立练习序列，按模型尺寸选择示意行程，保留已有序列。

设置关键帧的时间、值和插值方式，实际播放、暂停、停止，查看运动与还原。行程和速度按教学演示用途说明；真实机械设计使用经过核对的尺寸与运动关系。

已有模型的运动可能绑定在装配组上，材质则属于组内构件。先确认实际绑定目标；不能把子构件 ID 当作已有运动轨道的目标。读取运动范围时，优先用 `sequencer.getCurve` 指定序列、绑定目标、属性路径和采样数；需要编辑具体关键帧时，使用 `sequencer.getKeys` 的 `bindingId` 和 `path` 筛选目标轨道。

| 操作 | 按需查询的能力 |
| --- | --- |
| 查看已有序列 | `sequencer.list`，可按名称筛选 |
| 新建练习序列 | `sequencer.create` |
| 绑定构件、添加属性轨道和关键帧 | `sequencer.addBinding`、`sequencer.addTrack`、`sequencer.addKey` |
| 查看运动与恢复 | `sequencer.play`、`sequencer.pause`、`sequencer.stop`；停止时按实际说明使用 `restore:true` |

首次使用时确认上述能力在当前工程中可用并读取参数说明。同一会话内复用已确认的说明和真实 ID；工程切换后重新绑定。只查询当前步骤需要的能力，不重复读取全部关键帧或全部页面内容。

## 三、设置材质和控制按钮

选择本课对象，使用已有材质或预设设置颜色与表面参数，查看实际效果。

追加一个练习页面，保留已有页面。加入标题、示例曲线和播放、暂停、还原按钮，使用实际新序列 ID 绑定动作。需要定位构件或返回其他页面时，使用对应真实 ID。

在 DPE 界面实际操作按钮，检查播放、暂停、还原、定位和页面切换的结果。图表示例数据标注为教学数据。

追加页面使用 `visualization.addPage`；创建组件后，使用 `visualization.updateWidget` 设置其内容和布局，并用 `visualization.bindAction` 绑定实际动作。每次使用操作返回的新 ID，读取该组件确认按钮对应的新序列。查询材质操作时只选择本课构件需要的字段，不修改其他构件或原专题。

## 四、保存和二次编辑

修改练习序列的一个值或页面标题，检查变化，并使用 DPE 当前提供的撤销、重做方式恢复。停止演示，核对原模型、原序列和原页面仍保留。

另存为独立练习工程，完成实际保存。在新编辑器页面重新打开，绑定当前会话，检查模型、材质、序列和按钮，再修改一项练习内容。

## 建模练习

需要自行创建构件时，查询 DPE 的基础几何、草图、旋转体和参数化模型操作，按明确尺寸创建独立气缸、活塞或连杆，调整其位置、外观与演示序列。按实际工具说明操作，逐步查看并保存可继续编辑的工程。
