# 暂未暴露的能力（处理边界）

以下能力在源资料中存在或被提及，但 CLI 未暴露对应 operation。用户提出时如实说明并停止，不要绕过 CLI 构造请求。

| 能力 | 原因 | 建议话术 |
| --- | --- | --- |
| 按 userId 列表批量查个人日报 | 服务端忽略该过滤（`filter.userIds`/`empIds`/`userId`/`creator`），恒定返回登录人自己的日报且不报错，会造成「查 A 得到 B」的静默错误 | 「按人查请逐人查询，我用 query_user 按天扫描」 |
| `unRead` 时间段查询 | 该接口在当前租户三种请求形态实测恒返回空列表 | 「统一改用群体查询或单人查询」 |
| EB 日报应用接口族（查询/发布/编辑/删除） | 依赖租户启用 EB 日报应用；当前租户未启用，接口族与标准日报完全不同且启用状态需逐租户探测 | 「当前环境使用标准日报接口，能力一致」 |
| 删除日报 / 撤回已发送提醒 | 源资料未提供可靠接口 | 「暂不支持，请在客户端手动处理」 |
| 附件上传 / @ 提醒 | 源资料未给出经过验证的完整契约 | 「暂不支持」 |
