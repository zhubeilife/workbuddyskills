# 费用科目匹配规则

> **费用类型（科目）字段必须有值。优先使用 `invoice.reim.row-info`（或 `row-info-batch`）返回的 `subjectId`；为空时按下方查找表匹配；全部未命中则填兜底值 `"100502270000000104"`。**
> **绝不能为空、不能报错、不能放入 `unable_to_fill`。**
> **兜底科目 `"100502270000000104"` 见 [reim-workflow.md 共享常量](reim-workflow.md#报销共享常量所有-reference-统一引用本节)。**

---

## 匹配决策树（完整流程图）

```
invoice.reim.row-info 返回 subjectId?
  ├── 有值 → 直接使用，结束
  └── 空/null → 进入查找表匹配 ↓
        优先级1: expenseType 匹配?
          ├── 命中 → 使用对应 ID，结束
          └── 未命中 → ↓
        优先级2: sellerName 关键词匹配?
          ├── 命中 → 使用对应 ID，结束
          └── 未命中 → ↓
        优先级3: consumeContent 关键词匹配?
          ├── 命中 → 使用对应 ID，结束
          └── 未命中 → ↓
        优先级4: requestname 辅助匹配?
          ├── 命中 → 使用对应 ID，结束
          └── 未命中 → ↓
        兜底条件匹配（押金/电子设备/家具/研发/销售）?
          ├── 命中 → 使用对应 ID，结束
          └── 全不命中 → 填 "100502270000000104"，结束
```

## 赋值方式

费用科目字段（`fieldType="RelateBrowser"`, `marked=true`）直接用科目 `id` 作为 `value`：

```json
{"fieldId": "...", "value": "100502270000000006", "fieldName": "费用类型（科目）"}
```

> ID 必须原样复制，严禁修改。每行明细的科目独立匹配。
> 快速路径（`template.build`/`auto-prepare`）已内置科目匹配：`row-info` 返回 `subjectId` 为空时自动使用默认科目 `"1256664958132969489"`（日常消费）。
